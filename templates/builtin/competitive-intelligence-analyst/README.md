## Use it in Pi

```bash
cp -r templates/builtin/competitive-intelligence-analyst ~/pi-bots/competitive-intelligence-analyst && cd ~/pi-bots/competitive-intelligence-analyst
pi --approve   # trust the folder: loads AGENTS.md, .pi/APPEND_SYSTEM.md, skills/, prompts/
```

Or install only the skills and routine prompts: `pi install ./templates/builtin/competitive-intelligence-analyst`. The persona in `AGENTS.md` applies only when you run Pi inside the folder.

## What did not translate

- Grok Bot runtime features: shared box computer/browser desktop, Grok channels (Slack/iMessage/email send-as), team multi-bot wake, built-in X/Grok data tools.
- Routine scheduling and event triggers: Pi has no scheduler; see `prompts/`, `cron/`, `systemd/`.
