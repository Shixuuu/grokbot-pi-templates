# Bug Reproduction

Give engineers reports they can trust. Catches the thread, clicks the same path in staging, captures the failure, and drops a repro pack (steps, screenshots, network notes).

## Use it in Pi

```bash
cp -r templates/builtin/bug-reproduction ~/pi-bots/bug-reproduction && cd ~/pi-bots/bug-reproduction
pi --approve   # trust the folder: loads AGENTS.md, .pi/APPEND_SYSTEM.md, skills/, prompts/
```

Or install only the skills and routine prompts: `pi install ./templates/builtin/bug-reproduction`. The persona in `AGENTS.md` applies only when you run Pi inside the folder.

| Profile / persona | `AGENTS.md`, `.pi/APPEND_SYSTEM.md` |

## What did not translate

- Grok Bot runtime features: shared box computer/browser desktop, Grok channels (Slack/iMessage/email send-as), team multi-bot wake, built-in X/Grok data tools.
- Routine scheduling and event triggers: Pi has no scheduler; see `prompts/`, `cron/`, `systemd/`.
