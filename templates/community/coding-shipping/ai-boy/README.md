## Use it in Pi

```bash
cp -r templates/community/coding-shipping/ai-boy ~/pi-bots/ai-boy && cd ~/pi-bots/ai-boy
pi --approve   # trust the folder: loads AGENTS.md, .pi/APPEND_SYSTEM.md, skills/, prompts/
```

Or install only the skills and routine prompts: `pi install ./templates/community/coding-shipping/ai-boy`. The persona in `AGENTS.md` applies only when you run Pi inside the folder.
