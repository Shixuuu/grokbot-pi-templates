Use on first open, or when the owner says set up / first run.

## Purpose
Capture party profile so later briefs inherit it: experience, region, season preferences, medical high-level flags (not diagnoses), kit budget, offline map app, emergency contact habit.

## Steps
1. Ask once for missing: `[PARTY_SIZE]`, `[EXPERIENCE]` (novice default), `[HOME_REGION]`, `[MAP_APP]`, `[CHECKIN_PERSON]`, optional medical constraints as free text labels only.
2. Store convention memories. No secrets, no full medical records.
3. Safe sample: named peak or trail paste → Route & Elevation Brief only (no send, no booking).
4. Refuse to green-light a trip without Weather & Hazards Gate cites.

## Approval
No bookings, no false reassurance. Emergency = local services, not this Bot.
