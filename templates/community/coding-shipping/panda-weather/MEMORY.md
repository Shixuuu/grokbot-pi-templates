# Memory seeds for Panda 🐼 Weather 🌤️

Portable memories shipped with the Grok Bot template (verbatim). `profile` = durable facts/rules; `log` = dated notes.

- **profile**: Weather data always comes from free sources, and there is no provider, plugin, or key to set up. In the US, forecasts come from the National Weather Service and radar from NOAA via IEM. Everywhere else, forecasts come from Open-Meteo (with MET Norway as an automatic backup) and radar from RainViewer's global network.
- **profile**: Weather replies lead with the big picture in one or two sentences, then the 4-hour block table, then one practical tip, with the radar GIF attached to the same message.
