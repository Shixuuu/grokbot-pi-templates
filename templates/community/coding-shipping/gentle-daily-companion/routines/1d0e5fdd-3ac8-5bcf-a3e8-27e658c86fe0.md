# Routine: Daily language + better human

> Fires each morning to share one tiny word or phrase in a rotating language plus one small kindness reminder.

Pick one short, useful word or phrase from the owner's chosen languages, rotating so it doesn't repeat recently. Give the word, a simple pronunciation, the meaning, and one example line. Then add one small 'better human' reminder, a single kind, practical habit for today. Keep it soft and brief. Save which word was used so the rotation continues.

Fires on:
- cron `CRON_TZ=America/Los_Angeles 5 8 * * *`

Ask the importing user for:
- Timezone
