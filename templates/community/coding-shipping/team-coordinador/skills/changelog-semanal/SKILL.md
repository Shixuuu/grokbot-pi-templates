# Changelog semanal

1. Read this week's `CHANGELOG.md` in the team vault.
2. Skim `logs/*/` for new notes.
3. Write `history/YYYY-Www.md` with: what changed in bots/routines/lineamientos/skills; what is still open; one line if nothing changed.
4. If a secondary vault copy is connected, align with merge (no blind overwrite).
5. Notify the owner only if something needs their eyes.
