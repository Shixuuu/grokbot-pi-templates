# Score ideas de negocio

## Cuándo usarlo
- Nueva idea, “¿vale la pena?”, o elegir entre 2+ oportunidades digitales.
- El bot de negocios debe priorizar antes de investigar a fondo.
- Llega un análisis largo: primero comprimir, después scorear.

## No usar
- Empleo / vacantes.
- Portfolio o coaching career.
- Educación financiera o instrumentos.
- Impuestos / caja / cuotas.

## Paso 0 — Comprimir (si el input es largo)
Reduce a 3 líneas. Ignora proyecciones, cert stacks, GTM de 90 días y vanity metrics.
1. Idea en una frase
2. A quién se vende (rol + geo/idioma)
3. Cómo cobra / entrega (oferta + canal)

Si faltan, pide solo eso. No scorees el ensayo.

## Scorecard (0–2 cada uno; máx. 14)
| Criterio | 0 | 1 | 2 |
|---|---|---|---|
| 100% digital | Local/stock físico fuerte | Híbrido tolerable | Puro digital |
| Empezar ya | Semanas de setup | 2–7 días a 1ª conversación de compra | Hoy/mañana puede hablar con un buyer |
| Capital | Alto o stock | Medio | Bajo para el experimento |
| Oferta clara | Vaga | Oferta ok, buyer flojo | Oferta + buyer concretos |
| Canal + idioma | Sin canal / idioma imposible hoy | Canal posible; idioma/geo flojo | Canal + idioma usable ya |
| Encaje horario | Choca con horario laboral | Ajustable | Cabe fuera de oficina / async |
| Evidencia | Opinión / TAM sin fuente | Señal débil | Señal concreta |

## Kill → NO GO
- No es digital / capital alto sin retorno claro
- Empleo disfrazado o aprender por aprender
- Depende de crédito o decisión legal/tributaria sin especialista
- No hay primer paso en <48h
- Exige certs / landing / repo / brand antes de 1 buyer

## Salida
Idea / Buyer / Score X/14 / Kill / Hechos / Supuestos / Veredicto GO|MAYBE|NO / Por qué / Primer paso ≤48h / No hacer

## Reglas
Español directo. No inventes precios ni demanda. MAYBE = un experimento barato. GO = un solo siguiente paso.
