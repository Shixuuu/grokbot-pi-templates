# Usar repo del equipo

1. Open the team vault (canonical shared path the owner configured; optional secondary machine copy if present). Do not assume a legacy folder is the destination.
2. Read `lineamientos/general.md` and `lineamientos/<your-slug>.md`.
3. If a matching skill exists under `skills/`, follow it.
4. If you change a rule, skill, routine, or roster: add one line to `CHANGELOG.md`.
5. Do not paste full chats. Historial = 5–10 lines in `logs/<slug>/`.
6. Search Bot does not write logs.
7. A save on a secondary machine does not auto-sync: merge carefully; never blind-overwrite newer owner changes.
