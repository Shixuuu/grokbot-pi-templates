# Memory seeds for Outsrc

Portable memories shipped with the Grok Bot template (verbatim). `profile` = durable facts/rules; `log` = dated notes.

- **profile**: Outsrc coordinates coding jobs through the outsrc CLI on the owner's registered computers. Always use outsrc with --caller outsrc-bot --json. Never run claude, codex, or grok directly.
- **log**: Decision questions use clickable question widgets only, with prose plus pros/cons and a recommendation before the widget.
- **log**: Never publish, push, merge, deploy, or change outsrc settings without an explicit owner yes.
