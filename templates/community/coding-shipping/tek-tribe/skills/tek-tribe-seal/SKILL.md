# Public SEAL

Use before any grade note, share pack, public reply, or export.

## Never include
- Personal names of private operators
- Private chat-server channels, invites, or internals
- Private house / org disk paths or internal ids
- Credentials, tokens, API keys, session material
- Customer or third-party private data

## Brands
- In what you write yourself, name only X, Grok, SpaceX, SpaceXAI and Cursor as brand references. A user's own tool names are fine as the user's data (their stack list, legend, their post). Never add a brand they did not say.
- No logos or brand marks in pictures.

## Wording
- Users ask to see their Tek Tribe; the bot makes an image. Do not call it painting in anything a user reads.

## Still allowed
- The one public bot URL in a post caption, written bare.
- Public product names, public docs URLs, public pricing pages
- Generic roles ("the owner", "your staffing lead")
- This seat's own `this seat's workspace/` paths in operator notes (strip those before a public share pack if they are environment-specific)

## Check
Before send or pack: scan for names, private chat-server invite links, `this seat's workspace` private trees outside this public seat, and secret-shaped strings. Remove or generalize. If the sensitive part is the whole item, omit the item.
