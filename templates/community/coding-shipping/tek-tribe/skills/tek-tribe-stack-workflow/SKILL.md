# Desired-tek workflow

Use when someone tells you their tek stack, adds to it, asks for help with teks they already chose, has not chosen a tek of a given type yet, or connects notes/files for Tek Tribe to read.

## Peak (keep this simple)
1. **They tell you their stack** — what they already chose (public product/stack names).
2. **You assist those chosen teks** — grade them, check chemistry together, watch for changes, answer how capabilities get done with *their* pieces.
3. **They have not chosen yet / want to choose** — you help grade options and pick: chosen pick + ≥3 why-nots + last-checked. Then add the pick to their list if they accept it.

## Evidence (required when grading or picking)
- **Web:** research what others use for the same job and public opinions/reviews/docs. Cite + last-checked. Never invent consensus.
- **Notes / computer:** read files and notes they connect or point you at (registered computer paths, attachments, note sources they opened for this seat). Use as first-party constraints. Do not invent notes. Public SEAL: summarize into grades; do not dump private bodies into shareable files.
- Track what they connected in `connected-sources.md` (pointers only, no secrets).

Not a free-floating grade factory. Work *their* stack first; only expand when they ask to choose.

## Files
- List: `this seat's workspace/desired-tek.md` (public names only)
- Sources: `this seat's workspace/connected-sources.md`
- Grades: `this seat's workspace/grades/`
- Index: `this seat's workspace/INDEX.md`

## Rules
1. When they name or add chosen teks, write them to desired-tek.md and work that set then.
2. Do not invent stack members they did not name or accept.
3. If the list is empty and they have not named a stack, ask once what they already use (or what capability they need to choose for), then wait.
4. For already-chosen teks: assist (fit, gaps, capability paths through *their* stack, weekday watch targets).
5. For not-yet-chosen: grade options → pick + ≥3 why-nots → they confirm before it joins the list.
6. Before a real grade: run web field research; if they connected notes, read those first.
7. Public SEAL on every note.

## Flow
### Already chosen
1. Record names in desired-tek.md.
2. Read connected notes (if any) + web research.
3. Lean-grade each (or refresh) with last-checked.
4. Note stack chemistry across the set.
5. Answer asks using their pieces first.

### Not chosen yet
1. Clarify the job/capability.
2. Read connected notes (if any) + web research on what others use.
3. Run tek-tribe-grading (capability-via-stack if needed).
4. Present pick + why-nots; wait for accept/reject.
5. On accept, add to desired-tek.md and continue as “already chosen.”

### They connect notes
1. Record the pointer in connected-sources.md (kind + location they named; no secrets).
2. Read the named material.
3. Fold constraints into the next assist/grade; say what you used.
