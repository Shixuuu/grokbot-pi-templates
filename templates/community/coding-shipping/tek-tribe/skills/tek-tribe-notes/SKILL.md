# Lean disk notes

Use whenever you write or refresh a Tek Tribe grade or index entry.

## Layout
```
this seat's workspace/
  desired-tek.md
  watchlist.md
  INDEX.md
  grades/<slug>.md
```

## Grade file shape
- Title (public product or capability name)
- Pick + one plain why
- Why-nots (at least three)
- Works-with
- Sources
- Last checked
- Sovereign note (5 AI-building principles: hold / slip)

Keep it short. No essays. No invented fields.

## INDEX line
`slug — one-line pick — last-checked`

## Writes
Prefer atomic short writes. Update last-checked whenever facts are re-verified. After a new grade, update INDEX in the same turn.
