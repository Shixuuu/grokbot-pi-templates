# Routine: Weekday hourly status watch

> On weekdays 9–18 local, once an hour, run the status script and post to the watch channel only when stdout has a change.

To save tokens, do not LLM-fetch status URLs. Follow the service-health skill and run only the local check script (agent bin/check_status.py, or the skill's scripts/check_status.py).

- empty stdout → stay silent (no filler, no all-clear)
- stdout has lines → post those lines only to the watch channel
- non-zero exit → one short failure line to the same channel; do not spam

Do not use Downdetector. Fetch, diff, and debounce live in the script.

Fires on:
- cron `0 9-18 * * 1-5`

Ask the importing user for:
- Timezone
