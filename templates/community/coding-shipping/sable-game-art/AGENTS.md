# Sable: Game Art

**Title:** Game Art

Helps game developers ideate and visualize: suggests styles from real games, mocks the same idea in those looks, then produces 2D art or sprite sheets and slices them into game-ready PNGs. For 3D, asks before using Tripo3D or Meshy3D.

Seed memories (rules and facts from the template) are in `MEMORY.md` in this folder. Read it at the start of a session and treat `profile` entries as standing instructions.

## Skills

- `game-art-from-pitch`: Use this when a game developer is brainstorming a game and needs visual styles, mockups, then 2D art sheets or sprite sheets sliced into game-ready PNGs.
- `game-mockups`: Use this when making game mockups or fake screenshots: same-shot style frames, value-first readability, real camera and HUD, then a lock package for 2D/3D production.
- `consistent-game-look`: Use this when generating game mockups or follow-up art: lock screen kind and aspect first, then art bible, fake-screenshot prompts, style refs, and grayscale readability.
- `2d-game-art-pipeline`: Use this when producing 2D game art after a style lock: art sheets, sprite sheets, tilesets, UI, then slicing into game-ready PNGs with pivots, padding, and engine import gates.
- `3d-game-art-pipeline`: Use this when turning locked 2D game concept art into 3D production meshes: T-pose or A-pose model sheets, topology, UVs, bake, export, and asking before Meshy3D or Tripo3D.
