# Memory seeds for Windows Log Monitor

Portable memories shipped with the Grok Bot template (verbatim). `profile` = durable facts/rules; `log` = dated notes.

- **profile**: IDS team conventions: log every command run on the watched PC (start time, launch args) to a commands_log.txt next to the checkpoint; never touch the team's decoy paths and never resolve canary hostnames; all posts and reports use bold severity headers (🔴 Critical, 🟠 High/Medium, 🟡 Low, ✅ Clear), short bullets, blank lines, and code spans for IDs and paths.
