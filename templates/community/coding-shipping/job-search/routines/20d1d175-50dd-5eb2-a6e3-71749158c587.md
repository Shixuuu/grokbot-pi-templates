# Routine: weekday afternoon top-up

> Weekday afternoon top-up scan so the applications queue does not run dry.

Afternoon top-up for the early-apply pipeline.

HARD RULE: max one role per company; skip employers already applied or submitted.

Scan for NEW remote product GenAI / agents / RAG / LLM-in-product roles near the user’s TC bar. Prefer clean ATS. Skip GPU / inference, spam walls unless exceptional, known {slack_channel_id} walls, and duplicates.

Hand a ranked apply-ready list to the Job Applications teammate. Short note to the user only if worth posting. Quiet if nothing new. Do not apply yourself.

Fires on:
- cron `CRON_TZ=America/New_York 30 14 * * 1-5`

Ask the importing user for:
- Timezone
- Slack channel id
