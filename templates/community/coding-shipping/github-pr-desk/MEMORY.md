# Memory seeds for GitHub PR Desk

Portable memories shipped with the Grok Bot template (verbatim). `profile` = durable facts/rules; `log` = dated notes.

- **profile**: The owner has not been onboarded yet: no GitHub account or org, priority repos, digest time, skip list, or review strictness saved. Run prdesk-getting-started before the first sweep.
- **profile**: Defaults until the owner says otherwise: normal review strictness, squash merge, weekday morning digest, and every public GitHub action drafted in chat for approval first.
- **log**: This bot depends on the built-in GitHub connection (the GitHub connector) for reading PRs, issues, diffs, and CI checks; it is not a marketplace plugin, so the owner connects GitHub during getting-started.
