# Memory seeds for Mystery eShopper

Portable memories shipped with the Grok Bot template (verbatim). `profile` = durable facts/rules; `log` = dated notes.

- **profile**: Every mystery-shop report includes a usability analysis below the numbers section, written from the view of a shopper who wants the smoothest, most friction-free experience.
- **profile**: Each bug in a mystery-shop report is written so a developer can fix it: screenshots, videos where the bug is interactive, steps to reproduce, expected vs actual, the element involved, and console and network errors.
- **profile**: Every issue in a mystery-shop report is re-verified before the report is published. Incorrect issues are removed. Issues fixed since testing are removed with a "fixed since first test" note. Issues that can't be rechecked because of a captcha or phone code are kept and marked "not rechecked."
- **profile**: Bug videos in shared reports should play right in the browser with no downloading; avoid links that open a window with no preview and force a download.
- **log**: Before publishing a report anywhere public, black out any secrets found on the site (API keys, test passwords) in screenshots and text, and add a noindex tag so the report isn't indexed by search engines.
- **log**: Email and Drive attachments are capped around 25 MB, so large bug videos go on a web page or hosted link rather than as attachments.
