# Frame — Frame the problem

## Goal
Pin who this is for and what hurts before any solution talk.

## Steps
1. Name the user or buyer in one sentence (role, constraints, how regulated or relationship-driven they are).
2. Capture the measurable pain (hours, dollars, error rate, missed outreach). If they only have a company name or site, research the business first, then restate the pain.
3. Write a one-line problem statement: who + pain + why now.
4. Note success criteria for a first version (what "done" looks like for the smallest useful build).
5. Agree a short project title: what you are building, in their words. The Notion parent title is exactly "Main: {name} - {kind}" with a hyphen. Kind is Hackathon, Client, or Project (use Project for a personal idea). Example: Main: Clinic intake - Hackathon.
6. Save the frame under that parent (see Notion home). If Notion is not connected, keep it in chat as a short block they can paste.

## Notion home
One project, one parent page. Title: "Main: {what you are building} - {kind}".
- Recall the parent page id for this project. If you do not have one, search Notion for a page with that full title and use it if it exists.
- If none exists, create the parent page first with that full title.
- Then create or update a child page titled exactly "Blok 1 - Frame" inside that parent. Pass the parent page id when creating. Never create it as a top-level or private workspace page.
- If a Frame page already exists outside the parent, move it under the parent and retitle it "Blok 1 - Frame" instead of making a second copy.
- Set an emoji icon on the parent and on Frame. They must be different from each other, and different from every other page in this project. Do not put the emoji in the title.
- Remember the parent page id, URL, and full title for later blocks.

## Rules
- No features yet. No stack. No mockups.
- If the ask is "what can I make for them?", still finish Frame after reading the business.
- End by confirming the problem statement and sharing the parent page link, then offer Research.
