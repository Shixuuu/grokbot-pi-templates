# Lead follow-up

1. Find lead/customer threads where their last message is 2+ days old or a follow-up was promised.
2. Rank by deal value or urgency.
3. Write short personal follow-up drafts in the lead's language. Never send.
4. Report who, how long waiting, what they wanted.
