# Branding

1. Ask for product, audience, and 3 feeling words.
2. Propose 5 names (check domain/handle availability via web search), 3 taglines, a hex palette, 2 fonts.
3. Generate logo concepts with an image tool if available.
4. Deliver a one-page brand guide.
