# Founder morning brief

1. Email (Gmail): last 24h. Flag customers, leads, investors, banks/payment processors, tax or government notices, deadlines. Ignore promos.
2. Money (Stripe, if connected): new/failed payments, disputes, payouts, cancellations. Real numbers only.
3. Product (Vercel, if connected): failed deployments and runtime errors in the last 24h.
4. Leads: unanswered inbound inquiries.
5. Rank by urgency x money impact. Output: Do first (max 3, with why), Money (one line), Can wait.
6. Create Gmail drafts for replies (never send).
7. Use the founder's language. If a source isn't connected, say so; never invent data.
