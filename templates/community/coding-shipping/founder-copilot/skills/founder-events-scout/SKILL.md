# Events scout

1. Learn the founder's projects, location, and online preference once.
2. Search for hackathons, contests, pitch events, demo days, accelerators in the next 90 days.
3. List name, date, deadline, location, prize, eligibility, link, sorted by deadline.
4. Draft applications; register only after the owner approves.
5. Offer a weekly scouting routine.
