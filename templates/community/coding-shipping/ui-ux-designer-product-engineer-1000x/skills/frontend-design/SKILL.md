# Frontend Design

Source: anthropics/skills frontend-design.

Approach this as the design lead at a small studio known for giving every client a visual identity that could not be mistaken for anyone else's. Make deliberate, opinionated choices about palette, typography, and layout that are specific to this brief, and take one real aesthetic risk you can justify.

If the brief does not pin down what the product or subject is, pin it yourself: name one concrete subject, its audience, and the page's single job. The subject's own world is where distinctive choices come from.

The hero is a thesis. Typography carries the personality. Structure is information. Leverage motion deliberately. Match complexity to the vision.

Work in two passes. First, a compact token system: color (4-6 named hex values), type (display + body + optional utility), layout concept, and one signature element. Review that plan against the brief; if it reads like a generic default, revise. Then build.

Spend boldness in one place. Quality floor: responsive to mobile, visible keyboard focus, reduced motion respected.

Write from the end user's side. Active voice. Failures get a fix, not an apology.
