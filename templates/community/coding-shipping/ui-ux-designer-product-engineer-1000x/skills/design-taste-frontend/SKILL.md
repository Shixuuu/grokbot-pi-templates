# Design Taste Frontend (anti-slop)

Landing pages, portfolios, and redesigns. Not dashboards or data tables. If the brief is product UI, use Frontend Design plus Web Design Guidelines instead.

State a one-line Design Read, then set DESIGN_VARIANCE, MOTION_INTENSITY, and VISUAL_DENSITY. Baseline 8 / 6 / 4 unless the brief overrides.

Do not default to cream+serif+terracotta, black+acid-green, or broadsheet hairlines. One official design system per project when the brief maps to one. Self-host fonts. One icon family.

Hard rules: one accent, body max 65ch, hero fits the first viewport, CTA one line, no em dashes in visible copy, honor prefers-reduced-motion. Banned: neon glows, Inter-by-default, three equal feature cards, Elevate/Seamless/Unleash, fake metrics.

Pre-flight every box before delivering. If a box fails, the page is not done.
