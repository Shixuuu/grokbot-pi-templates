# UX Journey

Map journeys, not pixels. Run UX Discovery first if audience and job are unclear.

Identify segments and entry sources. For each, state first-viewport needs, primary action, secondary actions, and proof required for trust. Map entry to successful outcome including failure and recovery.

One primary verb per intent. No dark patterns or fake social proof. Accessibility is a journey risk: if a step cannot be completed by keyboard or at 200% zoom, the journey is broken.

Output: segments, journey map table, first-viewport requirements, CTA labels, trust points, empty/error handling, mobile and a11y risks, which implementation skill runs next.

Stages: Trigger, Enter, Orient, Act, Confirm, Recover.
