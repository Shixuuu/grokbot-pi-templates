# Landing Page Scaffold

Generate a self-contained marketing-page prototype with a clear conversion path. Pair with Design Taste Frontend for anti-slop execution.

Default sections: hero (thesis, one headline, supporting paragraph, primary + secondary CTA), social proof (named, real), features (2-3 asymmetric rows, never a uniform 3-column icon grid), pricing (honest, one recommended), final CTA (same verb as the hero). Add nav + footer.

Pin subject, audience, and the page's single job. Write real copy before layout. 90%+ neutrals, one accent. Sentence case. Mobile first, tap targets 44px.

Anti-slop: identical feature-card grids, ALL CAPS headings, purple/cyan gradients, eyebrow on every section, two labels for the same intent.
