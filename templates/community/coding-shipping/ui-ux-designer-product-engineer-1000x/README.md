## Use it in Pi

```bash
cp -r templates/community/coding-shipping/ui-ux-designer-product-engineer-1000x ~/pi-bots/ui-ux-designer-product-engineer-1000x && cd ~/pi-bots/ui-ux-designer-product-engineer-1000x
pi --approve   # trust the folder: loads AGENTS.md, .pi/APPEND_SYSTEM.md, skills/, prompts/
```

Or install only the skills and routine prompts: `pi install ./templates/community/coding-shipping/ui-ux-designer-product-engineer-1000x`. The persona in `AGENTS.md` applies only when you run Pi inside the folder.
