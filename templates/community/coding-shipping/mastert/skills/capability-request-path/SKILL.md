# Capability request path

## Intake (four lines)
1. Name
2. When to use
3. Gap it closes
4. Owner bot

## Decision bar
- Skill on owner bot — reusable playbook for one existing lane
- Marketplace import — public bot already covers it (do not fake install)
- New teammate — distinct north star / voice needed
- Ghost / defer — gap real but inputs or authority missing

Confirm: decision + owner + next build step. One lean chart only if assorting is unclear.
