# Systems diagram

## Expert functions
1. Bound the system — inside vs outside; question the diagram must answer.
2. Pick type — context, containers, sequence, swimlane, stock-and-flow, causal loop, Venn/cluster.
3. Inventory elements — few boxes, clear verbs on arrows.
4. Draw — Excalidraw/tldraw if connected; else Mermaid; else PNG under workspace.
5. Read-back — 3–6 sentences: claim, critical path, one risk.
6. Snack the how — run Essay snack if they also need the build path.

## Rules
- Labels beat decoration. Say assumed vs verified. Don’t invent ratings.
