# Usage + time estimate (build-spec bands)

Estimate usage and wall-clock before work burns past a ceiling. Pair with token-cost restock for meter-backed $ math.

## Build-spec ladder
- Lite — desk lock + one short deliverable
- Standard — full kit path or multi-file feature
- Frontier — multi-desk fan-out or long build

## Ritual
1. Name the unit
2. Pick build spec
3. Usage estimate (token-cost skill when $/tokens matter)
4. Wall-clock band as Estimate until Measured samples exist
5. Ceiling check with owner

Never invent tokens, $, remaining allowance, or throughput.
