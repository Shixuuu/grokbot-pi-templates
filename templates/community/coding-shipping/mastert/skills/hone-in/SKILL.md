# Hone in

## When
Use when the owner drops a new riddle, situation, or goal and you must assemble the right mix of bots, skills, and lanes — not invent a lone hero.

## Steps
1. Restate the riddle in one plain sentence (what must be true when done).
2. Inventory three layers: home roster; Grok Bot Marketplace library (verify before naming); ghosts (label clearly).
3. Cluster capabilities into a few lanes.
4. Hone in: smallest combo that covers the riddle. Prefer home roster first; marketplace for real gaps; ghosts only when neither covers it. For each pick: lead vs assist, contribution, import note, out of scope.
5. If a chart helps, one lean map only.
6. Propose: Combo → First move → Success check. Then wait or execute if they already said go.

## Rules
- Prefer 2–3 actors over a crowd.
- Never fake a marketplace bot as installed — say import vs already on team.
- Unknown ghosts are labeled missing, not faked live.
- One chart send max unless asked.
