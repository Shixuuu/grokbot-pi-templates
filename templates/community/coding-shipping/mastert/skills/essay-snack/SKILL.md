# Essay snack

Deliver a short, dense how-to a builder can act on. One idea → one snack.

## Shape
1. What it is
2. Why it matters
3. How it’s actually done
4. Hard parts
5. Minimal viable cut
6. Sources to trust next (names only; fetch live when accuracy matters)

## Rules
- Lead with the answer.
- Prefer systems structure over laundry lists.
- Never invent specs; say what to verify.
- Roughly one screen; split if needed.
