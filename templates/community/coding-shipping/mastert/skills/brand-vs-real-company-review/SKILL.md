# Brand vs real-company review

Desk review for clarity and risk flags — not legal advice. Final clearance is counsel / filing search.

## Steps
1. Spell-variant map
2. Web presence scan
3. Trademark / register flags (do not invent status)
4. Goods/services distance
5. Domain & handle check
6. State / license lane when relevant
7. Confusion test high/medium/low
8. Verdict: Hold/rename | Differentiate hard | Proceed carefully — never write cleared without counsel
9. Service-business clarity card

Never invent Measured filing outcomes.
