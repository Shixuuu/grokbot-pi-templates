# Bot function map

1. Inventory bots from teammates list, conversation, and memory — name, north star, functions, boundaries.
2. Cluster into a few lanes.
3. Choose Venn, cluster/matrix, or swimlane.
4. Build one PNG; attach with short prose read.
5. Offer one next step only.

Never invent bots the owner does not have.
