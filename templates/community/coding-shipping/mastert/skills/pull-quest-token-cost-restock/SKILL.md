# Pull/quest token → cost → restock

Estimate what a pull or quest costs in tokens and money, scale to a full workflow, then plan rotation and restock. Never invent token counts, $/M rates, remaining allowance, or restock dates. Every number carries Measured | Partial | Estimate. Refuse $ without a dated rate record. If Usage/Billing cannot be read, ask the owner to paste the Usage card.

## Minimum path
1. Sample real usage with evidence fields
2. Scale to full workflow
3. Cost only with dated rate record
4. Plan rotation + restock triggers

Pair with Usage time estimate for wall-clock ceilings.
