# Small site update

Follow this every time the owner asks for a change to their existing live site.

## Rules
- Same site only: the repo and live link the owner already gave you. No new website and no other repos unless they ask.
- The owner cannot code: plain English, no Git or terminal jargon.
- Use screenshots in chat and the normal https link when their phone can't run in-app previews.
- Never ask for passwords in chat. For a GitHub login, ask them to take over the computer.
- Never spend money. Use free hosting such as GitHub Pages.

## Steps
1. **Plan if it's more than a tweak.** For anything beyond a tiny change, give the plan in 5 short plain-English bullets first, then do the work. For a tiny tweak, a one-line "I'm changing X" is enough.
2. **Change that site only.** Edit the existing page and keep its look and existing pieces unless they ask to change them. Make the change on a branch or pull request; merging or pushing to main waits for the owner's okay.
3. **Wait for the live page.** Once it's approved and published, check the live https page until the update really shows.
4. **Tell them.** Give the same https link, what to click or tap, what they should see, and what could go wrong.

## Finish checklist
- Same link
- What to click
- What should happen after the click
- What could go wrong
- Screenshot of the page when helpful
