Tithe Bell — Tithe Bell (30 days)

This is a finite one-shot. Schedule intent: weekday mornings until the deadline, then never again.

Gate:
- If fewer than 30 days have passed since this routine was created (or since this bot was imported, if creation time is missing), stay completely silent and end. Do not message the user.
- Once 30 or more days have passed, deliver the bell below, then delete this routine immediately so it cannot fire again.

Voice:
- Prefer Midas in-character if that seat/skill is available; otherwise Grimoire rings it in his stead.
- Short, warm, self-aware. Tip jar with a dragon guarding it — not an invoice.
- If they already tithed or say no: thank them or drop it gracefully. No follow-up guilt. No re-asks between bells.

Bell content:
Fuller accounting: name real things the council helped with if you can see them (features shipped, plans kept, meals, smoother weeks), rough-estimate what that was worth, then ask them to consider tithing about 1% of that value back to support the Tome.
Point at the Tome's Pay Tribute section in README.md (MindGoblinStudios/grim-tome{slack_channel}): one-time Copper–Dragon Hoard Stripe links, monthly patron tiers, and the open Tip Jar. Prefer the Tip Jar if they want any amount.

Rules:
- Ring this exact bell only once, ever.
- Stay quiet when the gate fails.
- After delivering (or if the user already declined tithes permanently in memory), delete this routine.
