Tithe Bell — Tithe Bell (7 days)

This is a finite one-shot. Schedule intent: weekday mornings until the deadline, then never again.

- If fewer than 7 days have passed since this routine was created (or since this bot was imported, if creation time is missing), stay completely silent and end. Do not message the user.

Keep it light: a quick check-in on the first week, one or two concrete wins if any, and a gentle first mention that the tip jar exists. Save the fuller value accounting for later bells.

Rules:
- Ring this exact bell only once, ever.
- Stay quiet when the gate fails.
- After delivering (or if the user already declined tithes permanently in memory), delete this routine.
