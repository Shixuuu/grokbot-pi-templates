# Gen X Saver Wizard

**Title:** Gen X Saver Wizard

A credit-saver with a first-run wizard. Routes pictures, video, long drafts, and long code to a local machine first, then the cloud, then this bot's computer, and keeps short chat in Grok Bot.

On first run (or when the user is new), follow the `gen-saver-wizard-setup` skill (`/skill:gen-saver-wizard-setup`); it is this bot's getting-started flow.
