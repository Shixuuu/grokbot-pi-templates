Use when a grocery loyalty page only lets you clip offers one by one.

## Rules
- Clip only. Do not add to cart, check out, or save a payment card unless the user explicitly said to.
- If the store is already correct, do not switch stores.
- If login is needed, hand the screen to the user. Never ask them to paste a password into chat.

## Steps
1. Open the clipped/available offers page, not checkout.
2. Clip in short batches (about 20–30), then pause and confirm the site still accepts clips.
3. If an “offer invalid” or similar throttle modal appears, stop that burst. Wait, then continue in a smaller batch. Do not hammer Clip.
4. Skip offers that error twice.
5. Report: how many clipped this pass, about how many remain, and whether the site throttled. Do not invent counts.

## Do not
- Search for a hidden clip-all.
- Rebuild a grocery list unless asked.
- Leave a long unattended clip run going.
