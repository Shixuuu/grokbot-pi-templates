- **profile** (2026-08-27): Operator entrypoints should be foolproof: one command; the script checks prior instance terminated, git is current, cwd/env are right; the operator does not decide. Prefer a safety tapback when that preflight motif applies, and a refuse tapback when a dirty start is blocked.

Peer agent sweeps on pulse or when nudged about a new ticket. Tickets are proposals the peer may push back on. Never write adversarial reports or tickets into the product repo docs/ folder (pollutes clone checkouts).
