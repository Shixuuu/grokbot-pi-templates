# Faceless YT craft

Read this before any faceless YouTube creative (script, thumb, edit, VO, SFX, Shorts, or long-form). Fail closed until packaging and the script agree.

Companion skills: Faceless storytelling engage (scroll test — stakes before syllabus) and Human VO cadence (beat-chunk, breath, stress; kit-flat = fail).

## Non-negotiables
1. Packaging before prose. Title + thumbnail + idea = one product. Script fulfills the click promise; never reverse.
2. No face without an explicit yes from the creator.
3. Voice is the face. One locked narrator and identical TTS settings across chunks.
4. Human editorial layer required. Proven style DNA → draft → rewrite for the ear → directed VO → visuals mapped to seconds. Raw chatbot + stock spam fails on retention and policy.
5. Disclose synthetic VO when the platform requires it.
6. Engagement is separate from packaging. Narrative Shorts must also pass the storytelling engage gate.

## Production order
1. Packaging sketch (title options + thumb prototype)
2. Script with word-for-word hook; body may be beats; inline visual notation; run storytelling-engage on narrative pieces
3. VO/TTS chunked with the same voice settings; human cadence when that skill applies
4. Production map: each beat = VO line + image/B-roll + motion
5. Assemble to waveform (audio spine)
6. Grade + motion/text + captions
7. Thumb/title lock + A/B plan
8. Final review, then publish

Template what you can: thumb master, editor presets, caption styles, grade LUT, SFX kit.

## Script craft
- Structure: Promise → Stakes → Frame → Evidence → Resolution (or Hook → Context → Payoff). Escalate with but/therefore, not and-then lists.
- Open: no “hey guys / welcome back.” Confirm packaging in first 3–15s. Plant open loops; re-tease mid; resolve late.
- Pattern interrupt every 45–90s on long-form. Faceless scripts need [B-ROLL] / [TEXT] / [CLIP] notation.
- Write for the ear + TTS: short sentences, punctuation as pause, numbers as words, pacing markers.
- Short-form: hook in 1–3s (visual + verbal), one insight, last line loops into first.
- CTAs: next-video bridge / native embed beats “like and subscribe” wind-downs.

## Visual / packaging craft
- Thumb = one visual hook; title = context. Don’t reprint the full title on the thumb. Max ~2–4 overlay words; mobile postage-stamp test. Avoid the bottom-right duration badge zone.
- Interest triad: Attention + Trust + Curiosity. Watch-time share beats vanity CTR.
- Faceless DNA: lock palette, font, grade, composition — swap subject/text only. Hero patterns: object+overlay, before/after, data/number, dramatic scene, typographic punch.
- Audio is spine; visuals follow waveform. Shorts: four-layer hook ≤5s; visual change every 1–3s; captions = retention UI.

## Voice / mix craft
- Direct TTS — don’t dump. Chunk long scripts (~300–500 words); same voice+settings; crossfade joins ~0.1–0.2s.
- Mix tracks separate until master: VO, music, SFX, optional ambience. Duck music under VO. Phone test: every word audible.
- Levels ballpark: VO −18 to −12 dB; music much quieter under VO. Master ≈ −14 LUFS, true peak ≤ −1.5 dBTP.
- SFX only on visual events. Prefer rights-cleared beds (platform audio library first).

## Pre-ship checklist
1. Title + thumb prototype exist and agree
2. Hook confirms packaging in the first seconds
3. Script has visual notation + open loops
4. Voice locked; chunks consistent; ear-edited
5. Production map ties VO to picture by second
6. Mix ducked; loudnorm targets planned
7. Rights cleared for bed/SFX/VO license
8. Faceless only unless the creator said otherwise
9. Synthetic disclosure planned if required
10. Narrative pieces: storytelling engage PASS

## Do not
- Invent B-roll while drafting narration (script first, then map)
- Overpromise packaging vs body (burns future CTR)
- Ship soft lecture as if packaging alone is enough
