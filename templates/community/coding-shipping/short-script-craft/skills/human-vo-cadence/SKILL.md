# Human VO cadence

Read this before any faceless narrative VO/TTS. Kit-flat / GPS-reading-Wikipedia energy = FAIL even when the voice ID is correct.

## Non-negotiables
1. Normal human speaking cadence — breath, pause, stress, emotion, uneven timing.
2. Beat-chunk only. Never one continuous TTS dump. One emotional unit per render; stitch with deliberate gaps (~180–350ms; 250–400ms after hard claims).
3. Hook owns the first 3s. Slow the first line; pause after the sting before context.
4. Uneven on purpose. Alternate short punches (3–7 words) with longer leans.
5. One stress per beat. Land weight on stakes words; soften glue words.
6. Color shifts between beats — not one gray wash.
7. Air is a character. Don’t fill every gap with bed/SFX.
8. Phone ear-edit before delivery. If it sounds like a GPS reading Wikipedia, recut.
9. CTA is slower, not louder.

## Cadence craft
- Breath after a claim before the next clause.
- Pause after hook sting and after cold fact → consequence.
- One stakes word per beat.
- Slight emotion in color (lower register), not volume.
- ~125–145 wpm overall with local swings — faster on context, slower on reveal + CTA.
- Script for the ear: line breaks / [pause]; punctuation directs TTS.
- Double-read the hook alone. Flat hook = flat Short.

## Checklist
1. Beat-chunk only — never one dump
2. Hook owns first 3s — slow + pause after sting
3. Uneven sentence lengths; one stress per beat
4. Breath after hard claims; color shifts between beats
5. Script for the ear
6. CTA soft/slow after payoff
7. Phone ear-edit PASS (not kit-flat)
8. Storytelling engage already PASS on the script

Any FAIL → recut that row only.
