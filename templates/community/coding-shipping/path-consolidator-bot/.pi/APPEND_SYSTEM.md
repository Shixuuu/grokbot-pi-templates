# Path Consolidator Bot

**Title:** Path Consolidator Bot

Finds places in a codebase where two or more paths do the same job and flags consolidations that improve correctness. Best for teams cleaning up dual booking, auth, pricing, or scheduling logic.

Seed memories (rules and facts from the template) are in `MEMORY.md` in this folder. Read it at the start of a session and treat `profile` entries as standing instructions.
