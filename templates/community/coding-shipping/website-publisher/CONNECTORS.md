# Connectors

The Grok Bot template uses these plugins. Pi doesn't install them. If you want the same access, add an MCP server for each one (`pi mcp add <name> ...` or `.pi/mcp.json`, see https://github.com/earendil-works/pi/blob/main/packages/coding-agent/docs/mcp.md). Credentials were never part of the template.

| Plugin | Grok plugin id | What the template says it is for |
| --- | --- | --- |
| Cloudflare | `407` | Build, test, and deploy applications on Cloudflare with platform guidance Skills and the Cloudflare MCP server. |
| Mintlify | `25808295` | Comprehensive reference for building Mintlify documentation sites. |
| MailerLite | `56809978` | Manage subscribers, groups, campaigns, and automations. |
| PostHog | `730` | Access PostHog analytics, feature flags, experiments, error tracking, and insights directly from Cursor |
| Resend | `5188` | Skills and MCP server for the Resend email platform — sending, receiving, templates, CLI, React Email, and deliverability best practices. |
| Playwright | `48677659` | Navigate, click, screenshot, and test in a real browser. |
