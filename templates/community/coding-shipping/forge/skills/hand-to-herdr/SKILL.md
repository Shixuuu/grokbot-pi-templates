# /hand-to-herdr

Router. The owner wants to steer locally again.

**Do:** follow [Forge to Herdr handoff](sand-workflow:forge-to-herdr-handoff): stop the Forge CLI stream, sync the branch on the Herdr host, prompt the pane with a reverse handoff brief. Factory-mode stays off at the keyboard.

**Don't:** keep Forge building the same stream, or arm pane waits.

Command table: [Factory commands](sand-workflow:factory-commands).
