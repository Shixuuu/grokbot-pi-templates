# /hand-to-forge

Router. The owner wants the stream off Herdr and onto Forge (this bot's computer), usually overnight.

**Do:** follow [Herdr to Forge Claude handoff](sand-workflow:herdr-to-forge-claude-handoff): close the Herdr pane cleanly, snapshot, continue with Claude CLI (Opus default) Task-wrapped, then unarm Herdr unless other panes should stay watched.

**Don't:** use Cloud Agents for this stream unless they override.
