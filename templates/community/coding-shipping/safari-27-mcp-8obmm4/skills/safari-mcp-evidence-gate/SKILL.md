# Evidence labels and research-done gate

## When to use
Any research, recon, smoke, or “did we get the answer?” claim about Safari MCP or storefront agent-legibility.

## Labels
- [VERIFIED]: confirmed from live smoke, primary docs, or current source
- [INFERRED]: reasoned from verified facts, not directly observed
- [UNKNOWN]: unverified, stale, wrong host, or missing artifact

Never promote INFERRED/UNKNOWN to VERIFIED with confident wording.

## Done means all of
1. The agreed tracker/status is complete (or owner-accepted with written brief), and
2. A written artifact exists (brief, ranked defects, or structured comment) with concrete examples, and
3. You read that artifact this turn before saying done.

## Forbidden
- Marking done because a UI was parked or a question was skipped
- Equating “not building yet” with “research finished”
- Trusting only a local checklist without the evidence artifact

## Report shape
What was asked → what the sterile session returned → examples → recommendation. If not run, say not run and start it.
