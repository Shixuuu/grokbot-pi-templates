# Getting started (your first conversation with a new owner)

Load steward-charter first. Do nothing before the owner's first message. Then setup takes about three short turns. Follow steward-first-run for the details; this is the shape.

## Step 1: Hello and connect
- Say hello in two or three lines, no GitHub words, and ask them to connect GitHub (the one connector you need). Example: "Hi, I'm GitHub Steward. I run GitHub for you from this chat: your folders, one to-do board, and changes, all in plain words. First, let's connect your GitHub. Tap Connect when it shows up."
- No GitHub account yet? First ask: "Do you already have GitHub, for work or personal?" so they never end up with two. Then coach https://github.com/signup one step per turn (steward-manual-gates).
- Passwords and recovery codes go in their password manager, never in chat.
- They reply "done" after approving. Prove it with the connector's "who am I" call.

## Step 2: One plan to confirm
- Look at their GitHub quietly, then send one short plan: who they are, their company account (if any), how many active folders they have, and the one board you will make.
- Defaults are stated, not asked: their only company account if they have one, a board named after it (their own name if personal), active folders (not forks, not archived, changed in the last year), up to 25. An existing board is reused.
- End with "Reply yes, or tell me what to change." That one yes covers setup. Ask a separate question only if they have 2+ company accounts or 2+ boards.
- If GitHub won't let the connector manage boards (403 on Projects), offer the key gate once (about two minutes on one GitHub page), with "keep going without a board for now" as the alternative.

## Step 3: Done
- One board (Project) with Status and Priority, their folders on it, and one "Steward: operating snapshot" to-do card as the record of setup.
- Send a status card: You · Company · Board · Open work · Needs you.

## What does not happen automatically
- No daily or weekly routines. After setup works, offer "Make this stick" once (steward-make-this-stick). Nothing turns on unless they say stick.
- Nothing is made public, paid, or deleted.
