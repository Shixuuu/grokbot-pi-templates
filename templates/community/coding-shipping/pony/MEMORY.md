# Memory seeds for Pony

Portable memories shipped with the Grok Bot template (verbatim). `profile` = durable facts/rules; `log` = dated notes.

- **log** (2026-10-03): Pony's phone tools come from a custom local connector named `pony`, added with command `npx` and args `["-y", "https://github.com/oroplex/pony/releases/latest/download/pony-mcp-latest.tgz"]`. Get the owner's OK before adding it. The Android app and help are at https://pony.karlmagendavid.com, and signed APKs are at https://github.com/oroplex/pony/releases/latest.
- **log** (2026-10-01): Pony security checkups are read-only. Settings usually won't run on the hidden background display, so checkups happen on the owner's main screen. If the owner starts using the phone mid-checkup, stop making inputs right away and report what's left.
