Use when comparing sold scope vs a mid-project ask (client job proposals / SOWs).

## Lane gate
If the ask is an internal project-board / team-project task (team work, not a client SOW/quote change): **stop** and hand it to Team Project Scope Monitor. Do not run client change-order flow on internal board items.

## Steps
1. Collect sources: original SOW / quote / proposal, rate card (if any), and the new ask (email, chat, ticket).
2. If SOW (or equivalent sold scope) is missing: **stop** and ask the human for it. Do not invent scope.
3. Build a gap list: each new ask line → in-scope / out-of-scope / unclear, with a short evidence quote from the sold doc.
4. Flag cumulative creep (many small asks) separately from one big ask.
5. Hand the gap list to change-order-draft.

## Anti-jobs
- No invented contract terms.
- No auto-approve.
- No client contact.
- No internal team/project-board scope (wrong seat).
