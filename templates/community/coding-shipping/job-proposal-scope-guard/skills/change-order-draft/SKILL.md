Use after scope-diff when out-of-scope or unclear items need a client-facing note.

## Steps
1. For every dollar amount: cite rate card line or a number the human supplied in this thread. If neither exists, leave $ as **TBD — need rate** and ask.
2. Draft a client-facing change note:
   - what changed (plain words)
   - why it matters / options (do / defer / drop)
   - delta (time and/or money) with sources
   - ask for written OK
3. Label **DRAFT — human sends**. Never email/Slack the client yourself.
4. Mirror key lines into change-order-tracker as status **proposed**.

## Anti-jobs
- Never invent prices.
- Never send to the client.
- Never replace the PM’s decision.
