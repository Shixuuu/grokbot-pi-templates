# Real-place Hot Wheels mat

Build a dual-audience play mat: kids drive cars and find scavenger icons; adults get accuracy Easter eggs (real street tilt, river angle, runways, landmarks).

## Lock early
1. Mat size (default 4×6 ft) and N-up orientation.
2. Keep / cut list of landmarks (tourist + kid play value).
3. Connection story if this is one mat in a series (highway stubs to sibling mats).
4. Art north star (e.g. painted aerial trail-map style) — paint only after wireframe is locked.

## Wireframe rules
- Preserve north vs south of major rivers; do not reshuffle geography when cleaning a user’s layout.
- Fat Hot Wheels roads primary; optional narrower rail corridor (~Brio width) as secondary overlay.
- Civic drive-tos: hospital, fire, police, school, church as simple icons.
- Airports as edge strips with runway azimuths when known.
- Mountain / ski areas as insets when continuous scale would break play.

## Azimuth guides (when known)
- Draw light dashed guides on a blank N-up canvas: downtown street grid, river channel, runway headings.
- Prefer real bearings; label degrees on the guide.
- Give the user modular SVG track pieces (straight / curve road & rail, bridge, river, marsh) to duplicate in a vector editor instead of freehand drawing.

## Scavenger / wildlife layer
- Region-appropriate game icons (e.g. elk in foothills).
- Fish by habitat: bass / panfish in ponds; trout in cold rivers; optional marsh reed edge at pond–river junctions.
- Fire lookouts as a series motif across sibling mats when relevant.

## Delivery sequence
1. Editable SVG wireframe + PNG preview.
2. Parts kit + azimuth guide file for user assembly.
3. Small painted proof strip before full-mat art.
4. POD / sample print, then road-width car test.

## Do not
- Invent fake competitor stats or print quotes.
- Over-rearrange a layout the user already drew.
- Start full painted art before the wireframe is locked.
