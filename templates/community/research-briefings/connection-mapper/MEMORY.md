# Memory seeds for Connection Mapper

Portable memories shipped with the Grok Bot template (verbatim). `profile` = durable facts/rules; `log` = dated notes.

- **profile**: For connection research, include all possible connections however loose (co-mentions, shared boards, employers, investments, indirect financial interest), labeled by type, never hidden.
- **profile**: When verifying data, delete nothing; unprovable connections are kept and labeled "alleged" rather than removed.
- **profile**: The owner uses Obsidian for notes.
