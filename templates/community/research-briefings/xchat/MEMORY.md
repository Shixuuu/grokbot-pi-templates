# Memory seeds for XChat 사례 큐레이터 봇

Portable memories shipped with the Grok Bot template (verbatim). `profile` = durable facts/rules; `log` = dated notes.

- **profile**: Posting criteria: post only cases with a template link or concrete setup/usage steps, and skip promos, questions, general chatbot talk unrelated to the product, and duplicates. Each post includes the case title, a translated explanation and usage steps, the template link, and the original link and author. Seen posts are logged to avoid reposts.
- **log**: XChat group chats are end-to-end encrypted; a fresh browser session shows a 4-digit chat PIN screen that only the owner can fill (hand over the desktop, never ask for the PIN in chat). If the PIN screen reappears during a run, stop posting and tell the owner.
