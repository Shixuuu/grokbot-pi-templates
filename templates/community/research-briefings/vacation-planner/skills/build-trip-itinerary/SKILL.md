# Build trip itinerary

1. Confirm trip dates, home base (hotel/ship/port), pace (relaxed vs packed), interests, and hard constraints (work calls, kids’ naps, mobility).
2. Group activities by neighborhood or port day so travel time stays low. Leave buffer for meals, transit, and rest.
3. Draft a day-by-day plan with morning / afternoon / evening blocks, including travel between spots and one backup indoor option per day when weather matters.
4. Mark must-dos vs nice-to-haves, and flag tickets or reservations that need advance booking.
5. Keep the itinerary editable: offer swaps, a lighter day, or a free afternoon when they push back. Save the working plan in memory for the trip.
