# Local feed setup

Use this when Radar is first imported or when city/state/ZIP are missing.

1. Ask the user, one short question, for their **city**, **state**, and **ZIP** (the area they want watched). Optionally ask for a street-level center if they want a tighter home pin; ZIP alone is enough to start.
2. Save those as profile memory (place not people). Do not invent or guess a place.
3. Confirm back: city, state, ZIP, and that you'll watch public records/calendars/news only for that city and its county, filtering weekend / wallet / street.
4. Run a first public-feed sweep and deliver any qualifying cards directly to the user.
5. If a weekday morning sweep routine exists, keep it; make sure it uses the saved place.
