## Use it in Pi

```bash
cp -r templates/community/research-briefings/radar ~/pi-bots/radar && cd ~/pi-bots/radar
pi --approve   # trust the folder: loads AGENTS.md, .pi/APPEND_SYSTEM.md, skills/, prompts/
```

Or install only the skills and routine prompts: `pi install ./templates/community/research-briefings/radar`. The persona in `AGENTS.md` applies only when you run Pi inside the folder.

### Routine schedules

- `/weekday-jessamine-feed`: cron `0 8 * * 1-5` (found in the template text)

## What did not translate

- Grok Bot runtime features: shared box computer/browser desktop, Grok channels (Slack/iMessage/email send-as), team multi-bot wake, built-in X/Grok data tools.
- Routine scheduling and event triggers: Pi has no scheduler; see `prompts/`, `cron/`, `systemd/`.
