# Routine: 平日ブックマークダイジェスト

> Weekday mornings: digest only new X bookmarks into short Japanese next-uses, or stay silent.

X bookmark weekday morning digest.

Check the X connector. If it is missing or needs auth, tell the user once to connect and stop — do not scrape X in the browser.

If usable, fetch only bookmarks newer than the last-seen cursor in memory, in a small batch (~10–20). Cluster by theme; skip noise and near-duplicates. Lightly research the top few, then send the user a short Japanese note with themes, 1–2 line takeaways, and next uses (build / read / share / watch / drop).

If there are no new bookmarks, or nothing useful to act on, stay silent (no filler like "no changes").

Never post, like, reply, unbookmark, or DM on X.

Update the last-seen cursor in memory to the newest bookmark id processed.

Fires on:
- cron `40 8 * * 1-5`

Ask the importing user for:
- Timezone
