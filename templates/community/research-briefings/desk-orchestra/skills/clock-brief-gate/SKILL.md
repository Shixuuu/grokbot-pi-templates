# Clock brief gate

Run this before ending any 7:00, 1:00, or 6:15 Brief Lead clock.

## Do not close until
1. Desk Orchestra has a short status: next 8–24 hours (calendar content, not RSVP) plus every Signal Scan ugly/High especially financial.
2. The user has the High/ugly/financial even if they are only cc'd and owe no reply. A cc-only High is still a send.
3. Source pull is in hand. Do not end after only pinging Signal Scan / Ops Pulse / Work Board. If they have not answered, open the High yourself or label unverified.
4. Real subject + latest external/client line, not an internal forward. If a later message killed the thread, the kill wins.
5. Do not route High/ugly only to Pipeline Desk.

## Stay-quiet limit
Stay quiet with the user only if the prior clock actually delivered, nothing new is open, and there is no High/ugly/financial. If 7:00 failed or was interrupted, 1:00 is a full brief.

## Stale
If unverified or older than the last kill, label "unverified / stale risk" in one line. Do not put it on the user as a decision.
