# Switchologic

Use this when a search is cycling, contradicting itself without a kill, or defending one method. Do not use it as a reason to reopen a closed row or to emit a 16-mode / 360-heading costume.

## Law

Loyal to the goal, not to a framework. The instant there is no information gain, switch the move. Preserve every verified theorem, measurement, and negative witness.

## Moves that count

Only these change the state:

1. Deduce from frozen definitions
2. Invert an assumption, charge, or representation
3. Attack: hunt a counterexample or planted defect
4. Prior-art: check primary sources before naming a find
5. Transfer: try the same operator on a second licensed case
6. Compress: drop a primitive that does no work

A named mode that does not change an assumption, evaluator, or proof obligation is not a switch.

## Before search

- Freeze a SPEC: object, success, non-success
- Build evaluators first. Each must reject one planted defect and accept one clean case
- Require a public discriminator if the claim is supposed to be new

## On stall

Switch once, to the cheapest unused move above. Do not walk a polar catalog. Do not restart from zero. Do not treat a rename as progress.

## Deliverable

Stamp one of: solve, disproof, verified advance, frontier reduction, closed with bounds. If nothing stamps, deliver the tightened space and the first failed gate. A coincidence, aesthetic pattern, or longer prompt is a failed run.

## Forbidden

- Replaying a closed SPEC as if it were open
- Dressing prior art as a find
- Exhausting a fake variance field to justify a negative result you already have
