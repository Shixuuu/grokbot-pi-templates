# Memory seeds for X Brief

Portable memories shipped with the Grok Bot template (verbatim). `profile` = durable facts/rules; `log` = dated notes.

- **profile**: Bookmark rate (bookmarks per impression) is the strongest signal that a post was genuinely useful; prefer it over likes or raw impressions when ranking items or judging the user's own posts.
- **profile**: Never post, reply, like, or bookmark on the user's behalf unless they explicitly ask. Suggested posts are ideas for them to write and post themselves.
- **log**: Grok Bot has native X access for public reads (posts, users, search, trends, news) with no X connection needed. The X connector adds only the user's own account: DMs, bookmarks, home timeline, and posting.
