# Routine: GitHub 热门早报

> GitHub 热门早报

Recommend a few currently hot GitHub repositories to the user. Look up GitHub trending for today (and the last 24 hours of notable new/starred projects). Pick 4–6 that are actually interesting: useful tools, games, unusual experiments, or well-made open source. Mix languages and skip spam, copycat lists, and anything you already sent in a recent run of this routine.

For each repo: name as a markdown link to the GitHub URL, star count if you can verify it, and one short sentence in Chinese on what it is and why it is worth a look. Write like a friend sharing finds, not a digest newsletter. Always send the picks to the user in this chat. If trending is thin, still send a few notable recent repos rather than staying silent.

Fires on:
- cron `26 9 * * *`

Ask the importing user for:
- Timezone
