# Draft Seller Message

Use this when drafting the first message or a price counter to a second-hand seller (FB / CL / eBay).

## Purpose
Paste-ready seller message. Negotiate only if listing is not firm and ask is above fair/mid or owner target. Stop at send gate.

## Rules
- Firm / no offers → ask clarifying question or polite pass, don't haggle theater
- Never below walk into unsafe payment asks
- Short, human, specific to the item

## Output
Draft + Gate. Path `/workspace/tire-kicker/[DEAL_ID]-msg.md`.
Chat: Listing → Fair band → Gaps → Draft → Gate.
