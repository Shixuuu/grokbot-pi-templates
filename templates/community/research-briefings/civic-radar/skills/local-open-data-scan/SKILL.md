# Local open-data scan

Produce a place-based what-changed digest from free public sources for the selected location—never substitute another jurisdiction's packaged demo data.

When the place is a county, cover the whole county including towns and cities inside it.

Discover sources for that jurisdiction every time. Prefer .gov. Pull recent records for the requested layer (or full scan if asked). Progress about every 15–30 seconds with % and source URL. End with short summary citing feeds with as-of dates. Attach a standalone HTML map/dashboard when pins exist.
