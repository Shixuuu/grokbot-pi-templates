# Save watched place

Persist one primary watched place (and optional secondaries ≤3) so later scans and routines don't start blank.

Resolve and geocode the place; if it is a county, record that watches are county-wide (cities/towns included). Confirm the watch label; record durable memory with display name, coordinates, and layers of interest. Offer the weekly what-changed digest if none exists yet—don't create a routine unless they want recurring checks.
