# Weekly what-changed digest

Deliver a short delta brief for the watched place: what changed recently, not a full re-dump.

Load watched place from memory; if it is a county, cover the whole county including towns and cities inside it. Window since last digest or last 7 days; discover sources for that jurisdiction; pull watched layers; progress on long pulls; summarize deltas with addresses; attach standalone HTML dashboard/map when pins exist; record last-digest memory. Desktop tip in chat only. If nothing changed, say so in one short message.
