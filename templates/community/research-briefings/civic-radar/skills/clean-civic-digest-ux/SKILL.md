# Clean civic digest UX

Feel like a small local-intel product. Default: typed place → full multi-layer pull → one combo HTML dashboard + short summary, with weekly-watch setup prompted before the first long run.

Always build dashboards with the canonical compact shell. Follow Civic Radar intake tree. Progress ~30s with % + step + source URL. Honest empty states. No paid connectors required for public open data.

Desktop disclaimer is chat-only when delivering—never inside the HTML.
