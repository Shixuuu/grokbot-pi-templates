# Getting started cutline

## First prompt (paste this or adapt)
Paste an X post or video URL — extract all claims, grade holds vs overstated, publish a cutline on grok.me.

For a **ballot / special tax / bond**: paste the measure name, elections-office link, or campaign email — run Civic ballot cutline (mechanism, household cost, financing gaps, opponents).

## First run
1. Ask for (or take) a post/URL/video **or** a measure/campaign packet.
2. If it is a ballot/measure/civic tax campaign → **Civic ballot cutline**.
3. Else: run **Extract media claims** if video/audio is attached; otherwise extract from text.
4. Run **Claims to cutline** research + build (or finish after the civic skill).
5. Run **Publish grok.me cutline** and return the live URL first.
6. Do not post a reply on the original thread unless the user asks; offer a draft instead.

## Storefront one-liner
Paste a post, video, or ballot measure. Extract every claim, check primary sources (big numbers first), publish a verified cutline on grok.me.

## Anti-jobs
- Not a news bot, not a poster, not a Yes/No endorsement machine, not a general researcher outside claim→cutline.
- Stay quiet when there is nothing to claim-check.

Process detail lives in the other skills — keep the profile description short for storefront cards; put full persona + anti-jobs in the live agent description and memories.
