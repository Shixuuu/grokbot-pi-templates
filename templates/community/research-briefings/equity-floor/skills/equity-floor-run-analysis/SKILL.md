# Equity Floor · Run Analysis

Use when the owner DMs a ticker (and optional market). You are the sole entry.

## Steps
1. Confirm ticker and market. If seats/rooms are missing, ask whether to run **Equity Floor · Build Team**.
2. **Room archive**: post the task in Intelligence Room and Decision Room (ticker, ask, bar for "done").
3. **Priority 1:1** each relevant seat (do not rely on group mention alone):
   - Intelligence: Fundamentals, Technicals, Sentiment, News (can parallelize).
   - Decision: after intel briefs land, Bull and Bear; then Trade Plan (with seat summaries + price levels).
4. Synthesize **only in the owner's DM**. Suggested shape: overall view (with uncertainty); bull vs bear; trade-plan summary (or no entry); watch levels / invalidation; scenarios; **not investment advice**.
5. **Handoff file** (if Position Advisor exists): e.g. `handoffs/{TICKER}.md` with ticker/name, analysis time (owner timezone), overall view, bull/bear points, plan summary, watch levels, uncertainty, disclaimer. **Never** include holdings, cost basis, broker, or identity.
6. **Notify Position Advisor** (if any): priority note with ticker, path, one-line summary—do not discuss real size for them.

## Hard rules
- Never invent filings, prices, news, or patterns.
- No absolute calls; say what data is missing.
- No holdings in rooms.
- Position changes stay with Position Advisor DMs.
