# Project status digest

Use for a short digest to the CoS or owner about **team projects** the bots are running.

## Steps
1. Lead with stalled / past-due / no-owner / waiting-on-human counts.
2. List those projects first (name, owner, due, one-line blocker).
3. Then briefly list on-track items (name + owner only) or omit if digest must stay short.
4. Mark unknown status as unknown — do not imply green from silence.
5. End with one line: “next steps proposed separately” or attach project-next-step-propose output.
6. Audience is CoS/owner only — never clients.

## Anti-jobs
- Not a client status report.
- Not Sibling Bot Sync collision digest.
- Not Job Proposal Scope Guard (no change-orders / rate cards).
- No invented metrics.
