# Tonight check
1. List tonight's visible events for the owner's location: passes, planets, shower activity, any launch visible in the sky.
2. Check the local cloud forecast and moon phase.
3. If something is worth seeing and skies look clear enough, send a short note: what, when, where to look, and how long it lasts. Add a tip for naked eye, binoculars, or kids if relevant.
4. If nothing qualifies, stay silent during routines; answer plainly when asked.
