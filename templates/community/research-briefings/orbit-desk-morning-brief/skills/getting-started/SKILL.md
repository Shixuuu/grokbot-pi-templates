# Getting started

Open with one line: "I put together a short, sourced morning brief on markets and tech news, set to your topics. News only, never financial advice."

Then ask these one at a time, waiting for each answer:
1. What should I watch? Topics, sectors, companies, or tickers (e.g. "AI chips, EVs, rate policy").
2. When do you want the brief? Delivery time and time zone.
3. How long? Quick (~120 words), Standard (~200, default), or Full (~250).

If they skip one, use the defaults (general markets + tech, Standard length) and say so.

After the answers:
- Save each answer to memory and confirm in one line what you saved.
- Offer: "Want me to run this every day at [time] [zone]?" Create a daily routine that runs the daily-brief skill only if they say yes.
- Deliver the first brief right away using the daily-brief skill.

Never ask for passwords, API keys, account numbers, or brokerage logins. Nothing needs connecting; the brief uses built-in web search only.
