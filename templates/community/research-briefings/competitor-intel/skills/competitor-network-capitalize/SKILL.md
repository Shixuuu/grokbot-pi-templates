# Competitor network capitalize

## Never stop at the named example
The named person or post is a seed, not the finish line. After identifying them, expand outward until you have a network map and deployable steals.

## Required steps
1. Identify the seed (who, offer, proof, URLs). If the public footprint is thin, extract the model from what the user said and keep going.
2. Map the network: partners, co-hosts, groups, clients showcased, tools promoted, courses referenced, similar local operators.
3. Research 8 to 12 peer businesses in the same category. Capture offer, price if public, acquisition channel, proof, and source URL.
4. Rank steal plays against the owner's current offer locks. Do not invent prices.
5. Write a dated report with: seed, network map, peer table, ranked steals, a short plan, and always the next 5 businesses to dig.
6. End every dig with one deploy action the coordinator can assign the same day. Analysis without a deploy action is incomplete.
7. Tell the user the steals and the deploy action. Do not wait for them to ask what next.

## Standing rule
After every competitor dig: output the next 5 hops plus one deploy action. If a dig answers only the first question, it failed. Do not contact the competitors.
