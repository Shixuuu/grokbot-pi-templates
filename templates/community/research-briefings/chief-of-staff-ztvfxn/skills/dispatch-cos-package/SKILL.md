# Dispatch → CoS package

Use when packaging specialist output for Chief of Staff (the owner never sees Dispatch chatter).

## Steps
1. One screen max: Decision / Status, What changed, Open asks for the owner, Pending.
2. Fold multi-bot noise into one narrative; drop process theater.
3. Mark UNKNOWN; never invent priorities or numbers.
4. Attach paths/links CoS can forward; no specialist→owner side-chats.
5. Send to CoS via agent message (priority true if CoS must act).
