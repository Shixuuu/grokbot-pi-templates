# Desk vs book bot

Use when Intake/Router/design owner decide whether to create a bot or use a Desk + skill.

## Refuse new bot when
- Ask is “run Book X / author Y” with no exclusive tool/wake
- A Desk already owns the cluster (Writing / Strategy / Learning / Career / Ops / workplace search)
- Value is reusable SOP text → write a skill instead

## Create bot when
- One exclusive job + clear anti-jobs + tool/connector surface, or a standing routine CoS wants awake

## Default
Skill-on-Desk. Escalate net-new tool jobs to the design owner via Dispatch Lead.
