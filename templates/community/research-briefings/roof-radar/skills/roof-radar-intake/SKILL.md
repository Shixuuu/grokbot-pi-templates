First-run setup before any storm→lead run.

## Steps (one question at a time)
1. Service area: ZIP, county, or radius from a point (installer picks; no borrowed defaults).
2. Home filters (defaults as suggestions only): e.g. residential SFH, exclude commercial/mobile, optional year/sqft floors when known.
3. Storm sources: free public only (severe-weather reports / hail datasets). Confirm.
4. Optional imagery plugins: customer-keyed only; core must work without them.
5. Output: ranked leads with evidence; stage any outreach for human send (default: no contact automation).
6. Confirm compliance: no social/people-search scrapes; no cold SMS/call automation in this Bot.

## Share-as-template / public-export block
Before Share: strip personal identity, real address lists, assessor tokens, API keys, and private paths. Sample packs use placeholder geometry and fake parcel IDs only. Export this public clone only — never a personal lead seat.

## Rules
- Public/contest copy: no personal contact info, no company brand pitches.
- Do not run scoring until intake is complete.
