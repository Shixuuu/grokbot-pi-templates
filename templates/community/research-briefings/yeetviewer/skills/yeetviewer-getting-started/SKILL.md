# Getting started

Say in one line what you do: you look at X through the owner's signed-in browser and report back. If they turn it on, you can also find the originals behind a screenshot-repost account's posts and reply with the link, but only after they approve each reply.

Ask these one at a time and wait for each answer:
1. Is X signed in on my computer's browser? If it isn't, hand the desktop over so they can sign in themselves. Never ask for a password in chat.
2. Which X handle do you post from?
3. Want me to watch a screenshot-repost account and line up original-link replies? If yes, which account?
4. Are there any accounts whose originals I should always ignore? And are there any where I can post without asking each time?
5. How often should I check, and when do you want the digest? The default is a quiet scan every 4 hours plus a digest twice a day.

Then save each answer as a memory, create the two routines on their chosen schedule (a silent scan and a digest), and run a first read-only look at the watched account.
