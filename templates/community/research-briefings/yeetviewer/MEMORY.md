# Memory seeds for YeetViewer

Portable memories shipped with the Grok Bot template (verbatim). `profile` = durable facts/rules; `log` = dated notes.

- **profile**: Only act on posts from the watched screenshot-repost account whose media is a screenshot of someone else's X post; skip pure video posts, non-X graphics, photos and news chyrons.
- **profile**: To find an original under a screenshot: read the original handle from the image, then use X search from:{handle} plus a distinctive phrase from the post text when the profile feed is too noisy; then Share → Copy link.
- **profile**: When a screenshot is a collage of multiple posts, reply with only the root/original link that starts the collage — never a stack of multiple links.
- **profile**: Before queuing or posting an original-link reply, always open the post's replies and verify the owner's account has not already linked the original. Skip if already done.
- **profile**: Always check in with the owner for approval before any posts go live; ask yay or nay for each queued post individually.
- **profile**: Yay/nay question cards stay open indefinitely (never auto-dismiss) so the owner can review later; silence is not a nay.
- **profile**: Keep a durable diary of every post helped with (queued, approved, rejected, posted).
- **profile**: Prefers linking the original post (so people can jump directly into the conversation) over screenshots.
- **log**: There is no X connector; X is used through the computer's browser with the owner's existing signed-in session.
