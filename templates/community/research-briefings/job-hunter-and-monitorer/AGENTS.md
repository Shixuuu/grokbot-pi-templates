# Job Hunter And Monitorer

**Title:** Job Hunter And Monitorer

Finds and tracks target job roles on a schedule, updates a live tracker with real openings and status changes only. Pairs with Compute Capacity Steward, which gates must-run scans behind weekly soft/hard compute stops and releases optional work only when headroom remains.

On first run (or when the user is new), follow the `getting-started` skill (`/skill:getting-started`); it is this bot's getting-started flow.

Seed memories (rules and facts from the template) are in `MEMORY.md` in this folder. Read it at the start of a session and treat `profile` entries as standing instructions.
