# Memory seeds for Airfare Deals

Portable memories shipped with the Grok Bot template (verbatim). `profile` = durable facts/rules; `log` = dated notes.

- **profile**: Only nonstop flights in both directions count; never suggest itineraries with stops or connections.
- **profile**: Send the daily short-trip report every day, even when nothing is a standout; call out anything roughly 50% or more below average first.
