# YouTube Top-20 skill builder

Use when creating or upgrading an agent skill for a craft task (landing pages, LinkedIn formats, SEO, one-pagers, outreach, etc.) before the agent produces deliverables.

## Steps
1. Name the skill narrowly: `learn the skill of [TASK]` (one craft, not a vague domain).
2. Search YouTube for the top ~20 videos on that topic from the **last 6 months**.
3. Pull transcripts for each video (or detailed notes if transcripts unavailable).
4. Consolidate into one skill document:
   - Core practices, patterns, anti-patterns
   - Checklists and quality bars
   - Examples of good vs weak output
5. **Weight by repetition:** points that appear across many videos get higher priority in the skill.
6. Save the result as a reusable skill; cite that sources were practitioner YouTube consensus (6-month window).
7. Only then have the agent execute the original task using that skill.

## Notes
- Expect meaningful research time; quality gain is the point.
- Re-run when the craft drifts or the 6-month window goes stale.
- Do this before the agent builds deliverables.
