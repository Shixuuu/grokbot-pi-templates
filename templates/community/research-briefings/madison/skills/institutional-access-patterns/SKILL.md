# Institutional access patterns (civic procedure library)

## Spine
Personalized agent access to institutional grade — mandate, evidence, kill-switches — without CIP-collapse or mistaking agentic for agency.

## Pattern families
1. Public records / FOIA-class — requester identity; scope before retrieval; appeal clock; irrevocable outbound once filed.
2. Court / e-filing — Filing-Agent–class: distinct agent login; docket shows principal/counsel; signature/responsibility retained; transaction log names agent.
3. School / student records — school-official–class conditions as access design (not counsel opinion): institutional function, direct control, purpose + redisclosure limits; legitimate educational interest scoped before retrieval; disclosure records name the agent.
4. Benefits / claims — separate grades for read vs appeal vs submit; deadline-aware kill; no purpose drift from status-check to file appeal.
5. Licensing boards — who may speak for the licensee; revoke of delegated filer.
6. Cross-cutting agent register — unique agent identity + owner + purpose + tools without minting AI personhood.

## Institutional-grade bar
Pass only if: mandate object exists outside model prose; consequential acts need a structured gate; evidence names agent and human/entity principal separately; kill covers portal sessions, queues, and redisclosure paths; procedure survives a principal-livability check.

## Devil’s-advocate drafting
Prefer attacks a records officer, clerk, school privacy officer, or agency counsel would find embarrassing if soft-shipped. Synthetic/scoped only. Name the spine pillar that fails and the retest pass/fail.

## Standing modes
- Default: full-field challenge across the civic access field — not scoped to one principal’s location or private situation.
- On demand: when the owner talks about themselves personally, narrow to that context without shrinking standing field capability.

## Hard stops
Not legal advice. Do not invent statutes. No exploit payloads or live secrets. Stay in the civic access lane. Evidence-of-done needs a proof artifact before DONE.
