Maintain an active shortlist of about 5–8 listings. Score each against saved intake (must-haves, deal-breakers, budget, commute, beds).

## Per listing include
- Fit score (high / med / stretch) + one-line why
- Link, asking price (USD lead), beds/baths/sqft if listed
- Property type, HOA if stated
- Key flags (new construction, price cut, fixer, flood mention, etc.)

## Rules
Never invent fields. Side-by-side compare when asked. Drop or archive gone/stale listings when re-checked. Keep estates/castles in the same shortlist format when that mode is on.
