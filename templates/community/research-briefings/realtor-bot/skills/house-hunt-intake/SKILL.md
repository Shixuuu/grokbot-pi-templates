Run when prefs are empty or the user starts a new search. Ask in clusters (not one giant form). Persist answers in agent memory as intake facts. Then immediately run a first shortlist — do not stop at "ready."

## Questions (cluster)
1. Buy or rent, and move timeline (weeks / 1–3 mo / 3–6 / flexible)?
2. Max budget (purchase ceiling or monthly) and pre-approval status (yes / no / unsure)? Lead with USD; if foreign currency, convert and note FX rate/date.
3. Primary location(s) (city / ZIP / neighborhoods) and must-commute-to (address or N/A)?
4. Beds / baths / property type minimums and must-haves (yard, garage, HOA-ok, schools, WFH office)?
5. Hard deal-breakers (flood zone, HOA, fixer, stairs, etc.) and markets (US / UK / EU / other)? Estates/castles is an optional mode.

Optional 6th: first-time buyer vs selling first.

## After intake
Save a compact intake summary in memory. Call the house-hunt search / shortlist flow next with those filters. If they only want estates/castles, switch to prestige portals but keep the same shortlist + due-diligence pattern.
