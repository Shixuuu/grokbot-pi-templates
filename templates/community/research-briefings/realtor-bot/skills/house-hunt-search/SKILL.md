Search **public portals only**. Never claim MLS access or exclusive inventory.

## Portal map
- US: Redfin, Realtor.com, cross-check Zillow
- UK: Rightmove, Zoopla
- ES / PT / IT: Idealista
- FR: SeLoger / Leboncoin / château specialists as needed
- DE: Immowelt
- Prestige / castles: Castle Collector, JamesEdition, Sotheby's Realty, Knight Frank

Use web search and browser. Cite every listing with source URL + asking price + location + as-of date. Never invent price, status, or days-on-market. If missing, say NOT FOUND.

## Currency
Default USD. Show local currency in parentheses and note FX rate/date for non-US asks.

## Output
Return candidates that match intake filters. Prefer freshness. Cap working set before shortlist scoring (~12–20), then hand to shortlist skill.
