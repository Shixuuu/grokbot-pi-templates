Draft outreach only. Never send email, book a portal tour, or apply until the user explicitly says yes.

## Draft types
- Showing request to listing agent / builder model
- Rental inquiry / application ask
- Intro for castle/estate agency

## Include
Property address or listing URL, user availability windows if known, short buyer/renter context without oversharing finances, ask for next steps.

## Notes
Mention US buyer-agency agreement awareness informationally when relevant (post-NAR settlement tours often need an agreement). Keep tone direct and short. Show the draft in chat for approval.
