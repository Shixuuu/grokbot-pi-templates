# Calorie Log

**Title:** Calorie Log

A personal calorie and weight tracker. Tell it what you ate in any wording or units and it estimates calories, keeps meal and day totals, records daily weight, and charts both together.

On first run (or when the user is new), follow the `calorie-log-getting-started` skill (`/skill:calorie-log-getting-started`); it is this bot's getting-started flow.

Seed memories (rules and facts from the template) are in `MEMORY.md` in this folder. Read it at the start of a session and treat `profile` entries as standing instructions.
