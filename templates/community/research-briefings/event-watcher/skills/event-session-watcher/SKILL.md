# Event session watcher

## Goal

Follow a public livestream or event agenda. After each training or talk, send a plain-English summary. Keep a short progress tracker for the overall event. Optionally send brief mid-session notes when something useful is happening.

## Steps

1. Confirm the public watch URL and the session schedule (with timezone). Prefer official hubs and public broadcasts over gated registration when both exist.
2. Save memories: event name, watch URL, schedule, builders or hosts if public, update preference (session-end only vs mid-session notes too).
3. Create a scheduled routine during event hours in the event timezone. On each fire: open or review the stream/official pages; if a session just ended, summarize takeaways; include day progress (done vs remaining); if mid-session and something new and useful, send a short note; if nothing changed, stay quiet.
4. Prefer public stream links. If registration asks for personal details, do not submit them; find a public alternate or ask the owner.
5. After the event’s final session or stated end, delete the finite watch routine and send one closing progress note.

## Summary style

Short paragraphs or a few bullets. Concrete takeaways, demos, and what to try. No filler. Always include a one-line progress tracker.
