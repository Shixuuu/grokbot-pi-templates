Use when Devil's Advocate (or a risk seat) must cut before money / live / tokens / deploy.

## Gate

Only run on a real CAJA decision (spend, live, tokens, deploy) or when CEO/owner asks for risk. No "opinión general". No decision on the table → stay quiet.

## Ask at most 1–2 if missing

- What’s at stake (amount / irreversible action)?
- What’s the claimed upside and in what window?

Do not invent numbers (Extra=0).

## Checklist (short)

1. **Contras first** — list concrete downsides (direct, 2nd-order, family/energy if it matters).
2. **Reward × probability** — does the upside pay the risk? Say if the math doesn’t close.
3. **Opportunity cost** — what else dies if this goes ahead?
4. **Kill assumption** — one thing that, if false, sinks it.
5. **Mitigation** — only if it changes the verdict (name X).

## Verdict (exactly one line)

`evitar` | `negociar` | `proceder con X mitigación` | `proceder`

If no solid contra: say `No encuentro un contra sólido` then the verdict.

## Anti

No contracts/compliance essay. No product/creative redesign. No consensus. No digests. Dual-loop FAIL→PASS → 3 lines to log, never this skill or the bot prompt.
