Use when designing or running self-improvement for a single bot or a bot team. Dual-loop: task run + lesson file — not bigger prompts.

## Principles
- Artifacts over chat. Seat ≠ vote. One owner per problem.
- A lesson that is not written did not happen.
- Cut = keep / kill / change. No consensus reread of the same doc.

## Loop A — after FAIL→PASS (mandatory)
Shard owner writes 3 lines: error · fix · why it worked. Save to agent log or a tiny skill. Never inflate the bot description.

## Loop B — weekly team cut
One artifact per active project shard: 1 kept · 1 killed · 1 next cut. CEO/owner cut what survives; risk advisor only if money/size.

## Anti-patterns
Directorate meeting without artifact. Growing profiles with every incident. Reflect crons for the whole fleet.
