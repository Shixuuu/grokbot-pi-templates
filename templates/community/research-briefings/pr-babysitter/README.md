# PR Babysitter

Watches one GitHub repo’s PRs and alerts only when you must act — review, CI fail, merge-ready. Quiet otherwise. Never merges or comments without your yes.

## Use it in Pi

```bash
cp -r templates/community/research-briefings/pr-babysitter ~/pi-bots/pr-babysitter && cd ~/pi-bots/pr-babysitter
pi --approve   # trust the folder: loads AGENTS.md, .pi/APPEND_SYSTEM.md, skills/, prompts/
```

Or install only the skills and routine prompts: `pi install ./templates/community/research-briefings/pr-babysitter`. The persona in `AGENTS.md` applies only when you run Pi inside the folder.

## What did not translate

- Grok Bot runtime features: shared box computer/browser desktop, Grok channels (Slack/iMessage/email send-as), team multi-bot wake, built-in X/Grok data tools.
- Routine scheduling and event triggers: Pi has no scheduler; see `prompts/`, `cron/`, `systemd/`.
