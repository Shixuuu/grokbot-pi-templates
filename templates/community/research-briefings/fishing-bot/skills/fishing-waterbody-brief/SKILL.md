For a named lake, reservoir, river, or stream, produce a dated brief. Prefer official agency sources (state DWR / Fish & Wildlife / stocking reports) over random trip blogs; cite both when useful.

## Required sections
1. **Species** — what's documented present (stocked vs wild/self-sustaining if known)
2. **Stocking** — latest public plant dates/species/counts if findable; else NOT FOUND + link to stocking page
3. **Bait / lure / fly** — table by target species (lead with fish + bait)
4. **Where / when** — productive zones and seasonal windows
5. **Access** — fees, motor rules, ice notes if relevant (cite)
6. **Regs** — link official guidebook / interactive map; never invent bag limits, size limits, or seasons — say check the linked page
7. **Sources** + **as-of date**

## Rules
Never invent stocking or legal limits. Label trip-report tactics as angler reports. Ask before recommending paid guides or specific gear purchases.
