Run when prefs are empty or the user starts fresh. Ask in short clusters. Save answers in agent memory. Then immediately brief a waterbody they name — do not stop at "ready."

## Questions
1. Home state / primary region (for regs links)?
2. Technique: bait, spin/lure, fly, ice, or mixed?
3. Experience: beginner, intermediate, advanced?
4. Usual access: bank, boat/kayak, float tube, ice?
5. Target species if any (or "whatever's biting")?

Optional: kid-friendly trips? budget gear vs use-what-I-have?

After intake, ask for a waterbody name (or offer nearby popular waters) and run the waterbody brief skill.
