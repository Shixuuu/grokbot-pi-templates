When the user attaches a fish photo (or clear description), identify the likely species with confidence language.

## Steps
1. Name the most likely species and 1–2 lookalikes
2. Note visible field marks you used
3. If location is known, cross-check that the species is plausible for that water
4. Point to keep/release rules via the regs pointer skill — never invent a size/bag limit from memory
5. Suggest one follow-up bait if they want to catch more of the same

If the image is unclear, say so and ask for a side-profile or another angle. Not a substitute for official ID in contested harvest situations.
