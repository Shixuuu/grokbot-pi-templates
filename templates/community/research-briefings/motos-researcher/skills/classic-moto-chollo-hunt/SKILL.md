# Classic moto chollo hunt (Spain)

## When
Spanish classifieds hunt for restorable classic trial/road bikes under a hard euro cap.

## Sites (every run)
1. Wallapop — prefer SEO `/motos/<brand>/<city>`; keyword search often empty.
2. Milanuncios — `/motos-de-segunda-mano/<marca>.htm?hasta=1000&desde=250&orden=baratos&demanda=n`. If captcha, stop after one ask.
3. Facebook Marketplace — try guest first; dismiss login modal with the X. If forced to full login, skip that run unless the owner signed in on the agent computer. Search Montesa/Bultaco/Ossa/Puch/Derbi/Cota/Sherpa near the primary metro and secondary town, max ~1000 €.
4. miclasico.com
5. motos.net / motos.coches.net
6. el-parking-moto.es (and similar aggregators)
Optional: Todotrial / La Maneta / Clasf only for clear chollos.

## Target
Trial and classic-era Spanish bikes: Montesa, Bultaco, Ossa, Puch, Derbi Antorcha/FDS. Skip Vespa/Vespino unless asked.

## Filters
- Price: ideal a few hundred €; purchase cap default 1000 €.
- Area: primary metro first, secondary town second.
- Condition: restoration OK if complete and quality; prefer engines that do not need a rebuild.
- Prefer ≤125 cc (A1). Larger OK if all-in is a chollo.
- Prefer private sellers. Flag dealers.

## Papers
- Ciclomotor (~50 cc): papers cheap (~70–150 € all-in). Score complete stored mopeds even without docs.
- Motocicleta: add DGT + ITV histórica + STVH (~300–700 €+) to ask before calling chollo.
- Always state papers/ITV/baja.

## Method
1. Search live ads at or below the cap across reachable sites.
2. Capture title, year, cc, price, location, papers, condition, URL, platform, ad age.
3. All-in = ask + paperwork. Rank. Only keep real candidates; if nothing new vs last run, report nothing.
4. Never contact a seller without an explicit OK on that listing.
5. Deliver in the owner's language with links and listing photos.
