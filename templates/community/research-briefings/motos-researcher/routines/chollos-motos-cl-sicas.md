# Routine: Classic moto bargains

> Twice-weekly morning hunt for classic motorcycle bargains on Spanish classifieds.

Hunt real-deal classic motorcycles in Spain for the owner (primary metro, also a secondary town they named). Do this every Tuesday and Friday morning.

Deprioritize Vespa/Vespino if they already have one.

Target: trial and classic-era bikes. Montesa (Cota, Impala, Rapita), Bultaco (Sherpa, Mercurio, Frontera), Ossa, Puch (Cóndor, Minicross, Super, Cobra, Caribe), Derbi Antorcha/FDS/similar.

Budget: purchase cap 1.000 €, ideal a few hundred. Restoration projects IN SCOPE if complete and engine likely does not need opening. Skip chassis rust-through, missing engine, parts piles.

Papers:
- Ciclomotor (≤50 cc): papers matter little. All-in often ~70–150 €.
- Motocicleta: for paperless/de baja ADD DGT + ITV histórica + STVH (often ~300–700 €+) before calling chollo.

Location: primary metro first, secondary town second. Prefer ≤125 cc (A1); larger OK if all-in is a chollo.

SITES EVERY RUN:
1. Wallapop — SEO `/motos/<brand>/<city>`.
2. Milanuncios — `/motos-de-segunda-mano/<marca>.htm?hasta=1000&desde=250&orden=baratos&demanda=n`. Captcha → stop that site after one ask.
3. Facebook Marketplace — try guest first (dismiss login modal with X if present). If guest is forced to full login with no dismiss, skip Marketplace that run and note it once; ask the owner to sign in on the agent computer only if they want Marketplace coverage next time.
4. miclasico.com
5. motos.net / motos.coches.net
6. el-parking-moto.es
Optional: Todotrial / La Maneta / Clasf for clear chollos only.

Each run: search ≤1000 €; open promising ads; all-in = ask + paperwork; only surface new/changed chollos (stay quiet if nothing new); never contact sellers without explicit OK; tell the owner in their language with links and photos.

Deduplicate against recent finds already reported.

Fires on:
- cron `0 9 * * 2,5`

Ask the importing user for:
- Timezone
