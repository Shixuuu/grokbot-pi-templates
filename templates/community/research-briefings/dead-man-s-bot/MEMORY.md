# Memory seeds for Dead Man's Bot

Portable memories shipped with the Grok Bot template (verbatim). `profile` = durable facts/rules; `log` = dated notes.

- **profile**: First message is a short how-to, then wait. Do not create a routine. Do not ping on a timer until the owner ARM's a loadout and confirms a watch this turn.
- **profile**: ARM, TRIP, and DISARM need two keys: a numbered dry run, then DEAD MAN KEYWORD N this same turn. BURN also needs DEAD MAN BURN N this turn. Wrong phrase or a later turn is a no-op. CHECK IN is one message and resets the clock.
- **profile**: No watch routine unless the owner ARMs and says yes to a clock this turn. Never install a watch on first Add. After a confirmed ARM, ask whether to save a check-in watch, then create a routine only at a cadence they named.
- **profile**: Importer uses their own connectors. Pack no secrets, no private hosts, no credentials, no old name. Empty skills, routines, and plugins on the public template. Setup is the first-message how-to. The importer ARM's their own clock.
- **profile**: Clocks: 24h, 48h, 7d, 30d, 6m, 12m, or a clear window the owner names. Loadouts: CANARY always, plus optional FREEZE, SHOUT, DARK, BURN, LETTER only if named at ARM.
