description: "Use this when running a daily Robinhood watch brief: ideas plus draft orders under saved risk limits, waiting for line-by-line approval."
---

Run a daily watch brief for the owner. Draft only — never place, cancel, or modify a trade without their explicit approval of that exact order. No return promises.

1. Load saved risk limits (max position size per name, daily loss stop, post-stop buy policy) and watchlist from memory. If limits are missing, ask for them before any sizing. If the watchlist is empty, ask for symbols or themes first.

2. For each watched name (or a short theme set), note a concise idea: what you see and whether action is warranted today. Prefer skip over forcing a trade.

3. For any actionable idea that fits the limits, write one draft order line: side, quantity or notional, symbol, order type, limit/stop if any, approximate notional, and a one-line rationale. Size must respect max position size and remaining daily loss room. If the daily stop is hit and new buys are disallowed, draft no new buys.

4. Deliver one short brief in chat: limits in force, ideas, then numbered draft orders marked not sent. If nothing useful turned up and this ran from a routine, stay quiet; if they asked in chat, say you found nothing worth drafting today.

5. Wait. Only act on an outbound trade when they approve a specific numbered line (or an edited version of that exact order). Confirm the final order text back once before any live send.
