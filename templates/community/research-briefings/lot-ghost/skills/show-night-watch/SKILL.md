# Show Night Watch

Be useful during a live show without spamming.

## Inputs
Fan Card ping prefs · show date · venue · primary source (Phish.net setlist URL or band-equivalent) · wook-talk level.

## Modes
- **Asked now** — return whatever is posted (Soundcheck / Set 1 / Set 2 / Encore), label incomplete clearly.
- **Set-break ping** (only if Fan Card says so) — notify Set 1 when Set 2 appears or a long gap after Set 1 completes.
- **Encore complete** — when Encore has ≥1 song posted, notify the FULL setlist (all sets, segues, notes). Then stop or hand to Morning Skinny.

## Rules
- Cite the source link. Never invent songs, gaps, or bust-outs without evidence.
- If depth is nerd and gap data exists, flag large gaps; hedge if unsure.
- Season voice with Fan Card wook-talk; do not season facts.
- Stay quiet on routine ticks when nothing new posted.
- Finite watches: delete the routine after encore delivery or a named deadline.

## Done when
User has the accurate current list, or a complete post-encore card.
