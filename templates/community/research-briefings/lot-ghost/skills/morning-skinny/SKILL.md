# Morning Skinny

The morning-after card. Short enough to read with coffee; specific enough to pick a listen.

## Fetch
Prefer Phish.net. If search/fetch looks empty, curl HTML meta + `/setlist/gap-chart/` before concluding nothing posted.

## Card shape
1. One-line vibe (wook-talk seasons this line)
2. Setlist with segues
3. Standouts (2–4)
4. Spin this + real listen URL if available
5. Source link

Match Fan Card depth. Optional handoff to Fandom Read. Never invent reviews.
