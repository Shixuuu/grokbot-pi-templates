# Memory seeds for Tesla Bot

Portable memories shipped with the Grok Bot template (verbatim). `profile` = durable facts/rules; `log` = dated notes.

- **profile** (2026-09-29): HARD RULE: Never wake any monitored vehicle under any circumstances without the owner's explicit permission stated in that moment. Overrides any prior instruction to poll or fetch data that would require a wake. If asleep, leave asleep — skip SOC and other awake-only fields; record asleep only. Read battery percent and awake-only fields only when the car is already online on its own.
- **profile** (2026-09-29): Home Fleet Monitor sheet logging: write a Poll log row immediately in the same poll that detects the change (not deferred) when connectivity state changes (online/asleep/offline transitions, including external wakes) or when battery level, total mileage, charging status, driving status, location/geofence, sentry mode, open doors/frunk/trunk, tire pressure, software update status, cabin temperature, or climate settings change. Unchanged no-wake polls with no connectivity change must not be logged
- **profile** (2026-09-29): Home Fleet Monitor Poll log columns when online: Battery Level, Total Mileage, Charging Status, Driving Status, Location/Geofence (unavailable without vehicle_location OAuth scope), Sentry Mode, Open Doors/Frunk/Trunk, Tire Pressure (psi), Software Update Status, Cabin Temperature, Climate Settings, plus identity/metadata columns. Asleep/offline: only connectivity/metadata; awake-only columns blank. Never wake for missing fields.
- **profile** (2026-09-29): Home Fleet Monitor Poll log has Remaining Range column immediately after Battery Level on each vehicle sheet; value is charge_state.battery_range in miles; write it whenever battery/charge data is logged.
- **profile** (2026-09-29): Home Fleet Monitor Poll log has Miles per 1% column immediately after Remaining Range on each vehicle sheet: remaining range miles ÷ battery percent; blank if either missing; sheet ARRAYFORMULA plus monitor field for future rows.
- **profile** (2026-09-29): Home Fleet Monitor Poll log has Total Expected Range column immediately after Miles per 1% on each vehicle sheet: Miles per 1% × 100 (expected range at 100% battery); blank if Miles per 1% missing; sheet ARRAYFORMULA plus monitor field for future rows.
- **profile** (2026-09-29): Home Fleet Monitor EPA baselines: store each vehicle's original EPA range (miles) when new; Battery Degradation % = (EPA − Total Expected Range) ÷ EPA × 100.
- **profile** (2026-09-29): Home Fleet Monitor Poll log has separate columns for each logging trigger: Battery Level, Total Mileage, Charging Status, Driving Status, Location/Geofence, Sentry Mode, Open Doors/Frunk/Trunk, Tire Pressure, Software Update Status, Cabin Temperature, Climate Settings. No combined Event Details column.
- **profile** (2026-09-29): Home Fleet Monitor SOC: no-wake polls call vehicle_data for battery_level only when a vehicle is already online (never wake_up for SOC). Asleep/offline leave Battery Level blank. SOC is stored in poll snapshots and last-known state; Poll log Battery Level is written when SOC changes or first becomes available.
- **profile** (2026-09-29): Home Fleet Monitor temperatures: always convert and log cabin/outside/climate temps in Fahrenheit (°F), never Celsius. Applies to every vehicle Poll log and all future polls.
- **profile** (2026-09-29): Tesla Poll log timestamps use a local timezone column that is DST-aware: 12-hour AM/PM plus the real PDT/PST (or other) label from the offset. Never force a fixed UTC offset or label everything as one abbreviation year-round.
- **profile** (2026-09-29): Home Fleet Monitor formatting is global: any formatting change the user requests for one vehicle Google Sheet must be applied identically to every vehicle sheet unless the user explicitly names only one sheet.
- **profile** (2026-09-29): Tesla vehicle logs are split: each VIN writes only to its own spreadsheet Poll log. Log every interaction with notes including wake_called; Battery Level and Total Mileage only when those values are actually available without waking.
- **log** (2026-09-29): This bot uses the Tesla Fleet API (vehicle_device_data scopes) plus Google Sheets and Google Drive for Poll log spreadsheets. There is no marketplace Tesla connector; credentials are stored securely on the bot computer and never pasted into chat.
