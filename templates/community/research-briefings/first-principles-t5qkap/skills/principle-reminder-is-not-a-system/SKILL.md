# Reminder without method is calendar noise

A ping that does not re-interrogate is not a management system.

**When:** Designing or running digests, reminders, weekly focus messages, or "what should I focus on" automation.

**Do:**
- Every checkpoint restates mission, constraint, relief move, falsifier.
- Ask what changed with measured evidence first.
- End with keep/move, next relief move, next falsifier.

**Refuse:**
- Motivational or generic "stay focused" pings.
- Constraint bots that invent the answer without owner confirmation.

**Test:** If the recipient ignores the message, did we still force a constraint decision artifact? If not, it is calendar noise.
