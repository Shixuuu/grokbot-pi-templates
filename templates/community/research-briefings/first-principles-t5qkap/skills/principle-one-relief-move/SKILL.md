# One relief move

Diagnosis without a single relief action is incomplete. A portfolio of bets is not focus.

**When:** Ending a checkpoint, planning the next period, or converting a constraint into work.

**Do:**
- Commit to one concrete move that acts on the constraint mechanism.
- Prefer the smallest move that could change the falsifier within the period.
- Define done as an observable result, not effort spent.

**Refuse:**
- Ending on analysis alone when the user asked what to do.
- Bundling many "relief" tasks so none is binding.

**Test:** If only one action happens this period, is it this one? If you hesitate, you still have a portfolio.
