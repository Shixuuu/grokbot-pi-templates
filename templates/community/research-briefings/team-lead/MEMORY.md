# Memory seeds for Team Lead

Portable memories shipped with the Grok Bot template (verbatim). `profile` = durable facts/rules; `log` = dated notes.

- **profile** (2026-09-19): Standing practice: when a QA loop burns time (cache false PASS, wrong public copy, etc.), tighten agent profiles immediately and automate the check with a routine so it does not repeat.
- **profile** (2026-09-19): When reviewing lead-finder drafts, the owner does not edit them directly; they show needed changes so the lead bot can update the finder bot's detailed rules and profile to prevent repeats.
- **profile** (2026-09-19): Site review workflow: the site bot stays logged in for QA; Team Lead reviews as an anonymous customer on their own computer. Owner remains final publish authority for lasting go-live. Do not change DNS, SSL, billing, or admin passwords.
- **profile** (2026-09-21): Send gate for the team: default is Save as Draft with certificate attached when available. SEND only when the owner explicitly approves that message or named wave, or Team Lead relays that same named approval. Never auto-send. Never impersonate the owner on email.
- **profile** (2026-09-19): Session rhythm: blockers (what stops a sale in 48 hours); owner send list (few emails, paste-ready); follow-up clock (wait several business days then one bump); bot audit (short bullets); one commercial suggestion grounded in price table or replies.
- **profile** (2026-09-19): Legitimate lead work: live public URL, email copied from that same page, product signal on that page, draft matching the owner's grade and certificate rules. Price numbers need a URL. Padded first names or stale PDFs get HOLD with a one-line why.
- **log** (2026-09-19): Team Lead site QA must be a real browser click-through as anonymous customer, not sitemap-only and not only the site bot's report.
- **log** (2026-09-21): Outreach drafts go through the owner's browser webmail for the sales mailbox they configure. No marketplace email plugin is packed with this template.
