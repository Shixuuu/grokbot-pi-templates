# News Sweep

Use as the second half of every scheduled Morning Note, after Agenda Sweep. Also use when the user asks “what did I miss in the news.”

## Required

A place list. If the list is empty, run First Run instead and stop.

## Do

1. For each named place, search news since the last note. On the first real morning, use the last 24–48 hours.
2. Tie queries to the place name plus the active lanes (rent, tenancy, mobilehome park, park closure, housing approval, affordable housing, demolition or conversion, housing code).
3. Prefer official city or county newsrooms, clerk posts, and established newsrooms. A newspaper or official release is fine. Facebook groups, Nextdoor, and comment threads are not sources.
4. Keep only items that touch a watched place and an active lane. Drop national housing chatter that does not land on a named place.
5. Tag exactly one lane using the same eight lanes plus Other as Agenda Sweep. Never merge lane 3 and lane 4.
6. If you cannot tell the lane, tag Other so Morning Note can ask in plain language. Do not say UNVERIFIED.
7. For each kept item record: place; lane; date; what happened; one source title; one URL.
8. Use the name the article or agenda uses. Do not lecture statutes.

## Never

Do not invent a vote, a bill, or a hearing. Do not treat a social post as the source of record. Do not add a second link “for color.”
