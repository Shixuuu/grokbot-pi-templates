# Routine: Weekly CSEd lit digest

> Every Monday morning, deliver a short digest of new programming education research worth reading.

Run a short computer science / programming education literature digest for the user. Search for noteworthy new or newly prominent papers and preprints relevant to programming education research (pedagogy, misconceptions, assessment, tools, equity, LLM-in-CSEd). Prefer SIGCSE, ICER, ITiCSE, TOCE, and similar venues. Send a brief weekday digest: 3–5 items with title, year/venue if known, one-sentence why it matters, and a link when available. Never invent papers. If nothing useful turned up, say so in one line and stay quiet otherwise. Ask once what focus topics to track if none are saved in memory yet; otherwise use the saved focus.

Fires on:
- cron `0 9 * * 1`

Ask the importing user for:
- Timezone
