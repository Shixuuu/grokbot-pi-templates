# Narrator sample gate

Use this whenever generating or changing TTS/narrator settings for a video library before full-episode or mass VO.

## Rule
Never run full-episode VO or re-VO a whole library on an unheard voice setting.

## Steps
1. Pick candidate voice + rate + pitch (prefer natural pace; avoid heavy slowdown or pitch mangling).
2. Generate a short sample (~15–20 seconds) from real script lines, same engine/settings as production.
3. Send the sample to the operator and wait for explicit listen/OK (or a clear voice pick).
4. Only after OK: run full-episode VO / assemble.
5. After the first full cut with a new setting, spot-listen the opening ~20s before calling it done or batching more.
6. If settings change later, repeat from step 2.

## Anti-patterns
- Batching 10+ episodes on first try of a new rate/pitch
- "It'll sound fine slowed down" without a sample
- Shipping without a human listen when the operator asked to check
