# Memory seeds for Faceless Explainer Studio

Portable memories shipped with the Grok Bot template (verbatim). `profile` = durable facts/rules; `log` = dated notes.

- **profile**: Scripts and narration should not ask viewers to like or subscribe; end on the story. YouTube's native end screen (next video + corner subscribe) can stay as platform UI.
- **profile**: Do not silently swap production (stills tool, voice, look). If a tool is down, tell the owner and stop instead of substituting a different pipeline; never draw stills in code.
- **profile**: Run the channel without babysitting: make safe growth and production changes from Studio data (thumbnails, Shorts, end screens, upload cadence) without asking first; only escalate narrator voice, visual style, or topic lane after a real multi-episode pattern, or when a blocker needs the owner.
- **log**: Keep the episode template consistent: same stills format and length, kill the common myth quickly, one named person, a story not a tip.
- **log**: Launch growth is packaging (thumbnail and title) plus a tight first-five library in the same format so YouTube can pattern-match, not extra agents.
- **log**: Shorts are bait, not the product: 1–2 clips sliced from each long video, same narrator voice, 20–35 seconds, pointing at the full video; do not run a Shorts mill.
- **log**: Post video 2 about 3 days after episode 1, then about two videos a week while the first few are in the can; do not dump several uploads the same night.
- **log**: Progress is judged by retention (average % viewed and graph shape, returning viewers, CTR, subs from video) over raw views until about 10–15 public videos; tweak hooks and thumbnails first if CTR or 30-second retention is weak; change style only if retention is fine but nobody returns.
- **log**: Episode-1 success is retention, not views: a few dozen to a couple hundred views in the first days is normal, and seven day-one views is not a verdict.
- **log**: Upload a faceless channel to a new YouTube channel, not mixed with an existing personal, vlog, or monetized channel, unless the existing one is empty or already this exact niche.
- **log**: Set YouTube's altered/synthetic-content disclosure explicitly and truthfully at upload; leaving it blank at scheduling caused YouTube to apply its own AI label.
- **log**: Vertical Shorts must be encoded with setsar=1; a bad sample aspect ratio left one Short Public in Studio while its watch page was unavailable.
- **log**: When several channels share one Google login, enter Studio through the target channel's content list and confirm the channel name before every edit; opening a video edit link directly can land on a different channel.
- **log**: YouTube channel banner must be 2560x1440 and under 6MB with important art inside the 1546×423 all-devices safe box; avatar is 800x800. X banner is 1500×500, not a 16:9 crop.
- **log**: Do not put a proxy, anti-detect browser, or fake fingerprint in front of the verified channel login; channel-farm playbooks are not for this channel.
- **log**: Services this workflow uses without a packaged connector: a text-to-speech service such as ElevenLabs (API key added by the owner as a secret), an image generation tool for stills, ffmpeg for assembly, and YouTube Studio plus the owner's optional social account through the browser, signed in by the owner.
