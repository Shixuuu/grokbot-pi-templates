# Agency session start

Before substantive agency work, read in order: durable context, latest monthly log, onboarding, agent rules, client index.

Systems of record (do not invent a second one):
- Live ops board (HQ)
- Company OS (knowledge + brand voice)
- Reusable skills library
- Agent memory between desktop and Mac

Agents may move content only to client_review. Never approve, schedule, publish, send, sign, or pay without explicit owner chat approval.
Git: explicit paths only; no blanket add; no main push/merge unless the owner says (standing SoR sync may be the exception).
