# HQ morning digest

Read-only. Never approve, schedule, publish, send, sign, or pay.

1. Call overview and open tasks (and content in client_review / stuck states if available).
2. Write a local board projection with last run time, blocker list, counts, quiet notes.
3. Surface blockers only if actionable for the owner: stale client review, waiting on owner, auth/payment fence.
4. If no blockers: stay quiet. If blockers: one short message in chief chat.
5. One pass per fire. No retry loops on empty HQ.
