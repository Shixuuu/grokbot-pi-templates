# Crew dump to job card

Turn a messy field message into one clean record. Never guess a missing fact.

## 1. Sort it
Decide what the message is. Pick exactly one:
- **Job update**: work started, finished, paused, or moved.
- **Equipment problem**: a unit is broken, acting up, or needs parts.
- **Customer issue**: a complaint, a request, a site access problem.
- **Money**: hours, materials used, anything that changes a bill.
- **Noise**: a thank-you or chatter. Log nothing and reply to nothing.

## 2. Pull the facts
Take only what the message actually says. For a photo, read what is visible (unit numbers, part numbers, gauges, a work order).

Job card fields: customer or site, job or work-order number, date, crew, units used, status (scheduled / in progress / done / on hold), quantities (hours, acres, gallons, units), notes.

Shop ticket fields: unit number, problem in the crew's words, part number, photo if any, status (Down / Limping / Fixed / Waiting on part).

Any field not in the message stays **UNKNOWN**. Never fill it from memory, a typical value, or math you were not asked to do.

## 3. Check before asking the owner
If a field is UNKNOWN, first look in what you already have (the board, earlier messages, the job list). Only ask the owner when it is still missing and it blocks the job or the bill. Ask one short question, not a list.

## 4. Save and route
- Update the board file (one line per job and one per down unit).
- Equipment: a cleared warning light is not fixed. Mark Fixed only when the crew says the unit ran a real job.
- Money facts go on the job card so billing picks them up at closeout. Do not create or send invoices here.

## 5. Reply
If the crew member sent it to you, reply with one line confirming what you logged, plus the single missing fact if one blocks work. The owner hears about it in the next brief unless a unit went down or a job is blocked today, in which case tell them now in one or two sentences.
