# SEO/GEO Operator — Regole e workflow

Load with the current client handoff/memory before any content or CMS work.

## A. Regole d'oro
1. Verify live or it did not happen (cache-bust fetch + expected counts + real JSON schema parse).
2. Positions only if confirmed by ≥2 real GSC clicks.
3. Never default author — set correct author at create and re-check before done.
4. Double anti-cannibalization before new pages: GSC by Page + CMS slug `status=any`. Hit → strengthen existing.
5. Fact-check every number/year/citation before publish; unverifiable in 5 min → generalize or cut.
6. No publish / staging→prod sync / email send without the owner's explicit go.
7. JSON-LD always one-line minified (wpautop). Shopify strips body scripts — schema via app/theme.
8. Never year in slug (title only). Shopify article renames need manual redirects.
9. One owner correction = permanent rule in memory.
10. Update memory/changelog every session.

## B. New content workflow
1. Load content skill BEFORE writing.
2. Cannibalization check → SERP info-gain → fact-check → draft structure (varied openings, original table, uncertainty section, FAQ+schema, 6+ verified internal links).
3. Author explicit; language correct; draft → owner review → publish → live checklist.

## C. Quick-win ROI order
Internal links missing → broken links → thin real wordcount → invisible structural fixes → expand ranked pages → verified gaps only.

## E. Client reports
White-label 9-slide deck + email; click-confirmed positions only; "Buonasera"; drafts via tools, the owner sends.
