# SEO/GEO Content (universal)

Load before writing or expanding any client page. The weekly WP protocol is NOT in this skill — only the transferable rules.

## Philosophy
Twin goal: Google rank + LLM citability (AIO, ChatGPT, Perplexity). Citability, extractability, authority, freshness, consensus alignment. Never fabricate stats. Unverifiable in 5 min → qualitative language or cut.

## Anti-template (post-HCU, overrides any fixed layout)
Required coverage (answer-first, extractable, FAQ, sources) — presentation MUST vary on the same site.
- Vary the opening (QA box is one option, not the law). Direct answer in the first chunk, container can change.
- ≥2 information-gain points absent from top-3 competitors. Citations alone ≠ originality.
- Product/CTA after context, with when-NOT-to-use. Own-product: italic disclosure.
- Skip the same visual every time. Break ≥2 old-template elements per new piece; tell the owner what you broke.
- YMYL: add an honest-uncertainty section.

## Red lines
- No fake authors, credentials, years of experience, or invented experts.
- Certs/seals/awards attach to the EXACT product that earned them (never "the line").
- Own products: transparent, never fake-neutral discovery, never trash an ingredient the client sells.
- Proprietary original is the tiebreaker AFTER matching live AI-answer consensus (entities, structure, format).

## Before ANY new URL
1. Target keyword, intent, audience, existing content, commercial relationship.
2. Cannibalization twice: `site:domain keyword` + CMS status=any + GSC by page (a dest page may already rank for "cost").
3. Two pages on the same topic ≠ auto-merge if each variant has its own volume — differentiate and cross-link.
4. Collect 8+ real internal URLs and 2-3 authoritative externals (not competitors) before writing. 6-10 real internal links in the piece. Zero placeholders.

## Refresh > new (default this month)
Half of SEO/GEO is improving what already ranks.
- Read the actual content, never trust the slug.
- Ask before editing sponsored posts.
- Replacement beats append; density beats length.
- If you find one template bug, scan the whole category (CMS search is unreliable — fetch raw and regex).
- After edit: verify via API `content.raw`, author byline survived, forbidden-terms regex. Live cache can lie.

## Draft / publish
Client work = draft for the owner. No publish, staging→prod sync, or client email without explicit go. Verify live or it did not happen.

## GEO coverage (form varies)
Author + dates; answer-first first chunk; FAQ 5-10; comparison table if evaluation; steps if how-to; Fonti when citing science; schema matching the CMS plugin (Rank Math FAQ blocks only if Rank Math is actually installed).
