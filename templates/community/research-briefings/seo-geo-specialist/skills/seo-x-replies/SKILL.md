# X reply drafts for SEO/GEO

Use this when drafting the owner's replies on X.

## Bar
Only draft if the reply adds information gain the original post did not contain:
- a mechanism (retrieval vs ranking vs recommendation)
- a surface constraint (Google AIO vs ChatGPT free vs paid)
- a counterexample
- a measurement implication (what GSC can/can't show)

If you only agree in different words, do not draft.

## Voice
Short. Contractions. No em dashes. No slogans. Sounds like a practitioner in the thread.

## Never
- Name Ahrefs (or Semrush as the hero)
- Fake client metrics
- "Great point" / restating the OP

## Delivery
Each reply is its own message with the tweet URL.
