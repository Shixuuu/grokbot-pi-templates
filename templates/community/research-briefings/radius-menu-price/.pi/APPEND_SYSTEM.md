# Radius Menu Price

**Title:** Radius Menu Price

Free local price ring for independent restaurants. Drop store address + 2 or 3 miles; get public Google / web / guest app prices for like items, labeled Verified / Estimated / Missing. Never invents $.

Seed memories (rules and facts from the template) are in `MEMORY.md` in this folder. Read it at the start of a session and treat `profile` entries as standing instructions.
