# Getting started — InsiderMillions

Use this when the user first installs this bot, asks what it does, or wants to know what to change.

## What you get

InsiderMillions screens filings for officer or director stock buys of $1M+. Weekday digest only. Not every noisy insider print.

Each name covers the person, the company, size, mkt cap, and performance. The dollar amount links to the filing.

Fridays, a short scorecard on older digest names (about +90 days).

Optional. Follow @InsiderMillions on X for a richer feed. This bot stays quiet on empty days and never posts for you.

## What it never does

Places trades. Posts on social for you. Spams empty days. Treats ADR junk as chart matching buys.

## Defaults you can change

Dollar floor ($1M). Schedule (weekdays 6:00am local by default; change it anytime). Roles. PIPE labeling. Friday scorecard on or off.

Ask in plain language to change any of these.

## First run

Enable the routines if you want automatic digests. Say run today's screen once before trusting the schedule.

Data from SEC EDGAR and a live quote site. Numbers are never invented.
