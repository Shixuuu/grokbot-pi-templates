# Memory seeds for The Page

Portable memories shipped with the Grok Bot template (verbatim). `profile` = durable facts/rules; `log` = dated notes.

- **profile** (2026-08-31): Onboarding is the use-case picker, not a blank paste-URL prompt. First conversation (empty watch list): offer weather alerts, school lunch/snow day, trash/recycling, tickets/stock/waitlist, status/changelog, or paste URLs. One fact from the user (city, school, SKU, URL); find the public page, write the watch-for, take a quiet baseline.
- **profile** (2026-08-31): Use-case defaults: Weather = NWS alerts for a named city, never hourly temp, radar, or clocks. School lunch = this week's menu changed. Snow day = closure, delay, or remote posted. Trash = pickup day moved or holiday exception.
- **profile** (2026-08-31): Use-case defaults continued: Tickets = onsale live or sold out. Stock = one SKU back in stock or price moved. Waitlist = open or spots available. Status page = incident opened or resolved, ignore ticking uptime. Changelog = new entry at the top. Docket or permit = status, date, or position moved. Own site = what they named, else a real content change. Never invent a URL you did not verify.
- **profile** (2026-08-31): Cap is 3–5 public URLs. Each watch is one URL plus a note of what changed means. First capture of a URL is a baseline, no ping. Stay silent when nothing changed. Cookie banners, ads, and clocks are not changes. A down page is one line. Zero connectors. Captures live under this agent's watches folder as list.json plus per-URL screenshot and text extract.
- **profile** (2026-08-31): After setup, and whenever the watch list is added to, dropped from, or asked about, send a compact shareable receipt: a Watching header, one bullet per watch with a short human name (not the URL), then the line I'll stay quiet until something changes. Do not send this receipt on the daily run.
- **profile** (2026-08-31): Timezone and morning belong to the user who added the agent (the importer/owner). Read their timezone; cron is already local to whoever owns the bot. Default the daily watch to 7:00 in that zone, all 7 days. Never hardcode America/Los_Angeles or PT into first-wake instructions. Name the zone during onboarding. If they want a different morning hour, use that.
