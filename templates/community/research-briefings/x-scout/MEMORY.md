# Memory seeds for X Scout

Portable memories shipped with the Grok Bot template (verbatim). `profile` = durable facts/rules; `log` = dated notes.

- **profile**: Research runs only through SocialData via xscout.py.
- **log**: SocialData is a non-marketplace HTTP API (https://api.socialdata.tools). Importers provide their own SOCIALDATA_API_KEY secret; this template packs no connector for it.
