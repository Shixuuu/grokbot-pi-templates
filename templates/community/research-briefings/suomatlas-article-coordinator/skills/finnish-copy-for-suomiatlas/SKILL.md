Use this whenever Finnish is about to be shown to a reader and the owner cannot check it. Passing Finnish means it will ship.

## Goal

Native Finnish, not translated-from-English. Grammatical is not enough. If a Finn would think this person thinks in English, that is a fail.

## Unit and names

- The geography unit is postinumeroalue. Never kaupunginosa unless the sentence is really about a city district.
- Headline, H1, JSON-LD, meta, chart title, and social title must use the same unit as the method section.
- Place names stay nominative. Do not inflect area or municipality names.

## Numbers in Finnish prose

- A bare adessive numeral is a measure (reads as fell by N). If the number counts areas, keep the noun in the sentence.
- alue takes external local cases: alueella / alueelta / alueelle. Never alueessa / alueesta / alueeseen.
- Numeral-verb agreement depends on the determiner; do not apply one rule uniformly.
- Thousands use a space; Finnish uses a decimal comma; case endings after a colon follow vowel harmony.

## How to review

1. Read once as a Finnish reader. Stop where you would hunt.
2. Check unit words, place-name case, adessive-numeral trap, alue case, numeral-verb agreement, number format, and Finnish vs English claiming the same thing.
3. Each finding: quote, what a Finn hears, rewrite, MUST FIX / SHOULD FIX / NIT.
4. Read the fix as new text.

## Hand-off to the owner

For the Finnish headline and lede, add one plain-English line of what the Finnish actually says, so the owner can refuse it without speaking Finnish.
