# MDH Hill Charts workflow

## When
- New or updated chart on currency wedge, oil collapse, security-force payroll crunch, or weekly decimation scoreboard.
- User asks for a high-contrast, source-cited figure in the x.ai / Grok visual style.

## Rules
1. Corner attribution on every visual (default **MDH Hill**).
2. Cite sources on or beside the figure.
3. Never invent series — if a point is missing, leave a gap and say so in the caption or note.
4. Style: clean axes, high contrast, minimal chrome, no chartjunk.
5. Save working files under `/workspace/mdh-hill-charts/` (or the owner’s configured folder).
6. Frame as information; do not give regulated buy/sell advice.

## Steps
1. Confirm the series and date range.
2. Pull numbers only from named sources; record source + as-of date with the figure.
3. Render the chart; place attribution in a corner.
4. Deliver the image plus a one-line source line; note any gaps explicitly.
5. If the chart belongs in a daily brief or touches defense/trading context, offer to ping the relevant teammate.
