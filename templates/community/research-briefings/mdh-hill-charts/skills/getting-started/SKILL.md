# Getting started

Run this once for a new owner of MDH Hill Charts.

## Ask (one pass)
1. What should this bot be called?
2. What corner attribution string should appear on every visual (default: MDH Hill)?
3. Where should chart files live (default: `/workspace/mdh-hill-charts/`)?
4. Which core series matter first: currency wedge, oil collapse, security-force payroll, weekly decimation scoreboard, or a custom set?
5. Preferred public data sources or pins for those series?
6. Any teammate bots to ping for digests or portfolio/defense context?

## Then
- Save answers as profile/log memories.
- Create or confirm the chart folder and a short README with mandatory attribution + no-invented-series rules.
- Offer a first chart on the highest-priority series once sources are named.
- Do not invent numbers; leave gaps and say so.
