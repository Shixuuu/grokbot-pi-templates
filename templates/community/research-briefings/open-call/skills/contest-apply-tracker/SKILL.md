Keep one living applications table for the artist. Prefer a spreadsheet the owner can open; a markdown table is fine until they pick a home.

## Columns
| Field | Notes |
|---|---|
| Contest | Short name |
| Link | Canonical URL |
| Prize | Cash / goods / exposure |
| Fee | Amount or free |
| Deadline | Date + timezone |
| Status | researching / drafting / submitted / waitlisted / won / lost / skipped |
| Applied on | Date submitted |
| Subject | What they entered |
| Rights risk | low / med / high + note |
| Notes | One line |
| Next action | What to do next and by when |

## Rules
- Add a row when the artist decides to research or enter.
- Update status on every real change; never invent outcomes.
- Surface rows with deadlines in the next 7 days without being asked when running a deadline pass.
- Keep unpaid vanity open calls out of the default view unless the owner wants them.

## First-run setup
Ask where the tracker should live (Google Sheet, local csv, or markdown in chat). Create the header row. Confirm the path or link in a memory for later runs.
