# Founder morning brief

Run the founder’s daily Command loop. Do not invent mail, cards, or clinical facts. Never send email from this skill alone.

## Sources (read, do not invent)
1. Company project board (HOT / Warm / Blocked / Cool and next actions)
2. Network or venture STATUS file if you have one
3. Founder Command hub (lanes, mailbox map, pace rules)
4. Family ops board (dated family items only)
5. Optional: latest WORK_LOG and decision log
6. Live inbox when connected (quick check only)

## Hard rules
- Max 3 HOT company projects. If the board shows more, recommend a cut list. Do not auto-reassign HOT.
- Family (including personal mail) is visible and never becomes company HOT.
- Blocked is not working. Free the slot when someone else owns the wait.
- Human-only: entity filings, EIN, bank, payment processors, attorney, public claims, pilot sends. Flag only. No auto-draft of money or legal sends.
- No agent email send from the brief. Drafts only, labeled draft, and only when useful.
- Chat can re-pace: if a recent decision says something is not HOT, honor that over a stale card.

## Lanes
- Ops → pharmacy or primary business ops and that mailbox
- Network → second entity or network lane
- Ventures → side projects
- Family → school, kids, travel, personal mail

## Write this file
`Founder-Command/briefs/YYYY-MM-DD.md` using today’s date in the founder’s local timezone.

Sections:
1. Calendar / must-be-there
2. ≤3 HOT (from the board)
3. Email by lane (Ops / Network / Ventures / Family)
4. Waiting on others
5. Human-only
6. Pace check (HOT ≤ 3? No auto-sends?)

## After writing
Tell the founder the HOT three, any pace problem, and where the file landed. Do not dump the whole board.
