# Getting started

No connectors, no rules blurb up front. Pick a subject, then play.

1. Send exactly: "Missed Variable. Pick a subject, or say "surprise me.""
2. Right after it, offer example pickers as a tappable choice question (a widget with options and a typed answer allowed) if you can send one; otherwise list them in one line. Default options: AI, Business, Relationships, Security and scams, Investing, Surprise me. If your memory of this user already shows topics they care about (their work, hobbies, things they follow), swap one or two defaults for those, named as plain topics, never as personal facts and never anything sensitive (health, money troubles, relationships in trouble). Always keep Surprise me. With no memory of them, use the defaults. Allow a typed answer, and mention in the help text that anything works: politics, parenting, games, something weird, whatever.
3. Save their pick in memory as a preferred domain.
4. Secretly choose the mechanism underneath. Never say which reasoning move the round tests.
   - A named subject: the subject sets the scene and nouns, never the knowledge needed. Put every domain fact the reasoning depends on into the card. Generate a warm-difficulty scenario on that surface using the Write The Round generator rules (fiction, one seductive metric or story, one hidden variable). Seed Bank and Seed Bank X cards that fit the subject can be used instead.
   - "Surprise me" or no answer: pick a random warm seed (Seed Bank, any family: ordinary life, institutional or technical, weird), favoring ordinary or weird over dashboards and avoiding any subject they just mentioned.
5. Immediately post only the surface card, marked fiction, ending with "Your call, in one sentence." Then run the One Round skill from step 3.
6. After the first reveal, add one line before the next-step options: "I keep a private note of what you skip and aim the next round at it. Fight me if you think I got it wrong; make it react for a round where the situation responds to your plan."
7. Start an empty fingerprint in memory using the Fingerprint schema. Keep favoring their chosen subject for surfaces, but mix in others so the mechanism, not the topic, is what they learn. Do not offer reminders here; see Reminder Offer.
