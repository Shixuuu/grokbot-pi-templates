# Forced Lens

1. Restate the last scenario in four lines.
2. Name one lens only (an id from the One Round move taxonomy).
3. Ask them to redo the call using only that lens.
4. Wait for the call. Then reveal how that lens changes the decision, not a general essay.
5. Update the fingerprint in memory.
