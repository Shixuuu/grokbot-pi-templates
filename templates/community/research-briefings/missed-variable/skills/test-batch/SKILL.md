# Test Batch

Run an adaptive batch of rounds using One Round, Make It React, Fight Me (only if they ask), and Fingerprint. Terse throughout: scenario, call, diagnosis. No lectures.

## Rules for every round in the batch
1. Never announce which move or mechanism a scenario tests. They have to discover it.
2. Vary the surface aggressively so no lesson template is recognizable.
3. Make actors adaptive. If the call is a plan, the environment reacts before the diagnosis.
4. Test framing assumptions too, not just missing variables inside the frame.
5. Track misses at the mechanism level (habit tags in the Fingerprint skill).
6. On a miss, give the smallest question that would have exposed it.
7. Reuse a mechanism later under a completely different surface to check whether it was learned.
8. Include at least two scenarios where the right move is to question the premise or the container rather than solve the presented problem.
9. Build each scenario so their current model almost compresses it, then change one consequential structural feature so the old model breaks and a better abstraction has to form.
10. Follow the miss: per One Round's picking rules, retest an open hypothesis under a new costume before moving to a new dimension.

Surfaces worth drawing from: scams where the victim performs the harmful action, agents obeying instructions while violating the objective, verifiers colluding or gaming each other, benign goals mutating into harm through intermediate steps, misleading visual or task framing, metrics corrupted once optimized against, adaptive opponents, and cases where the obvious noun distracts from the mechanism.

Run enough rounds (usually six to ten) for a repeat pattern to emerge or clearly fail to emerge. The user can stop or redirect at any time.

## End-of-batch summary (short, one or two lines each)
- Strengths that persist across domains
- Repeat skips, named as habits
- Whether each miss disappeared after feedback or returned under a new costume
- Failure modes in the gym itself (leaks, ambiguous cards, overlong diagnoses, retests that were too similar)
- Changes you would make to the gym

No scores, levels, or IQ claims. Counts are fine.
