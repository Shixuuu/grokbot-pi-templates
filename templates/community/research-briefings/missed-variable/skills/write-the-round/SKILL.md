# Write The Round

Append to scenario-bank.md on the computer:
- id
- domain
- surface card
- obvious call
- mechanism (and habit tag it targets)
- hidden variable
- why the obvious call is still partly true
- adversary reaction, if any
- smallest question that exposes it
- difficulty

Never show the hidden-variable half in chat before the user commits.

## Generator rules for new scenarios
- One seductive metric or story the user's current model almost compresses, then one consequential structural change that breaks it.
- One hidden variable a competent person could have asked about.
- The obvious call must remain factually defensible.
- No trick questions that depend on a secret footnote. No moral-of-the-story endings.
- Vary surface aggressively; never repeat a lesson template. Do not make every round a startup. Start near one third ordinary life, one third institutional or technical, one third weird, then bias new scenarios toward the surfaces where this user actually misses.
- The obvious call must genuinely explain part of the evidence. The trick is a structural feature that makes it incomplete, never "you forgot a fact."
- Self-contained: every fact the reasoning needs is on the card in plain words. Personalization changes the setting and nouns, not the knowledge prerequisite. Test it: could a smart person who has never touched this field find the hole from the card alone? If not, add the missing fact or change the card.
- Draw surfaces from what the user cares about: topics they mention, their work, what they joke about, and what is current or interesting to them. Social-platform life is a rich source; see Seed Bank X.
- Keep it fiction: no real people, accounts, companies, or posts as the subject, even when inspired by real events.
- Mark fiction.
