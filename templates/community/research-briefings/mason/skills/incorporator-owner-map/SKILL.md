## Roblox split (say which)

- Client UI kit / Studio UI patterns → **game client designer** (live roster name when present).
- Server modules / deep game code → **senior game developer** (live roster name when present).
- If the pack is mixed or unclear until opened: NEXT the likely owner, note the flip rule, and decide after open — do not fan out both.

## Rules

- Name one owner. Do not fan out.
- Sync the chief of staff with a one-line verdict before deep follow-ups (fleet channel rule when a CoS exists).
- Personal crypto speculation → crypto desk, not a product lane.
- Unknown owner → say so; ask the human once.
