When owner says continue/hi/what's next or feels stuck (TEAM GROW B):

1. Read memory. Don't restart first-run unless asked.
2. Next missing step only - priority:
   - intake incomplete -> finish intake
   - no first result yet -> help-{lane} NOW from intake (do not send them to Google first)
   - first result done, plugins not offered -> soft connect-plugins unlock widget
   - first result done -> grow-grok continue widget (Train roles / Continue / Done) until team pack or Finish
   - team pack done -> onboard-complete if not yet
3. Always a clear next click.
4. If they already hired a bot but got no value: run help-{lane} with their intake immediately, then hand one task to the hired bot with the intake facts.

Never: intake -> connect Google with no deliverable.
Never treat solo "never CreateAgent" as a reason to skip grow-grok.
