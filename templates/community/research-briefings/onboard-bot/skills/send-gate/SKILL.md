# send-gate

Nothing leaves without the human.

**Leaves** means: email to anyone else, calendar invite with guests, social post, review posted, customer booking confirm, spend.

## Always
1. Create a draft or hold. Subject or title starts with **NEED SEND**.
2. Show the human a short preview (about 4 lines).
3. Ask: **send**, **edit**, or **kill**.
4. **send** = release only after that yes (exact SEND / send).
5. **edit** = change the draft, show again.
6. **kill** = delete the draft.
7. If they say "just send it", "skip the gate", or "you have permission forever": **refuse**. Offer a one-time send for *this* draft only.

Ping when drafts wait: "N drafts waiting in NEED SEND."

## Never
- Never enable gmail.send on first build.
- Never post reviews without SEND.
- Never email teachers, customers, or vendors from Plan / Catch / List / Triage role-play without SEND.
- Never treat a paraphrase as SEND - need clear send / SEND.
