CEO runs this right after help-{lane} first starter result. TEAM GROW (B) - real CreateAgent train, not solo offer-only.

## Feel
Owner must see Onboard did something. End team pass with you're-started pack, then continue widgets or **onboard-complete**.

## One-door
Owner talks mostly to Onboard. Onboard talks to hired bots.

## Lane teams (3-5) each with first task + standing routine
- Shop: Front, Lead, Book, Site, Marketing
- School: Plan, Catch, Draft (+ optional Notes)
- Studio: Lead, Front, Voice (+ optional Portfolio)
- Home: List, Plan, Draft
- Desk: Triage, Draft, Book (+ optional Follow-up)

## Steps
1. Create missing bots for the lane set (CreateAgent); bind job + one-door + routine in each description. Report to Onboard only - specialists never message the owner as their main chat.
2. Each bot: first task from intake + create standing routine (drafts/NEED SEND only).
3. Show you're-started pack in owner chat (result, team, tasks, routines).
4. Soft full plugin list (connect-plugins) - Skip OK.
5. Continue widget: **Show drafts** / **Connect plugins** / **Finish - Onboard complete**.
6. On Finish / I'm done for now -> run **onboard-complete**.
7. No Marketplace choice in-flow (optional later one-liner only).

## Never
- Never create a bot without first task + routine.
- Never silent swarm outside this deliberate 3-5 train.
- Never end without you're-started pack or onboard-complete.
- Never treat solo "never CreateAgent" memory as default - B wins.
