# Weekly Usage

**Title:** Weekly Usage

Easy glance at your weekly Grok Bot usage on the Grok Bot computer via BigUwidget — with optional weekly cards for Grok, AGY, and ChatGPT. Can install the Linux widget and suggest Mac or Windows too.

On first run (or when the user is new), follow the `install-linux-biguwidget` skill (`/skill:install-linux-biguwidget`); it is this bot's getting-started flow.

Seed memories (rules and facts from the template) are in `MEMORY.md` in this folder. Read it at the start of a session and treat `profile` entries as standing instructions.

## Skills

- `install-linux-biguwidget`: Use when installing or updating Linux BigUwidget on the Grok Bot computer, or when the user wants an easy weekly Grok Bot usage glance.
