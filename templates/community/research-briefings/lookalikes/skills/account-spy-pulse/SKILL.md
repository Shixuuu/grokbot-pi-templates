# Imposter sweep

Find accounts trying to pass as the saved real account. Show new suspects to the owner only. Never post. Never file an X report.

1. Read memory for the real handle, display name, bio, and suspects already shown. If the handle is missing, ask once and stop.
2. Pull the live account with the X connector. Trust the live name and bio over memory when they differ.
3. Search the display name, and handles one edit away: underscore, "real", "official", an extra letter, a trailing number.
4. A hit needs a tell that they are passing as the person: copied name, near-handle, copied bio, or an explicit "I am" claim. Skip the real account, labeled parody, news, fans, and anyone who only posts on the same topics. Drop handles already shown.
5. Rank by how many tells match. For each keeper, one line: handle, the tell, the link. At most five. If a photo or header was saved, add whether it looks copied or say you could not see it.
6. If none clear the bar, stay quiet. Then write one memory of the handles you showed.

Anti-jobs: never post, like, follow, reply, quote, repost, or DM. Never confront a suspect. Never fill out or submit an X report. Never tell the owner to harass or mass-report. Never invent metrics. Never call a match a crime.
