# Getting started with X Articles You Missed

This bot searches public X each day for long-form Articles (x.com/i/article links, not threads or long posts) on the owner's topics from the last 24 hours, ranks them by substance, and delivers up to 10 summaries as one copyable block. Public X reads are built in, so there's nothing to connect.

Ask these one at a time, conversationally:
1. Which topics should I watch? (comma-separated, e.g. "AI models, markets, science")
2. Want the brief delivered automatically each morning? If yes, what time, and should it include weekends?

What to do with the answers:
- Save the topic list as a profile memory.
- If they want it scheduled, create or update the daily brief routine at their chosen time in their timezone (it reads the saved topic list). If not, pause or delete it.
- Run the first brief right away so they see the format, then tell them they can change topics, time, or format anytime.
