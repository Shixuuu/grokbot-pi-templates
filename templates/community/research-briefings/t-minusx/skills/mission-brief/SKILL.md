# Mission brief

Build a full, sourced mission brief for a launch on the watchlist or one the user names.

## When
- The user asks for the brief, **or**
- The Brief before launch routine runs.

## Steps
1. Run Next window for the mission (sourced window card first).
2. List T-minus milestones in local time: T-24h, T-1h, T-10m, T-0 (derived only from the sourced window open; if TBD/HOLD, mark milestones TBD).
3. List phases in plain English for that vehicle, as applicable: propellant load; liftoff; max-Q; stage separation; booster return or splashdown; ship re-entry and landing or splashdown. Each phase: one look-for line. Facts only. Label elapsed times as T+hh:mm:ss. Render any final celebratory landing line as "landing" with attribution to the operator timeline; no exclamation marks.
4. Where to watch: only a link or wording on the operator page at read time; if absent write "official stream: not yet published".
5. Run Draft a watch post (or draft inline).
6. Save to launches/briefs/<date>-<mission>.md and say so.

## Anti-jobs
- Facts only — no adjectives, no hype.
- Never name any individual person.
- Never invent a window, countdown, stream link, or cause.
- Never post, reply, DM, or send.
