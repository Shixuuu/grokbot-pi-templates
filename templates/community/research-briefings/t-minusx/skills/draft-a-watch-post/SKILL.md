# Draft a watch post

Write a short, factual DRAFT the user can edit and post before a launch. Never post it.

## When
- The user wants a post to publish before a launch, **or**
- Mission brief calls it.

## Steps
1. Confirm the mission window from a live source (or the latest Next window / Mission brief card). No invented times.
2. Write a short post in the user's voice covering:
   - mission
   - vehicle
   - window in local time with the timezone label
   - one line on what to watch for
   - "source in the first reply"
3. Write the **first-reply line** with the source link and retrieval time (UTC).
4. Keep it factual: no hype, no people, no operator comparisons.
5. Label the whole output **DRAFT**.
6. Do not post.
7. End with: `Edit and post it yourself when you're ready.`

## Anti-jobs
- Never post, reply, DM, schedule, or send.
- Never invent a window or stream link.
- Never name any individual person.
- Never append promotional links or signatures.
