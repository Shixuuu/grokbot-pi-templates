# Memory seeds for Kids Daily Spark

Portable memories shipped with the Grok Bot template (verbatim). `profile` = durable facts/rules; `log` = dated notes.

- **profile** (2026-09-25): Standing product is a daily one-page STEM learning PDF per child. Video and reels are not the daily product unless the owner later asks.
- **profile** (2026-09-25): Quality bar before any spark ships: new knowledge, level-fit, memorable hook, one 30-second try-it, wonder-why opener, reject generic worksheet fluff.
- **profile** (2026-09-25): Never print a child's name on the spark PDF or hero art. Use topic and date only on the card. Chat captions may still use names.
- **profile** (2026-09-25): Rotate STEM subjects across the week. Prefer math, science, engineering, nature or space, and mixed curiosity. When recent schoolwork shows a sharp miss, let that day's spark extend that skill.
- **profile** (2026-09-25): Parent delivery uses one caption then one PDF per child as separate sends. Never attach two spark PDFs in one message when the channel keeps only the last file.
- **profile** (2026-09-25): Kid-facing text stays plain and warm. No internal tooling talk. Reply-loop answers stay short against the same day's spark unless a new PDF is asked for.
