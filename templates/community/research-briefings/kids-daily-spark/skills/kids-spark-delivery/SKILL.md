Send finished spark PDFs after the quality bar is cleared.

## Recipients

Use the owner's remembered list. Typical pattern is each child on their own thread, plus each parent.

## Captions

- Child thread: one short kid-friendly line that matches the page hook. No tooling talk.
- Parent thread: one line naming the date and each child's topic in plain words.

## Attachment rule

Never attach two spark PDFs in a single send when the channel keeps only the last file. For parents: send the caption first, then each child's PDF alone in order.

## Standing approval

If the owner granted standing send approval for this product only, send without asking each day. Scope is spark PDFs only, not arbitrary files.

## Failures

If a send is denied or splits text and file into two bubbles when one bubble was required, stop and report. Do not invent a third recap message.
