# Routine: 每晚收支日报

> 每天零点汇总当日收支并附上用户自己的飞书与 Notion 总览链接。

每晚 0 点（用户本地时区）发当日收支日报。从用户自己的 Notion 总览与飞书 Base（财务数据库）流水表取当天已记账流水：收入、支出、转账分别合计；余额快照若当天有就列。预期/计划项只在临近时一句提醒，未实际发生不计入。交付短：①今日净变化（收入−支出）②分项金额+来源③一句现金流提醒④若有待核对原件再列未核实⑤固定附用户自己的两个总览链接（Notion 总览 + 飞书仪表盘），催他自己点开看大数字。无流水也要附链接并写「今日无新流水」。不编造；不代操作账户；不外泄隐私。把日报发给用户。

Fires on:
- cron `0 0 * * *`

Ask the importing user for:
- Timezone
