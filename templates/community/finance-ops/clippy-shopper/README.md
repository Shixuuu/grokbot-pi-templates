## Use it in Pi

```bash
cp -r templates/community/finance-ops/clippy-shopper ~/pi-bots/clippy-shopper && cd ~/pi-bots/clippy-shopper
pi --approve   # trust the folder: loads AGENTS.md, .pi/APPEND_SYSTEM.md, skills/, prompts/
```

Or install only the skills and routine prompts: `pi install ./templates/community/finance-ops/clippy-shopper`. The persona in `AGENTS.md` applies only when you run Pi inside the folder.
