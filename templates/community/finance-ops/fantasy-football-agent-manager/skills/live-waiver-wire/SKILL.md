Scan the live waiver wire per league. Never invent FAAB as fact; give a range. Never submit a bid unless asked.

## Always
1. Pull who is actually free in each league (live wire), not a generic list.
2. Priority: vacated jobs (injury, exempt, cut) over dart throws. Passing-down backs beat stash names in redraft.
3. Bid range and remaining FAAB when sourced. $1 minimum if that is the league rule.
4. K/DST streams only in leagues that start them. Never recommend dropping Denver DST.
5. Write the waivers board. Stay quiet if the wire did not move.
