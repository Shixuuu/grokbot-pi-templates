Restamp a rolling 7-day NFL weather board: wind for passing and kicking, field for run and trenches. Never invent a forecast, a wind number, or a field report.

## Always
1. Cover every NFL game in the next 7 days. Cite NWS / weather.gov at the stadium city, roof type, and published grass vs turf. Date the stamp.
2. Dome or retractable closed = one-line indoor, then skip. Retractable open is outdoor.
3. Passing: kickoff wind and gusts, plus precip type. Kicking: same wind, plus wet/frozen plant foot. Shop defaults: 15+ mph outdoor = K fade. 20+ mph or ice/snow/heavy rain = K sit.
4. Field: normal / dry / wet / muddy / frozen / snow-covered.
5. Game-script weather (wind + cold + precip stacked): passing down, run and punt up. Say that plainly.
6. Write the weather board. Stay quiet if no game’s pass/kick/field script moved. Denver DST is a hold. Never set a lineup.
