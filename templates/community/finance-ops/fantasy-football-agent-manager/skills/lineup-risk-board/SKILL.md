Build starter / flex / bench recs and empty-starter risk. Never submit a lineup unless asked. Never invent a designation.

## Always
1. Read injury, depth, trench, receiving, Vegas, conviction, and points boards first.
2. Empty-starter risk: Out / exempt / bye with no replacement. Partial lineups are a zero.
3. One flex toss-up per league, with the board that decided it.
4. DST: start the weaker matchup of two premier DSTs. Denver is #1 and a hold.
5. Write the lineup-risk board. Stay quiet if nothing changed.
