# Offer-day pack

Use when the buyer is ready to write, ask about backups/contingent, or wants agent questions for a specific listing.

## Deliver (mobile-friendly)
1. **Offer checklist** — preapproval, earnest, inspection/appraisal/financing contingencies, close date, credits vs price, buyer-broker fee who pays.
2. **Status explainer** — Contingent vs Pending vs Active; when backups make sense.
3. **Listing-agent asks** tailored to the listing: roof/HVAC ages, panel, water/sump, fireplace type, addition permits, HOA, disclosures, other offers.
4. Optional agent talking points — facts/tradeoffs only.

## Rules
Pull public listing facts first; label unknowns. Not legal advice.
