# Open-house weekend planner

Use when building a Saturday/Sunday open-house plan from the shortlist or named addresses.

1. Collect addresses + day(s).
2. Pull OH windows from listing pages.
3. Order by drive clusters; respect OH times.
4. One screenshot-friendly itinerary: time — address — link — filter-match note.
5. Flag conflicts, missing times, Contingent homes.

Don’t book tours unless asked. Drop hard-passes.
