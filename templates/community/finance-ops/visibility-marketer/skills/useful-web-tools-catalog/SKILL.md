# Useful web tools catalog

Curated free-web toolkit. Prefer these when a free browser tool fits the job. Always include ≥1 text source for NotebookLM work when relevant; this catalog is separate. Prefer legal library/publisher access; do not use tools to pirate copyrighted works the user does not own rights to.

## Discovery & archives
- `alternativeto.net` — free app alternatives
- `justwatch.com` — where to stream content
- `archive.org` — old web pages / archives
- `archive.ph` — permanent page snapshots
- `gutenberg.org` — free classic books
- `openculture.com` — free university courses
- `similarsites.com` — site alternatives
- `downdetector.com` — is a site down

## Math, media, graphics
- `wolframalpha.com` — math / computation
- `photopea.com` — browser Photoshop
- `squoosh.app` — image compression
- `remove.bg` — remove image backgrounds
- `cleanup.pictures` — remove objects from photos
- `unscreen.com` — remove video backgrounds
- `carbon.now.sh` / `ray.so` — code screenshots
- `shots.so` / `smartmockups.com` — product mockups
- `tineye.com` — reverse image search

## Privacy & temp sharing
- `haveibeenpwned.com` — breach check
- `virustotal.com` — malware scan
- `privnote.com` — self-destructing notes
- `temp-mail.org` / `10minutemail.com` — disposable email
- `file.io` — auto-deleting file share

## Music & focus
- `radio.garden` — world radio
- `everynoise.com` — genre map
- `tunefind.com` — TV show songs
- `musicforprogramming.net` — focus music
- `mynoise.net` — custom soundscapes
- `coffitivity.com` — café ambience

## Academic research
- `elicit.org` — AI paper assistant
- `consensus.app` — scientific consensus search
- `connectedpapers.com` — paper relationship maps
- `semanticscholar.org` — academic search
- `scispace.com` — understand papers

## Dev & productivity
- `summarize.tech` — YouTube summaries
- `phind.com` — AI search for developers
- `regex101.com` — regex tester
- `codebeautify.org` — format code
- `jsonformatter.org` — readable JSON
- `explainshell.com` — shell command explainer
- `raindrop.io` — bookmarks
- `fast.com` — speed test
- `smallpdf.com` / `ilovepdf.com` — PDF edit/merge/split

## How to use
1. Match the user’s ask to a category above.
2. Open the tool (box browser when needed) rather than inventing a workflow.
3. For academic/media downloads, stay within legal entitlement.
4. Mention the tool name/URL when you use one so the user can reuse it.
