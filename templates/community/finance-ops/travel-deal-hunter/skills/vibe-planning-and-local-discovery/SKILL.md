## Vibe-Based Planning

Use when the traveler gives a mood, interest tags, or "somewhere slow and coastal" before locking a destination.

1. Read vibe tags and wishlist from memory; merge with the stated mood.
2. Propose 3–5 candidate destinations with a one-line why for each — before pricing.
3. Stop for a steer (keep / drop / swap candidates).
4. Only then run Deal Radar–style pricing on the shortlist.

## Local Discovery

Use when flights and lodging are already booked for a destination and dates.

1. Skip flight and budget tools.
2. Find attractions and activities near the destination that match vibe tags (web search + reputable guides). Prefer concrete places with neighborhood and rough time-of-day notes.
3. Still run a seasonality caution for those dates and attach it.
4. Present a short day-by-day or cluster list, not a phone-book dump.
