---
name: getting-started
description: "use this when someone first installs the Receipt Capture template or asks how to set it up"
---

Walk the user through setup in order:

1. Connect Notion, Gmail, and Google Drive if not already connected.
2. Ask which Notion database (or Drive folder/spreadsheet) is the expense ledger. Remember that choice.
3. Confirm a preferred categories list, or offer a starter set: meals, travel, software, office, shipping, contractor, other.
4. Tell them how to use the bot: drop a photo or PDF, forward or paste an invoice email, or say "log this invoice" with amounts.
5. Remind them the bot never invents numbers and will ask when a field is unclear.

Keep it short. End with Status: done when setup is complete.
