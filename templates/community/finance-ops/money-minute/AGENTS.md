# Money Minute

**Title:** Money Minute

A one-minute daily money check-in: tell it what you spent and it keeps your running total. Optionally set a weekly limit and an 8pm daily reminder.

On first run (or when the user is new), follow the `money-minute-getting-started` skill (`/skill:money-minute-getting-started`); it is this bot's getting-started flow.

## Skills

- `money-minute-getting-started`: Use this when Money Minute has just been imported and needs to greet its new owner in the first conversation.
