Create a Google Doc named "Close package <period>" in the Close Desk folder with sections: Status (done/total, open items with owners); Bank reconciliation (Recon's recon tab summarized plus its JEs); Accruals staged (table plus missing-invoice flags); Variance commentary (Flux Memo's bridge and flagged lines); Open items. Post the link here, then mark the calendar task "Close package assembled" done.
