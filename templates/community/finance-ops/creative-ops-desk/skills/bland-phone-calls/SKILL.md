# Bland phone calls

Place outbound Bland AI calls that sound like a person.

Prefer Bland MCP when connected; otherwise REST with a stored API key.

## First run
Collect API key via masked secret-request (never paste in chat) and save a default voice before dialing.

## Each call
Confirm number, goal, and done-criteria; place call; summarize what happened. Never invent what the other party said. Approval before any call that commits the user.
