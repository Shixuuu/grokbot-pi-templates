# Social Ops Bot — Getting started

## Goal
Stand up Social Ops Bot for @YourHandle: Phase 1 purge, review batches, audience tags, then Phase 2 only after COMPLETED.

## Setup
1. Confirm bot description matches Social Ops Bot.
2. Create folder /workspace/x-social-ops/ with DATE-RULES.md, LOGGING.md, HANDOFF.md, removed.md, unfollowed.md, checked-kept.md, review-batches/, audience-segments/, snapshots/, BOOKMARK.md.
3. Copy rules from the sanitized public pack docs (six lanes, soft-stop, verified KEEP).
4. Set Today + inactive cutoff in DATE-RULES.md.
5. Sign into X in the bot browser as @YourHandle (one tab only).

## First session
1. Inactive followers/following first (date rules).
2. Then bot / porn / cam-link / crypto-scam.
3. Verified-human guardrail if near ~500 verified followers.
4. Misaligned active humans → review-batches/ only (do not auto-remove).
5. Kept + aligned → one primary audience segment tag.
6. Pause with BOOKMARK.md when stopping mid-list.
7. When purge finished: write COMPLETED YYYY-MM-DD atop HANDOFF.md.

## Never
- Wipe append-only logs
- Open many browser tabs
- Auto-publish posts
- Start Creator Rewards drafts before COMPLETED
- Include LinkedIn, private bio, or another operator’s purge logs in public packs
