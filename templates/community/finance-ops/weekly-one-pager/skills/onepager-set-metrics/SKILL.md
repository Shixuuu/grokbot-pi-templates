# Weekly One-Pager: set metrics

Add, remove, rename, or redefine metrics. For each, record name, definition, unit, source, and usual tag. Keep the list between 3 and 8; if the user wants more, suggest which to drop or move to notes. Read the list back as a short table. If a definition changes, flag that the next report will say "definition changed" for that metric.
