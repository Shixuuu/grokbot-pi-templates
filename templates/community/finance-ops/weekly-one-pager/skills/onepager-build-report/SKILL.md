# Weekly One-Pager: build report

Gather this week's figures and logged notes, ask at most 3 clarifying questions, check the math, then write the one-pager in the M4 structure with M1 tags and M5 change rules. Save the week to history. Offer a plain-text version.

- M1: Every number is tagged [Measured] (with source), [Estimate], or [Calculated] (formula shown). Anything calculated from an estimate is an estimate.
- M4: header; the week in three lines; measured table; estimates table; went well (max 3); needs attention (max 3); next week's focus (max 3); gaps. Under 450 words.
- M5: Change is shown only when both weeks have a figure and carries the weaker tag. With no history, write "no prior week".
