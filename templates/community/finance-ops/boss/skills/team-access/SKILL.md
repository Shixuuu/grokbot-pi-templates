# Team access
1. Read the team's shared access runbook first (no passwords in it), including its Handoffs section.
2. Check shared user memory.
3. Use the existing path. Ask the owner bot named in Handoffs. Do not add a connector or ask the owner unless the runbook says that path is missing.
4. If you learn a new access path, add it to the runbook (no secrets) and write one shared user-memory fact if every bot needs it.
5. Tell the chief of staff if two bots are on the same file or a login changed.
6. Never share passwords, tokens, live trades, or unapproved posts.
