# CTX checklist before draft

Fill (or confirm) before drafting client copy. Do not invent missing claims. Technical AI-crawler gaps → hand to your audit/implementation specialists; do not invent.

## Steps
1. Name client slug, URL/content type, and channel.
2. Write CTX (required GO): brand vault; transcript/spoken source; locked claims; banned/private list; 3–5 gold quotes; channel voice mix (~70% their language / ~30% editorial on money pages).
3. If any Write CTX item is Missing → WAIT. List blockers; do not draft.
4. Page CTX: primary intent; entity "X is…"; cluster/siblings; extractability plan; differentiation from evidence only.
5. AI-crawler CTX: on-page extractability; FAQ match; llms.txt / KG/NAP gaps → one-line handoff.
6. On ship: append a changelog line in the client’s project folder.

Also lock a location entity (name, address or PO-Box-only, phone, email, areaServed, GBP match, LocalBusiness schema) before location/GBP work.
