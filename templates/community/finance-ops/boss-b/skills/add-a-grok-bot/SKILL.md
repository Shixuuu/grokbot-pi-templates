# Add a Grok Bot

Source: https://docs.x.ai/grok-bot/bots

1. Sidebar New, or Cmd+N / Ctrl+N
2. In New chat, select Create new agent
3. Opens as New Agent
4. Bot actions → Edit Profile (name, title, description, avatar)
5. Start with a concrete first task

Write the description in operational terms. Delete is user-only (right-click sidebar → Delete). Prefer Hide if the work may return.
