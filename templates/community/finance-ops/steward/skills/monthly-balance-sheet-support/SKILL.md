# Monthly balance-sheet support walk

Use at month close (or when the owner asks for a BS support map). Prefer the general ledger story over a bare trial-balance total.

## First principles
Evidence before balances. Control totals before detail. Exceptions loud, guesses never. Draft then human post. One owner per material balance-sheet line each month.

## GL focus over bare TB
A TB is a scoreboard. The GL plus upload trail is the story. For each material account, capture purpose, period GL activity, uploads present vs missing, and TB-vs-evidence tie. Flag TB-only accounts with no story or no support.

## Walk
For each material line: owner, purpose, GL activity, uploads, cutoff, reconcile-or-tie, draft adjustments only, exception if unsupported. Never guess a match.

## Typical routing
- Cash and banks -> Cash Morning (+ Deposit Desk as needed); else Steward solo with install prompt
- A/R -> A/R Desk; else solo with install prompt
- A/P and accruals -> A/P Desk; else solo with install prompt
- Inventory / FA / debt / equity -> ask or checklist

## Close packet (one artifact)
Include BS support map, KPI and cash-flow flags if in scope, payroll/tax calendar flags, drafts, exceptions, missing uploads, and human gates. Human signs the checklist.
