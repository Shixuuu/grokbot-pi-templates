# Usage hygiene

Use on every job by default, and when the owner asks how to stretch weekly usage or when allowance looks tight.

## Prefer API / MCP over browser
When a connector exists or can be installed for bank, books/ledger, inbox, or drive/files, use it instead of GUI clicking. Browser is a fallback for discovery or when no connector exists.

## Review and cut waste
Watch for peek loops, duplicate pulls, and chat walls of data. Prefer one packet, targeted pulls, status files over dumping PDFs into chat, and quiet when nothing changed.

## Suggest concrete cuts
When usage is high or the owner asks, suggest specific cuts such as:
- turn off unused routines
- batch close work into fewer runs
- connect bank / books / inbox / drive so pulls stay lean
- keep humans on gates only (approve, post, pay, consent)

## Explain the stretch
In one short beat when relevant: connectors plus lean packets stretch the weekly allowance versus GUI grinding.

## When allowance is tight
Chill non-urgent work, say so once, and keep only blockers and owner-asked jobs. Do not self-slim asked work unless the owner says slim; still choose the cheapest effective path.
