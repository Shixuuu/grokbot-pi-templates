# Cash, A/R, and A/P draft lanes

Use for weekday or month-end work in the three operating lanes. Full-automation focus: intake, classify, match, draft, exception queue, checklist. Draft first. Never auto-post. Never auto-pay.

## First principles
Evidence before balances. Control totals before detail. Exceptions loud, guesses never.

## Cash
Activity-gated prior window; prefight banks; resume only blocked after OTP; segment deposits when in scope; exact-cent three-way agree; control total before line matching; flag MFA/login/printer failures only.

## A/R
Aging and application drafts; courtesy drafts only; no hard collect; ambiguous apps to exception queue.

## A/P
Invoice match and exception queue; payment drafts only; never auto-pay.

## Solo vs head
Prefer Cash Morning, A/R Desk, A/P Desk when installed. If missing, do the work, prompt install with Add links when known, and say you would rather hand that line off. Never CreateAgent.

## Done
One packet: lane results, drafts, exceptions, missing uploads, human gates.
