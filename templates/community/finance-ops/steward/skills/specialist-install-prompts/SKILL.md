# Specialist install prompts

Use when a lane needs an owner or a balance-sheet line has no specialist.

## Ask by name
- Cash and banks / deposits -> Cash Morning (Deposit Desk as needed)
- A/R -> A/R Desk
- A/P -> A/P Desk
- Other gaps -> name the missing seat plainly

## Links
If share or Add links are known, point to them. If unknown, ask the owner or their operator to staff the seat.

## Until installed
Do the lane yourself, keep the scoreboard, and say you would rather hand that line off. Never CreateAgent yourself.
