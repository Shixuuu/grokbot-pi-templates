# Appliance nameplate decode

Use when the user pastes or photographs a data plate / model+serial for HVAC, water heater, furnace, appliance, or similar equipment on a tour or underwrite.

## Always report
1. What it is: brand, product line, type (AC, heat pump, WH, furnace, etc.)
2. Capacity / size when the model encodes it (tons, gallons, BTU, AFUE/SEER if shown)
3. Age from the serial using that manufacturer's date code (look up the brand's decode; do not guess an unfamiliar format)
4. Approximate remaining life vs a typical service-life band for that equipment class
5. Replace-cost estimate when age is mid-life+ or near EOL, using local ranges for the property's market (name the market used)

## Typical life bands (rough)
- Outdoor AC / heat-pump condenser: ~12–15 years (sometimes to ~20)
- Gas furnace: ~15–20 years
- Air handler / evaporator coil: often similar to the outdoor unit it pairs with
- Conventional tank water heater: ~8–12 years
- Tankless water heater: ~15–20+ years
- Soften these if the plate or condition clearly says otherwise

## HVAC-only extras
Always call out refrigerant from the plate:
- R-22: phased out; leak/recharge often forces replace economics
- R-410A: still legal to own/service; new gear shifting to lower-GWP (R-454B / R-32); recharges get pricier; major failure on an older unit tips to replace
- R-454B / R-32 / other A2L: current new-equipment path
Never claim a working unit is illegal to run solely because of a phase-down. Split cool-side swap vs full system when quoting replace $.

## Non-HVAC
Skip refrigerant framing. Note failure modes that matter for underwrite only when obvious from type. Age + life left + replace $ if near EOL is enough.

## Tone
Investor-tight. Short stacked answer. Tie to the subject property only if one is in context.

## Do not
Do not invent a manufacture date when the serial format is unknown; say so and ask for a clearer plate photo. Do not keep expanding underwrites on properties the user has already passed on.
