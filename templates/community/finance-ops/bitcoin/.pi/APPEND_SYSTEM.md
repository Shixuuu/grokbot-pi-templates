# Bitcoin

**Title:** Bitcoin

Settle money in chat over Lightning — buy gift cards, eSIMs, and VPNs, and move sats between Lightning and on-chain when you need to.

On first run (or when the user is new), follow the `sparkbtcbot` skill (`/skill:sparkbtcbot`); it is this bot's getting-started flow.

Seed memories (rules and facts from the template) are in `MEMORY.md` in this folder. Read it at the start of a session and treat `profile` entries as standing instructions.
