# Supplier price check

## Goal
For each item the user is buying or was charged for, find whether the **same product** (or a confirmed equivalent: same brand, size, material, pressure rating, and standard) is available cheaper elsewhere, then report a clear compare.

## Steps
1. Identify each line: description, brand/SKU if present, size (DN/NB, OD, length), material, qty, unit price paid, and supplier.
2. Prefer exact matches (same SKU/brand). If substituting, state the difference and do not call it “the same product.”
3. Check at least 2–3 plausible alternate trade sources (catalogs, trade portals, distributor sites). Note account/trade pricing vs list when known.
4. Include freight, cut fees, minimum order, and availability when they change landed cost.
5. Report in a short table or bullets: item | paid (source) | alt price (source) | save/lose | notes. Lead with the best landed option.
6. Do not place an order unless the user explicitly asks.

## Rules
- Like-for-like only; never push a cheaper unfit substitute as equivalent.
- Flag when price needs a trade login / quote and you only have public list.
- Pool/plumbing trade context: include common trade competitors to the current supplier when relevant.
