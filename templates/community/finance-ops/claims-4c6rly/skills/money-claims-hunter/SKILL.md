Exhaustive money-recovery hunt. Search every surface before done. Never forge signatures/docs. Submit only with explicit per-claim approval. User decides what to file — no dollar minimum.

## Location is intake-custom (critical)
Do NOT hardcode Illinois or any state. Official state portals come ONLY from intake cities/states lived. Then MissingMoney multi-state + remaining-states expansion unless user narrows. Settlement matching also uses lived-in states.

## Safety
Field-by-field asks; no fabricated IDs/signatures; no SSN in memory/skills; official .gov + court-appointed admin sites; no finder's fees when DIY free; captcha/2FA hand to user; distrust fake claim-deadline pages.

## Intake
Required: legal name, aliases, every city+state lived (this builds the portal list), mailing address. Optional: banks, employers, utilities, insurers, cars (model/year/diesel), retailers/apps, landlords, breaches, veteran/FHA, countries abroad. Confirm checklist. PBGC last-4 only when searching PBGC.

## Tier 1 States
1) MissingMoney.com 2) unclaimed.org map → each lived-in official portal 3) every lived-in state+DC official site 4) remaining states 5) Canada if intake says so. File only on official state sites. Active big-bank deposits are not in FDIC — they escheat to state UP.

## Tier 2 Federal (same for everyone)
FDIC closedbanks.fdic.gov/funds (captcha, name); NCUA public list grep; PBGC last name+SSN last-4; DOL lostandfound.dol.gov Login.gov+SSN; HUD entp.hud.gov/dsrs/refunds; VA insurance.va.gov/UnclaimedFunds; Treasury Hunt RETIRED 2025-09-30; UCF ucf.uscourts.gov; IRS refunds; USA.gov index.

## Tier 3 Settlements
Sweep TopClassActions, ClassAction.org, OpenClassActions, Consumer Action + keyword every intake brand. File on official administrator sites only. Score likely/maybe/no. List closed + watch-list.

## Tier 4–5
Deposits/rebates with process; international if warranted.

## Workflow
Intake → show personalized checklist naming their states → execute tiers → hit log → user triage → file one-by-one → ledger → offer re-hunt.

## Coverage checklist
MissingMoney; each lived-in official portal by name; remaining-states; FDIC; NCUA; PBGC offered; Treasury Hunt retired noted; HUD; VA if relevant; DOL offered; UCF; 4 aggregators; brand keywords; leftovers; international if warranted.

## Export hygiene
Strip PII and any example state that looks like a hardcoded default. Importers run Intake — their lived-in list customizes the hunt.
