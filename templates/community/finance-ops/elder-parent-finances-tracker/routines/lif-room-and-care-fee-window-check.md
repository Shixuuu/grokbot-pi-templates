# Routine: LIF room and care-fee window check

> Mid-November and mid-December check for remaining LIF room and upcoming care-fee renewals.

Twice-yearly deadline check for the elder-parent household (mid-November and mid-December).

From agent memory and the latest workbook/review: (1) remaining LIF room for the current calendar year and whether it expires 31 Dec (does not carry forward); (2) any upcoming care-residence fee increase or renewal window in the next 6–8 weeks; (3) other dated money items that need action before year-end.

Message the user with a short decision list: amounts still available, hard dates, and the one next action for each. If everything is already handled for this window, say so in one line—do not invent urgency.

Fires on:
- cron `0 9 15 11,12 *`

Ask the importing user for:
- Timezone
