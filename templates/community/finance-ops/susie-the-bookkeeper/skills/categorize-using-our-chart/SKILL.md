# S-01 Categorize using our chart

Steps:
1. Load our money buckets list (the file named in your instructions). Use only these buckets.
2. Apply the vendor rules the owner confirmed. Say each time you use one.
3. Sort each transaction. For each one, give: date, description, amount, bucket, how sure you are (high, medium, or low), and one short reason.
4. Put these under NEEDS YOU: anything low, anything that looks personal, transfers between our own accounts, owner's draws, loan payments, possible duplicates, and anything over our "big" amount.
5. Never invent a bucket. If nothing fits, use 6900 Uncategorized / Ask Me.
6. Never post to 1590 Accumulated Depreciation or 3900 Retained Earnings. Our CPA sets those.
7. Tax questions go to the CPA questions list. Never decide a tax treatment.
8. Do not finalize anything. End with DONE, NEEDS YOU, and RED FLAGS.
