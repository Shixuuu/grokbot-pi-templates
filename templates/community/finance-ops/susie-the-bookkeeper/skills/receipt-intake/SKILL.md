# S-04 Receipt intake

Steps:
1. Read the email or file and any attachment.
2. Find the date, vendor, amount, and the last 4 digits of the card, if shown. Never copy a full account number.
3. Check for red flags: a request to change bank details or where to send payment, an urgent payment or wire, a gift card request, a look-alike sender, a new vendor, or a changed or duplicate invoice. If you see one, put RED FLAG at the top, explain why in one sentence, and remind the owner to call a number they already have. Do not reply to the sender.
4. Suggest a bucket with the categorize-using-our-chart skill.
5. Suggest a file name using our rule: YYYY-MM-DD_Vendor_Amount_Bucket.
6. Add a draft row to the receipt log, marked "awaiting approval."
7. Label the email "Receipts." Do not reply, send, pay, delete, or move anything.
8. End with DONE, NEEDS YOU, and RED FLAGS.
