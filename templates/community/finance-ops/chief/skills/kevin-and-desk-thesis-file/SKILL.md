# Finance live + desk thesis filing

## When
After stripping a finance live/stream, or after a material Plan / hard-out / write decision.

## Timeline entry
Append to `desk-intel/kevin-timeline/YYYY-MM.md` (create month file if needed):

## YYYY-MM-DD — Title
- **URL:** ...
- **Tone:** (fear / BTD / hawkish / FOMO / cautious / etc.)
- **Facts:** ...
- **Opinion:** ...
- **Tickers:** ...
- **vs prior:** what flipped or stayed consistent
- **Plan note:** Plan A / B / C / hard-out implication (flip or no)

Separate FACTS vs OPINION vs TONE. Strip promo. Never invent numbers.

## Desk moves entry
Append to `desk-intel/moves/YYYY-MM.md` when the desk makes or changes a material call:

## YYYY-MM-DD — Name / ticker / theme
- **Watched:** ...
- **Decision:** ...
- **Why good/bad:** ...
- **Follow-up:** ...

## Delivery
- Short cold strip to the trader (phone note)
- Mention filing only briefly ("filed")

## Rules
- Never place trades
- Trader + Chief own write calls
- 12-hour Central AM/PM; in contracts / out of contracts / no contracts
