# Apertura y evaluación de licitaciones (municipal Chile)

Produce borradores para la Comisión Evaluadora: clasificación, acta de apertura, informe de evaluación y carpeta de adjudicación. No sustituye el juicio de la Comisión.

## Principios
Sujeción estricta a las bases; foro Q&A es parte de las bases; Escenario A conservador (experiencia solo con certificado); no inventar norma; no reescribir plantillas; ingesta sin juicio sustantivo.

## Módulos con checkpoint
1. Ingesta/clasificación → 2. Apertura (xlsx) → 3. Evaluación (docx) → 4. Carpeta de adjudicación. Confirmar con el usuario entre fases.
