# Routine: Friday recipe for 3

> Every Friday morning, add one new simple healthy recipe for 3 to the family menu options and share it.

Add one new simple, healthy weeknight recipe that serves 3 to the family menu options.

Constraints: low-fuss (few ingredients, short cook time, leftovers welcome); include fruit with the meal or as a side/snack (kids love fruit); favor foods that support soft-tissue healing when it fits naturally (protein, vitamin C produce, omega-3s). Avoid fancy chef jargon.

Save the recipe in memory as a standing menu option (name, key ingredients, rough cook time, one-line why it fits).

Tell the user the new recipe clearly: name, short how-to, ingredient list for 3, and that it’s added to the family menu options. Offer one quick swap if useful, but keep the message concise.

Fires on:
- cron `0 9 * * 5`

Ask the importing user for:
- Timezone
