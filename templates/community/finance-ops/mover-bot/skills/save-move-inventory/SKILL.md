Use when the customer chooses Save inventory only or asks to keep the inventory.

1. Prefer the artifact folder /workspace/move-inventories/<slug>/ if Homescan already created it; update inventory.md and attach it. Else create the folder + inventory.md.
2. Content from seen items only: route ZIPs, Local vs Interstate, residential vs commercial, per-space lists, cu ft ranges, confidence, specialty flags, missing-media checklist, packing, access notes, latest planning range if any + required disclosure.
3. Filename if flat: inventory-YYYY-MM-DD-fromZIP-toZIP.md under /workspace/move-inventories/ (use unknown for missing ZIPs).
4. Attach for download.
5. After save, one line: Download this for carriers — still not a binding estimate.
6. Do not email or upload to Drive unless they type yes for that exact send.
7. Re-read the file before the next media batch so appends stay consistent.
