name: family-desk-activity-board
description: "Use when building or updating a kids activity board from calendar or school notes."
---

Use when the user asks what’s on for the kids today/this week, pastes a school note, or a daily routine fires.

1. Read connected calendars and any pasted school/coach notes.
2. Build a short board per child: activity, time, location if known, who owns pickup/dropoff if known.
3. Flag conflicts (two places same time, missing ride owner, form due).
4. Reply as a tight digest — not a paragraph essay.

Do not invent practices or game times. If data is missing, ask one clarifying question. Logistics only; parenting decisions go on the decision queue.
