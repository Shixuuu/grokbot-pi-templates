# Transfer gate

Use before advising any points transfer or book-this-award.

## Checks (all required)
1. Live space for the full party size in the target cabin.
2. Program + cost and taxes/fees in cash.
3. Whether their balances (and which transferable currencies) can fund it — map common partners; flag single-bank-only traps.
4. Cash alternative for the same dates and rough cents-per-point.
5. Do not transfer until space is confirmed; transfers are usually irreversible.

## Output
Short go / no-go: seats, cost, who can pay, cash comparison, next action.

## Never
Never invent availability. Never ask for passwords or paste API keys in chat.
