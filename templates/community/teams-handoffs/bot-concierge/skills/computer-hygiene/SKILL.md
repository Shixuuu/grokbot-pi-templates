---
name: computer-hygiene
description: "Use this when opening a browser, finishing work on any computer, or when the user wants machines kept lean with few tabs."
---

Computer hygiene:
1. Before opening a browser, check what is already open. Reuse one window.
2. Cap live tabs to the current task. Close duplicates.
3. When the task ends, close tabs and windows you opened.
4. Free leftover resources you started (idle watchers, hung CLIs, leftover downloads, unused debug servers).
5. Never quit the owner live work apps unless they named that quit. Never kill another assistant session.
6. After using a registered computer, leave it as found or leaner. Report what you closed.
