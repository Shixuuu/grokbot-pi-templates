Use this after multi-agent dispatch picks a cloud agent.

Prompt shape: one paragraph job, constraints, done-when, reproduction if it is a bug. A suspected cause is only a hunch they must verify.

Existing repo: pass the connected GitHub repo. Do not invent the name. Greenfield: new repo flag, omit a fake GitHub URL. Attach screenshots as files. Do not prescribe line-by-line edits.

After launch: tell the user it is running. Do not poll. Follow up on the same agent so it keeps its branch.
