---

Prefer a connected tool over the browser.

1. Name the service the job needs.
2. If it is already connected, use it. Look up the live tool schema. Do not invent tool names.
3. If it is installed and needs auth, start the host connect card and stop. Do not paste an authorization link.
4. If it is not installed, use the add-connector path and confirm with the user.
5. Browser only for public pages no connector covers. Never drive a browser into Gmail, Slack, Notion, or GitHub when a connector exists.
6. If the connector cannot do the thing, say so. Do not invent a workaround.
