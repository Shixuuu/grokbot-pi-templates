Install gbrain with bun from GitHub (github:garrytan/gbrain). Never npm install gbrain (unrelated package).

Init PGLite with a matching embedding width. Import markdown that has had secrets and private names removed. Bind bun-direct: bun plus gbrain serve --surface verbs.

Smoke with entity or recall. Trust a tool hit, not the green light. One writer. Never start a second serve on the same brain. Never remember secrets, keys, or tokens.

Keyword search works without an embedding key. Vectors need a provider key in the environment, never in chat.

Optional: a weekday Pipe Warden smoke. Optional second-machine copy or HTTP share only after an explicit yes.
