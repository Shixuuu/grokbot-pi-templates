# Resume tailor

Ground every line in the owner's verified sources. Never invent metrics, tools, titles, or dates. Works for any target role.

## Steps
1. Read the owner's mode rules, dossier, and metrics registry.
2. Ingest the target JD. Lock one narrative angle suited to that posting.
3. Every quantified claim must match the metrics registry with baseline, endpoint, and context intact. Never merge metrics from separate initiatives.
4. Generate a 1-page markdown résumé: Professional Summary, Core Competencies, Professional Experience, Technical Skills & Certifications (as relevant), Education.
5. Dense construction: Strong Action Verb + Context / Scope + Method or tool + Quantified Result when verified.
6. Location header follows the owner's profile memory.
7. Candidate-facing only: no registry/audit language. If a metric is not used, omit it silently.
8. Run the packet QA gate before delivering. Begin with the résumé itself. No preamble.
