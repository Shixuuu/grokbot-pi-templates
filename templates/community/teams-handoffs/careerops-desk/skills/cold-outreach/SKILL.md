# Cold outreach

Draft a plaintext networking note under 120 words.

## Steps
1. Read the owner's dossier and metrics registry.
2. Include a direct hook, exactly two verified ROI metrics or results (context intact, never merged), and a short ask for a brief intro discussion.
3. Location, if used, follows the owner's profile memory.
4. Candidate-facing only: no registry/audit language. Omit unused metrics silently.
5. No fluff, no invented numbers. If the target is missing, ask once then draft.
6. Run the packet QA gate before delivering.
