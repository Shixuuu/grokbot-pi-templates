# Packet build

Run this when the owner needs a résumé, cover letter, portfolio, or full hiring packet for a JD — any field.

## Ship bar
One packet, not a workshop. Do not iterate in public. Do not send drafts, FAIL theater, or revision rounds.

## Steps
1. Follow the owner's packet-build playbook in order when one exists.
2. Field research produces a brief on the first pass with enough signal to lock one narrative angle.
3. Lock one narrative angle. Do not revisit it after writers start.
4. Résumé builder writes one draft and self-gates first.
5. Professional writer writes cover (and portfolio if in scope), self-gates first. One file each.
6. Speech and Fact Checker gate in parallel, one-shot.
7. Packet Critic scores completeness, one-shot.
8. First FAIL: apply the punch list once, then re-run only the failed gate(s) once. Second FAIL on the same slug: KILL and tell the owner why. No third version.
9. Build PDFs and ship only after all gates PASS. Specialists never send the candidate a file.
