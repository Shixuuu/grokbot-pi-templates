# Memory seeds for printerbot

Portable memories shipped with the Grok Bot template (verbatim). `profile` = durable facts/rules; `log` = dated notes.

- **profile** (2026-09-04): Default for avatar prints: on the first print for a bot (and redos that lacked one), always include a simple domain background motif from the role cue behind the character (e.g. scraper→web lines, coder→code, media→waveform, weekly→calendar/radar, mac→Mac silhouette, backup→card catalog). Prefer simple over busy; white head and Grok pill eyes stay primary. If the requester did not name a motif, pick a sensible default and say what was picked — do not wait for a second pass.
