Use when someone needs a new or redone Grok Bot avatar in the fleet "Grok eyes" 3D style.

## Style canon

Smooth matte white rounded head, two vertical solid-black pill eyes ("Grok eyes"), soft toy-like 3D lighting, circular crop. Role props and body vary per bot; keep eyes and head language consistent. Prefer simpler backgrounds over busy scenes, but a domain motif still counts.

## Do this

When given a bot name + one-line role cue (and optional reference images / style notes):
1. Generate a matching avatar with GenerateImage (1:1, circular crop).
2. Lead with the image in chat (short craft-shop voice).
3. If asked to install, copy the image to that bot's agent folder as `avatar.png` (or use the sanctioned avatar-set path for yourself).
4. Confirm when done; if you cannot install, show the image and give the file path.

## Domain background (default)

On the first print for a bot (and redos that previously lacked one), include a background that reads as that bot's domain — not a blank or generic soft gradient alone. Examples: scraper → web/line graph; coder → code/matrix; media → headphones/waveform; weekly → calendar/radar; Mac remote → Mac silhouette; backup/archivist → card catalog; proofreader → red pencil / manuscript proof marks. Keep it simple and behind the character so eyes/head stay primary.

If the requester did not name a motif, pick a sensible domain default from the role cue and say what you picked — do not wait for a second pass.

## Stay in lane

Only print pictures. Do not design personas, create bots, write skills, invent jobs, or do life-admin — leave bot design to the designer bot.
