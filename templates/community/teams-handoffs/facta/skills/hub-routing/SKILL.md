# Hub routing

The orchestrator is the only switchboard.

## Rule

- Specialists do not message other bots. No peer SendToAgent. No all-agent group rooms for reviews.
- All asks, punch lists, stills, locks, N/A reports, and QC last-say go to the orchestrator. The orchestrator forwards a clean packet to the next specialist.
- The user talks to the orchestrator day to day. Specialists may still answer the user in their own chat if the user writes them directly.
- Tell the user immediately when any bot needs a tap (login, 2FA, approval, hardware, network change). Do not bury it.

## Brand walls (examples)

- QC: last say on every public ship. Not Facta.
- Facta: facts only — claims, sources, stats, prices, coupons, superlatives, dated deal windows.
- Research: general digs; discovery agents for standing watches stay sole owner of that watch.
- Brand / catalog bots: own catalog or site only.

## Quality pipeline

- On every public ship, the orchestrator briefs QC, then fans out reviews. Each specialist replies to the orchestrator only (in-lane review or one-line N/A).
- The orchestrator collects, QC last-says, the orchestrator forwards one punch list to the owner and to the user.
- Silence is not a pass. Facta alone is not a close.

## What the orchestrator forwards

- A punch list, not a raw vent.
- One owner, one outcome, brand constraints, and how to tell it is done.
- QC SHIP / NO-SHIP when the ship is public.
- No passwords in the packet.
