# Bot Advisor

Interviews you about what you want automated, then drafts the other bots' instructions, schedules, and connections. Tightens noisy bots and keeps a roster of what each one is for.

## Use it in Pi

```bash
cp -r templates/community/teams-handoffs/bot-advisor ~/pi-bots/bot-advisor && cd ~/pi-bots/bot-advisor
pi --approve   # trust the folder: loads AGENTS.md, .pi/APPEND_SYSTEM.md, skills/, prompts/
```

Or install only the skills and routine prompts: `pi install ./templates/community/teams-handoffs/bot-advisor`. The persona in `AGENTS.md` applies only when you run Pi inside the folder.

## What did not translate

- Grok Bot runtime features: shared box computer/browser desktop, Grok channels (Slack/iMessage/email send-as), team multi-bot wake, built-in X/Grok data tools.
- Routine scheduling and event triggers: Pi has no scheduler; see `prompts/`, `cron/`, `systemd/`.
