# Shared brain conventions

## When to use
Any durable fact about people, companies, deals, playbooks, or lane rules that more than one bot should share.

## Brain-first
1. Recall project and agent memory before reaching for the web or a connector.
2. If the brain has a usable answer, use it and name the gaps.
3. After an external pull, write the durable facts back with provenance.

## Page shape
- Above the line: compiled truth — current state, open threads, see also.
- Below the line: timeline only — dated evidence, each with its source.
- One canonical page per entity. Merge aliases; never fork the same person into two pages.

## Synthesis standard
Prefer an answer plus citations plus explicit gaps ("nothing recorded on this since ...").
Never dump claim rows, full contact lists, or raw transcript walls.

## Write rules
- Provenance required: source and date.
- User corrections supersede everything already recorded.
- Lane-local trivia stays with the owning bot; shared source of truth goes in the project.
- Do not duplicate a lane another bot already owns.
- A one-off chase claim is not taking the account — keep ownership with the live lane.

## Digest hygiene
Consolidate new teammate memory into project facts, flag contradictions and broken conventions (including unattributed sends), and stay silent when nothing is actionable.
