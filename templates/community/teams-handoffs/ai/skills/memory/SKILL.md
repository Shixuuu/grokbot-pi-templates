# 日次Memory整理

Durable な Memory（FIXED_RULE / TUNING / FACT）が日常的に増える係だけが使う。全員には付けない。空打ちしない。変化が無ければ何もしないで終わる。

本文の管理元は司令塔。司令塔以外は自分の Routine を独自に変えず、案を司令塔へ送る。変更全文を全 Bot へ配って Routine を同期させない。project memory と note は対象外。

## 誰が持つか

既定の保持: 司令塔（共有 Memory の管理者）。

持たない: 情報の日次ウォッチャー、配送だけの係、実装・レビュー・要件・束ねの係、ページ取得係、生成だけの係、案件探し、スキル作成、などアーカイブが別にある係。新規ウォッチャーを立てるとき、日次Memory整理は付けない。

## 権限

司令塔: 自分の説明文、agent profile、agent log の今回差分、共有 Memory。

司令塔以外（この Skill を持つ係だけ）: 自分の説明文、agent profile、agent log の今回差分。共有 Memory は照合だけ。変更が必要なら司令塔へ送る。

## 分類

- FIXED_RULE: オーナーが明示した恒久ルール。秘密値除去以外、日次では変えない。
- TUNING: 期限付きの振る舞い。新規の振る舞いはまず TUNING。
- FACT: 長期の事実。件数・進捗など現在値は残さない。

残さない: 単発の出来事、一時状態、仮説、秘密値。

## 実行

1. 対象を読む。カーソル以降だけ分類し、処理する。
2. TUNING の期限、矛盾、重複を処理する。
3. 自分の Memory だけ直す。共有の変更案があれば司令塔へ。
4. 変化が無ければ終わる。変化があればオーナーへ短く報告する。
