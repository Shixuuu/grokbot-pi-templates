Use when a board ticket looks like it needs a coding or logged-in browser worker. Do not launch chrome or grok CLI from this chair. Logged-in work browser is hired through Tentacles. The chair browser is public looking only.

This chair does not start cursor-agent, grok, codex, or chrome CLIs. Tentacles is the hire path.

Never app, login, or admin work in the chair browser. Work Chrome is offloaded via Tentacles to a lab on the user's machine. Do not ask the human to click around a login.

Grok Code sessions use instance grok. Never instance hermes. Hermes as a lab is not the Grok Code path.

Hire split: the strong implementation lab does most work. Review and bugs use the review lab. Grok Code only charts UI.
