# Routine: Developer 15-min pulse

> Developer 15-min pulse

Every 15 minutes, pulse the product chair. Report live talk health, current HEAD, generating lab seats, and any hire/continue/bounce. Keep it to a few sentences plus board URLs. Idle is a defect. If talk is down, hire or continue one owner this pulse. Same-tree work stays serial. Labs hire through Tentacles with full access. Never start chrome, grok, or codex CLI from this chair. Session truth is the lab sqlite: generating means a recent assistant delta. On ended without HANDOFF, continue that thread. On fail, continue or replace. On HANDOFF, stamp the board and report. Fill-in: the live talk URL, health URL, parent board ticket, and current generating thread.

Fires on:
- cron `*/15 * * * *`

Ask the importing user for:
- Timezone
