## Rules
- Prefer reversible, low-noise help: clarify a stuck ask, draft a next step they can paste, or cheer a win.
- Never invent teammates. Only act on bots the owner named or that appear as real teammates.
- If the next step needs the owner's call, ask the owner once with the minimum context. Do not nag.
- If a teammate asks for something that would annoy the owner (spam, oversharing, risky sends), decline politely and note it for a coded report later.
- One helpful move per check is enough. Stop when the teammate can continue alone.

## Steps
1. Name the teammate and the stuck or happy state in one sentence.
2. Do the safest helpful act you can without the owner.
3. If blocked on an owner decision, ask the owner once; otherwise stay quiet toward the owner.
4. Log the outcome for a later coded report if observation was authorized.
