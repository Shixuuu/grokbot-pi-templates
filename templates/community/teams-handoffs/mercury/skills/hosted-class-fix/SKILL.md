Use this when the hosted product fails a sit and the instinct is to text the Cursor writer a last-fail sentence or a company name.

The failure mode this exists to stop is the fix-and-retest trap: patch the last pictured case, local tests go green, the next mixed-name sit moves the hole onto a neighboring face. Local test counts are recall of the last picture. Hosted mixed-name pictures are the score.

A filing dollar is a cell (issuer, form, period, statement, face). That is the XBRL fact (entity, concept, period, unit, dimensions). A closed cell does not accept a parent total, a later 10-Q, a YoY percent, leftover English, or a last ticker as a substitute. Unowned ticker is the restricted public-name door, not an empty cell. Two printed lookalikes are a swap, not empty-cell.

## Sequence (never skip, never reorder)

1. Sit the hosted product only. Never localhost. Pictures of every click. Writer claims and local tests do not count.
2. Score pictures as a class, not a company. Gold: bind the asked cell or refuse that cell. Full cell refused = PRODUCT FAILURE. Wrong concept on the same print = PRODUCT FAILURE. Hang = PRODUCT FAILURE. Geographic cell or leftover last name as cousin = PRODUCT FAILURE.
3. Name the emit function that produced it. No writer prompt until that name exists.
4. Write a short plan in full sentences: the gate, where it lives, the holdout proof, what will be sat after.
5. Send that plan to the existing PR writer using the required prompt shape below. Fake names only (Studio / Harbor / ZZ). Never eval question strings. Never deploy env unless the plan says so. Never a second writer.
6. Sit the host again on the same class, mixed names. Restore the intended public usage cap after that sit.

## Required writer prompt (the tool call)

Every follow-up to the PR writer must contain all of:

- The class in one sentence (empty-cell over-refuse / cousin fill / form-period swap / leftover English as ticker / parent total as face / reader cover dump).
- The emit function if known.
- A Studio / Harbor / ZZ holdout: one case of the same class that is not the last hosted picture. If the patch only makes the last picture pass, this holdout must still fail.
- Done-when: a new hosted deploy survives a mixed-name sit of that class. Writer claims do not count.

If a draft names a live issuer, a last dollar, or a last question string, delete it and rewrite.

## Do not

- Pin the last failed sentence or last company.
- Treat neighboring product lines as separate bugs when the cell is empty or swapped.
- Fold the last hosted fail into the local suite and call that a fix.
- Declare shareable off a writer claim.
- Send the owner's private question list to any coding agent.
