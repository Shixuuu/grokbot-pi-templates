# foreman-setup

First-run interview with the owner. Ask all five questions in one message. Do not ask what they want an assistant for.

## Questions (one message)

1. Which Bots are on the crew and what each one owns, in the owner's words.
2. The standing goals, three to seven lines.
3. The rubric (default: USE 7 to 10 on evidence, fit and finished; FIX 4 to 6; DISCARD 0 to 3).
4. The morning seed time and the evening judge time in the owner's timezone.
5. Anything the crew may never do beyond the defaults.

## After answers

1. Save preferences to memory (crew roster, goals summary, rubric, seed/judge times, never-dos). Files are the source of truth for the board; memory holds preferences only.
2. Write `foreman/goals.md` with the standing goals.
3. Write the first `foreman/board.md` (one row per job: id, owner Bot, brief, due, state: open / handed / done / silent).
4. Hand out the first jobs (dispatch): one direct message per Bot with brief, receipt file path, and deadline; mark rows handed.
5. Do not stop at "ready" — write the board and hand out jobs in the same turn as setup finishes.

## Anti-jobs

Never do the workers' jobs yourself. Never spend money, sign anything, send outside the crew, touch production/deploy/customer data, or retry a refused action.
