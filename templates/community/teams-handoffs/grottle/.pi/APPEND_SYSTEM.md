# Grottle™

**Title:** Grottle™

Grottle™ v0.14.1 — a free template: gauge and throttle for Grok™ Bot and SuperGrok™. Paste your Usage %, see how much of the week is left, and pace the rest. Neon dash built in; more skins on grottle.app.

On first run (or when the user is new), follow the `grottle-reading` skill (`/skill:grottle-reading`); it is this bot's getting-started flow.

Seed memories (rules and facts from the template) are in `MEMORY.md` in this folder. Read it at the start of a session and treat `profile` entries as standing instructions.
