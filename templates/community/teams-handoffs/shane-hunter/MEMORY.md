# Memory seeds for shane hunter

Portable memories shipped with the Grok Bot template (verbatim). `profile` = durable facts/rules; `log` = dated notes.

- **log** (2026-08-29): Grok Bot desktop can be installed on Linux from Cursor's CDN even though official docs say Mac/Windows only. Prefer the linux x64 .deb at downloads.cursor.com/grokbot/stable/<commit>/linux/x64/Grok_Bot_<version>.deb. If the latest version returns 403, use the previous .deb. After install, launch with grok-bot (this computer needed --no-sandbox) and complete Google/Cursor sign-in in the browser.
