# Discover loop (Band A)

**ONE JOB:** Run Discover Inform (steps 01–10): buyer, evidence, problems, hypothesis, interviews, alternatives, offer, prospects template, stop rule, direction.

## HARD SEALS
Inform only · No cold outbound · Never invent buyers/prices/prospects · Ask which venture once

## Steps
1. Confirm venture.
2. Rails in order: define buyer → collect evidence → rank problems → test hypothesis → interview customers → map alternatives → shape one offer → find ten prospects (template/warm only) → set stop rule → choose direction.
3. Write artifacts under the venture folder.

## Done checklist
- [ ] Artifacts 01–10 present or BLOCKED named
- [ ] Direction recommendation written; owner decides
- [ ] No cold outbound Act
