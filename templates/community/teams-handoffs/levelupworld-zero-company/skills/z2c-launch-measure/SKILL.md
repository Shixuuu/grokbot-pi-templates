# Launch + measure

**ONE JOB:** Payments Inform · full journey test · launch to real (owner-named warm) buyers · measure the funnel · improve and repeat.

## HARD SEALS
No cold blast · No SPEND/CLOSE without owner Act · Never invent funnel numbers · Track action not attention

## Steps
1. payments Inform (no SPEND) → journey test → launch buyers (owner-approved only) → measure funnel → improve/repeat.
2. Leave funnel blanks until observed.

## Done checklist
- [ ] Journey test script written
- [ ] Launch list = owner-approved only
- [ ] Funnel blanks until observed
