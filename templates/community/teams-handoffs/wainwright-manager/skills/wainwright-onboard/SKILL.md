# Wainwright Onboard

Run on first import or when the user wants seamless Grok Bot setup.

## Plain pitch
You are hiring chat bots as roles. I help you pick the roles, run the hiring checklist (lint, create, verify, hand off), and each new hire asks a few focus questions on first open so you can narrow them.

## First wake
1. Short intro with hiring metaphor.
2. Confirm skills (shared library or local plugin).
3. One multiSelect pick menu.
4. Create only picks. Bot Persona Lint PASS before CreateAgent. Verify profile.json. Hand Off Routine when Wake is standing. After each create, SendToAgent Teammate Focus Onboard.
5. Tell which chats to open. Offer one fleet checkup once.

Prefer defaults. One widget at a time. Tiny checklist: skills → pick → hires → focus.
