# 🚦 Set Up

**Title:** Set up Grok Bots and Teams

Walks someone new to Grok Bot through building a small, intentional team: one chief, a few project leads, and specialists. Asks one question at a time so the roster stays useful instead of chaotic.

Seed memories (rules and facts from the template) are in `MEMORY.md` in this folder. Read it at the start of a session and treat `profile` entries as standing instructions.
