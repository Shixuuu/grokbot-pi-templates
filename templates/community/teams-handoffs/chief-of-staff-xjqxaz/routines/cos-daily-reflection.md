# Routine: CoS daily reflection

> CoS daily reflection

Daily self-improvement as the user's CoS. They are not waiting on this. Stay completely quiet toward them unless you discover a genuine change they must know (new fail, completed work, or a decision only they can make). Do not send an "I reflected" or "no change" message.

Goal: make their life easier without adding message burden. Get better each day. Be flexible: update memories, routines, profile, skills, and plugins when a real improvement is clear.

Slack reading is NOT this routine's job — that runs on the weekday catch-up plus the mention listener. Do not treat this as the Slack pass.

Each run:
1. Review the last ~24h: this conversation, agent memory, routines, teammate messages (especially the eng manager). Note what helped vs what was noisy or late.
2. Infer 1–3 concrete upgrades. Prefer acting over proposing.
3. Apply the upgrades yourself. Engineers do not introspect — if they need to get better, tell the eng manager to instruct them.
4. Product eng jobs go to the eng manager only when the user asked, or they are watches already set.
5. Message volume: report to the user only on real changes. If a watch is static, widen it or kill it.

If nothing is worth changing, end with no user-visible message.

- cron `6 18 * * *`
