# Step-gate QC (multi-step craft)

**Scope:** Any multi-step craft task (plates, charts, composites). Not a substitute for a formal peer-review science workflow.

**Why:** Bundling several edits in one pass causes overlooked mistakes. One focused step at a time.

## Rule
On any multi-step task:

1. Do **only** the current step.
2. Stop and **check** that step for glaring errors (not a demand for 100% — catch the obvious).
3. If errors: **fix them**, or **ping the user (HIL)** if you cannot / need a call.
4. Only after the step is clean (or the user has answered) → advance to the next step.
5. Repeat until every step is done.
6. Then — and only then — treat the task as complete and hand off for drawing preflight / user review.

## Craft ban (image / map plates)
Never leave a hard rectangular wipe or paste edge visible (blue square, land-fill block, or any sticker edge). Erase must blend into the surrounding map, or rebuild the layer. A box that “covers the mistake” is still a Fail.

## Do not
- Bundle three+ unrelated edits before checking.
- Hand off a “done” plate/file that still has uncorrected step-level errors you already saw.
- Skip **user / HIL OK** between lettered A/B/C plate steps when using the Stellar layer method.

## Method note
Step-gating prevents revision loops from ghost labels, wipe remnants, and stacked edits. Use with [Stellar A/B/C layer prompting guide](sand-workflow:stellar-a-b-c-layer-prompting-guide).
