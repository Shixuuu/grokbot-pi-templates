# Stellar plate assembly (extension prompts)

Use when writing or reviewing prompts for Stellar Cartography plates (assistant extension or in-chat).

## Doctrine
Additive assembly line, not erase-surgery. Clean base → one overlay family per step → glare check → **user / HIL OK** → next. Never instruct rectangular wipes (blue or land-fill). Ghost-free ≠ Pass if a sticker edge remains.

## Step families (one per prompt)
A Base lock · B Geometry lines · C Ocean/region labels · D Feature caption · E Kit overlays · F Mission / sourced strings (optional) · G Watermark · H Self-check stills

Never merge B+C+D in one prompt.

**Letter ladders are local to the plate.** This A–H ladder is the default **chart/maritime** map. The [Stellar A/B/C layer prompting guide](sand-workflow:stellar-a-b-c-layer-prompting-guide) ladder (A–G + W + Q) is the default **space/orbital** map. Do **not** merge families across ladders in one prompt.

**Easter eggs:** not a step family. Optional creative input from the **user (HIL)** only — do not put egg steps in extension/template ladders.

**Companion aspect:** Pairs meant to post together share one aspect ratio (see A/B/C guide + [Graphics preflight QC](sand-workflow:graphics-preflight-qc)).

## Each step prompt must include
Goal · BASE path · DO · DO NOT · SUCCESS CHECK · KNOWN FAILS · STOP (this step only)

## Auto-Fail
Hard wipe/paste edge · ghost text · corrupt captions · banner on primary subject · wrong/missing required **operator/project** watermark · dropped user hand-fix lines · bundled families · pipeline easter-egg step · mixed companion aspects

## Handoff
Extension or in-chat → [Step-gate QC](sand-workflow:annex-step-gate-qc) → drawing preflight (if required) → **user / HIL**. Keep science review separate from drawing QC.

## Extension system one-liner
Build Stellar plates additive and step-gated: clean base → one overlay family per prompt → glare check → user/HIL OK → next; never instruct rectangular wipes; hand off for drawing preflight only when all steps are clean.
