# Graphics preflight QC

Use when preflight-checking a craft still (Pass/Fail drawing QC before the user posts).

## Scope
Check the **drawing only**. Do not rewrite the briefing. Do not invent OEM or measurements. Facts stay with science review.

## Checklist
- Every leader touches the feature it names
- No dimension line dies at mid-span
- Width is across the near face, not down the vanishing deck
- Length is hub-to-hub × gaps, or labeled catalog / not this still
- Hard numbers are not sitting next to an OPEN conflict
- Credit is readable
- Required watermark present when the project uses one: lower-right, ~100×100, ~35%, not covering text or primary elements
- Restraint: no markup or spectacle beyond what the still’s information load needs
- **No hard rectangular wipe/paste edges** (blue fill, land-fill, or any “sticker” block over map/ocean). A clean box that does not blend into surrounding map is an automatic **Fail** — same class whether blue square or land-fill patch. Ghost-free is not enough if the edge is visible.
- **Spellcheck / context labels:** Read every visible word on the still (title, footer, ocean/land names, banners, legend). Fail real typos and misspellings. Also Fail **geo-homophones / near-words that conflict with chart context** (e.g. “Golf” over the Gulf of Mexico, “see” for “sea” on water, “strait”/“straight”) — both words can be dictionary-valid and still wrong for the map. If unsure, Fail and name the string.
- **Companion / carousel aspect:** If this still is meant to post with another plate, both must share one aspect ratio. Flag mixed sets (e.g. 9:16 + 1:1) — do not treat as a clean pair handoff. Fine type dies when the taller frame is crushed.

## Decorative asides
Optional jokes or decorative asides may appear if the **user (HIL)** added them. Do **not** Fail them as clutter by default.
**Exception:** If an aside is a near-miss of a real geographic label (Golf/Gulf, etc.) or otherwise looks like a typo in context, **Fail or flag it** unless the user pre-cleared that exact wording. Prefer wording that cannot be mistaken for a misspelled place-name.

## Reply format (four lines only)
Pass or Fail
What failed (one line each)
What to fix
What you did not check (facts stay with science review)

If a line is short, say the line is short.
