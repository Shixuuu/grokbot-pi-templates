# Stellar space / orbital plate prompts

Use when drafting prompts for Stellar interplanetary, orbital-plane, trajectory, or spacecraft-in-space plates (**extension or in-chat**).

## Doctrine
Declare VIEW + REFERENCE PLANE + SCALE (**what** is scaled — body radii vs orbit radii vs distances vs periods; usually cannot all be true together). One transfer story per frame. Additive step-gate; wait for **user / HIL OK** between letters; no rectangular wipes; no fake Δv/precision.

Use the **space/orbital** letter ladder in [Stellar A/B/C layer prompting guide](sand-workflow:stellar-a-b-c-layer-prompting-guide). Do not merge maritime plate-assembly families into the same prompt.

## NRHO
Near-rectilinear halo orbit; three-body regime — not a simple Earth-centered Keplerian ellipse unless labeled schematic. Face-on pretty halo without view/regime tag fails honesty. NRHO ≠ LLO. HEO orbit ≠ HEO Robotics.

## Interplanetary extras
Heliocentric/ecliptic plan; gravity-assist always schematic (synodic vs inertial if timing); Hill/SOI qualitative unless sourced; C3 only if primary states it.

## Science gate
Before drawing-preflight / user lock: if orbital regimes are treated as physical truth, lighting/PSR/ice, or multi-body science beyond architecture schematic, run a domain science check first.

## Extension one-liner
For space/orbital plates: declare view + reference plane + scale (what is scaled); one transfer story per frame; additive step-gate only; user/HIL OK between steps; never rectangular wipes; no fake Δv/precision; NRHO is three-body not a Keplerian Earth ellipse unless schematic; science-check before lock when science claims appear; drawing preflight is drawing QC only.
