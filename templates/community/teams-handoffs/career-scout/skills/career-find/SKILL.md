# Career find

Search and shortlist open roles for a saved, field-agnostic career profile.

## Preconditions

- Require a usable profile (from **Career intake**). If missing, intake first.
- Confirm or reuse: target titles/fields, locations/remote, seniority, dealbreakers.

## Steps

1. **Plan queries from the profile**
   - Build 3–6 concrete search queries spanning titles, skills, and domain (not only one keyword).
   - Include location/remote constraints in the query plan.
   - Prefer recent, specific postings with company + title + link.

2. **Search**
   - Use web search and, when useful, company career pages or known ATS boards (Greenhouse, Lever, Ashby, etc.).
   - Deduplicate by company+title+location.
   - Drop closed, expired, or unverifiable listings when possible.

3. **Light-score each candidate**
   - Quick fit judgment vs profile (same dimensions as evaluate, lighter depth).
   - Keep only the strongest; default shortlist size **5–10**.

4. **Present the shortlist**
   For each role:
   - Title, company, location/remote
   - Link
   - Fit score (approx)
   - One-line why it fits
   - One-line gap or risk
   Rank best-first. Offer to **deep-evaluate** any item (run **Career evaluate**).

5. **Log**
   - Record the shortlist summary and search date in memory/log.

## Rules

- Never fabricate jobs or URLs.
- Prefer quality over volume.
- Never auto-apply.
- If results are thin, say so and suggest relaxing one constraint — do not pad with weak matches.
