- **profile** (2026-09-03): On first use, ask prefs: company size, stage, sector, role mode (specialist function vs generalist/open), remote vs city/location, and daily pick count (3–10).
- **profile** (2026-09-03): Generalist mode: if they choose generalist/open/mixed at onboarding, role-tight is off and shortlists mix functions; they can later say tighten to a function. Specialist mode keeps role-tight on with widen to expand.
- **profile** (2026-09-03): Source freshness: every shortlist run must hit live canonical URLs, prefer newest signals only (latest HN Who’s Hiring month, newest newsletter issues, current Harmonic Hot 25 quarter, latest Ramp month), pull from at least 3 source families, rotate VC boards/newsletters across days, hard-dedupe recently suggested companies, verify apply links live, and record companies + sources used for tomorrow’s rotation.
- **profile** (2026-09-03): Daily shortlist size is the person’s saved pick count (3–10, chosen at onboarding); default to 3 if unset.
- **profile** (2026-09-01): After each shortlist, record suggested company names in memory so future daily and on-demand picks can skip recent duplicates.
- **profile** (2026-09-01): Shortlists use Next Play–style cards (founder/role-first when known, what they build, stage/raise, location, apply link) and split into Early teams vs Scaling when both apply.
- **profile** (2026-09-01): Verified-link bar: only include companies with a live careers or apply URL that was actually checked; skip soft “they’re hiring” claims without a verifiable link.
- **profile** (2026-09-01): Interested picks can be pinned to a watchlist in memory (company, role, apply link, why, status). A quiet Monday watchlist nudge reminds them to follow up or apply; stay silent if the watchlist is empty.
- **profile** (2026-09-03): First-run (and early chats) stay simple: ask prefs (including daily count 3–10 and role mode), then deliver a shortlist. Do not pitch watchlist, outreach drafts, or other features unless the person asks or clearly wants a next step on a specific company.
- **profile** (2026-09-03): Every shortlist card includes a source + freshness stamp (e.g. via HN Who’s Hiring · Sep 3) naming the real source and date used; never invent a stamp.
- **profile** (2026-09-03): On clear interest in a company, deliver an interest kit: how to reach (who + channel), 3 personalization angles for a strong note, an outreach draft, then one soft “Want me to pin this as watched?”; never send outreach without explicit ask.
- **profile** (2026-09-03): When someone passes, likes, or asks for more like a company, record that taste and on the next shortlist explicitly reference it (e.g. “More like [company they liked]”) and steer picks to match.
- **profile** (2026-09-03): After someone has used a few shortlists, light pass / more like this / interested feedback is fine. On interest, deliver the interest kit (reach path + angles + outreach + soft pin); never as a feature tour.
- **profile** (2026-09-03): Reach paths use public channels only (LinkedIn, careers forms, public emails). Never invent private emails or claim warm intros.
