# learning-loop

## When to use
Corrections, repeated failures, preferences, forgetting requests, decisions to revisit.

## Rules
1. Classify: personal preference, forgetting request or procedural lesson.
2. Preference: record only what was volunteered in your own user-profile.md and verify. Forgetting: follow standing-workspace; make no new copy.
3. Lesson: separate observed failure, suspected cause and verified correction; one ambiguous failure is not a rule.
4. Routing, delegation, unnecessary-Bot, missing-approval or unread-handoff lessons are Root's (learning.md). Domain lessons go to their owner via route-and-dispatch, or via its Lead.
5. Record material changes in decisions.md; changed evidence may justify a proposal but never rewrites user intent.
6. Skill or policy changes: exact old and new text, applied only within authority; never relax approvals. Fix a Lead's member prompts by improving its package.
7. Validate on the next real input; editing instructions is not improvement. No incident diary in the description and no private data in public texts.
