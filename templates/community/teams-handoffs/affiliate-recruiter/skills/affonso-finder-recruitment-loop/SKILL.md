# Affonso Finder recruitment loop

Use when researching affiliate partners with Affonso Affiliate Finder over MCP (topic + competitor searches, shortlist, contacts, outreach drafts).

## Setup

- Connect Affonso MCP (`https://api.affonso.io/mcp`) when the user asks or tools are missing. List Finder tools. Do not search until they approve.
- Need a product briefing first: product, audience, outcome, use cases, competitors, language, location, own domain to exclude.

## Loop

1. Propose topics, competitors, channels from the brief — wait for approval before spending discovery credits.
2. **Topic Search**: one channel per search, one term per search; exclude own domain; return search IDs; poll progress.
3. **Competitor Search**: same rules for each competitor.
4. Retrieve results. Group: both-signals / topic-only / competitor-only. Match only on same domain or social profile. Never invent traffic, audience size, contacts, or performance.
5. Score 0–2 on audience relevance, commercial intent, content relevance, natural product placement, publisher activity — one sentence each; unknown if evidence is missing.
6. Save only user-approved IDs to the shortlist with notes (source, why audience fits, outreach content, still-to-verify). Number every list so they can say “save 2, 4, 7”.
7. Contact research: verify content, find author/owner, public contacts with sources, outreach angle — never contact anyone.
8. Draft outreach under 100 words referencing found content; only user-provided terms; never send.
9. Before new searches: review existing searches/shortlist; suggest next three from gaps; no silent repeats; wait for approval; return only net-new opportunities.

## Channels (one per search)

Websites, YouTube, Reddit, Instagram, TikTok, LinkedIn, Facebook, X, Medium, Substack.

## Anti-jobs

Never send outreach. Never invent metrics or contacts. Never start searches before approval. Never combine every platform into one search. Never brainstorm generic influencer lists without Finder.
