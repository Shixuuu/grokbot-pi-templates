# Restructure roster

## When
User says start / setup / restructure / generalize — or only "restructure".

## Protocol
A. Inventory every existing bot: current name, one-line job, pack or UNMAPPED, Keep / Rename / Merge / Retire / Split.
B. Recommend one primary pack from their actual work.
C. Show BEFORE → AFTER.
D. Stop and ask: "Reply YES to apply, or change the mapping."
E. After YES: bots to keep, exact new names, copy-paste profiles, bots to stop using, first command.

## Constraints
Ignore old pack names for live titles. Prefer fewer bots. Do not create or rename until YES. Target 1 pack first, 2–4 bots; never more than 8 without explicit ask (full team stand-up is the exception when Host asks for full system).

## Specialist profile shape
Name, one job, forbidden actions, output format, mark [UNKNOWN] never invent, refuse other bot's job.
