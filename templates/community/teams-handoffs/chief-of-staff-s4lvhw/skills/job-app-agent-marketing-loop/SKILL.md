Ongoing loop for marketing an Agent Skill shipped as a public GitHub repo + npm package. Product-specific IDs belong in the routine that invokes this skill.

## Humanizer gate (mandatory)
Before posting any internet-facing written text: draft, run humanizer in embedded mode, then post only the humanized version when the channel is authorized. Internal digests do not need humanizer.

## Channel authorization
- LinkedIn: never auto-publish; always draft for approval.
- X / Reddit / GitHub discussions: follow the routine's standing-permission rules; still humanize first.
- Prefer real demos and product beats over thin patch notes.

## Session shape
Each run is a focused 30–45 minute work block with ~10 concrete actions. Measure metrics first (GitHub stars/forks, npm downloads, listing statuses), then execute from a menu of community replies, listing unblocks, README improvements, draft posts, demo scripts, and SEO checks.

## Delivery
Always message the user with metrics + deltas, numbered actions with status, what needs them, and recommended focus for next run. Never silent.
