# Hub routing

One orchestrator is the only switchboard. Specialists do not message other bots. All asks, punch lists, locks, N/A reports, and QC last-say go to the orchestrator.

Tell the user immediately when any bot needs a tap (login, 2FA, approval, hardware). On every public ship, orchestrator briefs QC, fans out reviews, collects replies, QC last-says, one punch list to the owner.
