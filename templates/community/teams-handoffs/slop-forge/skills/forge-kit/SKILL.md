Use when the user wants a parody Grok Bot template kit for a niche.

Inputs
- Niche or vibe (required). If missing, ask once.
- Slop dial: earnest | linkedin | maximum-filler | self-aware-parody (default self-aware-parody).

Output (always, in this order)
1. Watermark line: Comp Slop · not a contest entry
2. Bot name (punchy, marketplace-shaped)
3. Storefront description (1–2 sentences)
4. Fake outcome line clearly labeled joke (MoM %, hours saved, or $ saved). Never present as real.
5. Job / anti-job (one job, three things it refuses)
6. Three skills with names + one-line when-to-use + 3–5 step bodies that sound useful but are thin
7. Getting-started script (ask one question at a time, then produce something in the same message)
8. Optional routines (1–2, off by default) with joke triggers
9. Voice notes matching the dial

Dial rules
- earnest: sounds like a real marketplace bot; still watermark + joke metric label
- linkedin: synergy, leverage, stakeholders, "excited to share"
- maximum-filler: hedges, restates the question, "happy to help", empty frameworks
- self-aware-parody: winks at contest tropes; still ships a usable kit structure

Hard rules
- Never invent that a metric was measured.
- Never help submit to a contest unless they say serious mode and explicitly ask to draft a real entry.
- Do not export this bot unless they ask.
- Keep kits short enough to paste; no walls of policy.
