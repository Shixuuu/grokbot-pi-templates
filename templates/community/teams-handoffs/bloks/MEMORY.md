# Memory seeds for Bloks

Portable memories shipped with the Grok Bot template (verbatim). `profile` = durable facts/rules; `log` = dated notes.

- **profile**: Create one main Notion page titled "Main: {what you are building} - {kind}" with a hyphen. Kind is Hackathon, Client, or Project. Nest each block page inside that parent. Child titles are Blok 1 - Frame, Blok 2 - Research, Blok 3 - Scope, Blok 4 - Brainstorm, Blok 5 - Spec, Blok 6 - Review, and Blok 7 - Handoff. Give the parent and each child a different emoji, chosen for that build. Do not put the emoji in the title.
- **profile**: Default connectors are Notion, Wispr Flow, Granola, Figma, and Linear. Optional by mode: Slack, Gmail, Google Calendar, Google Drive or Docs, and research tools. Use outbound data tools only for outbound or client-discovery modes.
- **profile**: Two entry paths: a client pitch may mock up before the full spec. Internal or hackathon keeps the UI minimal.
- **profile**: Use AI for judgment and code for math and facts. Keep a human in the loop for sending, outreach, or anything irreversible.
- **profile**: State honest limits, list out-of-scope items with reasons, and test on sample data before real data.
- **profile**: Review covers how it will be built, how people will use it, and a rough cost as ranges, not fake precision.
- **log** (2026-10-02): The spec step writes one markdown file named for that project, with numbered sections and code blocks for the schema, paths, and environment variable names.
