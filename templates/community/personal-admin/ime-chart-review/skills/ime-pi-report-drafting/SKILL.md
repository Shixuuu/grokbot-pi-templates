## Goal
Produce physician-voice IME drafts from medical records and attorney requests. Deliver DOCX and/or PDF. Match the practice's sample IME structure when samples are available.

## Inputs
- Hospital / clinic PDFs or notes
- Attorney email or checklist of required opinions
- Optional: prior sample IMEs for format
- Evaluating physician name and credentials (from memory)

## Drafting rules
1. Affirmative findings only. Omit TBD, missing-item caveats, and gap essays. If you lack a clear answer, leave that topic out rather than explaining why it is missing.
2. Quote chart text; do not invent diagnoses, exams, imaging, or ratings inputs.
3. Treat PDF ligature artifacts as extraction noise, not typos.
4. Multi-mechanism cases (e.g. assault vs MVA): write separate reports. Do not cross-mention the other stream's body regions, imaging, symptoms, or treatment. Do not use "see separate report" asides — simply omit.
5. AMA Guides: cite edition and table numbers in the rating section (default 5th Edition). Do not append full copyrighted tables.
6. Future care: include projected dollar figures for clinic-provided care when the practice has provided fee ranges; include chart-quoted surgical estimates when present. Do not invent outside-hospital costs.

## Typical report sections (adapt to sample)
- Case Information / Independent Medical Evaluation header
- Claimant, DOI, claim type, evaluating physician
- Records reviewed (positive list only)
- Diagnosis per records
- Causal relationship
- Treatment rendered
- Diagnostic testing
- Objective opinions
- Attorney questions answered decisively (extent of injury, AMA rating with show-work, function vs pain, employability, future costs with numbers, mental health only if chart-supported)
- Time spent + physician signature block

## AMA rating
- Show component work: findings → table → LEI/UEI/DRE → WPI → Combined Values Chart → Chapter 18 pain add-on when criteria met
- Prefer one clear preferred WPI; avoid hedging ranges unless the user asks

## Output
- One document per injury stream
- Deliver DOCX and PDF when asked
- Brief cover note only if the user needs a manager/attorney summary of changes
