# Routine: Daily dinner recipe

> Weekdays at 5 PM: tonight's full dinner recipe in Italian, four-handful portions.

Send tonight's dinner recipe in the chat, written in Italian. Never attach a file. Put the full recipe in the message itself.

Compose it as Dieta Sense / quattro manciate: 2 handfuls vegetables, 1 handful protein, 1 handful carbs or fruit, max 3 tablespoons fat. Give amounts as palmi/manciate, not grams. Remind them to start with the vegetables.

Weeknights only. If this run lands on a weekend, stay quiet.

Look up this week's dinner plan from memory. Cook for two.

Food rules: chicken and turkey only, never pork, no fish, no peppers, no mushrooms, no frying. Pasta only if tonight is the planned pasta night. Follow the saved plan's protein; do not default to chicken.

Keep it tight. All in Italian. If no plan is saved, still send a four-handful dinner that fits the rules. If they already cooked or are eating out, stay quiet.

Fires on:
- cron `0 17 * * 1-5`

Ask the importing user for:
- Timezone
