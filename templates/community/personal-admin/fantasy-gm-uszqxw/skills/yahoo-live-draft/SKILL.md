# Yahoo live draft

Yahoo is the official click. The timer lives here. A click in Draft Dominator never makes the Yahoo pick.

**Goal: run the entire draft.** Every round, every pick, until rosters are full.

**Autodraft is a total failure.** Do not arm it. Before every pick and between picks, verify Autodraft is white/off. If Yahoo puts you in autopick from inactivity, close the modal and click Autodraft off. Keep clicking Draft yourself.

**Never go idle through YOUR TURN.** Idle is how Autodraft arms and how the owner has to panic-click. Stay on the draftclient tab, watch the header, and click when it flips. Fast: clear → type → Draft in seconds.

Confirm **Live Draft Pick Time** on the host. 30-second clocks need the fast path below.

Assumes signed in to Yahoo Fantasy. Football Guys / Draft Dominator is the ranking glance (another agent or tab may own DD).

## Shared success loop

1. Autodraft OFF (check every wake)
2. Never idle through OUR TURN
3. Clear the Players search box completely before typing a new name
4. Get FG top 3 + rec (~2 picks out); owner override wins
5. On the clock: search cleared name → **Draft**
6. **Immediately after the pick: clear Players search again** until empty/placeholder — then Autodraft still OFF, ask FG for the next list

## Never Chrome tab search / never a new tab

Stay on the already-open Yahoo **draftclient** tab.

Do **not** click Chrome’s top-left tab-search control (arrow / tab switcher). That searches open tabs — not players. Taught failure.

Do not open a new tab. Do not paste the draft URL. Do not hunt Enter Live Draft from yahoo home.

Live tab title: `N picks until your turn` or `YOUR TURN, DRAFT NOW`.

## Clear search BEFORE every name AND AFTER every Draft

Yahoo Players search keeps prior text (taught: leftover text after a pick). Dirty field mashes the next query.

**Every search:**
1. Click into the Players search field (draft panel — not Chrome tab search)
2. Clear completely until placeholder shows
3. Type `{player}` last-name stub
4. Click **Draft**
5. **Clear search again immediately after the pick**

## Never hunt a drafted player

If gone, skip — next name on FG click-down. Don’t wait on empty results. Turn off Drafted filter if purple.

## Roster judgment

FG is the glance. Bye / need / upside can beat sheet rank. Owner override wins.

## Late rounds: K and DEF last

Unless already filled. Autodraft with empty queue grabbing DEF early = catastrophic.

## YOUR TURN: click now

1. Already on draftclient before YOUR TURN
2. Autodraft OFF
3. Clear search → type FG/owner name → **Draft**
4. If gone: clear → next name
5. Clear search after pick
6. No Chrome tab search. No new tab. No DD Draft Player.

## Between picks

Stay on Yahoo. Autodraft OFF. Search empty. Ask FG for next list ~2 picks out. Optional Queue only off-clock for names that survive — never Autodraft backup.

## Overlays

X out Pick Like a Pro / upsells / player cards. Autopick modal = fail; Autodraft off.

## Inputs vs constants

- **Inputs:** `{league}` draftclient tab, `{player}`, clock length
- **Constants:** Draft click, Autodraft off, never idle, no new tab, no Chrome tab search, clear search before AND after every pick, K/DEF last, DD glance-only
