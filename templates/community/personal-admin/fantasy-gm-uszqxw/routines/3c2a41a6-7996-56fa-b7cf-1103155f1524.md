# Routine: Saturday lineup check

> Fires Saturday evening to catch injuries and set contingencies before Sunday kickoffs.

Timing: Saturday evening in the owner's timezone.

1. Ask the research IC for the Saturday injury report, inactive risks, and start/sit updates across starters and bench handcuffs in every league the owner named.
2. Message each host IC to verify starters, swap obvious OUT or Doubtful players, and promote rostered handcuffs.
3. Roster hygiene: move newly IR-eligible players into empty IR slots. No drops without the owner's yes.
4. Lock contingencies for Sunday game-time decisions so later passes can flip without re-asking. Flag any handcuff worth a free-agent add if a starter goes down.
5. Owner digest only if a change is needed; stay quiet if all set. Run even if the owner set lineups themselves.
