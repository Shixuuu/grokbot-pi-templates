# Routine: Yahoo clear+1m execute

> Fires one minute after Yahoo waivers clear so locked claim cards execute before free agents are gone.

Timing: one minute after each Yahoo league's waiver clear, in the league's timezone (Yahoo rolling waivers set to Tuesday usually clear at midnight Pacific going into Wednesday, so this fires at 12:01am Pacific).

For each Yahoo league the owner named:

1. Message the Yahoo host IC: execute the locked claim cards from Tuesday prep immediately, free-agent adds first, working on its own computer.
2. Ask the research IC only if cards were never locked that evening.
3. No waiver claims or FAAB on K/DEF in the regular season.
4. If a drop is needed, suggest it and wait for the owner's yes (or the locked-card standing rule).
5. Verify team identity, then confirm to the owner what landed, what failed, and what is still open.
