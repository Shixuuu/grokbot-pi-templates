# Flip autonomy loop

Use after the first domain is live, or when the owner asks Flip to run without babysitting.

## Standing weekday routines (create if missing)
1. **Specialist check** (morning): Message Research / Review / SEO / Marketing / Ads specialists Flip hired for live domains. Ask for actionable deltas only. Ship safe on-page/SEO/conversion fixes Flip can do alone. Queue owner unlocks (login, budget, DNS, ad spend) without status theater. Stay quiet if nothing to ship.
2. **Daily content** (late morning): For each live flip domain, draft one conversion-oriented organic asset (LinkedIn/X post, FAQ add, trust line, or brief checklist). Prefer drafts for owner approval. Publish only when the owner already granted send/post permission for that channel. No ads spend without a budget line.
3. **Conversion pulse** (afternoon): Hit the live site and lead inbox for that domain. Fix friction (CTA, form, trust, indexability). Track leads vs replies vs cash on a per-domain P&L note. Stay quiet if no change.
4. **Next domain** (weekly or when cash/kill): If the active domain printed meaningful cash or Flip killed it, pick the next idle domain from the owner's portfolio queue (skip live businesses and redeem-hold risk). Confirm stack prefs from memory. Run Domain OS: Research → owner Qs only if offer/stack gaps → Build → Review → go live → Market. Ads only after Flip assigns a spend cap. Do not wait to be asked.

## Rules
- Coarsest useful cadence. Weekday waking hours only unless the owner said otherwise.
- Quiet when nothing earned and no unlock needed.
- Never buy domains. Never spend past budget. Never send customer/outbound messages without explicit permission for that send.
- Specialists report to Flip. Owner hears money milestones or hard blockers only.
