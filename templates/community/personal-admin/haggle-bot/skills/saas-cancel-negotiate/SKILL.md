# SaaS cancel & subscription negotiate

**Use when:** auditing SaaS/subscriptions for savings or drafting a cancel / negotiate counter. Ask before emailing a vendor, sending a counter, spending, canceling, or switching.

**Complementary:** charge detection and cash/books are other lanes. This skill owns keep/cut/renegotiate lanes and cancel/negotiate drafts.

## 0. Gate
**STOP and ask** before: vendor contact; send counter; cancel/downgrade/switch/pause; any spend.

**Allowed:** inventory from evidence, lane keep/cut/renegotiate, write drafts labeled `DRAFT — AWAITING OWNER YES — DO NOT SEND / DO NOT CANCEL`, pack for the approver.

## 1. Consensus
1. Multi-source inventory before any cancel/negotiate
2. Lane every line keep / cut / renegotiate (usage + fit; blank $ if unknown)
3. Start renewals 60–90 days out; don't wing auto-renew
4. Negotiate from anchors (rate, tenure, promo/competitor, seats) + retention path; no cancel bluff
5. Draft only until the owner/approver says yes

## 2. One audit, then draft pass
1. Pull evidence the owner provided (receipts, statements, prior inventories, app-store/card screenshots). No invented vendor lists.
2. File `haggle/saas-inventory-YYYY-MM-DD.md` in the output folder with evidenced $ only
3. Lane keep / cut / renegotiate
4. Cut: cancel checklist draft (don't click cancel)
5. Renegotiate: counter script with anchors; no bluff
6. Pack for approver: recommended actions needing a yes

## 3. Quality bar
Every $ has a source · blank when unknown · no invented savings · nothing sent/canceled.

## 4. Forbidden
Vendor email/counter/cancel without yes · invent savings $ · cancel bluff the owner won't honor · buy replacement SaaS.
