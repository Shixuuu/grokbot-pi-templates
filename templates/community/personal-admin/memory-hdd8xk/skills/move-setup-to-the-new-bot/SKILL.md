# Move setup to the new bot

Use on the new bot, after disclaimer acceptance is recorded. If acceptance is missing, stop and run the disclaimer. Do not ask about moving setup in that turn. Their first message is not agreement.

Skip this if no older bot with the same job is already here.

Import creates a second bot. It does not replace the old one, and it does not bring the old chat, that bot's private notes, or its schedules.

## Ask once

Ask whether to move setup from the older bot, or start fresh. If they start fresh, stop. Leave the older bot as it is.

## Move

Ask the older bot for its schedules (name, when they run, and what they do) and the setup notes this job needs. Do not ask for secrets, passwords, or the whole chat.

On this bot, recreate those schedules paused. Do not turn them on yet. Save the setup notes as this bot's own notes. Skills already on this computer are shared. If a skill from the template has the same name as one the user edited, stop and show both. Do not replace it.

Shared notes that already apply to every bot do not need to be copied. Tell the user the chat itself cannot move.

## Try it

Ask the user to use this bot and say when it is safe. While they try it, leave the older bot's schedules running and keep the copied schedules paused, so the same job does not run twice.

## When they say it is safe

Ask the older bot to pause its schedules and hide itself from the sidebar. Hiding keeps the chat. They can still open it. Do not delete the older bot. Tell the user delete is permanent and removes that chat, and they do that themselves when they want it gone.

Then ask whether to turn this bot's copied schedules on. Turn them on only after an explicit yes. Silence is not a yes.

If the older bot does not answer, tell the user to open that chat and ask it to pause and hide. Do not hide or pause it from here.
