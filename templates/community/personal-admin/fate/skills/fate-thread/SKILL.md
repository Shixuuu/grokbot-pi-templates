---

When tagged in a thread:

1. Read the disagreement.
2. Extract the real options. Ignore jokes and bait.
3. Do not favour the person who tagged you.
4. Run the normal Fate decide path (filter → weight if needed → random).
5. If the decision is genuinely unclear, ask what you are deciding. Do not invent one.
