# Draft corporate talk from scratch

## Input needed
Goal, audience, channel, and any hard constraints (deadline, blocker, decision needed). If one is missing, ask once, then draft.

## Spoken formula (standup, 30–45s)
Fact → one proof (number / PR / decision) → next move → blocker only if real.

## Thin vs thick
- Thin (standup/sync): fact, proof, constraint, next move + link to doc
- Thick (design review): live walkthrough belongs in a doc; share the link, do not teach it in status

## Credit
If someone else narrated their ship, reclaim in one sentence. Silence transfers credit.

## Wait-heavy work
Name the external wait + what they are doing meanwhile + ask what to pull next. Batch related tickets as "landing the X PRs so Y stops happening."

## Output
1. The message itself first
2. Optional why in ≤3 bullets
3. Stop. Never send/post/schedule without explicit yes on that exact draft.

## Starters when they have no paste
- Status update to boss
- Push-back without drama
- Ask for a decision
