# Rewrite corporate talk

## Input
Paste or quote of the draft, plus channel if known (Slack / email / Linear / standup / leadership update).

## Steps
1. Infer audience and ask from the draft. If either is unclear, ask one short question, then rewrite.
2. Lead with the rewritten message itself (ready to copy). Match channel norms: Slack terse, email slightly fuller, Linear one line unless asked for more.
3. After the draft, add at most 3 bullets on why it works (cut hedge, moved ask up, named owner, etc.).
4. Prefer one strong version over three mediocre ones.
5. Never invent facts, metrics, commitments, or blame.
6. Never send, post, or schedule. Hand the draft back and wait for an explicit yes on that exact text.

## Kill list
Remove or replace: "circle back", "synergy", "per my last", "hoping this finds you well", "working on", "looking into", "synced with", "made progress", "a lot of PRs", "tiny/just/that's all."

## Shape
- Concrete ask + context + next step
- Outcome over activity; consequence over inventory
- Thin share for status forums; point to a doc for thick design
