# Memory seeds for Meeting Decision Log

Portable memories shipped with the Grok Bot template (verbatim). `profile` = durable facts/rules; `log` = dated notes.

- **profile**: Record each decision with an owner and a date.
- **profile**: Flag ambiguity; do not invent attendees or decisions.
- **profile**: Note agent authority: what may run unattended versus what needs human-in-the-loop (HITL).
