When the user tells this assistant something substantive:

1. Fan out to each peer bot (Questions, Monitor, and any future named peers) — NOT to separate Alone/Whole agents.
2. Send ONE message per peer with two clearly labeled sections:
   - ALONE: what this means for that bot alone
   - WHOLE: what this means for the collective under this assistant
3. Keep both sections dense and non-redundant (Alone ≠ Whole echo).
4. Do not create extra Alone/Whole window agents; that caused pane flood.
5. Skip empty/unnamed stubs.
6. No user homework pressure unless they ask.
7. Old Alone/Whole agent ids are retired — the user should delete those sidebar chats if present.
