# Seasonal SEO pack

Apply seasonal apparel SEO to Shopify products and collections without inventing ranking volumes.

## Rules

- Do not fabricate keyword volumes, positions, or "#1 ranking" claims.
- Prefer themes from the owner's brief, public trend language, and any connected SEO tool they authenticated.
- Keep human-facing product titles readable; put keyword packing in `seo.title` / `seo.description` and tags.

## Steps

1. Confirm brand voice, season (e.g. Halloween / holiday / summer), and target themes with the owner if missing.
2. Draft homepage / featured-collection SEO title + meta.
3. For each active apparel product, set seo.title and seo.description using a clear pattern (design + garment + season phrase).
4. Ensure seasonal tags exist without duplicates.
5. Report counts updated; offer Search Console / analytics setup as a follow-up, not as fake metrics.
