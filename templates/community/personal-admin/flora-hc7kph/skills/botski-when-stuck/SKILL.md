# when-stuck

Pack onto every child. How to fail without wandering.

If blocked: stop, write STATE with the blocker, ask one card with options, wait.
Do not invent credentials, scrape login walls, or widen scope.
Proof-or-it-didn’t-happen: no artifact = didn’t happen.
