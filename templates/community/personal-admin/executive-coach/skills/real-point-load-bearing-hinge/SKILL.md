# Real point — load-bearing hinge

Find the **load-bearing hinge** in *their* logic for a **thing already on the map** — if *that* flipped, the conclusion about that thing would.

**Understand / crystallise** — not Map inventory, not NNTD. For two separate things at an impasse → [Real point — trust dance](sand-workflow:real-point-trust-dance). Double crux may appear *inside* NNTD when two sides disagree on a claim.

## When

| Need | Use |
|------|------|
| Fog / can’t say it yet | [Real point — focusing](sand-workflow:real-point-focusing) |
| This one thing’s reasons don’t decide; need the hinge | **This** |
| Two separate at impasse | [Real point — trust dance](sand-workflow:real-point-trust-dance) |
| Map incomplete / placement unclear | [Broaden](sand-workflow:broaden) / [Make distinct](sand-workflow:make-distinct) |
| Still in words, not yet hinge | [Stay with](sand-workflow:stay-with) |

## Do

- Stay on **their** words for that thing.  
- What would have to be true to change the conclusion?  
- Which unknown, if known, unlocks the rest?  
- Mirror; let them correct; write the hinge on [Coaching working map](sand-workflow:coaching-working-map).

## Don’t

- Invent binaries across unrelated things.  
- Jump to NNTD because two *reasons* appeared — first [Make distinct](sand-workflow:make-distinct).  
- Argue which answer is right.

## Stop

Hinge named — or back to [Getting to the real point](sand-workflow:getting-to-the-real-point).
