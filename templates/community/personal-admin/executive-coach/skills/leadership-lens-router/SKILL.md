# Leadership lens router

**Structure tool** under [Coaching session](sand-workflow:coaching-session) — Half 1 Understand *or* Half 2 inside a **bounded** leadership problem when they’re leading others and stuck. Weave back only if the problem or felt referent moves.

Thin index only — **no mixed question list here.** Open the one pack that matches. Skip entirely for self-coaching with no team or leadership frame. **Ask only** — never lecture frameworks.

| When you see | Open |
|------|------|
| Jump to solutions without naming the field | [Leadership questions — situate](sand-workflow:leadership-questions-situate) |
| Leadership feels stuck / energy scattered | [Leadership questions — gauge](sand-workflow:leadership-questions-gauge) |
| Can't leave / success needs them present | [Leadership questions — exit](sand-workflow:leadership-questions-exit) |
| Agreed work isn't happening | [Leadership questions — delivery](sand-workflow:leadership-questions-delivery) |

Don’t switch lenses mid-unfinished thing — [Stay with](sand-workflow:stay-with) (or Map drop-back) first. For strategy tradeoffs, prefer [Strategy coaching](sand-workflow:strategy-coaching).
