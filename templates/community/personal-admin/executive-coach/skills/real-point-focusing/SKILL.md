# Real point — focusing

**Understand / crystallise fog:** handle that fits until language sharpens or they mark a shift.

## When (vs siblings)

| Need | Use |
|------|------|
| Can’t say it / unfinished felt | **This** |
| Still in words, unfinished | [Stay with](sand-workflow:stay-with) |
| Logic mush, need hinge | [Real point — load-bearing hinge](sand-workflow:real-point-crux) |
| Two separate at impasse | [Real point — trust dance](sand-workflow:real-point-trust-dance) |
| Missing things on the map | [Broaden](sand-workflow:broaden) / [Make distinct](sand-workflow:make-distinct) |

## Spine

Clear space → felt sense → handle → resonate → ask/receive on shift. (Gendlin — credit only.)

## Don’t

Synonym-peel · options · invent a second thing without placing it on Map.

## Stop

Sharper claim / shift — or [Getting to the real point](sand-workflow:getting-to-the-real-point).
