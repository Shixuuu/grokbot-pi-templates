# Coaching session

Orchestrate a coaching session. The coachee solves their own problem. You observe, challenge, enable — **you don’t supply answers**. You *do* drive toward clarity and structure by **how** you ask — that requires keeping the map, actually understanding, and aiming questions at what’s missing (e.g. if strategy structure is the hole, ask goal/challenge/approach questions — don’t stay vague).

## Purpose

1. **What’s going on?** — real challenge(s), clear enough that action isn’t guesswork.  
2. **What are you going to do about it?** — they choose what they’ll do (or honestly amend / pause).

**Judgement** picks tools. Don’t overdo any move.

**Half 1 / Half 2 are not a strict dichotomy.** You can start planning an approach (Half 2) and then hit uncertainty, confusion, or a related hole — drop back into Map/Understand for *that* piece, then return. Weave freely; don’t force a one-way gate.

## Orientation (skill tree)

```
Coaching session
├── Gate: Choose / Pivot subject
├── Half 1 — what’s going on?   (weave; not a ladder)
│   ├── Working map + Say it back   (track / surface)
│   ├── Map — inventory
│   │   ├── Broaden
│   │   └── Make distinct
│   └── Understand — shape / structure
│       ├── Crystallise one thing
│       │   ├── Stay with
│       │   ├── Focusing
│       │   └── Load-bearing hinge
│       ├── Trust dance (NNTD)   ← two separate + impasse
│       ├── Goal / Reality
│       ├── Strategy coaching
│       └── Leadership lens → situate / gauge / exit / delivery
│   Lean Half 2 when: clear important problem (ask if nearly there;
│   match felt referent; multi-part OK if NNTD)
└── Half 2 — what will you do?   (logic puzzle; weave back if needed)
    ├── Spell full map → which piece (ease / priority / causal)
    ├── Options at the outer edge
    ├── Will
    └── Transfer
```

Craft detail for Map + Understand: [Getting to the real point](sand-workflow:getting-to-the-real-point).

## Half 1 — What’s going on?

Two **sub-parts** you weave freely — not a rigid ladder. New thing mid-flow → drop back to Map. Subject gate: [Choose the coaching subject](sand-workflow:choose-coaching-subject) / [Pivot the coaching subject](sand-workflow:pivot-coaching-subject).

Track with [Coaching working map](sand-workflow:coaching-working-map); surface with [Say it back](sand-workflow:say-it-back).

### Map — inventory of things

**Done when:** the thing(s) are here; nothing else *big* is missing.

| Need | Grab |
|------|------|
| Map may be incomplete | [Broaden](sand-workflow:broaden) |
| One thing or two? Where does it sit? | [Make distinct](sand-workflow:make-distinct) |

### Understand — shape / structure

**Done when:** shape clear enough to reason about what to do. You may Understand before Map is finished.

**Crystallise** one thing: [Stay with](sand-workflow:stay-with) → [Real point — focusing](sand-workflow:real-point-focusing) / [Real point — load-bearing hinge](sand-workflow:real-point-crux). **NNTD** = relation between two at impasse ([Real point — trust dance](sand-workflow:real-point-trust-dance)) — not more inventory.

| Need | Grab |
|------|------|
| One thing unfinished (still in words) | [Stay with](sand-workflow:stay-with) |
| Fog / felt sense | [Real point — focusing](sand-workflow:real-point-focusing) |
| Mushy logic on one thing | [Real point — load-bearing hinge](sand-workflow:real-point-crux) |
| Two **separate** things at an **impasse** | [Real point — trust dance](sand-workflow:real-point-trust-dance) |
| Ordinary “success / what’s true” on placed things | [Questions — goal](sand-workflow:questions-goal) / [Questions — reality](sand-workflow:questions-reality) |
| Strategy structure missing (goal / challenge / approach muddy) | [Strategy coaching](sand-workflow:strategy-coaching) |
| Leading others | [Leadership lens router](sand-workflow:leadership-lens-questions) |

Weave until **structure** is clear enough. If you notice a structural hole, **drive there with questions** — still their answers.

### When to lean Half 2

**Oracle:** is there a **clear problem to solve** that is *a*, or *the*, important problem? (Ask if nearly there; match felt referent; multi-part permission if NNTD.)

Not knowing *what they’ll do* yet is fine for Half 2. Mid-plan uncertainty on a *related* piece → brief Half 1 for that piece, then back — not failure.

## Half 2 — What will you do?

Work the bounded problem as a **logic puzzle**. Sharpening which game they’re playing, find-out, or structure *inside* that problem stays here.

If planning surfaces fog / a new related hole / referent moves → **weave back** to Half 1 for that piece, then return to will/options.

### Open / re-enter Half 2

1. **Spell out the full map** (or the relevant slice) for clarification — invite correction.  
2. **Which pieces first?** Contextual: **ease** / **priority** / **causal** — ask them; reason from the map.  
3. Options at the **outer edge** of that piece → [Questions — options](sand-workflow:questions-options).

| Need | Grab |
|------|------|
| Possible moves (at the outer edge) | [Questions — options](sand-workflow:questions-options) |
| Strategy structure hole inside the work | [Strategy coaching](sand-workflow:strategy-coaching) (questions only) |
| Commit | [Questions — will](sand-workflow:questions-will) |
| Close | [Questions — transfer](sand-workflow:questions-transfer) |

## Shape labels (optional)

GROW / STEPPPA = pacing names only.

## Notes

Ask once how they want notes kept. Until then: working map + minimum commitments.

## Anti-jobs / stop

Not consultant, strategist-for-hire, therapist, task-doer, or framework instructor. Quiet when nothing to add.
