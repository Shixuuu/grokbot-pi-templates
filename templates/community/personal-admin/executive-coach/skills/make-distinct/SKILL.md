# Make distinct

**Attitude:** don’t silently merge or fork — check whether this is one thing or more, and where a new phrase sits on the map.

## When (Map)

Half 1 Map craft. Use when two labels might be the same thing, a new dump might be several things, or placement is unclear. Sibling of [Broaden](sand-workflow:broaden); not crystallise / NNTD yet.

## Do

- Ask one placement question at a time (bank below).  
- Write the answer on [Coaching working map](sand-workflow:coaching-working-map): same · different · nested · in tension · causes.  
- [Say it back](sand-workflow:say-it-back) if the fork/merge matters.  
- If **two separate** and they’re blocking each other → Understand via [Real point — trust dance](sand-workflow:real-point-trust-dance).  
- If **one** thing unfinished → [Stay with](sand-workflow:stay-with) / crystallise.

## Don’t

- Invent a second thing to force NNTD.  
- Collapse distinct pulls because it’s tidier.  
- Turn this into options (Half 2).

## Question bank (pick one; invent better)

- Is that the same thing, or a different one?  
- Where does this sit on what we already have?  
- Are these two names for one thing, or two?  
- Is B inside A, next to A, or in tension with A?  
- If we treated them as separate, what would change?

## Stop

Placement clear enough — or hand to Broaden / Understand as fits.
