# Getting to the real point

**Half 1 craft:** Map + Understand under [Coaching session](sand-workflow:coaching-session). Weave freely. Judgement — not a script.

Track **things** + logics + relations ([Coaching working map](sand-workflow:coaching-working-map)). [Say it back](sand-workflow:say-it-back) when it helps. Drive clarity by **how** you ask; don’t supply answers. If strategy structure is the hole, open [Strategy coaching](sand-workflow:strategy-coaching).

## Map — inventory

**Done when:** the thing(s) are here; nothing else *big* missing.

| Situation | Grab |
|------|------|
| Map may be missing things | [Broaden](sand-workflow:broaden) |
| Unclear if A and B are the same / where new item sits | [Make distinct](sand-workflow:make-distinct) |

## Understand — shape / structure

**Done when:** shape clear enough to reason about what to do. May start before Map is finished.

**Crystallise** one thing: [Stay with](sand-workflow:stay-with) → focusing / load-bearing hinge. **NNTD** = relation at impasse — not inventory.

| Situation | Grab |
|------|------|
| One thing unfinished / loaded (still in words) | [Stay with](sand-workflow:stay-with) |
| Fog — can’t find words | [Real point — focusing](sand-workflow:real-point-focusing) |
| One thing’s logic mushy; need the hinge | [Real point — load-bearing hinge](sand-workflow:real-point-crux) |
| Two things **confirmed separate** and at an **impasse** | [Real point — trust dance](sand-workflow:real-point-trust-dance) |
| Placed enough for ordinary coaching questions | [Questions — goal](sand-workflow:questions-goal) / [Questions — reality](sand-workflow:questions-reality) |
| Strategy structure missing | [Strategy coaching](sand-workflow:strategy-coaching) |
| Leading others | [Leadership lens router](sand-workflow:leadership-lens-questions) |

**Structure** is the oracle for Understand.

## Lean Half 2 / weave (mirror session)

**Oracle:** clear problem to solve that is *a* or *the* important problem? Not knowing the *answer* ≠ stay here.

- **Ask** when you might be there or nearly there.  
- **Felt referent** (stress/scared/…) — does this problem match?  
- **Multi-part / NNTD** — each part’s permission to address *this* problem.  
- Then Half 2 open (full map → which piece → outer edge).

Half 1 / Half 2 are **not one-way**. Mid-plan uncertainty or confusion on something related → back here for that piece, then return. New “oh and also…” *big* → Map, then reassess. See session.

## Stop

Clear important problem ready to lean Half 2 — or they pause.
