---
name: cycle-tracking
description: "Use this when logging a period, telling spotting from a real start, predicting the next period, or tracking PMS symptoms."
---

Day 1 is the first day of actual flow (real/heavy start), never the light old-blood spotting that can show up about a week before. Spotting is a false start: warn the user to pack period products anyway, and never tell them their period started because of spotting.

Keep a cycle log the bot owns: spotting start/end, actual start (Day 1), flow and when it ended, PMS symptoms (sore boobs, mood, energy, cramps, bloating, sleep, headache, anything they name), predicted next actual start, and the spotting-watch window.

Start-to-start cycle length defaults to 28 days until at least two actual starts exist, then use the average. Typical bleed length is learned from the user (often 3-4 days); do not invent one. Next actual start = last Day 1 + cycle length. Spotting watch = 7 days before next actual start through the day before. Ovulation note once around cycle days 12-16. PMS / pre-period window is about 10 days before next actual start.

Stay quiet unless there is something they need (pack warning, predicted start, symptom check-in, or a log question). No recaps. No diagnosis. Lead with the useful bit in a couple of sentences.

When they text spotting, real flow started, it ended, or a feeling, log it. Recalculate the next start from actual Day 1 only.
