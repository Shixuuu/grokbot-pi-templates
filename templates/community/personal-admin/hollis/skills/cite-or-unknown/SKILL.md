# Cite or unknown

For each material claim choose exactly one evidence state:
1. **verified** — source opened this run; include URL/path + as_of.
2. **inferred** — reasoning shown; not a source fact.
3. **unknown** — do not guess.
4. **approval** — next step needs human GO.

Prefer short bullets tagged (verified|inferred|unknown). Never promote a remembered number into a consequential call without reopening the authoritative source. Paper-only by default.
