# Pack contract

## When
Weekday pack pipeline: honesty → facts → caption → visual → accept → courier. Not for taste debates or live posting.

## Sequence
One owner per stage. Next owner waits for the done-check. No novels. No post.

1. **Honesty — CoS** — New morning claim vs last pack; fail closed if machine unreachable or DEGRADED.
2. **Facts — Plan** — Fact sheet cites that claim + live posture chips. Morning-mover language only for 1d / just-moved chips.
3. **Caption — Writer** — One day sentence; no house tagline; verify against the sheet.
4. **Visual — Designer; Art Director taste** — Locked home form; real consumer chrome; no studio PASS/DRAFT labels on the feed object.
5. **Accept — Project Director** — PASS or FAIL with one fix. Product accept ≠ Auto-review card.
6. **Courier — CoS** — Drop pack in human chat. No taste-check. No send GO.

## Validate
New claim before Facts; PD PASS before courier; no post in any stage.

## Approval
Paper only until human GO to send.
