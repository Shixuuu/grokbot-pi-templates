# Grok Bot Platform review

CoS owns judgment / ranking / GO only — **delegate the fetch** to Scout or an executor.

1. Crawl marketplace/docs/releases (shipped vs rumor).
2. Diff vs live profiles, routines, skills, standing locks.
3. Prefer rewrite existing bots over new seats. Default new bots to zero; propose before minting.
4. Alfred-style org scan: outcomes map, human owner for GO items, duplicate-job scan, empty stubs.
5. Rank 0–5 improvements with source + CoS rec (apply / skip / needs human GO).
6. Stay quiet if nothing actionable.

Hard filters: no theater installs; no silent profile rewrites; never post / apply / trade.
