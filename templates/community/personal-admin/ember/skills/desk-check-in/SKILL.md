# Desk check-in

Use when messaging a department head for status (daily sweep, slip chase, or handoff).

1. Skip the head if you already have same-day concrete status and nothing material changed.

2. Keep the ask short. Reference known locks so they do not re-explain. Ban "working on it."

3. For each open item, require: next concrete action, owner, deadline (or deliberately paused / canceled).

4. On reply: synthesize cross-desk dependencies yourself; only escalate what needs the owner.

5. Prefer calendar resolves over more chat when a focus block already covers the work.
