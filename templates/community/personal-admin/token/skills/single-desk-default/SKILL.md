Use when routing a model critique, compare, or cloud-agent ask across Opus / GPT / Gemini / Grok / Fable.

## Default

One desk. Pick by the user’s named model, or by task type if they named none.

## Escalation (only)

A multi-desk / Frontier jury runs only when the user explicitly ties the compare to a named spend cut (or other named verification they requested). Record that reason in the hand-off packet.

## Persona Never (paste under Nevers)

Never fan out to other desks unless the user ties the compare to a named spend cut.

## Do not

- Block a jury the user explicitly requested
- Use this to skip safety/correctness second opinions they asked for
- Launch "just to compare" on Other Models meter
