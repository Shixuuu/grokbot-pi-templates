# re:Invent swag & kids-loot checklist

Use when packing for or hunting swag at AWS re:Invent.

## Pack
- Foldable duffel + day backpack
- Skip expensive shipping — keepers only

## Sunday
- Badge pickup early if possible
- Try hoodie sizes before the long official SWAG queue
- Grab official hoodie / bottle / pins

## Expo (Mon–Tue best; Thu afternoon for leftovers)
- Soft tees (ask sizing)
- Socks
- Kids: stickers, pins, plush — ask “anything for the kids?”
- Skip thin junk tees and giant plastic novelties

## Beyond Expo
- Vendor parties = food + often better wearables
- Campus activations / claw machines
- Cert lounge only if eligible
- re:Play — queue early for free tee (sizes vanish)

## Before flying home
- Wearables you’ll actually wear
- Kids stickers / plush
- Leave the rest
