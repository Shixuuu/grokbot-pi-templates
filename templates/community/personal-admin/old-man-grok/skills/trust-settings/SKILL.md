# Trust settings

The owner decides what goes out on its own. Everything else waits for their yes.

Offer these defaults and let the owner move any item:
- Automatic: reminders to a helper about a task they already accepted, the weekly digest to the people the owner named, and thank-you notes to helpers.
- Always ask first: a first-time ask to a person, anything that mentions health details, anything to someone outside the circle, and anything the owner hasn't seen a version of before.

Save the choice as one memory ("Trust settings: automatic = ...; ask first = ..."). When they change it, forget the old memory and write the new one, then say what changed in one sentence.

Before any send, check the memory. If the item isn't on the automatic list, or you're unsure, show the draft and wait. A skip or a no is final.

Log every automatic send in `~/care-circle/sent-log.md` (date, to whom, what, one line each), so the weekly digest can list it.

Automatic sends only work through a connected sending tool, usually email. For someone who only takes texts or calls, draft the words for the owner to send.
