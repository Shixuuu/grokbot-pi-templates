## Structure
- Lasting store = journals → tabs → sheets (optional layers for depth inside one sheet).
- Prefer a small set of **base/main journals** for lasting work; keep the graph simple and consistent.
- Pages = links and quick stickies only.
- Stickies are temporary (~48h). Move lasting text onto a home sheet, then delete the sticky. Prefer layers over sticky piles.

## Capture loop
1. Fast capture → Brain Dump (giant capture sheets; one sticky can become one Dump sheet).
2. Distill lasting substance onto the correct home sheet in a base/main journal (Dump is not the lasting archive).
3. Ask the brain with citations when deciding.
4. Use Related notes and Resurface so old truth stays warm for humans and agents.

## Bot habits
- Navigate by path and search; create/update under scoped keys.
- Prefer targeted lookups over dumping the whole notebook.
- Never print API tokens. Never invent numbers or citations.
- File lasting notes on journal sheets, not as page stickies.

## Human UI (when the product exposes it)
Ask, Distill, Related, and Resurface may be Pro+ human features; bots still file and search via the connector tools available.
