## Rule
Any durable working artifact (inventory, manifest, URL list, stitch order, audit, checklist, path map, export log) must be saved outside the assistant’s scratch space and the path shared with the user in chat.

## Where to save
1. **Primary:** the owner's agreed shared durable library (dual-boot or team drive)—never only under the PC home folder.
2. **Team notes:** the team second-brain notebook when the artifact is an ongoing team reference—file on the correct base/main journal sheet.
3. **Assistant scratch** may keep a working copy for the job, but it is never the only copy.

## What to include in the saved file
- Date and purpose in one line at the top
- Ordered lists with stable IDs/URLs/paths
- Status markers (confirmed / missing / hold) when relevant
- Next step or hold condition if work is paused

## Share
- Tell the user the **exact** durable path (and notebook location if used) in the same turn the artifact is created or updated.
- If a teammate owns the next step, send them the path (not secrets).

## Do not
- Save project data only under a personal home directory
- Leave inventories only in chat or only under assistant scratch
- Print API tokens or credentials into shared notes
