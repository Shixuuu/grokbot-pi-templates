## Why two pieces
- **Grok Bot template (clone):** Lead habits—how the assistant runs a founder desk, files knowledge, routes work, and builds responsibly with Grok.
- **2nd brain transplant (MCP pack):** Notebook skeleton in the owner's own account—base/main journals, second-brain sheets, Brain Dump + Distill flow. **No secrets in the pack.**

Cloning the bot without a transplant gives habits with an empty or foreign notebook. Transplant without the Lead bot gives shelves with no librarian. Together, the Lead walks a structured brain that compounds.

## Rules
1. Use only the **new owner's** notebook API key (read+write). Never reuse another account's key.
2. Fetch the current **public** transplant pack JSON and bot handoff the owner points you to (do not invent URLs or tokens).
3. Run pack `steps[]` in order; resolve `$ref` / `saveAs` as the handoff says.
4. Do **not** create a legacy Admin Inbox/Holding stack—Brain Dump replaces capture.
5. When done, list journals/tabs/sheets created; ask the human to open the notebook app once so system Brain Dump appears if required.
6. Never put secrets, PANs, or private customer data into the pack or into shared notes.

## After install
Run a proof: Dump one idea → Distill onto a home sheet in a base/main journal → Ask with citations → confirm Related/Resurface if their plan includes them.
