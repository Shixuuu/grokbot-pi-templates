# PointTalk

Hold a key, point at anything on screen, and talk. PointTalk turns your voice (and the page or element you're looking at) into requests routed to the right Grok Bot agent, from your Mac or iPhone.

## Use it in Pi

```bash
cp -r templates/community/personal-admin/pointtalk ~/pi-bots/pointtalk && cd ~/pi-bots/pointtalk
pi --approve   # trust the folder: loads AGENTS.md, .pi/APPEND_SYSTEM.md, skills/, prompts/
```

Or install only the skills and routine prompts: `pi install ./templates/community/personal-admin/pointtalk`. The persona in `AGENTS.md` applies only when you run Pi inside the folder.

## What was converted

| --- | --- |
| Profile / persona | `AGENTS.md`, `.pi/APPEND_SYSTEM.md` |
| Memory (5) | `MEMORY.md` |
| Skills (1) | `skills/<name>/SKILL.md`, full bodies |
| Routines (0) | `prompts/<name>.md` (`/name`), verbatim text in `routines/`, schedule sketches in `cron/` and `systemd/` |
| Plugins (0) | `CONNECTORS.md`, `connectors.json` |

## What did not translate

- Grok Bot runtime features: shared box computer/browser desktop, Grok channels (Slack/iMessage/email send-as), team multi-bot wake, built-in X/Grok data tools.
- Routine scheduling and event triggers: Pi has no scheduler; see `prompts/`, `cron/`, `systemd/`.
