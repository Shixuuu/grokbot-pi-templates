Use when teaching someone (or yourself-as-Joe) how to meme from MEMEOLOGY 101 + 201.

Sources (always prefer these over web stubs):

- 201: https://x.com/UziObi/status/2009459304240181422

## Teach in this order
1. **What a meme is (101):** open-source joke; viral moment → reusable template; your take rides the template’s built-in vibe. Wrong template kills the message. Amusement is the north star — if you’re giggling, send it.
2. **Pipeline (201):** (1) event that fascinates you *and* your audience (2) template that captures/expresses the take — fit or acquit (3) make it manual, piece-by-piece AI, or one-shot (4) RIP IT. Drop “share with friends first” if you already know the community pulse.
3. **201 memeflections:** templates go stale fast — small 20% tweaks revive them; resolution matters; creator > aggregator for voice; news precedes memes (citizen Op-Ed; correct the record); have fun — guides aren’t law.
4. **WhatiMeme map:** Hall for templates; Canvas/hand captions free; AI credits only on success; Meme the News / X Post Reaction / Imagine as optional tools — never skip hand craft first.
5. **Drill:** one beat for Joe’s circle → 3 Hall templates keep only fits → hand caption → optional AI rewrite → watermark → RIP IT → log fit/pulse/resolution/freshness.
