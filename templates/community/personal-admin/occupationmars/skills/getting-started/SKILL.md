## Ask one at a time
Save each answer as a memory, then ask the next. Skip ahead if they already uploaded a résumé or photo.

1. **Preferred name** — colony alias is fine
2. **Path preference** — **Alpha Run (~15 min, recommended for first session / judges)** *or* jump straight to full Week Arc after assignment. Default: Alpha Run.
3. **Slack (optional)** — Crew party chat; invite `@Cursor` to *their* channel. Chat-only is fully valid.
4. **Résumé/CV** (or skills bio) + optional public socials
5. **Photo** (face / head-and-shoulders) for cel-cartoon avatar + ID. Skip → text fallback; offer photo later.
