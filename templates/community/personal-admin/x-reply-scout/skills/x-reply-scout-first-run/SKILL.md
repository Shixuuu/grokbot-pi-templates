# X Reply Scout — first-run onboarding

Use this when the bot is newly created from the template, or when the user asks to re-run onboarding.

## Goal
Learn the user's X taste, confirm it, set up hard filters and the weekday watch, then start recommending like-minded accounts to engage with. Never post, reply, like, follow, or DM as the user.

## Steps

1. **Greet briefly** (name/description are already in the profile — don't recite them). Say you're starting first-run.

2. **Pull X identity** via the X connector: authenticated profile, recent posts including replies, and note which replies/reposts/quotes got stronger engagement. Check usage credits before wide pulls; prefer targeted reads.

3. **Write a short taste brief** back to the user once:
   - Topics and tone that actually show up
   - Engagement patterns that work for them
   - Orbit / accounts they already lean into
   - Anything unconfirmed (don't invent interests)
   Ask them to confirm or correct (question widget is fine).

4. **Hard-filter setup:** The X connector may lack a following-list tool. Pull their Following page (browser if needed), cache handles locally, and use that cache as a hard skip list on every hunt. Refresh when stale (~14 days) or when they say follows changed.

5. **Aim reminder (after confirm):** Find like-minded people to contribute and engage with — build community around a shared set of ideas. Even mix across:
   - Fast-growing accounts
   - Relevant accounts of any size that are regularly active
   - Large established followings
   Qualifier for all sizes: active contributors who engage with their community daily (conversation, not broadcast-only or ads).

6. **Start hunting** with that mix. Prefer fewer high-fit picks. Each pick: @handle, why relevant / community fit, 1–3 post links or short quotes, why it fits their engagement pattern; tag bucket (rising / active / established). Append to a recommendation log so you don't re-ping without a new reason.

7. **Standing watch:** Ensure a weekday daytime routine exists (e.g. 10:30am and 2:30pm in the user's local time). Surface only when a pick clears the bar; stay quiet otherwise.

8. **Invite feedback:** Tell the user clearly that they can give feedback anytime — if picks aren't to their liking, say so and preferences will be updated. Do this after the taste brief and again after the first round of picks.

9. **Delivery rules forever:** Accounts + posts only. No draft reply text unless they turn that mode on. Stay quiet on empty hunts. Skip bait, conspiracy, and accounts they already follow. When feedback lands, update the taste brief / memory and apply it on the next hunt.

## Done when
Taste brief confirmed (or corrected), following cache in place (or soft-noted if blocked), at least one hunt attempted or the weekday watch armed, the user knows you'll only ping on clear picks, and they know feedback retunes preferences.
