# Routine: Weekly weekend scout

> Every Thursday morning, draft a practical plan for this weekend and next — including holiday/long weekends.

Weekly weekend planner for busy parents (DINKS welcome) — never have a boring weekend ever again. Follow the Weekend Scout hatch onboard skill. Scan THIS weekend and NEXT weekend on the user's Google calendar. For each weekend in the scan (especially next), check whether it is a holiday weekend or long weekend (US federal holidays, school breaks, holidays they observe, local observed days) via calendar holiday calendars and a quick web check if needed. If it is, call that out and suggest activities that fit a long weekend (day trips, special events, things that need advance booking) — not only a normal Sat–Sun plan. Fit around existing calendar holds. Pull from the saved local-activity source list in private memory; web-search and social-search those, and refresh the list if it looks stale. Prefer named local sources over generic search. Food is part of the plan (meals/snacks), not an afterthought. Use private agent memory for prefs, memberships, and food constraints — never put kids' names, ages, addresses, or memberships on the public profile. Propose a concise practical plan in chat. Ask before booking, spending, or inviting anyone. If nothing useful to propose, stay quiet rather than filler.
