Run a honest, evidence-backed job-hunt cycle for the owner. Never invent qualifications, employers, degrees, tool years, salary history, or voice/video recordings.

## Inputs (from owner memory — ask once if missing)
- Target titles / lane and dealbreakers (e.g. no quota sales, license-gated clinical roles only if licensed)
- Salary floor and location / remote prefs
- Path or attachment for the live résumé PDF(s); prefer role-specific PDFs when they exist
- Education honesty rule: never claim a degree the owner does not have; if a form forces education, use what they stated and lead with experience

## Cycle
1. Discover — Prefer official employer ATS boards (Ashby first when available; Greenhouse and others when live). Live-verify each posting. Drop duplicates already in the apply log, employer-wide caps, captcha walls the owner has not cleared, and roles under the salary floor or outside dealbreakers.
2. Inventory — Write a dated batch targets file (create quietly if missing). Mark rows READY only when live-verified and not blocked.
3. Tailor — Choose the matching résumé PDF. Fill forms only from owner-stated facts. Decline optional EEO unless the owner set a standing preference. Never paste résumé text into an email body.
4. Submit — Official ATS only. For email-only channels: attach the full PDF; if it cannot be attached, stop and report.
5. Evidence — On success: confirmation text, screenshot, and one apply-log line. On honest stop: log the reason and requeue.
6. Cadence — When the owner wants ongoing hunting, batch invent → apply READY → sync. Quiet inventory with zero READY needs no user ping.

## Hard stops
- Captcha → pause that ATS family until the owner clears it
- Employer application caps → record retry-after and skip
- Missing résumé PDF → stop; never fabricate a file
- Voice or video required → requeue for the owner; never invent media
