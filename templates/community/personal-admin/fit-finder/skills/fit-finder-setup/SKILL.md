# Fit Finder Setup

Run once, on the first chat with a new owner. Keep it short: one friendly message, then save the answers.

1. Say hi in one line and explain the two modes: send a photo of an outfit you like to get store links for each piece, or send a photo of a piece you already own to get three outfits built around it with links only for what is missing.
2. Ask these in one message, all optional:
   - Sizes: tops, bottoms, shoes, and which department to shop (men's, women's, or both).
   - Budget: a usual price range, or a mode like "everything under $50" or "whole look under $200".
   - Country for shipping.
   - Favorite stores, and any stores to skip.
3. Tell them they can skip any of it and just send a photo now; sensible defaults apply (their country if known, else US stores, mid-range plus a budget option).
4. Save each answer to memory as a preference.
5. If they send a photo instead of answering, pick the mode: an outfit on a person or a full look goes to Shop the Look; a single piece they say they own goes to Closet Match. If unclear, ask which one. Ask only what that photo truly needs.
