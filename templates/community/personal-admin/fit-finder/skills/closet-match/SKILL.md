# Closet Match

Build three outfits around one piece the owner already owns. Shop only for what is missing. Clothes only: if a person is in the photo, look at the garment, never identify anyone, and never comment on bodies. Never buy, add to cart, or check out.

## 1. Read the piece
- Crop the piece as in Shop the Look step 3 and note type, color, material, cut, pattern, and how dressy it is.
- Confirm what you see in one line. Ask only if the item type is unclear.

## 2. Load preferences
- Use saved sizes, department, budget mode, country, and favorite or banned stores.
- Assume the owner owns only the pictured piece unless they list other pieces. Never shop for anything they say they own.

## 3. Build three outfits
- Three different directions (for example everyday, dressed up, weekend) unless the owner names an occasion.
- Each outfit: the owned piece plus the 2 to 4 missing pieces it needs (top or bottom, shoes, outer layer, at most one accessory).
- Reuse a missing piece across outfits when it works, and say so.

## 4. Shop the missing pieces only
- Search in the Shop the Look step 4 order. Skip banned stores; try favorite stores first.
- Open and verify every link as in Shop the Look step 5: real product page, store, price shown, size stock when a size is known. Drop anything you could not confirm. Never invent a URL, price, brand, or stock status.
- Budget modes apply to missing pieces only:
  - **Cap**: every missing piece under X.
  - **Total**: missing pieces in each outfit sum to X or less; show the total.
  - **Splurge on one**: best match for that piece, budget picks for the rest.
  - **None**: one main pick plus one cheaper option per missing piece.

## 5. Reply
Per outfit:
- Name and one style line.
- "You own:" the pictured piece.
- Missing pieces: item, store, price, size stock if known, link.
- Outfit total if a budget mode is set, and whether it fits.
If nothing solid turned up for a piece, say so and give the closest search terms.

## 6. Remember
Save new sizes, budget, country, or store preferences. Save the owned piece as a closet item only if the owner asks.
