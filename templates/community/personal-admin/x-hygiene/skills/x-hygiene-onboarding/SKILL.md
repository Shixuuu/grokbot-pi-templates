# X Hygiene onboarding

Use on first chat, “getting started” / “how does this work”, or after Add before any scan. Clear numbered steps — one ask at a time.

## Opening (one short message)

Analyze an X account’s **followers and following**, score profiles, recommend **block** or **unfollow**. Never auto-act. Cost before any paid pull.

After setup, tell them short commands exist: `estimate` · `scan` · `quick` · `full` · `rescore` · `next 10 block` · `accept @user` / `skip @user` · `budgets`.

Walk steps in order (“Step 1…”) and wait for answers.

### Step 1 — Which X account?
Ask username (usually their own). Store allowlisted target. Confirm: “Got it — I’ll use @handle.”

### Step 2 — Set three budgets
USD: **Weekly** · **Monthly** · **Ad-hoc run**. All bind; tightest remaining wins. Store the three memory keys. Until set: estimates only.

Starters (examples): Light 10/40/15 · Medium 25/100/15 · Higher 50/200/25. Confirm numbers.

Optional knobs (mention briefly; defaults OK): alert when ≥5 new block recs; chat shows top 10 per list.

### Step 3 — X connector (reuse if it exists)
Check installed connectors first.
- If X already has followers+following list tools → “You already have an X connector — I’ll reuse it.” Do not reconnect or duplicate.
- If broken → plain fix steps for that same connector; re-check.
- If missing → numbered add-connector steps (no passwords/API keys in chat); re-check; then reuse forever after.

### Step 4 — Cost estimate (not a full scan)
Show Cost this run / full dual-graph estimate / budgets / fits / waiting on go. No full pull until “go” or `scan`.

### Step 5 — Optional schedules
Offer:
1. **Weekly estimate-only** (Monday) — quiet if unchanged; never auto-spend.
2. **Optional weekly/monthly scan** — only if they opt in; still budget-gated.

Create only what they want.

## Done when
Handle + three budgets saved (or deferred eyes-open), connector reused or guided, estimate shown, they know `go` / `scan` starts a real run and digests stay short with full lists in files.
