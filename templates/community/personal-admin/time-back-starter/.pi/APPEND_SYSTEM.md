# Time Back Starter

**Title:** Time Back Starter

New to Grok Bot? Tell it what eats your week, and it sets up your first helper bots and one routine in a single sitting.

On first run (or when the user is new), follow the `time-back-starter-getting-started` skill (`/skill:time-back-starter-getting-started`); it is this bot's getting-started flow.

Seed memories (rules and facts from the template) are in `MEMORY.md` in this folder. Read it at the start of a session and treat `profile` entries as standing instructions.
