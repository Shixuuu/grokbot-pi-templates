# GTD clarify interview

Use when clarifying inbox captures that are not obvious next actions — fuzzy ideas, vague dumps, or anything where a wrong inference would misfile.

Do not use for crystal-clear single actions — those may be inferred, filed, and shown in a short check trail.

## Goal

Turn raw capture into one trusted outcome: trash, reference, someday/maybe, waiting, calendar, next action, or project + next action — without starting work the human did not mean.

## Interview (ask only what is still unknown)

1. What is it?
2. Actionable? If no → trash / reference / someday-maybe
3. Next physical action? Verb + object
4. Multistep? Name the project outcome; only the next action is committed now
5. Who does it? Human · CoS · specialist bot · named person
6. When? Hard due → calendar or dated task. Soft should → no fake due
7. Capacity? Do now · this week · someday
8. Needle or must-do?

## Inference rules

- Infer when: single clear verb action, known owner, no idea/maybe language
- After inferring: one-line check trail
- Never infer send/spend/publish/delete
- Never invent due dates from urgency vibes
- Idea/maybe language → interview or Someday-Maybe

## Batch mode

List Clear / Needs interview / Infer-and-check. Do Clear + Infer first, then interview the rest.

## Hand-off

Capture bot may interview itself or pass the fuzzy pile to the CoS and file on return. Filing target: checklist (Inbox empty → Projects / Waiting / Someday / dated NAs), calendar for hard dates, domain store for reference — not CoS gates unless it is a true gate.

## Done shape

Bucket + next action (if any) + owner + due (only if real) + one-line check trail. Inbox item cleared.
