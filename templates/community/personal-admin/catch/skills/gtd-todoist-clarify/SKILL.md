# GTD capture → clarify → organize

Use when processing an inbox dump (voice webhook, chat, capture-bot, mid-work idea, email, meeting notes) into a trusted system.

Capture is not work chat. Silent dumps do not require a live conversation. Mid-chat ideas peel off without derailing the workstream.

## Two jobs (do not mix)

1. Needle-movers — company/project progress and big personal outcomes. CoS owns focus gates.
2. Must-do / due — renewals, bills, appointments, chores with real dates. Lives on a visible checklist (Today / Upcoming / Overdue), not only in chat nags.

Hybrid default: the checklist app is what the human can open anytime. CoS does not replace it by nagging every item.

## Allen processing

Stuff → In-basket → What is it? → Actionable?
No → Trash · Someday/Maybe · Reference
Yes → What's the next action?
- Multistep → Project + next actions
- ≤2 minutes → Do it (except send/spend/publish/delete — exact yes in the current chat)
- Else → Delegate → Waiting · or Defer → Calendar / Next actions

## Extra interview

Fuzzy captures → run GTD clarify interview. Obvious single actions may be inferred with a one-line check trail.

Also decide: who does it; capacity (actionable ≠ do now); date-real vs soft; needle vs must-do.

## Checklist buckets

- Inbox — capture only; empty regularly
- Projects — multi-step outcomes; one visible next action
- Waiting — delegated/blocked; who + what
- Someday-Maybe — not committed or actionable-but-not-now
- Today / Upcoming — must-do checklist

## Clarify each item

1. Trash noise
2. Reference? File in the domain store — not as a task
3. Actionable? (≤2 min / one NA / multi-step / Waiting / Someday)
4. Fuzzy → interview; never invent due dates
5. Never leave clarified items in Inbox

## Weekly review (minimum)

Empty Inbox; scan Waiting, Projects, Someday-Maybe; glance calendar + Upcoming; separate needle vs must-do.

## Do not

- Auto-park dumps on CoS gate lists
- Replace the checklist with chat-only nagging
- Run a second task system in a calendar auto-scheduler
- Act on idea/maybe without interview
