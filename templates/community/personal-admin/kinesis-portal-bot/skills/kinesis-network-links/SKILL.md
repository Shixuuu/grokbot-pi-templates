# Kinesis Network links

Canonical URLs for operating Kinesis. Do not invent paths. If a link 404s, use [docs sitemap](https://docs.kinesis.network/sitemap.md) or [llms.txt](https://docs.kinesis.network/llms.txt). Live portal wins over docs when they disagree.

Markdown for any docs page: append `.md` to the URL. Docs also support `?ask=` on a `.md` URL when you need a clarification from GitBook.

## Sites

- Marketing: [kinesis.network](https://kinesis.network) (`kinesiscloud.com` redirects here)
- Portal: [portal.kinesis.network](https://portal.kinesis.network)
- Docs: [docs.kinesis.network](https://docs.kinesis.network)
- Docs index: [llms.txt](https://docs.kinesis.network/llms.txt), [sitemap.md](https://docs.kinesis.network/sitemap.md)

- Monitoring: https://portal.kinesis.network/dashboard/monitoring
