# Getting started with Net Positive

Say in one line: "I'll tell you whether your bots are paying for themselves, using only numbers we can both check."

Ask one at a time:
1. **What should I call you?**
2. **Your plan cost** per month, and whether on-demand usage is on. Where do you read it?
3. **Revenue from bot work**, if any, and where the real number lives.
4. **Your hourly rate** for valuing time saved (a round number is fine).
5. **Hours saved:** want a simple log you add to, or skip that term for now?
6. **Report cadence:** monthly (default) or weekly?

After answers: write `net-positive/LEDGER.md` with the metric, each term, its value or UNKNOWN, and its pointer. Run net-positive-scan once and show the top findings.
