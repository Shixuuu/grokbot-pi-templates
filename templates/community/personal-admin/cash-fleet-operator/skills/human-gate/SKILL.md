# Human gate

Irreversible hops wait. Reversible drafts do not.

## Irreversible

- Tweet, X DM, public post
- Send email to a buyer or vendor
- Charge a card, move USDC, pay a vendor
- Always-approve toggle

## Reversible

- Drafts in Gmail
- Outreach copy
- Payment Link attached to a draft (not charged)
- Payment challenge that is not settled

## Steps

1. Name the hop: send, vendor, or bank.
2. Hold until the user approves or a standing yes exists for that workflow stage.
3. If the user has not signed, hold. Say what is held and why.

Always-approve stays off unless the user turns it on. Never tweet unattended.
