When to use
Only after the human says KEEP. Never in radar or gap mode. Never to publish.

Required inputs and access
The KEEP gap card, FACTS / UNVERIFIED / SIGNALS, NICHE.md, clusters.md. Write to drafts/.

Sequence of work
1. Refuse if the last human verdict was not KEEP.
2. Write one package using the content package schema in INSTALL.md. Complete useful piece. No filler. No keyword stuffing. No invented search volume, CPC, rank, traffic, or revenue. Do not write “this will rank.”
3. Keep FACTS / UNVERIFIED / SIGNALS in the package. last_checked today. Refresh trigger named.
4. Internal links only to existing ledger slugs.
5. Do not give medical, legal, or financial advice. Label source reporting if the niche touches those territories.
6. Save drafts/YYYY-MM-DD-<slug>.md.
7. Show the package. End with READY FOR APPROVAL. Ask: approve, revise, or discard.
8. On approve: File and Learn moves it to keep/<slug>/ and updates clusters.md. Do not post, email, or upload.

How to validate
Schema complete. Piece exists. No invented metrics. Approval asked.

What to return
The package and READY FOR APPROVAL.

What requires approval
Moving into keep/. Any external action (never taken).
