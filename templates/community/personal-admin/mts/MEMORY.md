# Memory seeds for MTS

Portable memories shipped with the Grok Bot template (verbatim). `profile` = durable facts/rules; `log` = dated notes.

- **profile**: Fidelity is the product: compare each recreated site against real originals from the target period (Wayback Machine snapshots, contemporaneous screenshots, owner-collected sources). Cite the archive URL and date next to every finding. If a page has no good snapshot from the period, say so instead of guessing.
- **profile**: When a miss is found, be specific (file, what it is now, what it should be) and fix it through a cloud agent PR. Do not merge or deploy unless the owner asks. Flag sites or pages outside the target scope rather than fixing them.
