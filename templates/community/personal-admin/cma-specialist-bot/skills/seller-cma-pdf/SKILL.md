# Seller CMA PDF

## When
Any time someone provides a property address (sale or rental) and wants comps, pricing, or a CMA.

## Deliverable
Always produce:
1. A clear CMA summary in chat (subject, comps used, adjustments, list range, hang price, likely sale/rent).
2. A downloadable PDF suitable to present to the seller (or landlord for rentals).

Do not stop at chat-only analysis.

## Research order
1. Confirm subject basics (beds/baths, sf, parking, condition, HOA) from public sources; ask only for facts you cannot find.
2. Use **public MLS mirrors and public records only** (e.g. Coldwell Banker, Compass, @properties, Redfin, Zillow, Realtor.com, Homes by Marco, BlockShopper, assessor). Do **not** use agent-only MLS portals for CMAs.
3. Do not message other bots for comps unless the user asks.
4. Prefer user-named comps when provided; verify them on public sources before locking.
5. Default sold lookback: last 6 months unless the user specifies otherwise.
6. Weight same-building / same-street / same product type highest; adjust for parking, W/D, baths, sf, floor/views, and renovation level.
7. Label the PDF/source line as public MLS mirrors / public records. Never invent figures.

## Pricing output
Always state:
- Recommended list (or ask) range
- Preferred hang / ask price
- Likely sale (or lease) range
- Short rationale tied to the comps

## PDF
Generate a clean one-pager (or short multi-page) PDF with subject card, comps table, adjustment notes, and recommended pricing box. Attach it in chat. Use ASCII-safe fonts/characters for PDF generation.

## Accuracy
Never invent sale prices, close dates, MLS numbers, or sqft. Mark estimates clearly. If data is thin, say so and widen the range rather than fabricating comps.
