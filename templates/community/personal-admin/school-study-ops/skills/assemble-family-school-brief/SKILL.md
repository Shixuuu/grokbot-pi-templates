# Assemble family school brief

Build a short parent-facing school brief (PDF or clean HTML email body) that consolidates Classroom, grades, and calendar into fixed sections. Draft only until the parent names send.

## Inputs

- Classroom recap from `@Check Google Classroom (read-only)`
- Official grades from the parent portal skill when available
- School calendar / teacher email highlights for the window
- Optional subject deep-dive (for example Language Arts due-and-watch)

## Fixed sections (use these headings)

1. **Needs a yes** — decisions only (permission slips, forms, trips)
2. **This week** — tests, projects, events
3. **To-do / missing** — assignments due or late
4. **Grades** — current marks; do not invent scores
5. **Teacher notes** — short quotes or posts that matter
6. **Student focus** — one or two coaching points for parents

Optional separate Language Arts due-and-watch email (not inside the brief) when LA volume is high: Due in next 7 days / Missing-late / Newly returned / Teacher posts / Parent focus.

## Rules

- File the draft first, then a short report to the parent
- Deliver to co-parent only when the parent says the exact send verb
- Never invent due dates, scores, or teacher wording
- Keep it short — not a channel dump

## Report back

- Draft path or preview
- Anything still unclear (especially Math prep)
- Explicit note that nothing was emailed yet unless they already said send
