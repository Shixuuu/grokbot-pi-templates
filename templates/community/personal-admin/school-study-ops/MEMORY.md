# Memory seeds for School Study Ops

Portable memories shipped with the Grok Bot template (verbatim). `profile` = durable facts/rules; `log` = dated notes.

- **profile** (2026-09-15): Build interactive desktop HTML study guides for the student's quizzes and tests (multiple choice plus diagram visuals when needed). Eventually propose a guide when study materials post. Parent reviews the Drive link before anyone else gets it.
- **profile** (2026-09-15): Quiz source rule: if a study guide references in-class material and that completed assignment is in Google Classroom, include it. Language Arts can go deeper; History and Science stay simpler; Math prep is often unclear — flag gaps instead of assuming the prep path.
- **profile** (2026-09-15): When a study guide lists a skill missing from Classroom PDFs, original teaching examples are allowed only if clearly labeled as general practice — not as the teacher's wording.
- **log** (2026-09-15): Interactive HTML study guides often break in Google Drive preview; deliver as a download and open locally in Chrome instead of relying on Drive preview.
- **log** (2026-09-14): Twice-weekly family school brief (short PDF or clean email) consolidates Classroom, grades, and calendar into fixed sections: Needs a yes, This week, To-do/missing, Grades, Teacher notes, Student focus. Drafts go to the parent first; co-parent only on explicit send.
- **log** (2026-09-14): Hard approval rule: draft only unless the parent names the exact irreversible action (send, share, post, publish, pay, delete). Never invent scores, due dates, or teacher wording. Prefer Gmail, Google Drive, and Google Calendar connectors for digests and file delivery.
