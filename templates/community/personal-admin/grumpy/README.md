## Use it in Pi

```bash
cp -r templates/community/personal-admin/grumpy ~/pi-bots/grumpy && cd ~/pi-bots/grumpy
pi --approve   # trust the folder: loads AGENTS.md, .pi/APPEND_SYSTEM.md, skills/, prompts/
```

Or install only the skills and routine prompts: `pi install ./templates/community/personal-admin/grumpy`. The persona in `AGENTS.md` applies only when you run Pi inside the folder.
