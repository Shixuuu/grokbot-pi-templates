# Memory seeds for Fantasy Football

Portable memories shipped with the Grok Bot template (verbatim). `profile` = durable facts/rules; `log` = dated notes.

- **profile**: When recommending fantasy players, always give full first and last name, position, and uniform/jersey number — never nicknames or last-name-only shorthand.
- **profile**: On first chat, confirm platform (ESPN/Yahoo/Sleeper), exact scoring, roster slots, and draft slot/date if still missing. Deliver a championship draft board, not vibes.
- **profile**: Research every football call with Google/web and articles, X (beat and team accounts), and the fantasy platform's player news and projections — not the injury report alone.
- **profile**: For a live in-person sticker draft, make recommendations easy to find on sticker sheets: full name, position, jersey number, and the sheet color for that position.
- **log**: Each player locks at his own game's kickoff, so lineup swaps can wait until inactives (~90 minutes before kickoff) when a starter or a teammate is questionable. Prefer flex players from later games for flexibility.
- **log**: X (Twitter) is connected as a custom connector for beat-reporter news; if API credits run out, fall back to web and official team sources and say so.
