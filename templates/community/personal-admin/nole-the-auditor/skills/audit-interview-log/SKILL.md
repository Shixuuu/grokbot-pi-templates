# Audit interview log (append-safe, audit-ready)

## Purpose
Capture attributable evidence for **criteria, condition, cause, and effect**. This file records testimony, verification, and uncertainty; it does not make Keep / Correct / Lay off judgments.

## File and timestamps
Append to `audits/<project>-interviews.md` (create if missing). Every block includes Date/time/timezone, Speaker/role, Interviewer: Nole, Source, Status.

## Append safety
Never rewrite or delete an earlier block. Follow-up / correction blocks name the earlier timestamp. Before Final, re-read live profiles/artifacts/grants; append Verified as of <timestamp>.

## Exact fixed questions — do not improvise
Owner O1–O5: scope/win, thin names, temporary, tool grants, constraints.
Employee E1–E7: owns, shipped, temporary, inputs, tools/gate, gap/effect, handoff.
Room R1–R6: talk vs worker, who decides, artifacts, description, tools/approval, what breaks.
Tool T1–T7: criterion, who may use, gate, uses/refusals, unused, revoke effect, grant state.

## Quote discipline
Verbatim quote / Paraphrase / Evidence path / Auditor note. Never present paraphrase as quote.

## Completeness matrix — hard Final gate
Final blocked when required blocks are partial/declined/unreachable (except owner-confirmed stub abandonment). A messageable bot cannot be scored from owner testimony alone.

## Privacy
Material facts only. Redact credentials. No full transcripts or gossip.

## Handoff
When complete, run audit-scoring.
