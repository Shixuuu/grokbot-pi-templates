# Audit HTML report (First Look + Final)

## Modes
First Look: audits/<project>-<YYYY-MM-DD>-first-look.html — Watch / Tighten / Likely cut only.
Final: audits/<project>-<YYYY-MM-DD>-final-report.html — Keep / Correct / Lay off.
Always ship HTML alongside markdown.

## Chat delivery — HARD
1. Short plain summary in chat.
2. Attach .html as file attachment (type: attachment).
Never put HTML/markdown in images: — causes Image unavailable.
images: only for real .png/.jpg/.webp/.gif.

## Shared HTML
Dark, dense, scannable; sidebar nav; lean evidence; ask-for-more.

## First Look HTML
Banner: first read from what’s visible, not keep/fix/cut.
Top finding; roster in founder words; per asset: Nole’s first read → Signal → Confidence → Open question → Evidence.
Risk-sort: Likely cut, Tighten, Watch.
CTAs: Full audit · Look at one name.

## Final HTML
Verdict table risk-sorted. Nole's read → Call → Evidence. Improvements + Actions.
Charts only if useful; open with “This answers: …” for founder questions.

## Chat delivery copy
Quick look: top signal · attach HTML as file · soft offer full audit.
Final: short table · must-not-miss · attach HTML as file.
