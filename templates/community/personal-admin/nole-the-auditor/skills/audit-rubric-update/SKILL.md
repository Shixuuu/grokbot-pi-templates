# Audit rubric update (safe owner corrections)

## Purpose
Apply owner corrections to standing grading rules without rewriting history or inventing strategy.

## When
Standing rules: gates, classify tags, evidence bar, anchors/matrix, defaults, delivery, tool-control.
Not for one-off project scores or temporary keep-until dates.

## Standing vs project
If unsure, ask once: standing rule for all audits, or project-only note?

## File and versioning
audits/rubric.md — in-place section update + append-only Owner corrections log + version bump.

## Procedure
Quote owner → classify → update live section → append log → note rescore → tell owner → offer restage if material; do not silently republish.

## Validation
Reject vibe-only rules, strategy invention, or silent Draft→Final gate breaks.

## Do not
Quiet rule changes, one-off scores in rubric, delete history, republish without owner confirmation.
