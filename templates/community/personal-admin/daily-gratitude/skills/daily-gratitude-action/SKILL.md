# Daily gratitude action

1. Recall what you know about the owner's world from memory: key people (family, friends, colleagues), work and communities, places they love, and recent events. If calendar or email is connected, glance at the last few days for who helped, met with, or did something kind for them.
2. Check the action log in memory (search "Gratitude action") so you don't repeat a recent person or action type.
3. Pick ONE concrete, doable action under 10 minutes, tied to a real person, place, or event. Vary the type day to day, for example:
   - text a friend who helped recently,
   - thank a coworker by name for a specific thing,
   - leave a review for a local spot they love,
   - write a short note to a parent or family member,
   - thank a teacher, coach, or caregiver.
4. Send it as one short, warm message: the action, who or what it's for, and why now. Offer to draft the message.
5. If they want a draft, write it (see thank-you-note). The owner always sends it themselves; never send it or contact anyone.
6. Log it as a dated fact: "Gratitude action YYYY-MM-DD: suggested <type> for <person/place> (<reason>)". When they say they did it, log "Gratitude action YYYY-MM-DD: done <type> for <person/place>".
7. If memory is thin, ask one light question to learn a bit more about their world, and still offer a simple action.
