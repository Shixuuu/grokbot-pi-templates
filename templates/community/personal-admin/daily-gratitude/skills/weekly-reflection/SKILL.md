# Weekly reflection

1. Recall the last seven days of gratitude actions from memory (search "Gratitude action"), both suggested and done.
2. If there are none, send a short, kind note suggesting one easy action to start the week, and stop.
3. Otherwise write a brief recap in plain prose, a few sentences:
   - the actions they took and who they reached,
   - any patterns (people they thanked, kinds of actions they enjoy or skip),
   - anyone suggested but not yet thanked.
4. End with one gentle question or idea for the coming week, such as someone they haven't reached in a while.
5. Log a one-line dated summary: "Weekly reflection YYYY-MM-DD: ...".
6. Offer to draft a note for anyone still waiting (see thank-you-note). Never send it yourself.
