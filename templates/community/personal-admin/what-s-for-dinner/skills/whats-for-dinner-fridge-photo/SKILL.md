# What's for Dinner?: fridge photo

Two steps. Never suggest dinners in the same message as the item list if anything is uncertain or a possible allergen is present. Confirm first.

## Step 1: What I see (then wait)
1. Read all WFD memories (allergies, diets, household, time limit, equipment).
2. List the items in two groups. Use plain names and rough amounts only when they're visible.
   - **I can see:** items you're confident about.
   - **Not sure:** anything unlabeled, blurry, hidden, or easy to confuse (white tub: sour cream or yogurt? green bunch: parsley or cilantro? pack of meat: chicken or pork?). Give your best guess and ask.
3. **Allergen check (ALWAYS):** compare every item against the saved STRICT allergies and diets, including hidden sources (core-rules section 1). Flag:
   - items that clearly contain a listed allergen: "I'll leave these out."
   - items that might contain one or carry a "may contain" warning (sauces, dressings, pesto, bread, baked goods, granola, curry paste, stock): "Can you check the label for [allergen]?"
   - If no allergies or diets are saved, ask once: "Any allergies or diets I should know about before I suggest?"
4. If anything looks past its best, say "check it; when in doubt, throw it out." Don't judge freshness from the photo alone.
5. End with one short prompt: "Can you confirm the 'not sure' items and the labels? Then I'll give you 2-3 dinners."
If everything is clear and no allergen questions come up, you can go straight to step 2 in the same message.

## Step 2: Dinners from what's on hand
After they confirm, give 2-3 dinners. Each must pass core-rules (allergies, diets, time limit, equipment, kids) and should use mostly items from the photo.

For each dinner:
**[Dish]**: Total [X] min (prep [A] + cook [B]) · [$/$$/$$$]
- Uses: [items from the photo]
- Also needs: [staples or 0-3 missing items]
- Steps: 3-6 short numbered steps with times
- Kid tweak: [if there are kids]
- Allergy check: [one line, when allergies or diets are saved]

Then:
**To buy** (combined, only what's missing): short list. No prices, sales, or stock claims.
**Use first:** perishables that should be used soon (for example, open spinach, fresh chicken). End with: "Want me to keep these on your use-it-first list so I plan the next few dinners around them?"

Log the dish they pick in WFD recent meals (see daily-dinner). If they don't pick one, don't log anything.

## Use it before it spoils (WFD perishables)
- Save only perishables the user CONFIRMED (they confirmed the item and said yes to the list). Never save raw photo contents.
- One memory, updated in place: "WFD perishables: spinach (noted 2026-10-05); zucchini (noted 2026-10-05)". The date is when it was noted. Never guess or state expiry dates.
- Plan the next few dinners around these items (daily-dinner, weekly-plan, sunday-prep), still within every hard filter.
- Clear an item when the user says they cooked the dish that used it, used it, or it's gone or tossed. Confirm in one line ("Took spinach off your list.").
- If an item has been listed 5 or more days, ask once if it's still good: "When in doubt, throw it out."
- Items that might contain a listed allergen are saved only after the label check clears them.

## Rules
- Never use an item the user hasn't confirmed as safe when it might contain a listed allergen. When in doubt, leave it out and say so.
- Describe only the food. Ignore people, papers, and anything else in the photo. Never save raw photo contents; only user-confirmed perishables may be saved as WFD perishables.
- If the photo is unreadable, ask for a closer or brighter photo, or a typed list.
