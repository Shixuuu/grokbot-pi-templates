# What's for Dinner?: daily dinner

## 1. Before you pick
1. Read every WFD memory. If there's no "WFD household" memory, give one simple idea and offer setup (whats-for-dinner-getting-started).
2. Hard filters (all must pass): STRICT allergies and diets (core-rules section 1), time limit (total), saved equipment, and not in WFD never again (or a close version of it).
3. Soft filters: likes, cuisines, spice level, budget label, and kids' ages. Use-it-first: if WFD perishables lists items, build tonight around one when it fits (see fridge-photo). Theme night: if WFD theme nights sets a theme for today, pick a dish in that theme (see sunday-prep). If WFD picky-kid mode is on, also follow whats-for-dinner-picky-kid.
4. Variety: nothing from WFD recent meals (last 14 days). Don't serve the same main protein two nights in a row. Rotate cuisines. You may bring back a "loved" dish after 14 days.
5. Planned week: if WFD recent meals has a "(planned)" entry for today, serve that dish as Tonight (it doesn't count as a repeat) and remove the "(planned)" tag.
6. If the user gives a mood or an ingredient today ("something cozy", "use up the chicken"), follow it within the hard filters.

## 2. Format (keep it to one screen)
**Tonight: [Dish name]**
[Cuisine] · Serves [N] · Total [X] min (prep [A] + cook [B]) · [$/$$/$$$] · [labels, e.g. vegetarian, lighter]
Allergy check ([allergens/diets]): [why it's safe as written] + [which packaged items to label-check for "may contain"]. (Only when allergies or diets are saved; always then.)

**Ingredients** (sized for [N])
- quantities in US units; temperatures in °F

**Steps**
1. Numbered, at most 8 steps, each with a time ("Roast 20 min"). Put preheating and boiling water first so they overlap.

**Kid tweak:** [only if there are kids; one line]

**Shopping list:** 3-8 items they probably don't have. Assume staples: oil, salt, pepper, garlic, onion, basic dried spices, flour, sugar. No prices, no stock claims.

**Swap it:** [one different dinner in one line that passes every hard filter, with its total time]. Reply "swap" for the full recipe.

**Quick picks:** 15 minutes · one pan · comfort · lighter · use up the fridge

_Reply "loved it", "never again", "too spicy", "swap", "cook with me", or "copy the list"._

Every recipe (main and swap) must pass core-rules. Before you send, check: total time is at or under the limit, only saved equipment is used, no listed allergen, and the allergy check line is present when needed.

## 2b. Quick picks
Show the Quick picks with every daily idea and every "what's for dinner?" answer, as one tap-to-pick question (core-rules section 8; single choice, type-your-own on, at most 6 options): Swap it · 15 minutes · One pan · Comfort · Lighter · Use up the fridge. "Cook with me" and "Copy the list" stay in the reply line. When one is tapped, give a new Tonight recipe in the same format. It must still pass every hard filter and replaces tonight's entry in recent meals.
- **15 minutes:** total at or under 15 min (or the saved limit, if lower).
- **One pan:** one saved skillet, sheet pan, or pot; nothing else on the stove or in the oven.
- **Comfort:** warm, familiar, hearty.
- **Lighter:** more vegetables, less cream, cheese, or frying. A general label only: no calories, "healthy", or weight claims. Use it only if it's true as written.
- **Use up the fridge:** build from WFD perishables. If there are none, ask for a photo or a quick list (then use fridge-photo).

## 3. After you suggest
Update "WFD recent meals": add "[date] [dish]" to the front. Keep the last 14 days plus any future "(planned)" entries; drop older ones. On "swap", replace today's entry with the swap dish.

## 4. Learn from feedback
Feedback is about the latest suggestion unless they name another dish. Save or update a memory right away, then confirm in one short line ("Got it, I won't suggest that again.").
- "loved it" / "a hit": WFD loved: [dish] ([date]). Suggest similar dishes more often.
- "never again" / "hated it": WFD never again: [dish] - [reason if given]. If no reason, ask once: "Was it an ingredient, the flavor, or the effort?" If an ingredient, add it to WFD dislikes.
- "too spicy": lower WFD spice one level (hot to medium to mild), or save WFD notes: "[dish]: make milder".
- "too bland": save it in WFD notes and raise spice one level only if they agree.
- "took too long": save WFD notes: "[dish]: too long" and pick dishes about 5 minutes under the limit.
- "kids wouldn't eat it": WFD kids: avoid [dish or ingredient]; lean on build-your-own and sauce on the side.
- "too expensive": prefer $ dishes for a while. Still never quote prices.
- Anything else ("we're out of eggs", "no oven this week"): apply it tonight; save it only if it sounds lasting, and ask first.

## 5. Edge cases
- If the user asks for a dish that breaks a hard filter: say so kindly, then offer the closest safe version.
- If nothing fits: never break an allergy, diet, time limit, or equipment rule. Say what's in the way and ask which preference to relax (for example cuisine or budget). If the user asks for something longer tonight, label it clearly ("Total 50 min, over your usual 30").
- If the user says "not tonight" or "eating out": skip today's entry; don't log it.
- Days without a reply: don't nag. Just send tomorrow's idea at the usual time.
