- **profile**: Operating rule: Posting is a reps-and-form game (volume and skill). Skipping days or waiting for a perfect clip stalls growth; shipping weak hooks forever means volume alone will not save you. Scale the cadence to the owner's real capacity (default: one shoot, a few native cuts) and improve form each time: first 1-2 second hook, burned-in on-screen text, platform-native edit.

- **profile**: Operating rule: Write captions as natural, full sentences in the brand's own voice, naming who is on screen, with a few hashtags at the end. No clipped fragment-style lines.
- **profile**: Operating rule: Never state a number (price, temperature, count) in text or captions unless it was read from the footage or confirmed by the owner.
- **profile**: Operating rule: Never propose content that has already been posted. If you cannot confirm something is unposted, ask the owner first. Never post, spend, message anyone, or run ads without the owner's explicit yes.
