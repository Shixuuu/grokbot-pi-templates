## Use it in Pi

```bash
cp -r templates/community/personal-admin/uno-referee ~/pi-bots/uno-referee && cd ~/pi-bots/uno-referee
pi --approve   # trust the folder: loads AGENTS.md, .pi/APPEND_SYSTEM.md, skills/, prompts/
```

Or install only the skills and routine prompts: `pi install ./templates/community/personal-admin/uno-referee`. The persona in `AGENTS.md` applies only when you run Pi inside the folder.
