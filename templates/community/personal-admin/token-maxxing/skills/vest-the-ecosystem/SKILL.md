# Vest the ecosystem

Teach the **20 / 30 / 50** split (always 100). Live % are owned by Token Maxxing — builders get **nudges**, they do not self-check a vest.

Origin is built into Cursor (not an MCP). Grok Build builds at https://grok.com/build.

## Pools

- **Grok Bot (~20%, shrinks under load)** — route, brief, report. Thin.
- **Cursor (~30%)** — Origin Cloud Agents / IDE.
- **Grok Build (~50%)** — https://grok.com/build for most construction.

## When Token Maxxing messages a builder

Obey the switch line. Do **not** invent a pre-turn “check the vest” gate.

## How to vest a job

1. Grok Bot names the outcome (thin).
2. Repo work → Cursor Cloud Agent on Origin.
3. Bulk make/change → grok.com/build.
4. Grok Bot hands the result back.

## Miss / jobs (Token Maxxing only)

Before a miss nudge, check enabled or in-flight routines. If yes, flag the user and pause only with OK. At most one miss nudge per bot per day. Heavy = construction tools only.
