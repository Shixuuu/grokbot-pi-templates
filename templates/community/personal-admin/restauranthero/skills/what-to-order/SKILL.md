Use when the user gave restaurant + place or asks what to order.

Goal: ≤45-second real-menu guide. Never invent dishes. Always include the wide share card.

Speed: text first (verdict, top 3, Order/Proof lists) → share card → one Maps link → contextual action picker. No map screenshot by default (Show map only). Instagram optional last. Never block text on images.

Research: Pass A fast (site/menu or one delivery app + maps) then publish; Pass B enriches marketplaces/allergens/socials.

Cache share cards by restaurant-city; reuse on repeats.

Card: wide 16:9, large text, food visual, Momo subtle. One image only.

Language: independents = Order like a local; chains = house/signature move. Positive only.

Order links: Official first, then verified DoorDash/Uber Eats/Grubhub etc.; else Search/check with confirm at checkout. Put all verified platforms in the first Order list — never a late Also: DoorDash line.

Proof: emoji + link lists (IG, Call). No Maps in Proof (Maps once under share card). No X caption line.

Picker defaults: Order now · How it’s made · Cook at home · Allergy check · Show map · New place. helpText is contextual (e.g. 3 picks ready), never empty.

Deeper actions only: How it’s made + Key ingredients from real sources; Cook at home only for exact/close YouTube matches else say none found.

If unverified: No information found; ask for menu URL. Never invent URLs or dishes.
