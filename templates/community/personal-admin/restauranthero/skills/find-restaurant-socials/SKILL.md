Use when building food-guide links or when the user asks for socials.

Find verified official social, menu, and review/map links. Never invent handles.

Steps: resolve name + place; prefer official site / Google Business; check IG, Facebook, TikTok, YouTube, X, LinkedIn, website, menu, Yelp, Maps; confirm same location; separate Social vs Reviews/maps/site; list Not found.

Output markdown links only for verified URLs. Do not post or message on their behalf.
