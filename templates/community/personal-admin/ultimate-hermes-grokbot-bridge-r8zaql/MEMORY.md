# Memory seeds for Ultimate Hermes↔Grokbot Bridge

Portable memories shipped with the Grok Bot template (verbatim). `profile` = durable facts/rules; `log` = dated notes.

- **profile** (2026-10-02): Ultimate Hermes↔Grokbot Bridge: Grok→Hermes paths are native HTTP API :8642 (preferred for fleet) and SSH ask-relay (Desktop-primary hosts with no API gateway). Hermes→Grok paths are the local grok-bot-cli / allowlisted wrapper (primary) and a Tailscale-only webhook POST+Bearer fallback. Private net only; never Funnel or public webhook listeners.
- **log** (2026-09-17): Fleet ask and identity fronts: SOLE PATH HTTP :8642 over the private net. Soft “prefer HTTP” wording left an SSH door and caused flakes where bots claimed HTTP then health “magically” worked after SSH confusion. Do not probe SSH when :8642 fails — report BLOCKED on HTTP path; fix Tailscale, ACL grants, or the Hermes API sidecar.
- **log** (2026-10-01): Hermes→Grok webhook inbound must use Tailscale IP or MagicDNS with Bearer routine-key auth. CLI outbound from Hermes to the Grok Bot app uses loopback and does not need Tailscale. Prefer CLI first; webhook is the fallback when the app session is unusable or Hermes is remote.
- **log** (2026-10-01): grok-bot-cli doctor must show a usable Grok Bot app session. AMBIGUOUS_ENTRIES (multiple gateway descriptor entries with none active) blocks sends — recover by signing out/in or selecting one gateway entry. Do not invent alternate gateway credentials.
- **log** (2026-09-27): A Grok Bot Computer Update can wipe installed software and everything outside /home/box, including default Tailscale state. Keep Tailscale state, restore scripts, and configs under /home/box; store a reusable tagged auth key as an injected secret; run an hourly every-day detect-and-restore routine; pass the uninstall drill before calling setup done.
- **log** (2026-09-11): Typical private-net ACL pattern between a controller-tagged Grok Bot node and Hermes-tagged nodes: allow TCP for SSH, Hermes HTTP :8642, and the operator’s webhook port — not allow-all. Prefer MagicDNS over raw IPs.
- **log** (2026-09-27): Never share one messaging bot token across Hermes hosts via fleet-wide vault inject. Store TELEGRAM_BOT_TOKEN_<PROFILE> (and other per-host credentials as FOO_<PROFILE>) so Hermes auto-aliases per active profile; a generic FOO in the vault silently shadows per-profile keys.
