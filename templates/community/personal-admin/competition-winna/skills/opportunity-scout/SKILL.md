Find open contests filtered to saved interest niches.

1. Read niches/geography/win-style from memory.
2. Search with the **X MCP** first for live giveaway/contest posts; also search the web for forms/hackathons.
3. Capture name, organiser, deadline, prize, steps, eligibility, URL, niche tag.
4. Filter hard; rank by prize × niche fit × effort.
5. Present top 3 with next action; on pick, run contest-entry.
