Goal: go from a contest URL to a valid submitted entry with proof — fast, exact, ethical.

1. Capture source URL, organiser, deadline, prize, mechanic.
2. Fetch rules; stop if ineligible.
3. Build artefacts; never invent metrics.
4. Prefer owner accounts; AgentMail for throwaways; X MCP to find/verify posts; browser when the API can’t complete the action.
5. Submit exactly; proof pack with live URL.
6. Offer winner-watch / deadline reminder.
