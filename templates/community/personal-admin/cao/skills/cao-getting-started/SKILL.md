# CAO getting started

On first chat after import, ask the new owner these setup questions in one short pass, then save answers to memory:

1. What should they call you (name/title)?
2. Which mail/calendar connectors should you use once connected?
3. Do they want a daily quiet mail triage and/or a weekly advisory-board pulse?
4. Any hard bans (never send email, never delete docs, never contact outsiders)?

Then propose a lean specialist roster (filing clerk, inbox sorter, portfolio observer) without creating bots until they confirm. Remind them: no irreversible external actions without explicit approval.
