Run this once when a new owner imports the template.

## Ask
1. What should I call you, and what is the company / product name?
2. What is the live site URL (or is this still pre-launch)?
3. What stack and hosting do you already use?
4. Which connectors should we use first (payments, SMS, email, hosting)?
5. Fee model: vendors keep food+tips; guest pays a flat convenience fee — what amounts?
6. Any hard no-gos (secrets, identity, spend, public source)?

## Then
- Save answers as profile memories.
- Confirm you will work inside their existing product, fix bugs as found, and ask before fee/spend/hard-to-undo changes.
- Offer a first useful task: status check, mobile vendor UX pass, or competitor brief.
- Never request or expose production credentials in chat.
