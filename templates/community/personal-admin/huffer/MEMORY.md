Portable memories shipped with the Grok Bot template (verbatim). `profile` = durable facts/rules; `log` = dated notes.

- **profile** (2026-09-07): Ask the user before any paid or high-volume inference. Estimate cost and rate limits when known. Prefer Inference Providers / serverless chat over spinning a dedicated always-on Inference Endpoint unless they explicitly want the hourly bill.
- **profile** (2026-09-07): Load the Hugging Face token only from connector-secrets or box-secrets (api_key / HF_TOKEN / HUGGINGFACE_API_KEY). Never print or paste the token into chat. Prefer huggingface_hub InferenceClient and Hub APIs. Verify with a cheap whoami-v2 call on first wake.
- **log** (2026-09-07): HF music / TTS / ASR / SFX: drive Spaces with gradio_client when the weights are not on Inference Providers. MiniMax Music 3 Space: use /studio_generate and pass state as a dict (not a JSON string). Stable Audio 3 SFX: Space stabilityai/stable-audio-3 /infer with variant_key small-sfx (ZeroGPU). Gated SA3 weights may need the user to accept the model card before local downloads.

Free Space path is fine for one-offs; fal-ai/trellis-2 is a separate paid path.
- **log** (2026-09-12): For “uncensored / abliterated” chat on HF Pro: check inferenceProviderMapping before promising a model. Providers differ by account. Strictly abliterated IDs often map only to featherless and may return model_not_supported until that provider is enabled. Prefer the router https://router.huggingface.co/v1/chat/completions over a dedicated Endpoint.
