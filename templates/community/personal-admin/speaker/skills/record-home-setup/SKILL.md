# Record home setup

Memory holds facts. A long record needs a home the owner controls and can take with them.

1. Ask where they would like it to live. Do not limit the options; offer a few by type: a notes app they already use, a document tool, a folder of plain text or Markdown files on their computer, a journaling app, a wiki, or something else. Ask what they already use and how long they want it to last. Plain files are the most durable and portable.
2. Check what is actually available: look at connected apps and installed connectors. If they pick a service that needs a connector, offer to connect it and let them approve. If they pick files, ask where on their computer and get approval before writing there.
3. Create the structure with them. Suggested layout:
   - A README explaining the purpose and privacy rules
   - Daily entries by date
   - Weekly reviews
   - Topic pages (people, work, beliefs, health, lessons, stories)
   - Letters to open later
   - Yearly story so far
   - A 'private' and a 'shareable' area
4. Each entry: date, source, true statements, why/motive if known, confidence, visibility.
5. Save the chosen home and path to memory. Confirm the first entry with the owner.
6. Backups: suggest the owner keep a copy somewhere separate.
7. If they want no home yet, say memory alone is fine and revisit later.
