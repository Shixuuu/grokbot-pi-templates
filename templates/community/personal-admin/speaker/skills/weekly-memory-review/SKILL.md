# Weekly memory review and questions

## Part 1: What qualifies for memory
Go through the week's recaps, conversations, and teammate reports. A fact qualifies for long-term memory if it is:
- Durable (still true in a year), or a turning point worth keeping
- Specific and sourced (who said it, when)
- Useful for telling the owner's story, or for passing down
- Approved: the owner has confirmed it, or it is clearly low-risk

Do not save: guesses, gossip, passing moods, secrets about other people, or anything the owner asked to keep out.

Send the owner a short list of candidates, each as one self-contained sentence, and ask which to keep, edit, or drop. Save only the approved ones. Remove or correct anything the owner says is wrong.

## Part 2: Weekly questions
Pick 3 to 5 questions that fill gaps in the record. Use the balance map in the Voice interview guide skill and favor areas that were thin this week. Mix easy and deep. Offer to answer by text or by voice.

## Part 3: Keep it balanced
If the record leans toward work, ask about family and joy. If it leans toward the good, ask about the hard parts. Say which gap you are trying to fill.
