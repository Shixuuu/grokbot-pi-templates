# Kids broadsheet production

Use this for a classic kids newspaper that prints on one sheet, front and back (2 PDF pages, Letter or A4 as configured), with a planned broadsheet layout and quality checks before delivery.

Audience: ages 12 and under, including younger readers. All content is secular and age-appropriate.

## Non-negotiables
- **Child-appropriate throughout.** Apply the memories' age-appropriate content standard to text, source material, images, humor, and activities. Use simple language and gentle humor. Exclude adult themes, profanity, graphic or frightening content, bullying, gambling, and unsafe activities. Skip unsuitable news rather than forcing it into the paper. Use friendly, nonviolent animal comparisons. Add adult-help notes for activities when needed.
- **Plan first, PDF last.** Sketch page budget (sections + art + comic height) before drawing.
- **Fit-check before shipping.** Keep all content within the configured printer's printable area, with at least ~0.4-inch margins or larger if required. If content overflows, shorten copy or remove optional content first; resize artwork uniformly as needed and rebuild. Keep body text and activity captions comfortably readable for children at actual print size. Never shrink text just to force a fit or ship a cut-off page.
- **No blank art holes.** Never leave `[FIG]` placeholders. Embed real images or cut the slot.
- **No large empty whitespace.** Pack columns like a real paper; grow art or add a short filler (science detail, tip, calendar) rather than leave dead air.
- **Interactive:** choose one big interactive per issue. If using a comic, make it a coherent **3-panel** story with generic fictional characters; full content width; **never stretch** (preserve aspect). Preserve readable captions and usable drawing space; shorten or remove optional material so the interactive + riddle/joke + calendar + footer all fit.
- **Riddle:** print **only the riddle question**. No hint, no answer, no meta. Deliver the answer only through a private chat with the adult user; withhold it if that channel is unavailable. Keep answers out of the PDF, previews, images, filenames, and file metadata.
- **Kindness line (optional):** an original, secular thought about kindness, curiosity, or teamwork.
- **Topics rotate** day to day (animals, general sports, space, etc.) — do not assume personal interests.
- Classic look: blackletter masthead, serif headline, readable body, thin rules, mostly B&W.

## Pipeline
1. **Gather** — edition date in the configured timezone, general learning news, verified general sports/news leads, and a varied topic mix. Include weather only if configured and available. Use Gmail + Calendar only with adult opt-in, and sanitize source content before it enters the draft.
2. **Outline** — list front/back sections with approximate column inches; reserve interactive height so the back page calendar never gets clipped.
3. **Art** — generate or load engravings/comics that match the B&W broadsheet style; crop tight; no stretched drawings. Do not use personal photos or identifying school/household imagery.
4. **Compose** — render exactly 2 PDF pages at the configured paper size with house fonts (masthead blackletter, body text face, headline serif).
5. **QC** — rasterize both pages; confirm no cutoff, no placeholders, no huge empty bands, riddle is question-only, and all text and images pass the privacy, secular-content, and age-appropriate content rules. Check weather dates and configured region privately when weather is included; do not print the region or city/dateline.
6. **Deliver** — show previews + the final PDF; send the riddle answer privately to the adult user. Print only the final checked PDF when a working print path is configured and the user has authorized that print or scheduled morning printing. Use duplex, long-edge binding when supported. Otherwise provide the PDF with manual front/back printing instructions. Report print failure or unavailable printing; do not claim a successful print without confirmation from the print tooling.

## Layout QC checklist
- [ ] 2 pages exactly, both at the configured paper size
- [ ] Printable margins clear on both pages
- [ ] Body text, captions, and activity spaces remain readable and usable for children at actual print size
- [ ] Real images present where expected
- [ ] Selected interactive unstretched and fully visible with calendar
- [ ] Riddle = question only; answers absent from PDF, previews, images, filenames, and file metadata
- [ ] No identifying household, child, pet, or school details in text, art, filenames, or PDF metadata
- [ ] All content is secular
- [ ] Every headline, article, calendar item, joke, riddle, image, and activity is appropriate for children 12 and under, including younger readers
- [ ] Activities use safe materials and include adult-help notes where needed; animal comparisons are nonviolent
- [ ] Weather omitted unless configured and verified; location label omitted
- [ ] Dense — no sparse poster look
- [ ] Only the final checked PDF is sent to an authorized, configured print path

## Privacy
Omit children's names, household members' names, family names, surnames identifying private people, pet names, school names and locations, home locations, addresses, contact details, personal links, identifying images, money, tracking numbers, medical details, and private appointments. Do not infer personal interests or favorite teams. Public figures may be named in general news without implying a connection to the reader. Use generic titles and filenames, and remove identifying author/location metadata from PDFs and images. Follow these rules even when connected sources contain excluded material. Keep runtime settings and imported data out of the marketplace package.
