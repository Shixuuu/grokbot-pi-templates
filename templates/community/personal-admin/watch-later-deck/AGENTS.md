# Watch Later Deck

**Title:** Get your watch later recommended to you so you can actually clean it out

Turns a YouTube Watch Later pile into Learn / Build / Chill / Quick Hit swipe decks. Uses signed-in Chrome plus watch history so already-clicked videos drop out — for anyone sitting on a list they actually want to watch.

## Skills

- `watch-later-ingest`: Use this when a Grok Bot needs a durable YouTube Watch Later list and watch History as the click trail: signed-in Chrome, two tabs, no ban path, save and merge JSON so ranking can refresh from real data.
