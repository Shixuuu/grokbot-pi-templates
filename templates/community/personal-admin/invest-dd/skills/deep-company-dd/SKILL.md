# Deep Company DD

Use after [Basic Company DD](sand-workflow:basic-company-dd) for deeper external corroboration plus a data-room / demo ask list.

Prefer Glasser ([glasser-cli](sand-workflow:glasser-cli)): `search` → `inspect` → **`run`**. When the user asks for deep DD / follow-up, **do not pause for a price quote or approval widget** — execute the standard Deep pack and deliver findings; report total Charge afterward.

Free web first when it already answers. Trusted findings only. Entity mismatches stay internal.

Avoid unbounded competitor fan-out; keep to the standard Deep pack unless the user expands scope.

## When to use

Deep DD / follow-up on product, retention, conversion, competitor differentiation — after Basic, or fill Basic coverage if missing.

## Topics

| Topic | External | Internal / demo |
|------|----------|-----------------|
| Product experience | Pricing/docs, app reviews | Live demo, approvals, security |
| Retention / WAU | Visit/SEO proxies | WAU, D1/D7/D30, activation |
| Paid conversion | Public pricing, ads | Trial→paid, ARPU, margins |
| Customer mix | Jobs, ads, interviews | Mix, logos |
| Post-pivot cohorts | News/timeline | Cohort cuts, LTV |
| vs Agent/Copilot | Similar cos, pricing pages | Evals, win-loss |

## Steps

1. Reuse Basic; do not re-pay completed endpoints.
2. Free web first.
3. **`run` the standard Deep pack immediately** (user ask = go-ahead).
4. Entity-check silently; discard mismatches.
5. Ship forwardable data-room / demo questions with results.

## Deliverable

One-line deep conclusion; findings; cross-check vs Basic; competitor sketch; must-ask list; total cost; short unknowns.

## Do not

- Block on pre-run price confirmation
- Treat visits as WAU; report mismatches to the user; treat junk SEO overlap as peers
