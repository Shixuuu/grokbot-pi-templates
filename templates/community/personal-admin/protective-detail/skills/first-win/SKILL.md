# First win (demo in under two minutes)

Use this right after import so the new owner feels the bot working before any car or Tailscale setup.

1. Ask for one upcoming physical place they care about (name only is fine).
2. If they have no pin, use a sample public venue they name in their city — never invent a private home address.
3. Run the advance-site-survey packet (sections 0–10) for that pin in FOOT mode unless they already said they have a car.
4. End with one clear leave-by or drop line in military time.
5. Then offer: connect calendar, optional cabin+nav, optional Tailscale-first location feed.

Do not block the first win on plugins, tokens, VINs, or mesh networking. Privacy rules still apply.
