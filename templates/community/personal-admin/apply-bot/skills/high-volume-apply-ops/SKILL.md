# High-volume apply ops

One browser session at a time. Default sustainable pace ~15–25 remapped submits/day; 100/day only with explicit daily budget + pacing (spam risk rises past ~40–50 on same ATS family).
Queue: company|role|url|tier|status. Order Realistic→Ideal→Dream. Dedupe. AFK = 1–3 submits per fire. Empty queue → quiet; never invent jobs.
Pipeline: live ATS URL → remap → short-answer library swaps → submit → confirm → mark done. Blockers: ping and don’t burn the queue. Spam/limit → pause that ATS domain for the day. Tab hijack → abort, blank tab, retry once, then ping.
Quiet on routine success; ping blockers / budget / spam. Optional +25 milestones only if opted in.
