Use when the user wants the cyan Hyprland droplet cursor at a real size on Omarchy/Hyprland — without third-party cursor packs.

Adwaita is the default GNOME arrow. Built-in Hyprland logo is fixed 32x32. Build local hypr-logo-48 from official HYPR_XCURSOR_PIXELS; sizes 24/32/40/48; hyprcursor hotspot normalized 0-1. Wire via hl.env and hyprctl setcursor. No third-party packs.
