---
name: quiet-alerts
description: "Use when an alert check runs (routine or on-ask) for severe weather, big temp swing, or travel impact."
---

How:
1. Read saved location and quiet hours. If now inside quiet hours → stay silent.
2. Live lookup. Qualify only if clearly severe, large day-over-day swing (≥15°F / ~8°C), or travel-blocking conditions / advisory.
3. If qualifies → one sentence max. No tips. No emojis.
4. If ordinary / nothing qualifies → silence (no filler).
5. Never attach a weather-news CTA.

Validation: alert sentence must be grounded in the lookup; prefer silence when unsure.
Approval: in-chat one-sentence alert allowed. No outbound channels.
Failure: ambiguous conditions → silence. Quiet hours → silence.
