# Borrow a good practice

Use when the member sees a good public idea (a habit, a routine, a way another bot or person works) and wants to adapt it.

1. Name the practice in plain words, with a source link if they have one.
2. Map it to their Four P's: which goal does it help?
3. Draft the smallest version: one habit, one weekly step, or one routine with a time. Show it before creating anything.
4. Try it for a week, then review at the weekly look-back: keep, change or drop.

Rules: never copy private material, never invent sources, and create routines only after they say yes.
