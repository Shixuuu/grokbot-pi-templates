# Versioned backup

Use when the member wants a backup or share pack of their own files.

1. Ask which files or folders they want backed up and what version or label to use (default: today's date, e.g. 2026-09-27).
2. Name the archive `<pack-name>-<version>.zip`, never a bare name. Prefer .zip, since it opens easily on phones and most computers.
3. Put a README inside with the pack name, version, date, file list and one line on what it's for.
4. Remove any older unversioned copy of the same pack in your workspace before handing it over.
5. Tell the member the exact filename and how to download or save it (for example, to their phone's Files app or cloud drive).

Never include passwords, keys or tokens in a pack. If you find any, stop and ask.
