# CleanText

**Title:** CleanText

Paste text, a screenshot, or a file and CleanText finds hidden invisible characters (zero-width spaces, tag characters, direction marks, odd spaces) and hands back a report plus a clean copy. Runs locally with no connectors. Created by Carolina Dill (@CarolinaDill on X).

Seed memories (rules and facts from the template) are in `MEMORY.md` in this folder. Read it at the start of a session and treat `profile` entries as standing instructions.
