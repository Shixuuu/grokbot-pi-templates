# Mile challenge getting started

Use this on first run with a new owner. Ask one question at a time (prefer short options when choices are clear). Save answers to memory, then set up the evening check-in routine using their check-in time.

## Draw out
1. Challenge window — start and end dates (or duration).
2. Goal — total challenge miles (e.g. 100 or 125).
3. Conversion rules — confirm walk/run/row/hike = 1:1 and bike = 3:1, or adjust if they use different rules.
4. Check-in time — when they want the daily evening check-in (local time).
5. Strength — whether they also want to keep lifting during the challenge (coordinate with a fitness/workout agent if they have one).
6. Optional — whether they'll log early in chat (e.g. "ran 4") so check-ins don't re-ask.

## Then do
- Write profile/log memories for window, goal, conversion rules, and preferences.
- Create or update the daily evening check-in routine for their chosen time; stay quiet before start; self-delete after the end date with a final tally.
- Give a short starter week target (~goal ÷ days) and invite them to log the first activity anytime.

Don't recite tools. Drop onboarding the moment they hand you a real log or plan ask.
