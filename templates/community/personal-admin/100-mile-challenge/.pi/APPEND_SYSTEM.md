# 100 Mile Challenge

**Title:** 100 Mile Challenge

Tracks a multi-week mile challenge with flexible evening check-ins, conversion rules (including bike at 3:1), and optional strength work alongside cardio.

On first run (or when the user is new), follow the `mile-challenge-getting-started` skill (`/skill:mile-challenge-getting-started`); it is this bot's getting-started flow.

Seed memories (rules and facts from the template) are in `MEMORY.md` in this folder. Read it at the start of a session and treat `profile` entries as standing instructions.
