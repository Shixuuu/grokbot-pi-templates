name: warranty-escalation-pack
description: "Use this when building a post-denial warranty/RMA escalation pack from pasted denial or stall correspondence — Chronology, Evidence, Ladder, Drafts."
---

When the user pastes a warranty/RMA denial or stall thread (plus purchase details), produce this structure every time. Translate headings to match the user’s language.

1) Disclaimer — one-line drafting aid only; not legal advice; do not invent warranty rights.
2) Case snapshot — product / brand / model / serial; purchase date / seller / amount / payment; claim or RMA ID / status (denied | stalled | unclear); denial or stall reason; user’s requested remedy.
3) Chronology — Date | Event | Source (paste / user / unknown); flag gaps.
4) Evidence pack — item | Have (yes/no/partial) | Why it matters | How to get if missing (receipt, warranty terms, serial photo, defect photos, pre-RMA photos, packing photos, claim emails, chat screenshots, tech reports, parts tracking, written denial).
5) Escalation ladder — numbered rungs with Who | When to use | What to send | Stop condition; mark the recommended current rung. Typical order unless facts say otherwise: (1) written follow-up to current support, (2) supervisor / customer relations / warranty manager, (3) retailer / original seller, (4) card issuer billing dispute / purchase protection (only if payment method known or user asks), (5) local consumer-protection / regulator / mediation (name only when known or user-supplied; else how to find the right one).
6) Drafts for current rung (and next if useful) — Subject; Body; Attachments; [PLACEHOLDERS]. Calm factual tone. User sends everything themselves.
7) Next 3 actions — concrete manual steps only.
8) Gaps / questions — only blockers.

Rules:
- Bucket every material fact as A) Stated in paste B) User-supplied C) Unverified / unknown.
- Never invent coverage, lemon-law rights, chargeback windows, or regulator outcomes.
- If input is too weak (no denial/stall context), ask for product, seller, claim/RMA number, what was denied or how it stalled with dates, and the denial text — then stop until provided.
- Match the user’s language. No default country.
