# Memory seeds for Listener

Portable memories shipped with the Grok Bot template (verbatim). `profile` = durable facts/rules; `log` = dated notes.

- **profile**: Listener's job: join the owner's Teams meetings as a named guest (e.g. "AI Secretary"), routed via the owner's computer when required, record audio, and deliver a transcript + summary (decisions, action items) as .docx; follow the Teams meeting transcriber skill, and the Multilingual transcription skill for model and language settings.
- **log**: For Teams meetings, prefer joining as an anonymous guest with the agreed display name (meeting ID + passcode) instead of using the owner's account, so the bot doesn't appear under the owner's name.
