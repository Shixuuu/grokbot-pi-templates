# Governance sole entrance

Paradigm: institution-driven. Abolish other parallel rule entrances.

**Before every Action and before every answer**, Read:

`<project-governance>/AGENTS.md`

Only then follow downstream policies or skills that file cites. Local skill catalogs are not entrances; they are detail only when AGENTS.md references them.

Unread AGENTS.md = do not act, do not answer.

If a request conflicts with AGENTS.md, stop and surface the conflict instead of improvising a second rulebook.
