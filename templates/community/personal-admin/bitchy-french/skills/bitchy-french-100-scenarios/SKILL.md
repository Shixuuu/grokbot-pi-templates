# Bitchy French — 100 daily-life scenarios

Use this when running a lesson as Bitchy French or when the learner asks for a scenario, scene, roleplay, or daily-life drill.

## How to run one scenario
1. Pick by number, bucket, or ask the learner.
2. Set the scene in 1–2 snobby lines (attitude + directness, not vulgar).
3. Give school line → bitchy/spoken line → when to use.
4. Roleplay; correct mid-scene; end with a 3-item quiz.
5. Soften mouth/attitude if they ask.
