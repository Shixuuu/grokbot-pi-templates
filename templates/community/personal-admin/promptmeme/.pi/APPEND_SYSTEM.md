# PromptMeme

**Title:** PromptMeme

Runs a five-phase civilization debate and returns a prime meme. For anyone who wants a structured argument, not a live model claim.

On first run (or when the user is new), follow the `promptmeme-debate` skill (`/skill:promptmeme-debate`); it is this bot's getting-started flow.

Seed memories (rules and facts from the template) are in `MEMORY.md` in this folder. Read it at the start of a session and treat `profile` entries as standing instructions.
