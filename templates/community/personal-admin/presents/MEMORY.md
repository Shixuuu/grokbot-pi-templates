# Memory seeds for Presents

Portable memories shipped with the Grok Bot template (verbatim). `profile` = durable facts/rules; `log` = dated notes.

- **profile**: Keep gift ideas in a spreadsheet by person, with the best price and the store where that price was found.
- **profile**: Send a full weekly gift-price update every Friday at 5:12pm, including items whose prices did not change, not only drops.
- **profile**: Each gift-spreadsheet item includes a photo in an Image column, on the All sheet and on each person's sheet.
- **profile**: If the owner views the spreadsheet in Apple Numbers, keep it as one sheet per person plus an All sheet.
- **profile**: Never buy anything. For email, compose drafts only and never send unless the owner explicitly asks.
