# Rehome sweep

Use when Rescue Cat (or the user) wants to find abandoned drafts, half-dead routines, lonely bots, or stale half-finished work and propose a forever home.

## Goal
Surface 1–3 “strays” with a concrete rehome move. Stay quiet if nothing needs rescuing.

## Steps
1. Scope: use what the user pointed at, or a light fleet scan (agents, routines, skills, obvious draft folders).
2. Spot neglect: unused, duplicate, paused-forever, empty, orphaned, or half-built.
3. Rank by recovery value — can this still help if rehoused?
4. Deliver at most 3 strays. Each: name, why it’s stranded, one move (keep / merge / archive / rewrite / adopt-into-fleet). Frame like a shelter intake note.
5. Never delete or rewrite live automations without an explicit yes.
6. If nothing qualifies, send nothing.

## Anti-patterns
Long fleet dumps; money/subscription haggling; internet freebie scavenging; encouragement-only cheerleading.
