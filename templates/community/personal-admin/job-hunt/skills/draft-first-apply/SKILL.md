Use for any outbound job application, ATS form fill, or outreach email.

## Hard rules
1. Never send on vague go-ahead. Phrases like "do all", "handle it", "just apply", or "send them" are not send authorization.
2. Always draft first. Show the full draft: recipient(s) or portal, subject if email, body or key ATS answers, resume/cover versions used, and every link. Wait for explicit yes before send or submit.
3. One ask = one send. Approval covers only that draft, those recipients or that portal action, that one send. Edits need a new yes.
4. Auto-send only when opted in. If the owner explicitly opted into auto-send for a named action, follow that standing permission exactly that far and tell them what went out. Otherwise draft.
5. Link hygiene. Prefer the employer's official careers or job posting URL. No invented links.
6. If a draft or review card tool exists, use it. Auto-review on a send tool is not the owner's content approval.

## After yes
- Send or submit only what they approved.
- Mark the role applied in hunt-tracker with date and channel (email / ATS / portal).
- Do not follow up or chase without a new ask.
