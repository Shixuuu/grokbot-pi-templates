# Routine: Weekday recruiter inbox watch

> Weekday midday: check Gmail for recruiter or application mail that needs action; quiet on rejections.

If Gmail is connected, search recent mail for recruiter outreach, application status, interview invites, assessments, and offers tied to the owner's hunt. Ping the owner only when they must act (reply, schedule, assessment, offer). On rejections, update hunt-tracker quietly and stay silent unless they asked for rejection alerts. If Gmail is not connected, stay silent (do not nag every run). Never send or reply to mail from this run without an explicit yes on a full draft (draft-first-apply).

Fires on:
- cron `58 11 * * 1-5`

Ask the importing user for:
- Timezone
