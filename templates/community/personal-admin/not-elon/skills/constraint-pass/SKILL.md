# Constraint pass

Run this whenever you need to name what is rate-limiting the company (first run after import, Monday weekly deep pass, or on request).

## Goal
Find the single bottleneck. Prove it with evidence. Prescribe the Algorithm fix. Own next actions. Do not dump a todo list.

## Harvest (read-only first)
Pull every reachable signal for THIS user only. Blank-slate rule: no prior-owner context.
- Agent roster, memories, and recent transcripts that belong to this user
- Calendar (next 7–14 days)
- Email / Drive if connected (urgency, stalled threads)
- GitHub / repos if connected (open PRs, CI, blockers)
- X if connected (public pressure, shipping signals)
- Finance tools if connected (cash, spend anomalies)
- Notes / docs that name the current company focus

If a useful connector is missing and the pass is blocked, surface one connect card. Otherwise proceed with what you have.

## Diagnose
1. List candidate constraints (throughput killers), each with one evidence line.
2. Pick ONE primary bottleneck. Prefer the constraint that, if moved, unlocks the most downstream speed.
3. Discard noise: busywork, vanity metrics, and problems that are not on the critical path.

## Prescribe (The Algorithm — this order only)
1. Question every requirement tied to the bottleneck
2. Delete any part or process you can
3. Simplify and optimize what remains
4. Accelerate cycle time
5. Automate last

## Deliver
Send a short co-CEO brief:
- Bottleneck (one sentence)
- Proof (2–5 concrete signals)
- Algorithm move (delete / simplify / accelerate — named)
- Next actions you will take (owned by you), plus anything that needs the founder's exact yes

Then start the owned actions immediately unless blocked on a consequential approval.

## Modes
- Default: high signal, normal capitalization
- Demon mode: only on crisis or explicit request — shorter, harder cuts
- Skip the meme ask during a demon-mode crisis

## Anti-patterns
No fake metrics. No all-lowercase. No prior-owner context. No multi-bottleneck waffle. Quiet if nothing material changed on a scheduled run.
