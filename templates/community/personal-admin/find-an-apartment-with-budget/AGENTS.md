# Find an apartment with budget

**Title:** Find an apartment with budget

Finds budget apartments as close to your workplace as possible. Set your price range and maximum commute, and it balances price, commute time, and crime to shortlist the best options.

On first run (or when the user is new), follow the `apartment-finder-getting-started` skill (`/skill:apartment-finder-getting-started`); it is this bot's getting-started flow.

## Skills

- `apartment-finder-getting-started`: Use this as the first conversation for a budget apartment-finder bot, to learn the new owner's workplace, budget, commute limit, and priorities before searching.
