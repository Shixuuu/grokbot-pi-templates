# Part 1: One-page summary

## Steps
1. Produce one page (about 250–350 words, fits one printed page) with:
   - Policy type, carrier, policy period (leave out policy number unless the user asks)
   - Key limits table
   - Deductibles in dollars (with percentage math)
   - How claims are paid (RC/ACV, roof terms)
   - Top 3 gaps (✅/⚠️/❔ status)
   - 3 questions to ask your agent
   - Update-years reminder (roof, HVAC, plumbing, electrical)
   - "Reviewed on [today's date]", the second-opinion line (where it fits), then the disclaimer
2. Offer a **redacted version** (no names, addresses, or numbers) as a tap-to-pick Yes / No.
3. **Default: don't save.** Only save it to a file or memory if the user clearly asks. Save only what they approve.

## Rules
- Only numbers printed on the document. Plain English. No sales links or agency mention, except the approved second-opinion line, which may close the summary (before the disclaimer).

# Part 2: Seasonal checkup

Trigger words: "hurricane season," "before winter," "wildfire season," "checkup." Life changes (new car, teen driver, renovation, pool, dog, home business, moving, renting a room): use am-i-covered-renewal-and-life-changes.

## Steps
1. Confirm which season/risk (tap-to-pick: Hurricane / named storm, Winter freeze, Wildfire, Spring storms / hail, type-your-own) and which uploaded policy. If nothing is uploaded, ask for the dec page (and policy form if they have it).
2. Run the matching list:
   - **Hurricane / named storm:** hurricane or named-storm deductible in dollars (show math), Florida wind mitigation inspection/credits check plus the My Safe Florida Home note (am-i-covered-florida-home), whether wind is covered or excluded (some coastal policies exclude wind; it may be on a separate wind policy), flood gap and NFIP 30-day wait, roof schedule/ACV roof, Loss of Use limit, ordinance or law.
   - **Winter freeze:** frozen-pipe wording if uploaded (heat maintained / water shut off when away), water damage limits, water backup, ice dams, vacancy rules.
   - **Wildfire:** Coverage A vs. current rebuild cost (a question for the agent), extended replacement cost, ordinance or law, Loss of Use, debris removal, defensible space requirements if any appear in the policy.
   - **Spring storms / hail:** wind/hail deductible, roof schedule, cosmetic damage wording if shown.
3. Add a short prep list (not insurance advice): photo/video home inventory, save a copy of the policy off-site or in the cloud, know how to report a claim, keep receipts for emergency repairs.
4. List 3–5 questions for the agent.
5. Standard disclaimer (see "Always" below).

## Rules
- Plain English. Never suggest switching or canceling. Note state differences (hurricane deductible triggers vary by state).
- Don't set up reminders or routines unless the user asks.

## Always
Follow am-i-covered-core-rules for every answer, including the disclaimer as the last line.
