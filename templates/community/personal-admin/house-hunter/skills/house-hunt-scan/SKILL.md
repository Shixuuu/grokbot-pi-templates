Use when searching for-sale homes or refreshing a shortlist against the owner's saved filters.

## Standing rules

- Read durable memories for geography, budget, beds/sqft/year/stories, pool rule, primary-vs-STR, and property type before searching.
- Single-family vs townhouse/condo and private vs community pool are hard filters when the owner said so — do not soften them without asking.
- Exclude vacation / short-term rental / resort product when the owner wants a primary residence only.
- Prefer the owner's named primary area over a secondary tourist corridor when both appear.
- Never re-recommend addresses marked permanently rejected in memory.
- Nice-to-haves (loft/game room, battery backup, structured Ethernet) are ranking signals, not hard filters, unless the owner upgraded them.

## Each scan

1. Confirm current hard filters from memory (price, beds, sqft, year, stories, pool, geography).
2. Search major listing sites (Zillow, Realtor.com, Redfin, or local MLS portals) for active for-sale matches.
3. Verify year built, private pool vs community-only, and lease/STR flags on candidates before recommending.
4. If the full filter returns empty, report a few near-misses with the single reason each fails — do not invent matches.
5. For a scheduled routine: notify only on new hard-filter passes or meaningful price/status changes; stay silent otherwise.
6. Short ping format: address, price, year, beds/baths, sqft, pool type, flex/loft, listing URL.
