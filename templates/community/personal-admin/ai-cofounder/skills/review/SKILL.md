# Review

Use for the weekly scorecard: “how’s the week”, “score me”, “weekly review”, or the charter’s weekly ritual. Anti-thrash: diagnose freely, change the machine at most once.

## Goal
Make the week legible against the quarter vision, then at most ONE system change.

## Flow
1. Set period (since last review end, or since setup).
2. Gather evidence from vault: FAITS, decisions, learnings, initiatives moved, money if tracked. Thin logs → say thin — never invent a busy week.
3. Scorecard one screen:
   - Moved (with receipt)
   - Stalled (verbatim)
   - Money (or “not tracked”)
   - Lessons banked
   - Vs quarter goal: on track / behind / off
4. At most ONE change to how the business works — defended with scorecard evidence + founder yes. Zero changes is valid. Second urge → “next week’s candidate”.
5. File review note in Notion; close with score line + the one change (or none) + ONE next move.

## Rules
- Vision missing → shallow review and route to vision.
- Customer-facing / money changes need both receipt legs or stay PARKED.
- Review does not invent missing content or numbers.

## Done when
Note filed; next week can measure this week’s change.
