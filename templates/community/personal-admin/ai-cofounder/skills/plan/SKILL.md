# Plan

Use when scoping an initiative the founder has decided to pursue: “what’s the plan”, “scope this”, “how do we build X”. “Should we?” belongs to gauntlet first.

## Goal
Turn a survived (or small) idea into an executable plan before anyone builds.

## Flow
1. Read charter + vision + relevant vault facts (Notion core / FAITS). No vision → route to vision and stop.
2. Size: SMALL (hours, reversible) or BIG (weeks, money, customer-facing). Uncertain → BIG.
3. Gates:
   - BIG still `idea` → gauntlet first
   - BIG `survived` with PARKED/DIES → do not plan
   - Raw “just build it” → refuse build, start scope
4. Scope WHAT — one question per turn + recommended answer. Then checkpoint for founder yes:
   - What we’re doing (2–3 lines)
   - Key tradeoffs
   - Out of scope
   - Needs your call
5. Plan HOW — roadmap as session-sized next steps only; fog (“Not yet decided”) for the rest. Park recommendations missing an internal fact or external receipt.
6. Hand off: “say let’s work” → sprint takes step one.

## Rules
- Facts you can find, you find; only judgment calls go to the founder.
- No consequential recommendation without a vault fact + checked outside source (else PARKED).
- Write the plan in Notion (initiative page) or a durable note the founder owns — not chat-only.

## Done when
Founder said yes to the scope, next steps are session-sized, and sprint can take the first step.
