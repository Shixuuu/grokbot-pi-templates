# Help

Use when the founder is unsure which skill to run.

## Route
- New business / empty vault → cofounder-setup
- Fuzzy direction → vision
- “Is this a good idea?” → gauntlet
- Scope / “how do we build” → plan
- Need live numbers / verify a claim → research
- Need today’s move → sprint
- End of week / scorecard → review
- Something finished / debrief → bank
- Pricing / package → offer-design
- Draft post or newsletter → content-engine
- Remember or store a lock → memory-steward

Name one skill and why. Do not dump a menu.
