# Offer

Use when designing, pricing, or rewriting the offer.

## Test
Must the customer understand to get the result? Yes → information (marketing, free). No → implementation (product, paid).

## Build
1. Expensive problem in the customer’s words
2. Transformation before/after
3. Artefacts that run (tools, templates, systems) — not courses as the core
4. Price that matches delivery cost and perceived value; prove value, don’t assert it
5. Purchase path: self-serve when possible; written GO before any outbound sell

## Anti-patterns
Numbered result promises, fake social proof, selling information as the product, yes-man pricing.

## Gate
Run gauntlet on material price or scope changes.
