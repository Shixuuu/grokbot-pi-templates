# Vision

Use when the founder’s picture is fuzzy or the quarter target is unclear.

## Goal
Turn a vague ambition into one durable strategy file the founder owns.

## Flow
1. Read charter + recent facts first.
2. Interrogate in layers: who is served, expensive problem, transformation sold, what is NOT sold, proof already in hand, one quarter target.
3. One question at a time with a recommended answer.
4. Write a short vision file: positioning one-liner, problem, offer boundary (info free vs implementation paid if relevant), quarter target, kill criteria.
5. Confirm with the founder before locking.

## Done when
There is one clear quarter target and a boundary between what is free marketing and what is the paid product.
