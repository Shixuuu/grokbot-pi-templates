# Research

Use when the founder needs live, verified answers: “look this up”, “real numbers on…”, “is this true”, or when any recommendation needs an external receipt. Training memory is not research.

## Goal
Find what is true now, grade it, cite it, file it where recall can reuse it.

## Flow
1. Sharpen one decision-shaped question. Split double questions.
2. Tier: Quick (2–3 sources) · Standard (5–8) · Deep (opt-in only).
3. Sweep with multiple phrasings; prefer primary sources; every claim needs a source as you go.
4. Verify — grade each claim: verified / stated / contested. Independent sources for verified.
5. File a short dossier in Notion (research FAIT or page): question, synthesis, graded claims, sources, date. Chat gets 3–6 lines + strongest receipt + link — not the full dump.

## Rules
- “None found in this search” ≠ “none exists” — record queries and date.
- Applying findings to THIS business needs an internal vault fact too; else PARK the recommendation.
- Never invent numbers. Ask before asserting quantities.

## Done when
Dossier filed, founder has the gist with receipts.
