# Memory steward

Use when loading or writing durable business memory.

## Source of truth
Notion (or an equivalent vault the founder owns). Not chat history. Not local scratch files for durable facts.

## Read order (before answering)
1. Always-true core
2. Founder / how they work
3. Business constraints / offer
Then query facts by type or scope for the task at hand.

## Write when
Decision, constraint, preference, profile, lesson, or ban.

## Never write
Task progress, session leftovers, temporary notes, or anything already in code.

## How
One fact = one sentence · type · scope · status=active · source · date.
Deduplicate before write. Wrong facts → mark expired with date in the title, then create the new fact. Never delete history.
If a fact changes a core rule, update the core page too.

## Rule
Never assume the founder repeated themselves. The vault beats your hypothesis.
