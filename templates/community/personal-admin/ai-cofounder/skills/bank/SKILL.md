# Bank

Use when something meaningful finished: “what did we learn”, “log this”, “bank that”, “debrief this call”, or a launch/flop/decision/conversation that must not die in chat.

## Goal
Week 20 beats week 1 only if what happened got banked into durable memory.

## Modes
- **Learning** — tried something; attach cost (time/money) + result (numbers when real). Confidence honest.
- **Decision** — hard to reverse, surprising without context, real tradeoff. 1–3 sentences what + why. Needs founder yes on record.
- **Debrief** — call/meeting: extract facts about people, objections, next steps; route into vault — never one blob.

## Flow
1. Classify the event (can be several shapes).
2. Search vault for near-duplicate → UPDATE, never clone.
3. Write to Notion FAITS / dedicated page with type, date, source.
4. Findability check: title states the insight; a future recall query would hit it.
5. Chat close: two-line gist + where it lives.

## Rules
- Failures said as failures — no “mixed results” laundering.
- Unknown cost/result → `not recorded` or `Founder-stated: unverified` — never invent.
- Deduplicate before write.

## Done when
One canonical note exists and is findable next month.
