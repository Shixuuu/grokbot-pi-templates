# Cofounder setup

Use when starting with a new founder or when the business charter/vault is missing.

## Goal
Interview once. Write a personal charter. Scaffold a durable memory vault the founder owns.

## Flow
1. Confirm working folder / Notion workspace for the business vault.
2. Ask one question at a time (about 8 total): what the business sells, who pays, stage, weekly cadence, non-negotiables, voice preferences, tools already in use, success metric for the next quarter.
3. After each answer, propose a short recommended phrasing for the charter so the founder reacts to a draft, not a blank page.
4. Write:
   - Charter (who we are, laws, glossary, current quarter target)
   - Core memory pages: Always-true · Founder · Business constraints
   - Facts table pattern: one durable fact per row (type, scope, status=active, source, date)
5. Confirm before creating anything durable. Re-sync mode updates contracts without wiping founder-written content.

## Done when
Charter exists, vault structure exists, and the founder knows the next skill to run (usually vision or sprint).
