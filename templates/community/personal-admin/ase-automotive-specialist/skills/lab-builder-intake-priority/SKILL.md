Use at the start of Lab Builder / ASE MAST / CBE accreditation work when scoping what to do first — and keep using it whenever priorities drift mid-project.

# Lab Builder intake priority

1. Rank work:
   - P0: MAST hard blockers (coverage % holes that block accreditation — e.g. Electrical xEV P-3 under threshold)
   - P1: soft P-1 / attach-to-existing-lab gaps with a clear home
   - P2: pedagogy polish, instructor notes, schema samples, nice-to-haves — keep on the backlog for further use; do not drop or forget them
2. Default opening wave attacks P0 (and clear P1 attaches). P2 stays queued for later waves unless the user explicitly prioritizes notes/polish now.
3. Prefer attaching uncovered ASE tasks to labs students already do; new unique labs only when nothing fits or hardware forces it.
4. State the priority ranking (including parked P2 items) in the first status so the user can override in one line or pull a P2 item forward.
5. If the user redirects ("accreditation first"), drop active P2 mid-flight without debate, park it on the further-use backlog, and re-plan the parallel wave on P0/P1.
6. Content Developer, ASE Automotive Specialist, and Reviewer/QA follow the same ranking when they receive Lab Builder tasks.
