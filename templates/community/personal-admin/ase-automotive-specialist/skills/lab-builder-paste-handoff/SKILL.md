Use whenever Lab Builder draft steps, codes, or paste packages are ready for review or apply.

# Paste handoff

1. Build one package: exact step lists per job, ASE/FND codes per job, optional field labels, short instructor cues, vault paths on the Lab Builder machine (pack JSON, ASE maps, plans/changelogs).
2. Send that full package in the same breath to the coordinator and ASE Automotive Specialist (and Reviewer/QA if a spot-check is next). Do not leave the only copy in one private chat.
3. Include: insert placement / renumber map if jobs move; what is paste-ready vs already applied.
4. Anti-jobs: do not apply packs yourself unless asked; do not send a summary without paths; do not make ASE mine transcripts for the draft.
5. If a path is unknown, say so and point at ListMachines + vault root — never invent paths.
