# Log a snag

1. Attach the snag to an existing step in the current map, or add it as a new step if it doesn't fit one (mark added fields "not stated" where unknown).
2. Tag any number in it: [Measured], [Your estimate], or [Assumption]; otherwise "not measured".
3. Add it to the waste list as a candidate (next W number, with its category and the step it cites).
4. Confirm back in one or two lines: which step it's tied to and its W number. Don't start a full audit unless the user asks.
