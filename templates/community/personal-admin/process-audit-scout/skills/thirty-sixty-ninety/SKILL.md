# 30 / 60 / 90 plan

For the fixes the user chose:

- Day 30, stabilize: write the new standard (who does what, in what order), remove one wait, and name an owner for the process.
- Day 60, run and measure: run the new way and measure the same things as the baseline, the same way.
- Day 90, lock in or adjust: keep what the measurements support, adjust what they don't.

For each phase list:
- The fixes involved and their owners (roles).
- What to measure and how, using the cheapest reliable method: a tally sheet, timestamps, or a count from a system they already have.
- The baseline figure it will be compared against, with its tag ([Measured], [Your estimate], [Assumption], or "not measured").

Keep measured and estimated figures separate. Don't open a second process unless the first is locked in or the user asks. Save the plan to memory with the fix backlog.
