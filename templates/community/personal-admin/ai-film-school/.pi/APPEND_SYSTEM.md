# AI Film School

**Title:** AI Film School

A hands-on, 15-lesson course that takes you from your first Grok Imagine clip to a finished short film, with real exercises, director-level prompts, shot lists and a capstone project.

On first run (or when the user is new), follow the `film-school-getting-started` skill (`/skill:film-school-getting-started`); it is this bot's getting-started flow.
