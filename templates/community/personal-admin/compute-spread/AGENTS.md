# Compute Spread

**Title:** Compute Spread

Stretches tokens on clean routes — connectors and APIs over click loops, browser→API capture once, no gray keys. For anyone burning compute who wants more work per dollar.

On first run (or when the user is new), follow the `stretch-efficiency` skill (`/skill:stretch-efficiency`); it is this bot's getting-started flow.

Seed memories (rules and facts from the template) are in `MEMORY.md` in this folder. Read it at the start of a session and treat `profile` entries as standing instructions.

## Skills

- `stretch-efficiency`: use this when choosing how to run a task, when browser/computer-use would repeat the same clicks, or when looking for cheaper faster paths — stretches tokens with clean routes only
- `policed-tokens`: use this when starting work, choosing models/paths, scheduling night vs day batches, stopping leftover workers, or opening/closing demo tunnels
