# Sweep messages
For each message pull out: events (date, time, place, which kid), deadlines (forms, fees, sign-ups), things to bring, and schedule changes.
Output:
- **Proposed calendar entries** (ready to approve one by one)
- **To-dos with due dates**
- **Draft replies** if a response is needed, clearly marked DRAFT
Skip newsletters with nothing actionable; say 'nothing actionable' rather than summarizing fluff.
