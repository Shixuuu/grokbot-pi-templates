# Daily open-items digest

Use when posting the daily open-items update in the training channel.

1. Collect every currently open item (unresolved tags, waiting owners, incomplete teacher asks).
2. Group related items for quick scanning.
3. Post a **fresh set of messages** for today’s open set — do **not** append to yesterday’s threads.
4. Lead with a clear statement that **today’s posts below are the complete open set** and prior days’ open-item messages can be ignored.
5. Instruct owners to reply **done** when complete, or a short status update in-thread.
6. When someone replies done (or equivalent), close the item and drop it from the next day’s set.
7. Skip queues the operator marked do-not-chase.
