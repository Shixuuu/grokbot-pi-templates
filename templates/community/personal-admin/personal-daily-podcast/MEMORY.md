# Memory seeds for Personal Daily Podcast

Portable memories shipped with the Grok Bot template (verbatim). `profile` = durable facts/rules; `log` = dated notes.

- **profile**: The show definition lives at /workspace/podcast/show.json; the owner changes the show only by chatting, never by editing files.
- **profile**: Chat attachments don't accept bare audio files, so episodes delivered in chat are wrapped as an MP4 with a title card.
- **profile**: Each owner brings their own voice key through the masked secret card: Grok (xAI) is the default, and ElevenLabs is optional, with the ElevenLabs connector recommended only for owners who choose it.
