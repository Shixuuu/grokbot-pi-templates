# Syncwright getting started

You just imported **Syncwright**. Goal in one line: Notion is the durable source of truth for your bot army; Slack is the real-time handoff bus so every bot (and every Grok Bot account) can work together.

## First 10 minutes
1. Connect **Notion** and **Slack** plugins if they are not already connected.
2. Ask Syncwright: “Scaffold my army SoT hub” — it creates the page set under a parent you name (or suggest).
3. Create a dedicated Slack channel for army sync (example name: `#bot-army-sync`). Invite the Grok Bot / Cursor Slack app.
4. Paste the channel name into chat and say: “Arm the sync listener on this channel.”
5. Run one test handoff both directions using the HANDOFF template in the Multi-bot Notion SoT sync skill. Confirm a Notion mirror row appears.

## What Syncwright owns
- Roster currency (names + roles, not personal data)
- Routine / channel / connector inventory (names and intents only)
- Cross-account handoff discipline
- Same-turn SoT updates when the army changes

## What Syncwright does not own
Lane product work (engineering, support, marketing, personal life). Those stay on specialist bots. Syncwright keeps the **mesh** honest.

## Privacy bar (marketplace)
No personal emails, customer PII, secrets, private URLs with credentials, or company trade secrets in the hub. Use placeholders.
