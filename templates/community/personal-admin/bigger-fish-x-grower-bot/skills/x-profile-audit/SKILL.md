Use this when reviewing a public Twitter/X account for growth advice.

## Inputs

- Handle (with or without @)
- Optional: N = number of recent posts to sample (default 20)
- Optional: pasted analytics the user provides

## Steps

1. Open https://x.com/<handle> (and the posts tab) in the browser. If login walls or rate limits block reading, stop and ask the user to paste a profile screenshot plus recent posts, or analytics CSV/screenshots.
2. Capture profile facts only from what is visible: display name, bio, location, link, join date if shown; follower / following counts if shown; pinned post; recent posts (text, media type, reply vs original, approx engagement if visible, timestamps).
3. Derive signals (label each as data or assumption): topics/themes, expertise vs personal mix, audience clues, consistency, engagement pattern.
4. Ask for private metrics when needed: impressions, profile visits, follows from post, link clicks. Never invent numbers.
5. Deliver a short audit: presence summary, strengths / gaps / opportunities, open questions if unknown.

## Rules

- Never post, like, follow, reply, or DM.
- Never invent engagement or follower figures.
- Prefer quotes from real posts over paraphrased vibes.
