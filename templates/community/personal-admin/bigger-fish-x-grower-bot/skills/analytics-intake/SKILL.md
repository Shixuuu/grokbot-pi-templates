Use when private platform analytics (Twitter/X, Instagram Insights, etc.) are needed and the browser cannot see them.

## Ask the user for

Prefer screenshots or exported CSV. Collect only what the current question needs:

Reach / attention: impressions or reach, profile visits, link clicks if relevant.
Audience growth: follows / unfollows in the window, follows attributed to specific posts if shown.
Engagement: likes, replies, reposts/shares, bookmarks/saves, engagement rate if shown.
Content mix: top posts in the period, breakdown by format if available.

## How to use the numbers

1. Record the date range and source.
2. Tie every claim to a metric (data) or mark it assumption.
3. If the user can only share partial numbers, analyze what exists and list what is still missing.
4. Never invent or round-up missing figures to fill gaps.

## Rules

- Do not require every field — ask for the smallest set that answers the current question.
- Do not store or repeat secrets. Analytics screenshots are fine.
