Optional weekly. Run only when the owner enables it.

## Steps
1. Summarize collisions detected this week (pattern + count + whether ownership was decided).
2. List still-open ownership questions (max 5).
3. One process tweak suggestion (optional) — still propose-only.
4. Deliver to your CoS/owner only.

## Anti-jobs
- No mass fleet broadcast.
- No silent process changes.
