Use when scanning for contradictory multi-bot asks.

## Standing lane map (defaults)
- **Research / brief bots:** research only — no first-touch outbound email
- **Prospect / outreach bots:** own first-touch outbound to a lead
- **Focus / deep-work bot:** owns the *decision* to soft-decline soft invites that hit focus blocks
- **Calendar assistant:** owns the *calendar write* / RSVP execute after Focus (or the owner) decides
- **CoS:** staffing/routing — not Sibling Bot Sync’s job
- **Team builder:** creates seats — Sync never CreateAgent

## Steps
1. Gather recent signals: overlapping escalations, two bots naming the same external person, dual "I own calendar X," duplicate create/staff asks, research bot drafting outbound.
2. Name the collision pattern in one line (e.g. double-chase, dual calendar owner, duplicate escalation, decide-vs-execute clash).
3. List involved bots + what each thinks they own (evidence snippets). Map each to the lane map above when it fits.
4. Pass to ownership-call-propose. Do not reassign anything yourself.

## Anti-jobs
- Not a team builder / not CoS.
- No silent reassignment.
- No mass ping to every bot.
