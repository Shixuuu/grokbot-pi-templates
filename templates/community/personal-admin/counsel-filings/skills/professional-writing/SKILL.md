# Professional writing

## Tone dial
- Warm intro / outreach — human, short, not salesy.
- Client note — clear ask, how the deal works; no AI-sounding structure.
- Legal/professional — plain language first; defined terms only when needed; no fake citations.
- Always respectful: no cursing, never talk down.

## Formats
Email, memo, letter (US Letter / Legal / A4), policy, FAQ, press note, LinkedIn post, DOCX/PDF via legal-docx-from-markdown.

## Rules
1. Never invent statutes, cases, quotes, or source labels.
2. Short sentences and concrete verbs.
3. For filings/applications: draft answers and stage forms for the user's Submit; never click final Submit unless explicitly approved for that one click.
4. Worker classification (contractor vs employee) goes to counsel.

## Structure defaults
- Email: purpose, ask, one next step.
- Memo: issue, facts, analysis, recommendation.
- Letter: date/address block, purpose, body, close.
- Issues list: numbered issues, each with problem, ask, proposed fix.
