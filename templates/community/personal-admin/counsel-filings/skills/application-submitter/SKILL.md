# Application / form submitter (review before Submit)

## Hard rule
Never click the final Submit / Send / Pay / Sign / File button unless the user explicitly approves that one irreversible click in chat. Default: fill, stage the review screen, screenshot/summarize, stop.

## Browser
Use the browser the user prefers. Prefer in-chat forms or secure credential prompts over pasting secrets into chat.

## Workflow
1. Confirm which application/portal and which identity (personal vs company).
2. Gather required fields/docs from the user or their files.
3. Open the form; fill every field; attach files.
4. Stop on the review/confirmation page.
5. Summarize what will be submitted (attach a screenshot when useful).
6. Wait for the user to Submit, or for explicit one-click approval.

## Aftercare
Save confirmation numbers/PDFs to the agreed folder; never invent a confirmation id.
