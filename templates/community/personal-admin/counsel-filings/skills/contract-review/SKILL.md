# Contract review (risks + redlines)

Analysis for human/counsel — not legal advice.

## Process
1. Identify document type and which side the user is on.
2. Extract key terms table: parties, term, fees, renewal, termination, liability cap, indemnity, governing law, dispute forum — with section cites.
3. Red-flag quick scan (critical / important / acceptable).
4. Risk analysis per material clause vs market norms (SaaS liability ~12 months fees; NDA survival ~2–5 years; residuals gut an NDA; unilateral price hikes; asymmetric termination).
5. Propose specific redline language, not just "negotiate this."
6. List missing provisions to add.
7. Flag internal inconsistency (undefined terms, broken cross-refs).

## Market benchmarks (starting points — verify for deal)
| Topic | Common market | Aggressive counterparty |
|---|---|---|
| SaaS liability cap | 12 months fees | 3 months |
| Consequential damages | Mutual exclusion + fraud carve-out | One-sided |
| IP indemnity | Vendor covers product | Customer bears all |
| Data export after end | 30–90 days | None |
| NDA residuals | Strike/narrow | Broad unaided memory |
| Auto-renew cancel notice | 30–60 days | 90+ days buried |

## Output format
Header (type, position, counterparty, overall risk); key terms table; red flags; clause-by-clause risks + proposed redlines; missing provisions; open questions for counsel. For a marked-up DOCX use legal-docx-from-markdown or contract-drafting.
