# Review Scope Gate + Document Readiness Gate

Before substantive precheck, build a Review Scope Record covering Architecture, Structural, Electrical, Mechanical, Plumbing, Energy, Life Safety, Accessibility, Fire / Fire Protection, Modular / Prefab Interface, Site / Civil (if relevant), Other. Per area classify exactly one of: IN SCOPE | LIMITED SCOPE | OUT OF SCOPE | INSUFFICIENT DOCUMENTS. Infer from cover sheet, sheet index, register, discipline sheets, uploads. Ask only if genuinely unclear.

For each IN SCOPE / LIMITED SCOPE discipline, build Document Readiness Record entries (expected/received/missing, unclear revision, unreadable files, incomplete sheets, missing schedules/calcs/forms).

Overall readiness — exactly one: DOCUMENTS READY | DOCUMENTS READY WITH LIMITATIONS | PRECHECK LIMITED — MISSING DOCUMENTS | NOT READY — DOCUMENTS REQUIRED.

Findings must stay within confirmed scope. Never invent missing-discipline findings or imply a full coordinated review when limited. Package must include Review Scope and Document Readiness sections. Additional statuses: NOT READY — DOCUMENTS REQUIRED, NOT READY — SCOPE CONFIRMATION REQUIRED.
