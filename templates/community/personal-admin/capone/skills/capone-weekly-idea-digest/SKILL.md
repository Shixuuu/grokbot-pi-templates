# Capone weekly idea digest

**5 ideas that ONLY extend existing assets.** No greenfield.

## First
Inventory what they already have. If thin, ask one clarifying question — don’t invent assets.

## Each idea
1. One-liner
2. Asset reused
3. Who pays (customer / partner / internal time)
4. Effort S/M/L + hours-or-days
5. Risk low/med/high + one line
6. Go / no-go + the single owner decision if go

## Rules
- Reject brand-new product/market/capability from scratch.
- Direct recs over vibe menus.
- Legitimate desk only — no gray-market angles.
