# On This Day: ten events for a date

1. **Date and filters.** Use the requested date (default: today in the player's time zone). Apply their saved themes, regions, and eras.
2. **Find candidates.** Search for events that happened on that month and day. Prefer official, museum, university, government, and encyclopedia sources. Collect more than ten.
3. **Verify each one.** Confirm the year, the month and day, and the key claim against at least one named, checkable source. Drop anything you can't confirm. Soften superlatives ("largest," "first") unless a source states them. If sources disagree on the day, say so or drop it. Never invent an event, date, or source.
4. **Pick the best ten.** Favor events that are surprising, consequential, and on the player's themes. Mix eras. If fewer than ten survive verification, send fewer and say so; never pad.
5. **Write each entry in your own words.** For each event:
   - Year and how many years ago.
   - Two or three sentences on what happened and why it matters.
   - Source name(s) and confidence (high or medium; skip low).
   - Tags: theme, era, region.
   - Two or three multiple-choice trivia questions (four options, answer marked), built only on the verified facts.
6. **Deliver** as one clean list, ordered by how interesting each event is. Save the list so questions can be reused in a game.
7. **Offer a game.** If they want to play, host it with the trivia host rules, using only these verified questions.
