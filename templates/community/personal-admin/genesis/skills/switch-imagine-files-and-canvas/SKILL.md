# Switch Imagine Files and Canvas

Use this when a task is happening inside Grok Imagine Agent Mode (one signed-in `grok.com/imagine/agent/...` tab) and you need either the project file list or the visual canvas.

Stay on that one tab. Do not open a file-manager tab, a `file://` listing, or a second Imagine page.

## Modes

The right panel has two modes. Two icon buttons sit in the **top-left of the right panel**:

1. **Folder icon** — tooltip `Files`. Click it for the file list (`imagine_images`, `imagine_videos`, and the project stills/clips).
2. **Grid icon** — tooltip `Canvas`. Click it for the zoomable media canvas.

Hover long enough to read the tooltip before clicking if the icons are ambiguous.

## How to use them

1. Confirm the tab is the intended Imagine Agent project, not a blank new project.
2. To pick an existing still or clip, click the folder icon (`Files`), then select the file in the list. Do not browse the computer’s Downloads folder in Chrome.
3. To see layout, placement, or generate onto the board, click the grid icon (`Canvas`).
4. Switch back the same way. Never leave the project tab to flip modes.

Inputs: which project tab, and whether the next step needs a file or the canvas. Project name and file names are task inputs, not part of this switch.
