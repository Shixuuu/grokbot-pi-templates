# Navigate Imagine Saved takes

Assumes signed in to grok.com. This is the **main Imagine Saved / post** UI, not Agent Mode canvas/Files.

## Inputs
- `{post}` — which saved generation to open (thumbnail position, conversation, or post URL). If unspecified, open the most recent matching still the user named.

## Steps
1. Go to **Imagine** in the left nav, then open **Saved** (`https://grok.com/imagine/saved`), or open Saved directly.
2. Click the target thumbnail in the Saved grid to open the **post** view.
3. Use the filmstrip / take controls to flip between variants of that generation.
4. Zoom or pan only as needed to inspect detail; do not leave the post unless comparing another Saved item.
5. Return to Saved with the back control when done inspecting.

## Report
- Which take looked strongest and why (one or two sentences).
- The post URL if available.

Stay on one Imagine tab. Keep Chrome restored, not maximized.
