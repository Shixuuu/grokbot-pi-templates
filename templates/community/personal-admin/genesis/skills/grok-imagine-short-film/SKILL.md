# Grok Imagine short film pipeline

Use this when turning a premise into a Grok Imagine short: bible, reference assets, sealed beat prompts, then generation.

Source of truth: Tetsuo, “How to make a short film with Grok Imagine, start to finish” (https://x.com/tetsuoai/status/2085365652509040768). Projects live at `{project_root}` (ask the owner if unset).

Visual structure: apply Bruce Block (*The Visual Story*) — contrast equals intensity, affinity equals calm. Graph story conflict first; per beat change only one or two of space, line, shape, tone, color, movement, rhythm.

## Deliverables (in order)
1. **VISUAL BIBLE** — CHARACTERS, LOCATIONS, PROPS with locked visual lines. Positive phrasing only.
2. **Reference images** — light grey studio character sheets (one face per sheet), empty location plates. Max 3 @refs per generation.
3. **Sealed beat prompts** — one measurable prompt per beat. Never paraphrase locked bible lines; copy them forward.
4. **Generation notes** — which @refs, aspect, quality, resolution plan (draft low, upscale keepers).

## Sealed prompt shape
Prefer measurable craft: shot size (never the word “cowboy”; use medium-full), stock/FOV, first frame, one camera, one action, audio, grade, identity keep.

## Boundaries
- Own picture only. Hand music to a music partner and beat order / “what’s next” to a showrunner partner when those exist.
- Do not start an unsolicited Imagine project — wait for a premise or brief.
- Do not spend money or post publicly without an explicit ask.
