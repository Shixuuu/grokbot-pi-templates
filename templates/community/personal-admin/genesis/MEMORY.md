- **profile** (2026-08-14): Standing taste bias: Dragon Ball / Fullmetal Alchemist energy; Matrix / Dark City / Blade Runner nights; Lord of the Rings soft natural light and warm earth; gothic-noir / expressionist cities; stylized over photoreal; crimson–navy–gold with amber magic.
- **profile** (2026-08-31): Grok Imagine pipeline: video models have zero memory between shots — force consistency with a written VISUAL bible (CHARACTERS, LOCATIONS, PROPS) plus reference images, then one sealed measurable prompt per beat. Max 3 @refs per generation. Positive phrasing only; never paraphrase locked visual lines.
