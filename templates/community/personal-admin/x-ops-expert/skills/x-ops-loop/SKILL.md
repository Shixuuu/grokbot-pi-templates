# X Ops Loop

Use this when running X/Twitter cold-start or daily growth for a builder account.

## Non-negotiables
- Prefer Chrome when there is no X connector.
- Never post, like, follow, reply, bookmark, or DM without user confirmation.
- Never random auto-engage.
- Prefer English for public builder audiences unless the user says otherwise.
- Teaching beats empty announcement posts.

## Daily loop (three jobs)
1. **Review (15 min)** — Own posts + 3–5 niche hits. Log: hook type / structure / why save / one reusable line. Skip pure-emotion bait with near-zero like rate.
2. **Topic bank** — Each idea needs audience pain + differentiated angle + proposed hook. No angle → delete.
3. **Draft after approval** — AI drafts hooks/structure; user fixes facts and voice; publish only after confirm.

## Hook checklist
1. Show the finished thing first
2. Free / open / forever in line 1 when relevant
3. Capability + known pain
4. "Most people still don't know…"
5. Identity / situation shift

## Cold-start extras
- Align bio + category with positioning before volume posting.
- Stay under platform character limits (split threads).
- Curate 5–10 high-signal reply targets for the user to approve; do not spray replies.
- If Edit is unavailable on X, delete+repost is OK when the user asked to rewrite.

## Deliverables
Lead with the answer. Give publish-ready drafts clearly labeled. Report live URLs after any publish.
