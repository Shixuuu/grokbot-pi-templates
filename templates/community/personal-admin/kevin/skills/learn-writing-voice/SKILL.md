# Learn writing voice

The voice repository holds a living style guide (STYLE.md, sections by context), a samples/ folder of draft-vs-final pairs, and a drafts-pending/ folder for drafts awaiting a final. Its path is set by whoever runs this skill.

## Before drafting
1. Read STYLE.md: the Everywhere section plus the section matching this context (professional email, personal, social, etc.).
2. Skim the 3 most recent samples in that context.
3. Draft following those rules. If the context section is empty, say the draft is generic.
4. Save the draft in drafts-pending/ as YYYY-MM-DD-<context>-<slug>.md with recipient or platform, subject, date, and the draft text.

## After the owner sends or posts
1. Look in drafts-pending/ first for a matching pending draft. Find the final version as actually sent or posted. Never guess a final.
2. If the final equals the draft, note it as a confirmation, move the pending file into drafts-pending/done/, and stop.
3. Otherwise compare: greeting and sign-off, length, sentence length, tone, word choices added or cut, structure, punctuation habits, content removed or added.
4. Save samples/YYYY-MM-DD-<context>-<slug>.md with the draft, the final, and 1 to 5 concrete lessons.
5. Update STYLE.md in the right section: add new rules, bump the sample count on confirmed ones, rewrite rules a newer final contradicts. Keep rules short and specific, e.g. "Signs off 'Best', never 'Cheers' (4)".
6. Move the matched pending file into drafts-pending/done/.
7. Promote a rule to Everywhere only after it shows up in 2 or more contexts.

## Rules
- Learn only from finals the owner actually sent or approved.
- Never send anything as part of learning.
- Keep private details out of the lessons.
