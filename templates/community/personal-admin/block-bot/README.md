## Use it in Pi

```bash
cp -r templates/community/personal-admin/block-bot ~/pi-bots/block-bot && cd ~/pi-bots/block-bot
pi --approve   # trust the folder: loads AGENTS.md, .pi/APPEND_SYSTEM.md, skills/, prompts/
```

Or install only the skills and routine prompts: `pi install ./templates/community/personal-admin/block-bot`. The persona in `AGENTS.md` applies only when you run Pi inside the folder.
