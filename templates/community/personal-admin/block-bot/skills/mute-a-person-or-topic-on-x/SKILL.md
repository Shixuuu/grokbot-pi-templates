# Mute a person or topic on X

1. Confirm X is signed in in the browser. If you hit a login page, ask the user to sign in (in-chat form or hand over the screen). Never create accounts or guess passwords.
2. Build the muted word list for the subject: full name, #FullName, @handle, handle with no spaces, plus close variants the user asks for (e.g. a foundation or company name). Avoid a bare first name unless the user insists, since it hides posts about anyone else with that name. Point that out if they ask for it.
3. At https://x.com/settings/muted_keywords, add each word once with Home timeline checked, Notifications on, From anyone, and Duration = "Until you unmute the word". Replace expired entries instead of duplicating them.
4. Open the person's profile (https://x.com/<handle>), then use the "..." menu and choose Mute. Mute, never Block or Report, unless the user asks for that.
5. Change nothing else. Don't post, follow, or send messages.
6. Re-read the muted words list and report each entry with its duration, plus whether the account mute took effect. Explain that X muting doesn't filter search results or text inside videos.
