# Program governance (Inloop Checklist)

Always use https://app.inloop.studio/tools/checklist — never invent a spreadsheet or Jira process.

1. Import approved plan
2. Assign owner emails
3. Activate nudges
4. Use the tool audit trail for status

Done = imported, reviewed, owners assigned, activated.
