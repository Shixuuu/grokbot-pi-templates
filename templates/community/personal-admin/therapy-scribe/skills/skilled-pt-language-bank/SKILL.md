# Skilled PT language bank
Convention-based wording; check facility definitions. Never invent values: use "not stated"/UNK.

## Balance / LOB
- Pattern: [activity] with [assist] + [UE support/device] + [cue type/count] + [safety outcome].
- Terms: static vs dynamic sitting/standing balance; BOS narrowed/widened; weight shift; sway; retropulsion; posterior/lateral LOB (self-corrected vs required assist); reactive vs anticipatory postural responses; response to graded external perturbation (e.g., delayed reactive stepping); ankle/hip/stepping strategy; requires bilateral UE support.
- Assist scale: independent, supervision/standby, CGA, min A, mod A, max A, total A.

## Gait (always: distance, AD/no AD, SpO2, O2 titration/amount, overground, deviation, dyspnea, rest breaks, LOB)
- Pattern: "Ambulated [ft] overground with [AD/no AD] and [assist], [n] cues for [target], [deviations]."
- Deviations: step-to vs step-through; decreased cadence/step or stride length/foot clearance; decreased stance time; trunk lean; antalgic; wide BOS.
- Exertion: SpO2/HR/BP pre-peak-post; Borg/RPE for dyspnea; rest breaks standing vs seated with recovery time.
- O2: state system, flow before/after, target (e.g., titrated per protocol to keep SpO2 >= 90%).

## Ther act / early mobility
- Tasks: bed mobility, supine-to-sit, sit-to-stand, stand-pivot, progressive mobility (EOB, chair, stand, gait).
- Document: safety criteria met per unit protocol; orthostatic response (BP/HR position change, symptoms); lines/tubes/drains managed with RN/RT; stop event and response (pause, seated rest, secure lines, adjust O2 per protocol, resume lower).
- Skilled verbs: graded, facilitated, sequenced, modified, cued (verbal/tactile/visual), manually assisted, monitored.

## Skilled need / assessment
- "Requires skilled PT to [grade/facilitate/monitor] ___ due to [impairment/safety risk]."
- "Ongoing skilled need due to ___ as evidenced by [objective measure]; not safely progressed by nursing/caregiver."
- "Response to intervention: [objective change]; plan modified to [next task]."
- CMS logic: complexity requiring a therapist's skills; coverage turns on skilled need, not only improvement potential.

## Avoid to prefer
- "Tolerated well" -> objective response (HR, SpO2 nadir, Borg, recovery).
- "Continue POC" -> specific next progression and rationale.
- "Observed/supervised" -> monitored [metric]; provided [assist] for [risk].
- "Improving" -> measured change (assist level, distance, cue count).

Sources: CMS MBPM Ch.15 s220; APTA documentation guidance; APTA Cardiovascular and Pulmonary supplemental oxygen CPG.
