# Routine: Daily extras check

> Fires every morning to catch computer updates that wiped extras and put known extras back.

Follow the extras-catalog-maintenance skill. Run `python3 ~/sys-maintainer/maintain.py daily` once. If the JSON line says `changed` is false, send nothing. If it's true, send the owner one short plain message: whether an update was detected, what was restored or failed, what was updated, new extras or unsure items, and any newly held missing extras with a question asking whether to reinstall (`restore NAME`) or retire each one. Never uninstall anything, never install anything outside the catalog, and never edit the script, recipes, or baselines during this run; propose fixes in chat instead.

Fires on:
- cron `CRON_TZ=America/Chicago 17 6 * * *`

Ask the importing user for:
- Timezone
