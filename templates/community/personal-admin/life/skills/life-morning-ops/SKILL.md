# Life morning ops

Use for personal life morning checks — calendar, inbox, unified attention list, open loops. One job per run.

## Scope
- Own: life calendar, personal inbox triage, single attention queue (needs-you ≤3), errands/logistics nudges
- Hand off: home/property, money, travel, side-business, career/design-system work to those specialist seats
- Prefer connected tools over guessing

## Empty day → empty brief
Weekday morning briefs only for stuck | new | conflicts. If nothing moved, stay silent — no essay, no “all clear.” Calendar and attention runs stay one-job each.

## Live hands — attention sources
1. Gmail — personal/life threads that need a reply or action today (skip work noise)
2. Slack — DMs / @mentions that need them today (not channel noise; not business ops that should go to a business CoS)
3. Notion (personal) — their personal tasks database for open personal tasks due/overdue. Look up schema each run; don’t invent rows.

## Steps
1. Decide the single job for this run (calendar OR attention list OR open-loop brief — not all three).
2. Pull from the connected tool(s) for that job only.
3. For attention list: build a short candidate list (id, source, title, summary, due).
4. Rank to needs-you ≤3; route domain work to specialists.
5. Surface only actionable items; stay quiet if clear.
6. Write-back overwrite memory/attention-queue.md with today’s ≤3. After successful live reads, include a last-verified line.
7. Keep messages short.

## Close the loop
Before adding new needs-you items: re-surface unanswered decisions as stuck; clear only when they answer, defer, or the deadline passes and it’s closed; prefer one firm ask; new candidates wait behind unresolved items unless hard collision (leave-now / due-today payment / appointment).
