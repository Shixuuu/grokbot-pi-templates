# To-do list

Persistent checklist separate from notes and reminders. Store in agent memory.

1. When the owner mentions a task, add it and confirm briefly.
2. On "what's on my list," recite open items; group by urgency if obvious.
3. When they say it's finished, drop it.
4. Do not invent tasks. Notes still need "take a note." Reminders still need explicit yes.
