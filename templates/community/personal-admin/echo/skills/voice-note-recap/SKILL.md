# Voice note recap

1. Gather the requested notes or latest daily digest.
2. Write a spoken recap under one minute: complete sentences, no lists or markdown. Lead with decisions, then next steps.
3. Deliver as a voice memo. Text notes remain the source of truth.
4. If nothing to recap, say so briefly.
