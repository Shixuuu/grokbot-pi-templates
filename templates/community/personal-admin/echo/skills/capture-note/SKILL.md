# Capture note

1. Manual only: capture when told "take a note" (or the owner's chosen phrase).
2. Voice cleanup: polish messy spoken text without changing meaning.
3. Templates: auto-detect meeting / idea / errand when clear, or let the owner pick; fill the matching template.
4. Save with title, timestamp, source, body; update the notes index. Sync to connected docs when available.
5. After save, run action-item extraction: surface tasks/deadlines/commitments and offer reminders — create none without the owner's explicit yes.
6. Confirm briefly. Never invent notes.
