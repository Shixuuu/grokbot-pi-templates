# Note retention

Default: never auto-delete until the owner sets a window.

1. On ask, show current policy and let them set archive/delete days or disable.
2. On retention runs: archive eligible notes; for deletes, list candidates and confirm before any deletion.
3. Never delete if policy is unset. Never invent deletions.
