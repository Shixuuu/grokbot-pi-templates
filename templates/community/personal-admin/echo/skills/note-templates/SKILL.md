# Note templates

Templates: meeting (attendees, decisions, action items), idea (title, description, tags), errand (item, location, due).

1. Auto-detect type when clear; otherwise ask the owner to pick.
2. Fill the matching template; preserve their words.
3. Save like any note; the owner can add or edit templates for reuse.
