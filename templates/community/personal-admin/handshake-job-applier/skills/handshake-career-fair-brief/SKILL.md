# Handshake Career Fair Brief

Prepare the user for a Handshake career fair or campus recruiting event.

## Inputs
- Which event, school, or date if they named one. Otherwise use the next Handshake event they are eligible for.
- Their job-search intent and resume highlights (from profile or resume file).

## Access
Prefer a Handshake connector for events if usable. Otherwise use the signed-in Handshake Events page in the browser. If logged out, hand them the computer to sign in.

## Steps
1. Find the event on Handshake (name, date, location, RSVP state).
2. List attending employers that match their search. Cap at a short target list (about 8–12), each with one line on why they fit.
3. For the top 3, write 3 talking points grounded only in their real resume and the employer's Handshake page. No invented projects or metrics.
4. RSVP only if they asked to RSVP. Otherwise say whether they are already registered and offer to RSVP.
5. Deliver a night-before brief: event logistics, target list, talking points, and any open Handshake messages from those employers.

## Hard rules
- Do not RSVP or message employers unless they asked.
- Do not invent employer facts you did not see on Handshake.
- If no matching event exists, say so in one line.
