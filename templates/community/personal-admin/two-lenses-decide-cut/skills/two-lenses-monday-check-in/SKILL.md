# Two Lenses: Monday check-in
**First, read:** memory 2's log, the focus list, the number history, `one number` and `time zone`. "Today" is in the owner's time zone. Never invent a number, an outcome or a reason.

## A. Monday mode (one message, no follow-up)
0. **No `setup: complete` memory:** post nothing and stop.
1. **Due:** a row is due when it's open and its revisit date is on or before today.
2. **Nothing due (one short line or nothing):**
   - With a focus list, post: "Monday: nothing due for a check-in. Your one thing is still: <one thing>. Send notes or a number any time."
   - With a log but no focus list, post the same line without the one thing.
   - With neither, post nothing.
3. **Something due:** post one message of at most about 10 lines:
   - **Score:** "Score so far: worked W of N (partly P, didn't X)". Leave it out when N = 0.
   - **Calibration:** "High: worked <W> of <N> · Medium: … · Low: …". Show a level only once it has 2 or more scored rows.
   - **Due decisions:** one line each, oldest first, at most 5, then "+K more". Example: "D3 (cut the product tour, Sep 21; expected: more users finish signup): worked / partly / didn't / not yet?"
   - **The one thing:** if there is one.
   - **Number:** "What's your <one number> this week?" Ask only if the owner tracks a number.
   - **Notes:** "Notes on this week? I'll refresh your focus."
4. **Stop.** The reply is handled in mode B.

## B. Owner replies
1. **Outcomes:**
   - worked, partly or didn't → close the row with that outcome, plus a short note in the owner's words if they gave one.
   - not yet → keep it open, with the revisit date 14 days later.
   - If an answer is unclear, ask once.
2. **Number:** add a row (`N · date · value · owner's words`). Show the trend from the owner's values only (e.g. "last 4: 12 → 14 → 13 → 17"), or "not reported" if there are none.
3. **Score:** one line with the new score.
4. **Focus (only when the owner gave notes this time):** at most about 8 lines, built from those notes and the log:
   - the top 3
   - 3 things to say no to
   - one delete candidate (never protected)
   - **the one thing**
   Save it, replacing the old focus list.
5. **Caps:** apply memory 2's caps (50 log rows, 26 number rows).

## C. On demand
- **"Weekly review":** run mode A now.
- **"Show my decision log":** the score, then the open rows as a table (ID · decision · expected · revisit · status · outcome). Show closed rows only if asked.
- **"Change D<n>":** update only that row, then show the new score.
