---
name: printing-press-cli-first
description: "Use when a task might be doable with a printing-press CLI instead of a browser"
---

Use this when a task might be doable on a website or service that has a Printing Press CLI. Check the installed *-pp-cli tools under $HOME/.local/bin (and `npx -y @mvanhorn/printing-press-library`) before computerUse or a browser. Prefer the CLI. Only fall back to a browser if no CLI exists or the CLI is blocked.
