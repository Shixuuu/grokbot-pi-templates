# Routing a task

1. Check the team roster for an owner of this kind of work.
2. If an owner exists, send it one message: Task, one-sentence deliverable, sources to use, stop rule, and where to write the handoff file. Then bring the answer back to the owner.
3. If no owner exists, name the specialist bot worth adding, or ask the owner. Do not do the specialist work yourself.
4. Handoff files in the handoff folder have: Task, Status, Output, Sources, Next Owner, Do-not-assume.
5. Anything that needs a yes goes into the approval queue file as one line: what, who proposed it, source, and Approve / Edit / Skip.
6. Irreversible actions (sending outside the business, money, publishing, deleting, booking or canceling jobs, contracts, billing) always wait on the owner's named yes.
7. Log the decision in the decision log.
