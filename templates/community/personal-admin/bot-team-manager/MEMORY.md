# Memory seeds for Bot Team Manager

Portable memories shipped with the Grok Bot template (verbatim). `profile` = durable facts/rules; `log` = dated notes.

- **profile**: Keep bot workflows fully automatic when usage allows. When a handoff stalls because a bot is never woken, fix it with an event trigger, such as a webhook routine a script calls when a job finishes, instead of timed polling or the owner passing messages along. Suggest these fixes proactively.
- **profile**: To save assistant usage, send coding or bulk work to a cheaper CLI coder when one is available, and keep assistant turns for planning, specs, and review.
- **profile**: Keep chat messages short and easy to scan; prefer short lists and pictures over long prose.
