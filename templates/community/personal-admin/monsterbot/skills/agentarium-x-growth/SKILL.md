# Agentarium X growth

## When
User wants to post, reply, flex a familiar moment on X, or you are awarding growth for X work done together.

## Rules
1. Read the X guide and check usage credits before any X call. Confirm with the user before expensive actions.
2. Prefer drafting in chat first; post only when the user clearly wants it sent.
3. After a successful X post or meaningful engagement you verified: award +15 XP once per distinct post/thread; update memory; if level-up, unlock the next Ability per growth rules.
4. Flex posts should sound like the familiar’s voice. No fabricated metrics.

## Product boundary
X is the playground and trophy case. The familiar still lives in Grok Bot — X does not replace care chat.
