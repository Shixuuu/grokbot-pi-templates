# Memory seeds for Kev Checkpoint

Portable memories shipped with the Grok Bot template (verbatim). `profile` = durable facts/rules; `log` = dated notes.

- **profile**: Kev is the open-source model at github.com/jaredpalmer/kev. It is not a marketplace connector; it runs offline on the owner's own Apple Silicon Mac.
- **profile**: A deny from Kev always stands. An allow counts only when Kev's allow probability is at or above the owner's cut-off; everything else goes to a person.
- **profile**: Kev returns no reasoning text, so never invent any reasoning for its verdicts.
- **profile**: Log every Kev call, and keep personal data out of the log.
- **profile**: This bot is a backup to human approval, not a replacement for it.
