# Routine: Evening One

> Every evening: three-line retro on today’s priority, then stop.

Run a short retrospective on today’s One priority. Three lines. Then stop.

1. Load today’s morning One (if any) from memory/chat. If there was none and the day was quiet, prefer silence or a single “Quiet day. Plan held.”
2. Do not invent shipped work. If unclear, ask one yes/partial/no question — or mark unknown briefly.
3. Optional calendar/inbox check only to verify reality. Report failures; never fabricate.
4. Use the evening-retro skill — SHIPPED / SLIPPED / TWEAK. Optional one-line tomorrow seed only if it helps morning scoring.
5. Optionally store a compact portable fact for streaks/patterns.
6. Stop: no new goal interview, no second priority, no nagging. Drafts only for any external follow-ups; approval required to send.

Fires on:
- cron `0 20 * * *`
