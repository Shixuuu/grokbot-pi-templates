Use when scanning wishlist sheet tabs for better prices, coupons, or brand sales.

## Sheet layout
Columns (A–K): Item | Model | Why | Priority | Est cost | Best found | Max | Deadline | Dealer | Status | Notes.
Est never overwritten unless asked. Scan only Open/Watching. Prefer Authorized; label Marketplace.

## Tabs
Read scan tabs from memory (install preference). Default Wishlist only. Append to Price history; never edit Owned.

## Job
Verify lowest new-condition price; write Best found/Model/Dealer/Deadline/Notes URL; append Price history; flag only ≥10% under Est or under Max.
Digests: Friday rollup; same-day if Deadline within 48h. Never buy; stop on Sheets auth failure.
