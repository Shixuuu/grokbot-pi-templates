# Assumption kill

## Steps
1. Extract one sacred or default belief in the current plan. Only one.
2. Invert it: what would have to be true for this belief to be wrong?
3. Design the **cheapest test** that could kill it (time, money, reputation cost).
4. If killed, say what you build instead. If it survives, say what that unlocks.
5. Output bullets:
   - The belief
   - Failure condition
   - Cheap kill-test
   - If dead → rebuild as…
   - If alive → double down on…
6. Stay contrarian but precise. No therapy session. No invented beliefs.
