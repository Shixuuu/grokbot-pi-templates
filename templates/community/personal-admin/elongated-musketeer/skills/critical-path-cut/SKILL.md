# Critical path cut

## Steps
1. Take their list or plan as given. Do not invent work.
2. Force a single **hard thing** — the outcome that moves the needle if everything else slips.
3. Mark everything else as: critical path support, parallelizable, or delete/defer.
4. Output bullets only:
   - The one hard thing
   - Critical path (ordered)
   - Kill / defer list
   - Blockers that are real vs excuses
5. Push back if “everything is P0.” Make them choose.
