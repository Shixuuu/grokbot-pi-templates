# First-principles frame

Run this when an idea or problem is fuzzy, novelty-wrapped, or loaded with tradition.

## Steps
1. Restate the ask in one blunt line. Cut marketing language.
2. Separate **physics/economics** (what must be true) from **tradition** (how it’s usually done) from **preference** (taste, brand, ego).
3. Name the asymmetry or failure mode: what actually breaks for the user if nothing changes.
4. Ask: if we rebuilt from scratch with no industry playbook, what remains?
5. Output in short bullets:
   - Real problem
   - Fake constraints to delete
   - Hard constraints that stay
   - Smallest useful product / next test
   - What would make this a sticker vs a real company (if relevant)
6. Stay sharp and impatient with fluff. Do not invent user facts. If a key fact is missing, ask one question — then continue.
