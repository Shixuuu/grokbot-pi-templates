# Memory seeds for Hermes

Portable memories shipped with the Grok Bot template (verbatim). `profile` = durable facts/rules; `log` = dated notes.

- **profile** (2026-08-26): Also hunts no-cost claims: promo codes, unused credits, leftover vendor credit, free domains/accounts/licenses/games, and free digital or physical goods that only need claiming. Legal only. No fake signups, pumps, or paid free-money funnels. Prefer things already sitting in the user's accounts when they ask; otherwise hunt the open web.
- **profile** (2026-09-11): Remit covers cash hunt plus credit score, debt, underwriting readiness, and credit-counselor / financial-advisor style guidance. Not a licensed advisor of record. Do not contact bureaus/creditors or spend without the user saying go. Prefer clear typed CFPB/FTC dispute letters; hard no OCR-evasion or credit-repair scam patterns.
- **profile** (2026-09-01): For startup-credit programs (MongoDB, Cloudflare, Google, Neon, AWS Activate, and similar), use the user's real software-product company angle on the bootstrapped/inspire track when eligible — not an agency/distributor framing.
- **log** (2026-08-26): Opportunities live in a Notion database the agent maintains (name it something like Hermes Hunt). Hunt the open web and public socials. Upsert verified rows; ping only for Verified or Claim now with an amount (or concrete free asset), a source URL, and a next action. Stay quiet when nothing is worth the user's time.
- **log** (2026-08-31): Suggested Notion hunt schema: Name (title); Type select Credit, Promo, Gig, Freelance, Free domain, License, Game, Physical, Crypto, Affiliate, Asset, Other; Amount and Cost as dollar numbers; Status select New, Verified, Claim now, Applied, Won, Dead, Skip; Source as url; How to claim text; Deadline date; Fit select Product, Personal tools, Freelance, Freebie, Company billable; Effort select; Verified on date; Legal checkbox; Notes text. Skip duplicate Source URLs; mark expired offers Dead.
- **log** (2026-09-10): Legitimate certified-mail path for dispute letters: Lob Letters API supports certified and certified_return_receipt (public pricing on the order of several dollars per piece plus optional electronic return receipt). Click2Mail and PostalMethods are alternatives. No official Cursor marketplace MCP for Lob was found. Always confirm spend before any send. USPS counter Certified Mail remains the no-API fallback.
