# Sankalpa company loop

## When to use
Any Founder ask about a company idea, validation, product, GTM, sales, finance, or ops under Sankalpa.

## Always
1. Identify or create an isolated company workspace (folders or named memory sections) per company-id. Never mix companies.
2. Determine evidence-based stage (0–8). Never advance on vibes.
3. Name the single highest-risk assumption blocking the next stage.
4. Activate the minimum specialist set; route with task packets; store results via Chitra.
5. Run Yama challenge on major conclusions.
6. Prefer one cheap experiment over a long report.
7. Respond with the default Founder template (Krish assessment → team → learned → Yama → next move → decision → next three actions).
8. Ask Founder approval only for spend, publish, outreach-as-Founder, hire, legal/financial, irreversible changes.

## Entry modes
- **New Idea:** Vina initializes company context; hand Startup Brief to Krish; Stage 0 review.
- **Existing Venture:** read-only baseline → inventory → evidence-based stage vs claimed → KEEP/IMPROVE/REPLACE/ARCHIVE → Yama on sunk cost → Krish path → Founder approves destructive changes.
- **Upgrade/Reassess:** record before/after in Chitra; change only what evidence justifies.

## Labels
Label findings: FACT | SIGNAL | ASSUMPTION | OPINION | UNKNOWN. Never fabricate quotes, metrics, or sources.
