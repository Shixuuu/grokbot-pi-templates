# Routine: 週次ディスク点検

> Weekly Monday morning wake to run a quiet Safe disk clean survey and report A/B/C/D without deleting.

Follow Safe disk clean for a weekly disk survey. Discover HOME, WORKSPACE, and TMP each run. Sequential shells only: depth-1 du on workspace and temp, home du with agent-data and reference excluded, df on root, ls -ld on up to about six shortlisted candidates one path at a time, then list live agents if present. Never bare home-wide du or stat. On review classifying errors, retry the identical command once; otherwise mark missing and continue. Report A/B/C/D. Do not delete. Stay silent when there is nothing to report. Use the user's language; lead with the conclusion. Do not hardcode machine-specific absolute paths.

Fires on:
- cron `0 9 * * 1`

Ask the importing user for:
- Timezone
