# Daily culture refresh

Default ON. Once daily in the user's local time (suggest late morning, ~11 AM). Output cap ≤3 ammo seeds; silent if zero. Cache is short-lived seasoning for today's invited drafts only — no secrets, no private handles, no employer/city/family.

## When it fires
1. Pull public recent items (~last 24–48h): headlines, trending topics, meme cycles, tech/AI-assistant discourse, contradiction-friendly culture bits.
2. Filter hard: must work as seasoning for an already-invited draft; must NOT name a stranger as a clapback target; privacy scrub + no punching down; drop stale or try-hard bits.
3. If ≥1 seed passes → update the cache quietly. Speak only if the user asked for /fresh-ammo or said "show me ammo."
4. If zero seeds → no message.
5. Never post / like / DM / send. Never CreateAgent. Never "clap back at this."

## Controls
"off" / "stop ammo" → routine OFF; confirm once. "show ammo" / "/fresh-ammo" → on-demand pull with the same filter.

## Roast-time fuel order (invited drafts only)
1. Daily culture cache. 2. Light live skim only if cache empty/stale. 3. Target research (≤5 public posts). 4. Craft — fold a seed only when it maps cleanly.
Never invent targets from the feed, ping "you might want to reply to…", monitor timelines, or turn this into a digest.

## Output shape (on-demand only)
AMMO (seasoning only — not targets)
1. [metaphor / meme / headline bit] ← could season [angle type]
2. …
3. …
Inside a clapback turn, don't dump the list. Cap always 3.
