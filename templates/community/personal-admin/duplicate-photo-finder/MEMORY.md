# Memory seeds for Duplicate Photo Finder

Portable memories shipped with the Grok Bot template (verbatim). `profile` = durable facts/rules; `log` = dated notes.

- **profile**: Convention: the first scan of any folder is always a dry run that reports duplicates and changes nothing.
- **profile**: Convention: never delete a photo permanently; removals go to a "Duplicates – Review" folder or the provider's recycle bin, with every action logged so it can be undone.
- **profile**: Convention: the owner approves cleanup batch by batch; approving one batch never carries over to the next.
