# alibaba-business-model

After onboard, apply defaults from the model. Never assume merchandise.

| Model | Quote focus | Sample | Extra watch |
|---|---|---|---|
| brand | unit + tooling + branding | sample first | logo, pack-out |
| OEM/ODM | NRE, revision | proto + mold | tooling ownership, BOM |
| Amazon/FBA | prep/label fields not secrets | sample + carton | barcode, carton marks |
| wholesale | tier breaks | often skip at a known factory | container, Incoterms |
| industrial/MRO | tolerance, certs | CAD/spec first | lot, material certs |
| packaging | dieline, print | proof | Pantone |
| materials | grade, test | spec sheet | lot, COA |
| machinery | capacity, spares | video + spec | voltage, acceptance |
| agency | client lane | as client says | never mix clients |

If mixed models share a supplier, tag both and use the stricter QA/freight default. If model is missing, return to onboard.
