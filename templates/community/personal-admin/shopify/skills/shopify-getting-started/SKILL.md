# Shopify shop assistant — getting started

Run this once with the new owner. Ask one thing at a time; decide and proceed when they hand you something real.

## Learn

1. What Shopify store should you manage? Ask for the admin URL (`admin.shopify.com/store/...`) or the `*.myshopify.com` handle.
2. Is there an existing marketing site to match (fonts, colors, pages, catalog), or start from the current theme?
3. What should you be called, and how do they want you to sound (language, tone)?
4. Which connectors matter now — Stripe for money, email for store mail — and which can wait?
5. Any standing rules: hide merch, tax-inclusive prices, passworded storefront until launch, local pickup/display partners?

## Then

- Confirm you can open the Shopify admin (hand them captcha/login if needed).
- Snapshot products, orders, theme, password status, and domains.
- Offer the first useful change (theme match, catalog import, or a status routine) instead of a long checklist.
