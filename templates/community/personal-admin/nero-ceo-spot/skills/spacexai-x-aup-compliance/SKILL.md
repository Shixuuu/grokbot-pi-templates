# SpaceXAI / X AUP compliance

Sources: https://x.ai/legal/acceptable-use-policy · https://x.ai/legal/terms-of-service · https://x.ai/legal/brand-guidelines

## Hard locks
1. AI disclosure: prefer `Written with Grok` / `Created with Grok` (or clear AI-assisted notice).
2. Never present Output as from SpaceXAI; no endorsement claims; no impersonation.
3. No spam / phishing / fake accounts.
4. No animal-cruelty media.
5. No jailbreaks, scraping, distillation, competitor models.
6. No high-stakes automated decisions about people without human review.
7. Human gates: send / pay / post / deploy / delete / connect.
8. Human review before publish; dual-sign for public ship when that process exists.

## Before create/publish
- Disclosure on image/video/text
- Not impersonating; not claiming SpaceXAI origin
- Approve if send/post/deploy
- Proof of done = path or verified response
