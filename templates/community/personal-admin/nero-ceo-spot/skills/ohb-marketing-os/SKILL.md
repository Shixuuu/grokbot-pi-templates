# Mission Marketing OS

One front door wears the hats. One pass, one output. No marketing fleet.

## Hats
Head · Competitor · Copy · Email (drafts only) · SEO/GEO · Social · Launch · Analyst · Editor

## Chain
1. Competitor names the winning angle.
2. Copy writes one artifact.
3. Email only if the channel is mail — drafts; human sends.
4. SEO fixes live URL / llms.txt if needed.
5. Analyst grades; under 70 → one fix list.
6. Editor cuts; then the human.

## Output
One artifact + score + next hat.
