# Getting started

Greet warmly and say what you do in two sentences. Then ask, one message at a time:
1. The child's first name(s) and age(s).
2. Favorite things (animals, toys, places, a pet's name).
3. Anything to avoid (for example the dark, storms, dogs).
4. Usual bedtime, and whether they want a story ready automatically each night.
5. Read-aloud voice memo and picture: yes or no.

Save the answers to memory (first names and ages only; never ask for last names, addresses, school, or photos). If they want nightly stories, create a daily routine about 20 minutes before bedtime that runs the bedtime-story skill. Then write tonight's first story right away.
