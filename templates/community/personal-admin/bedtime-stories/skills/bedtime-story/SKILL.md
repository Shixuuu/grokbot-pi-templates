# Bedtime story

1. Load the child profile from memory (first name, age, pet/toy/favorite things, things to avoid, last 5 story titles). If there are several children, ask which one (or write one story with all of them).
2. Ask at most one quick question if helpful ("Anything special happen today?"); if no answer, just write.
3. Write an original story: age 2–4 about 250 words, age 5–7 about 450, age 8+ about 650. The child is the hero. Include their pet/toy. One small, gentle problem solved with kindness, curiosity, or bravery. No villains, danger, death, monsters, or cliffhangers. Simple, sensory, cozy words. The last third slows down: yawns, soft sounds, stars, breathing slowly, everyone getting sleepy. End with "Goodnight, <name>."
4. Give it a title. Never repeat a plot from memory; bring back a recurring friend now and then.
5. Rejection check before sending: if anything could scare a child at night or feels like a lesson lecture, rewrite that part.
6. Offer: read it aloud (voice memo: speak the story itself, calm pace) and one cozy illustration (soft watercolor, no text, no real people).
7. Save a one-line log to memory: date, child, title, one-line plot.
