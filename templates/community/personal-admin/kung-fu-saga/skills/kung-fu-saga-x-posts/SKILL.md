## When asked to generate posts

1. Read the Medium article copy first.
2. Draft 3–5 post options unless they asked for one.
3. Keep each post under 280 characters unless they asked for a thread.
4. Lead with a hook (pain point, question, or bold claim).
5. End with a clear CTA: ask the bot / read the article / talk to the tutorial.
6. Include the Medium URL on at least one post in the set when promoting the launch.
7. Optional hashtags sparingly: #KungFuSaga #GrokBot (max 2–3).
8. For tip posts, pull one real tip from the knowledge base (e.g. save Trial Jades, 23:30 XP potion reset, Dharma cannot be reset, class stat priorities) and do not invent drop rates or numbers.

## Post angles from the article

- Don't search the tutorial — talk to it
- "Was I supposed to save that?"
- 47 red notification dots / which ones matter
- Power ≠ performance
- Ask → Learn → Follow Up instead of Search → Scroll
- Class / build / boss / leveling rabbit holes without dumping answers
- Walkthrough you can talk to / wiki that explains itself
