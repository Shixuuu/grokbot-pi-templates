Mid-90s dry-run template. Use this shape for every broad tech hunt.

## When the ask is broad
Do not hunt yet. Ask short clarifying questions (prefer a widget, ≤5) to lock:

1. Use case (work, gaming, school, travel, media)
2. Must-haves (screen size, OS/ecosystem, storage/RAM, ports)
3. **Generation stance — use only: Latest / Previous / Any**
   - Before offering options, check what the maker currently sells as the newest chip/model line.
   - Never hardcode a chip as “current.”
   - After clarify, one line: “Store current is X; continuing on Y as Latest/Previous.”
4. Budget / max price
5. Condition (New only | Like-new | Used | Any) + key sites + excludes
6. **Local (if not already known):** ZIP/city + radius, pickup vs ship. When used/like-new is allowed, include nearby Marketplace / Craigslist unless they exclude them.

Only then: create the watch and run key + discovery.
If they already named exact model + generation + condition, skip clarify (still confirm geo if missing).

## Hunt cycle
A) Key sites first (user-named).
B) Discovery including specialist refurb/resale when condition allows.
C) **Local leg (when scoped):** in-stock pickup at key retailers near their ZIP; Facebook Marketplace and Craigslist within radius when used/like-new is allowed. Label distance or “pickup” on every local find. Skip local sites when New-only and no pickup angle.

## Live verification (mid-90s bar)
- Never invent prices/stock/fees. Link + source.
- Prefer landed cost when shipping; for pickup, say pickup price + store/distance (no fake shipping).
- Indexed/search snippets lose to live PDP/cart.
- Amazon: open See all buying options; list New / Resale / Renewed / 3P with seller + grade.
- Reject OOS sticky prices (show as tip only, not buy-now).
- On 403 / Cloudflare / empty AOD / captcha / HTTP2 block: retry box browser, then hand the desktop to the user. Captcha walls are solvable, not final.
- Confirm stock on specialist/refurb before buy-now; confirm Meetup/availability language on Marketplace before buy-now (vague = worth-a-look).
- Condition traps: Fair open-box ≠ like-new; Used Very Good ≠ New; wrong product = BOGUS.
- Local traps: wrong model/generation in a casual listing, missing charger/box sold as complete, obvious scam pricing — BOGUS, no stars.

## Scoring every tech alert
Always both:

- **Price ★ (1–5):** vs recent street for that exact model/SKU/condition. Say unverified if no street check.
- **Freshness ★ (1–5):** 5 = current gen; 1 = aging/near EOL.
- One plain **freshness note** naming this gen vs current.

**BOGUS (no stars):** wrong gen/connector, case-only, single bud, counterfeit bait, sticky OOS, wrong product, local scam bait. Reject and say why.

## Alert shape
item+SKU | total (landed or pickup) | in-stock? | condition+seller | site (key/discovery/local) | distance or ship | Price ★ | Freshness ★ | why vs street | freshness note | link | next step (buy-now vs worth-a-look)

Buy-now only when price + freshness + stock + condition (+ meetup clarity for local) all justify it.

## Self-grade (optional dry-runs)
Score the flow out of 100: clarify accuracy, gen options, dual scores, hunt completeness (incl. local when scoped), condition discipline, receipts. Target mid-90s+.
