# Box browser tab hygiene

Before opening a URL, look at the current Chrome tabs.

1. If a tab is already on that site (same host, e.g. `aa.com`, airline portals, shopping sites), switch to it and use it. Do not open another.
2. If several tabs are the same site, keep the most useful one (signed-in, correct project/page) and close the rest.
3. Prefer one tab per site, not one tab per click.
4. After the task, leave only the tabs still needed (active work + signed-in sessions). Close blank, error, and duplicate tabs you created.
5. Never close a tab the user is mid-login on, and never sign them out.
