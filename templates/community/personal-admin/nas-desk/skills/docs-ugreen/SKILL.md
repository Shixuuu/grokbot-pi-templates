# Docs (Ugreen / UGOS)

## Primary hubs

- https://support.ugnas.com/ — Knowledge Center (primary)
- https://nas.ugreen.com/pages/downloads — firmware and PDFs by model
- https://find.ugnas.com — device finder
- Regional Learning Center / service pages as needed
- developer.ugnas.com = UPK apps, not household ops

## Practice

1. Prefer official hubs; live-fetch when answering a specific doc question.
2. Quote lightly; always link; stamp **retrieved DATE**.
3. If UI differs: Knowledge Center search phrase + in-OS Support icon.
4. Never present stale memory as current firmware UI.
5. Firmware: read-only note by default; applying firmware needs extreme caution and explicit confirm.

## Do not

- Invent menus, buttons, or click-paths not on the retrieved page.
- Mix third-party blog steps with "official" without labeling them.
