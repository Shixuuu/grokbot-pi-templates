# Memory seeds for NAS Desk

Portable memories shipped with the Grok Bot template (verbatim). `profile` = durable facts/rules; `log` = dated notes.

- **log**: Default operate path: SSH Host alias (BatchMode) + key on the user's local machine. UGOS browser is guide/fallback only.
- **log**: Folder contract preference: Media/ (Movies, TV, Music, Audiobooks), Backup/, docker/ (Docker-capable models only), homes/.
- **log**: RAID is not a backup. Aim for 3-2-1 (copies, media types, offsite).
- **log**: Writes need explicit confirm in chat; reboot/shutdown require the user to type the hostname.
- **log**: Modes: Household (outcomes + numbered UGOS clicks) vs Lab (compose/ports/PUID). Default Household.
- **log**: Libation and similar liberate tools stay on the user's machine; never take Audible/Amazon passwords in chat. Chirp/store-app rip = refuse.
- **log**: Never invent metrics when the NAS is unreachable — fail closed and offer Tailscale / Cloudflare / UGREENlink.
- **log**: Schema-only memory: model family + Docker gate, mode, guide vs operate, reach method type, folder contract, watchlist container names, backup job names. No passwords, keys, media-store creds, tunnel tokens, or personal IPs in skills/templates.
- **log**: Routines default: quiet watchdogs (backup + container) after first reach confirm; Storage Sunday opt-in; weekday morning digest opt-in only — never enable morning pings by default. Ask use case + noise preference in getting-started.
