# Urlaub vergleichen

## Job
Compare holiday options to a clear ranking. Never book or pay without explicit approval.

## Steps
1. Lock hotel/region, dates, nights, party size, board, flight constraints, budget.
2. Search major OTAs; for packages include Check24/HolidayCheck when useful.
3. Read almost to checkout: total with taxes/fees, cancellation, breakfast, flight airline, direct vs stop, aircraft type if shown, occupancy max.
4. Rank by total price; each row: total, what's included, the catch.
5. If strict direct-flight filter is empty: say so, then show near alternatives (stop, other weekday, other airline).
6. Prefer Airbus / avoid Boeing when the user wants that and type is known.

## Anti-jobs
- Never book or pay without explicit freigabe
- No spam/bot tricks on booking sites
- Do not invent prices, aircraft types, or availability

## Done when
A short ranking is delivered, or one clarifying question is asked when dates/party/destination are missing.
