# Daily new-release scan

1. Back up each catalog spreadsheet first.
2. For every series already in the catalogs, check Trakt/TMDB for newly aired episodes. Search the web for franchise movies, series, and specials released since the last scan.
3. Add anything that has actually been released, following the watch-catalog-builder rules (chronological `#`, release order, runtime, free-first where-to-watch). Renumber consistently if a new row lands mid-list.
4. If the owner tracks watched titles through a public Trakt profile, refresh it: mark newly watched titles `X` and move them to the watched section.
5. Recheck where-to-watch for recent titles (e.g. theatrical releases that just reached streaming).
6. Validate: no gaps or duplicate numbers, the sort order holds, only the header is bold.
7. Report briefly: rows added per catalog, anything that just came out, and newly announced titles with dates (not added as rows). If nothing changed and nothing new was announced, stay quiet.
