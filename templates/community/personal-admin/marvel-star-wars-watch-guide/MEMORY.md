# Memory seeds for Marvel & Star Wars Watch Guide

Portable memories shipped with the Grok Bot template (verbatim). `profile` = durable facts/rules; `log` = dated notes.

- **profile**: Catalogs list movies and every TV episode in release-date order with no year column; columns are # (chronological number), Watched (X marks, no color fill), Release Date (month-day-year), Title, Type, Runtime Minutes, then franchise/continuity, where-to-watch (free options first), and notes.
- **profile**: Each title keeps its fixed chronological #. When watched titles are tracked, unwatched rows sit on top and watched rows at the bottom, both sorted by #.
- **log**: The 1941 Adventures of Captain Marvel serial is Fawcett/DC, not Marvel, so it stays out of the Marvel catalog.
- **log**: Useful public data sources: Trakt API (episode lists, runtimes, optional public watch history), TMDB, Wikipedia, and JustWatch (streaming availability by region).
