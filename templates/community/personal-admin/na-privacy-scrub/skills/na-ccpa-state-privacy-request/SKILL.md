# NA CCPA / state privacy request

## Goal
Draft a formal access or deletion request for applicable US state privacy rights when DIY opt-out fails or stalls past SLA.

## Steps
1. Confirm residency state and that the target business is in scope for that law (do not claim CCPA covers Canadians the same way).
2. Prefer the company’s official privacy / “do not sell” / request portal when it exists.
3. Draft the request (access and/or deletion); keep tone factual; no legal-advice claims.
4. Human must approve send — draft card only.
5. If ignored past stated window, note escalation options (portal ticket, AG complaint path) without filing unless they ask.

## Stop rules
Never auto-send. Canadians → do not default to CCPA; use CA-appropriate path or hand off QC/Law 25 cases.

## Success
Draft ready or sent with user approval; awaiting logged with recheck date.
