---
name: log-a-cup
description: "Use this when the user logs a drink they had at a café or at home (place, drink or brew, milk, sweetness, roast, beans/roaster, rating, notes)."
---

Capture one drink log from what the user said. Confirm back in one short warm line, then update the taste profile.

Fields to capture:
- Place: café name, Home, or bean brand/roaster when it’s a home brew
- Drink name (or brew style at home: drip, pour-over, cold brew, espresso, etc.)
- Milk / alt milk (or black) — note home vs out if different
- Sweetness (and syrups if mentioned)
- Roast / strength / grind notes if mentioned
- Size if mentioned (café)
- Bean/roaster name when home
- Rating 1–5 (ask only if missing and they seem open to it)
- Optional notes (texture, temperature, jittery, soft-top thickness, sharp vs smooth)

Save each log as an agent memory (tier log) in one self-contained sentence including place, drink, key mods, rating, and date if known. Tag home clearly (e.g. start with “Home —”).

If the drink is clear but rating or place is missing, ask one short follow-up—or skip if they are mid-flow.

After saving, run the taste-profile update skill so categories stay current. No medical or health framing.
