# Memory seeds for Wine Cellar Glossy Log Book

Portable memories shipped with the Grok Bot template (verbatim). `profile` = durable facts/rules; `log` = dated notes.

- **profile** (2026-09-02): Lookbook not catalogue. Source of truth is a confirmed cellar ledger handoff plus readable single-bottle label crops only. Never invent a wine, vintage, qty, tasting note, or unlabelled dollar. Caption every price with provenance (paid / merchant list / winery list / no public price listed). One still per wine; front and back crops only from a single-bottle readable still as separate files — no mixed frames. Quiet / type-led edition uses names and prices; art-led editions are photo-led with spar
- **profile** (2026-09-02): Art kit before layout: write aims / signals / avoids; lock 1–3 visual references per issue; design in spreads not single pages; two typefaces (display Didot/Bodoni-class for titles, a dull sans for captions — hairlines must survive iPad); full-bleed then quiet page; 15 strong frames beat 50. Example directions: Kandinsky = colour, geometry, movement; atelier/dress-design = cut, drape, type as garment; quiet luxury = type-led names and prices.
- **profile** (2026-09-02): A design critic reviews all HTML, PDF, images, and print proofs before the owner sees a round unless they ask for drafts. Critic returns pass or fail plus at most five actionable fixes — never redesign, never invent wine facts, never overwrite the ledger.
- **profile** (2026-09-01): Do not start a finished magazine until assigned with enough confirmed bottles. Never send, post, email wineries, sell, or pay without an explicit ask. Unknown is first-class: show NA or leave blank rather than guessing. Qty comes from ledger or readable carton writing, never from inventing a count.
- **log** (2026-09-01): iPad delivery: prefer Acrobat-ready PDF when the share sheet cannot open packed HTML in a browser; Word mangles magazine layout.
- **log** (2026-09-05): When rebuilding multiple issues, group wines by estate/maker, put a wine index early so spread numbers match, put $ immediately before every price with a provenance caption, and keep cover month as the trip month unless reassigned.
