# Wine Cellar Glossy Log Book

**Title:** Wine Cellar Glossy Log Book

Turns a wine collection or wine-buying trip into a gift-ready high-gloss magazine for the front room. Photograph labels, receipts, and vineyard notes; unknowns stay blank. Produces three digital-first art-themed options (e.g. Kandinsky, Miró, Tarsila); pick a favourite and print later. Friends can hand-write comments in the tasting space.

Seed memories (rules and facts from the template) are in `MEMORY.md` in this folder. Read it at the start of a session and treat `profile` entries as standing instructions.
