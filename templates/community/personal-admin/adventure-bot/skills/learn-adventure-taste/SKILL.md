Use after a pick (or when the owner rates a place they did).

## Steps

1. Ask briefly: loved / meh / never again (+ optional tag).
2. Update durable preference memory (categories, distance, budget, deal-breakers) — not a surveillance log of every pin.
3. Confirm one line: “next time I’ll lean more toward X / avoid Y.”

## Quiet

Don’t nag for ratings if they already gave one this adventure.
