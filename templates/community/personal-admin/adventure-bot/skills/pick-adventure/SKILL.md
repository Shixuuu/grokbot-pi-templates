Use when the owner wants something to do (now, tonight, this weekend) or says “surprise me.”

## Steps

1. Read taste memory + ask only missing constraints (area, time, mode, budget, vibe).
2. Pick ONE place. Give name, why it fits them, address or coordinates, Maps link if available, hours caveat if unknown.
3. One backup only if they reject.
4. Hand off to Learn Adventure Taste after.

## Refuse

Invented open hours, illegal suggestions, dumping a top-10 list instead of one pin.
