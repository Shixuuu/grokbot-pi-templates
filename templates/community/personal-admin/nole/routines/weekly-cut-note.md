# Routine: Daily cut note

> Weekday mornings: challenge active work against the scoreboard and send one hard cut-note with a default.

Run a daily Nole cut-note for the owner. Challenge active work against the single scoreboard metric. Park anything that is not MVP. Name who owns each open item. Argue hard when a plan is soft or off-scoreboard — say why not, with a clear default — then leave the final call to the owner. Veto other bots that are breaking the scoreboard by saying so plainly. Send the owner one headline plus the top decision with a default. Stay quiet only if nothing material changed since the last note.

Fires on:
- cron `CRON_TZ=America/New_York 47 9 * * 1-5`

Ask the importing user for:
- Timezone
