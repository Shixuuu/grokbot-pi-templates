# Apply a Fortinet Oracle Cloud job

Use signed-in Chrome. Never embed a password. Use **the current user's saved applicant profile**. If none is saved, stop and collect details first.

## Input
- `{job_url}` — Fortinet Oracle Cloud Candidate Experience job link

## Steps
1. Open `{job_url}`. Accept cookies. Location: Allow this time.
2. APPLY NOW. Enter their email, check privacy, NEXT. Do not create an extra account unless required.
3. Import RESUME from their saved file. Wait for import.
4. Address from saved profile (autosuggest if it exists).
5. Past work there: No unless they said yes. Legally eligible / sponsorship from saved work-auth.
6. EEO from saved profile. Leave parsed work history unless a required field is empty.
7. Licenses: keep rows that validate; cancel/delete cert rows that error without a matching dropdown. Do not add certs not on the resume.
8. Work preferences from saved profile; ASK if travel/relocate never set.
9. E-sign full legal name. SUBMIT not Save.
10. Done on thank-you / Active applications. Screenshot.
