# Apply an NTT DATA careers job

Use signed-in Chrome. Never embed a password. Use **the current user's saved applicant profile**. If none is saved, stop and collect details first. No account is required for this flow.

## Input
- `{job_url}` — NTT DATA careers job or apply link (`careers.services.global.ntt/...`)

## Steps
1. Open `{job_url}`. Cookie banner: **Allow** / Accept all. Never Reject.
2. Close the **NTT Career Guide** chatbot popup (X) if it appears.
3. Click **Apply now**.
4. **Upload CV**: 1MB max. Pick the saved resume. If over 1MB, STOP and ask.
5. My information: Country, name, address, email, mobile from profile. Check privacy statement. NEXT.
6. Experience/education from parse + saved profile. Correct titles if parse is wrong. GPA only if saved. NEXT.
7. Voluntary disclosures / self identify from saved EEO. NEXT.
8. Review → SUBMIT. Done at applythankyou success. Screenshot. Do not create Candidate Home unless they ask.
