# Apply an xAI Greenhouse job

Use signed-in Chrome. Never embed a password. Use **the current user's saved applicant profile**. If none is saved, stop and collect details first. If Greenhouse emails a verification code, stop and ask the user.

## Input
- `{job_url}` — the Greenhouse xAI job link

## Steps
1. Open `{job_url}`. Accept cookies. Allow location this time if asked.
2. Fill name, email, phone country code + phone, location, website, LinkedIn, X from the saved profile.
3. Attach the saved resume.
4. Education from the saved profile (search school/degree/discipline).
5. Native-language legal name = their legal name unless they saved otherwise.
6. Sponsorship from saved profile. “Worked at SpaceX/xAI/X/Twitter”: never, unless they said they did.
7. Exceptional-work / proud-of: paste saved blurb if present; ASK if missing. Leave ideal-candidate blank unless they provided text.
8. How heard: from the link source or saved preference.
9. Submit. If an email code arrives, ASK, then submit. Done at confirmation Thank you for applying. Screenshot. Do not click View more jobs unless they ask.
