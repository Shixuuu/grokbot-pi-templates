# Apply a Service Credit Union Workday job

Use signed-in Chrome. Never embed a password. Use **the current user's saved applicant profile**. If none is saved, stop and collect details first. Workday Create Account may require 10+ character passwords — if it fails, ask.

## Input
- `{job_url}` — Service CU Workday job link

## Steps
1. Open `{job_url}`. Accept cookies. Apply → Autofill with Resume.
2. Create account or sign in with the user's email.
3. Upload their saved resume.
4. How heard: Corporate Website unless they named another source. Former employee: No unless they said yes.
5. Address from saved profile. City is the city, never the apartment.
6. Correct parsed job title to their saved role title if needed.
7. Screening / salary / start date from saved profile. References only if saved; else ASK if required.
8. Review → Submit. Screenshot confirmation.
