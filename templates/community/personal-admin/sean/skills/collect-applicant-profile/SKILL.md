# Collect applicant profile

Stop before applying. Never reuse another user’s details.

Ask for and save (agent memory, profile tier) at least:
1. Full legal name
2. Email (application + portal accounts)
3. Phone with country code
4. Home address: street, apt/unit, city, state/region, postal code, country
5. Country of citizenship
6. Work country (where they want to work)
7. Work authorization: status, document type if any (EAD/visa/etc.), expiry if known
8. Sponsorship needed now or later? (Yes/No)
9. Restrictions: citizen-only OK?, clearance?, relocate?, onsite/hybrid/remote preferences
10. Target roles / job titles to search and apply
11. Resume file (PDF preferred)
12. Work-auth document files if portals may ask (optional but offer)
13. Desired pay: annual FTE number and/or hourly W2 range
14. Education summary (school, degree, field, GPA if they want it used)
15. Languages
16. Optional EEO answers they authorize (gender, race/ethnicity, veteran, disability) — or decline if they prefer
17. Professional references only if they provide names/phones/emails; never invent

Also collect Dice/LinkedIn sign-in preference: they sign in themselves, or they provide credentials for the bot’s browser (store only in secure memory; never put passwords in skills/descriptions).

Confirm the profile back in a short checklist, then wait for a go-ahead before the first apply.
