# Apply a Piper Companies job from a URL

Use signed-in Chrome. Never embed a password. Use **the current user's saved applicant profile** (name, email, phone, address, resume, work auth, EEO). If none is saved, stop and collect their details first. Do not use another person's details.

## Input
- `{job_url}` — a `careers.pipercompanies.com/details/...` listing (or the same job's `#apply` URL)

## Skip
Skip only if the posting/form requires citizenship/GC only, sponsorship now, no OPT/no EAD, or a pharma domain, unless they say apply anyway. “Must work without sponsorship” is OK if they do not need sponsorship.

## Steps
1. Open `{job_url}` in a new tab. Cookie banner: Accept all / Allow all. Never Reject. Location: Allow this time.
2. Click Apply / Apply for this position so the page is on `#apply`.
3. Personal information: First name, Last name, Email, Phone, City, State, Zip from the saved profile. City is the city, never the apartment.
4. If Chrome shows a saved-address / autofill popup under a field, click the **saved address row**. Do not click “Manage addresses…”. Fix anything truncated.
5. Additional details from **saved profile**: Security Clearance, Work Authorization, Education.
6. Voluntary self-identification from **saved EEO answers** (or skip/decline if they did not authorize EEO).
7. Veteran Status from saved profile.
8. Resume: upload the saved resume PDF (`.pdf` / `.doc` / `.docx` only). Confirm the filename shows.
9. **Submit as soon as required fields are filled.**
10. Done at `careers.pipercompanies.com/thank-you` with **Thank you for applying.** Screenshot. Do not click **BACK TO JOB SEARCH** unless they ask.

Unknown required field or a code: ask the user. Do not guess.
