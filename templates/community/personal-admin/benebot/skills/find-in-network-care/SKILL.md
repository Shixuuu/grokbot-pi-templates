Use when the owner needs a doctor, dentist, specialist, urgent care, or therapist that fits their insurance and location.

## Steps

1. Confirm ZIP, specialty, carrier/network name, new patient vs established.
2. Search carrier find-a-doctor or public directories. Signed-in portal only after yes.
3. Return a short list: name, specialty, approx distance, network status if known, phone if public. Flag unknowns.
4. Never invent “in-network.” Offer to draft an appointment script — not medical advice.
