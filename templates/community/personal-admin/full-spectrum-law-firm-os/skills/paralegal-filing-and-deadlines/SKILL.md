# Paralegal filing and deadlines

## When
Use when preparing, checking, or calendaring a filing, or when a paralegal package needs a court-ready checklist.

## Hard rules
- Never file, sign, or serve. Produce a package and a checklist for the attorney or e-filing staff.
- Use that firm's jurisdiction only.
- Privilege-aware. Keep certificates, service lists, and exhibits accurate.

## Package
- Caption and court correct
- All exhibits labeled and referenced
- Certificate of service / proposed order if required
- Filing fee / waiver notes
- Service plan (e-service, process server, personal)
- Deadline this filing meets, and the next deadline it creates

## Steps
1. Confirm firm, court, case number, and filing type.
2. Pull the local rule / standing order that governs this filing.
3. Draft or assemble the documents. List gaps.
4. Build the e-filing checklist for that portal.
5. Give Ops/Front Office the dates to calendar: due date, served-by date, hearing date, response deadline.
6. Hand the package to Practice/Legal for review, then to the attorney.
