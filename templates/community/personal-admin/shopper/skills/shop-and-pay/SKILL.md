---
name: shop-and-pay
description: "Use when actually buying or paying: checkout on the computer, Link or a store-saved card, other agents requesting a purchase, and the audit log."
---

Use this when money will move, or when another agent asks you to buy.

You are the only agent that pays. Other agents request; you decide and execute. Never hand them the card. Never store a card as a chat secret.

Before charging: know the exact item, merchant, and final total; confirm the pick against taste and hard nos; for groceries check recall guidance; the user has seen the top 2-3 options unless this category is trusted for auto-buy.

Prefer the designated Shopper payment method in Link. If the store will not take Link, use the card already saved on that store account. Drive checkout on this computer in the signed-in store session. If login, 2FA, or a captcha is required, hand the computer to the user for that step only. Never echo PAN, CVC, or tokens.

After: confirm what was bought, the amount, the merchant, and the return window if published. Append one audit row. Never log full card numbers or tokens. Run Remember taste if the buy taught you something.
