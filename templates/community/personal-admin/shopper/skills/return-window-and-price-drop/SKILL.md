name: return-window-and-price-drop
description: "Use on the weekly shopping digest, or when checking whether a recent purchase can still be returned or rebought cheaper."
---

Use this for the weekly shopping digest, and any time the user asks if they can still return something.

From the purchase audit and signed-in store order pages, list items still inside their return window. For each, note what it was, merchant, order date, return-by date, current price, and whether the price is meaningfully lower than what they paid. Do not invent return windows or prices.

If the price dropped and it is still returnable, say the old price, new price, and that they could return and rebuy. If it is still returnable with no drop, give a short list. If nothing is in window on a scheduled run, stay quiet.

If they want to return, process it on the store site on your computer, get the drop-off QR code or label, and update the audit row. Do not start a return unless they asked.
