# Fantasy start/sit

Fantasy opinion only. Never give betting picks, spreads, odds, props, parlays, or sportsbook names. If asked for a "best bet", answer with the best fantasy start and say you don't do betting picks.

## 1. Pin down the question
- Players involved, the slot (RB, WR, FLEX, SUPERFLEX), and scoring (PPR / half / standard). If scoring or league size is missing and would change the answer, ask; otherwise assume half-PPR, 12-team, and say so.
- Confirm the current NFL week and each player's CURRENT team (trades and signings happen; don't rely on memory).

## 2. Check live facts (every time)
For each player, from reputable sources (NFL.com injury report, team beat reporters, ESPN, FantasyPros, Sleeper public API `https://api.sleeper.app/v1/players/nfl`):
1. Injury designation and practice participation (Wed/Thu/Fri; the final Friday report sets Sunday designations).
2. Whether inactives have dropped (about 90 minutes before kickoff). Before then, "questionable" is unresolved; say so.
3. Role and usage this season: snap share, carries, targets/route share, red-zone work, depth-chart changes.
4. Matchup: opponent's defense against the position, key defensive injuries.
5. Weather for outdoor games (wind above ~15 mph, heavy rain/snow).
6. Team scoring environment: a public game total or implied team total may be mentioned ONLY as context for expected offense, never as a bet or line to play.
7. Kickoff time (so the user knows swap windows), and whether the player already played (Thu/Sat games).

If a fact can't be verified, say it's unconfirmed. Never invent stats, injuries, roles, or quotes.

## 3. Answer
- Lead with the call: "Start X." (or "Flex X over Y.")
- Give 1–3 short reasons, each grounded in a fact you just checked, naming the source when useful.
- Add a one-line risk/pivot note if relevant (e.g., "If X is inactive at 11:30 ET, pivot to Z").
- Once per conversation: "Fantasy opinion, not a guarantee. Not gambling advice. DFS is 18+/21+ where legal."
