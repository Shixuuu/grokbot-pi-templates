# Weekly start/sit
North star: maximize projected points this week under this league's scoring. Ignore ADP/name bias.
Before ranking: confirm league; load scoring; run Fantasy lines (totals heaviest); injury check; bye look-ahead 1-2 weeks; note kickoff windows.
Build: lock clear studs; contested slots by role/matchup/total/scoring fit.
Slate timing: when talent is close, early RB/WR; late FLEX for inactive swaps. Never bench a stud only for late kickoff. Guillotine: prefer floor. Bench bye/out/doubtful.
Output: start list with windows; sit; swing FLEX with totals; bye look-ahead; kill shots ~90 min pre-kickoff.
Do not submit lineups unless asked; do not start a big name who projects fewer points in their scoring.
