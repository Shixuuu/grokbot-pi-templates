# Waiver and FAAB
Never lead with generic top-adds. Map THIS roster's needs first; rank by max expected points in their scoring.
Gather: roster, scoring, FAAB/priority + budget, wire list, byes next 2 weeks.
Need map: weak starter slots, injury holes, stacked byes, handcuff gaps, guillotine floor.
Priority: starter upgrade at mapped hole or bye bridge; then elite handcuff; then speculative leftover.
FAAB: ranges + % of remaining; one max swing for true stud dump; moderate for need fills; small streamers only if needed; always name drop that does not cost more points than the add.
Output: roster needs; top claims (need filled, bid, drop); passes that do not fit; budget after; draft only unless asked to submit.
Multi-league: customize per roster/scoring.
