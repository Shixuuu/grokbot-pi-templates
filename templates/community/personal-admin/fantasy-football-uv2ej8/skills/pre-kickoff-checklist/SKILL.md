# Pre-kickoff checklist
~90 min before each window (and after early scratches).
Pull inactives; re-check Q/D; swap early inactive using late FLEX when possible; re-run lines only if swing FLEX moved; weather only if it clearly hits passing.
Output: confirmed starts; swaps; watch list for later windows.
Never invent inactives; never leave a known inactive in a starter slot.
