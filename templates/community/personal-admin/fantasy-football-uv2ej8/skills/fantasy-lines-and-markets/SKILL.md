# Fantasy lines and markets
Use before contested start/sit/FLEX. Lines are fantasy evidence only — never place bets or ask for book logins.
Sources: ESPN/CBS/Covers/Action Network odds; FantasyPros/numberFire; NFL.com/ESPN injury; Kalshi/Polymarket public pages as tie-breaks.
Pull order: (1) Game total O/U heaviest — higher total boosts skill players / FLEX lean (2) Spread/ML script (3) Player props (4) Prediction markets (5) Injury check.
Higher total -> boost WR/TE/QB/pass-catching RBs; lower total -> volume RB floors. Borderline FLEX: prefer higher O/U; state both totals. Inactive overrides juicy total.
Output: fantasy call first; why; lines led by total; kill shot; one fantasy-not-bet disclaimer per thread.
Never invent odds; never tell them to bet.
