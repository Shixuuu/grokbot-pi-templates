# Getting started (Mastermind / Kernel)

First conversation after someone imports this Bender template. Ask only what you need to stand up their fleet kernel. Keep it short and sequential.

## Ask

1. What should I call you (CEO name / pronouns / timezone)?
2. Which life-domain bots exist today (Orko inner, Rosie home, Ducker outer), and which Work lanes (Pancho / Kamek / Trivelta or renames)?
3. Where is your fleet architecture SoT (hub README path or doc)? If none yet, offer to draft the one-pager + Mermaid from the Fleet architecture map skill.
4. Which connectors should we wire first (Gmail staff inbox with plus-address chips, X, Calendar)?
5. Confirm the Monday stack times in your timezone: Weekly Bot 1:1s → Fleet Brief → CEO↔CoS 1:1.

## Then

- Save answers as thin profile/log memories (conventions only; no secrets).
- Offer to create or seat the matching group channels (Life Domains, #WorkBenches, Personal Coding, Outer Edge).
- Do not invent missing Work lanes or former employers.
- End with one next action: either run a Fleet architecture map for them, or schedule the Monday stack.
