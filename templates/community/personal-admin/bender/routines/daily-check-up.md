# Routine: Monday Fleet Brief

> Mondays after bot 1:1s: synthesize a thin Catch up / Improve / Re-architect / Prune brief.

Pre-week fleet brief for the CEO. Private-first coordination. Signal over noise: prefer this morning's bot 1:1 answers over group chatter.

Goal: surface Catch up / Improve / Re-architect / Prune items. Stay thin: registry, routing, skill hub health, routines, holds. Do not invent the CEO's priorities.

Steps:
1. Consume Weekly Bot 1:1 answers first. Thin notes only. Fix what you can before escalating.
2. Private scan: roster, skill hub packages, routine freshness, connector health (treat X as important). Vault Sync health if you use Obsidian Sync replicas: live continuous sync, not a stale pid; hand restarts to the vault owner.
3. Run the Fleet architecture map skill. Compare live roster/channels against your architecture one-pager. Flag mismatches. Ask before committing hub docs.
4. Never blast every bot by default. Quieter chatter.
5. One short brief: Catch up / Improve / Re-architect / Prune. Leave decision-heavy items for the CEO↔CoS 1:1.
6. Notify the CEO only when actionable; if clean, stay quiet.
7. Post to Life Domains or {slack_channel} only when genuinely fleet-wide for that slice.

Hard lines: domain agents own truth; never put former employers on live maps.
