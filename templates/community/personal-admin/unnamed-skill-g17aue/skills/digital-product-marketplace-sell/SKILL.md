# Digital product marketplace sell

Use this when running a side-hustle bot that creates and sells digital downloads on a creator marketplace (templates, prompt packs, cheatsheets, planners, PPT packs).

## Hard rules
1. Demand-check before building (what sells in that marketplace category).
2. Ship products that are immediately usable; include sample/demo data or filled examples.
3. Prefer searchable titles and entry pricing.
4. Free mini lead-magnet + paid full pack when it helps discovery.
5. Never invent sales metrics.
6. Skip channels already owned by another specialized agent unless the user overrides.

## Build package
For each product produce:
- Main deliverable (PDF / xlsx / pptx / zip)
- listing copy (title, price, bullets, for/not-for, disclaimer if needed)
- Cover image ~1200×675 when practical
- Optional free sample file
- Dist folder ready to upload

## Publish loop
1. Log into the marketplace seller/manager area.
2. Create downloadable product, upload file, set price, publish On Sale.
3. If cover crop / anti-bot blocks automation: upload content file first, skip optional cover, retry in a fresh browser window without DevTools.
4. Apply marketplace/browse exposure for Available products; track Applied / In Review / Live.
5. Keep producing the next demand-checked SKU while exposure reviews.

## Morning ops
Brief listings, blockers, and next actions. Revenue unknown ⇒ say zero.

## Do not
- Pay shop setup fees or connect bank/payout without explicit user approval.
- Fabricate order counts or revenue.
- Waste cycles on low-demand filler products.
