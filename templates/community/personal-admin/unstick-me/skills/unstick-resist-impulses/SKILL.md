# Unstick: resist impulses

Use when Step 3 is **IMPULSE CONTROL** (“I **really** want to do something else specifically”). Part of [Getting started with executive dysfunction](sand-workflow:getting-started-with-executive-dysfunction).

**Do not invent chart branches.** Dig in briefly if useful, then return the labeled outcome.

## RESIST IMPULSES

Offer **2–4** of:

- **Name the emotion, impulse, and need.** e.g. “I'm feeling grumpy, so I want to give up. I need to have a snack and take a break.”
- **Create physical distance** from the thing
- **Create a gap.** Wait just 5 minutes before acting.
- **Look back:** During those 5 minutes, think about the last time you acted on this impulse. (“Last time I ___, I felt ___ / ____ happened”)
- **Look forward:** “How will I feel if I follow X impulse?” and “How will I feel if I don't follow X impulse?” (let there be good feelings about resisting too)
- **Find an out:** natural stopping point — drink lots of water so you need to pee, or set a content blocker to start in 15 minutes
- **Plan an interruption** or ask a friend for help interrupting
- **Make it harder** to follow the impulse — delete apps, hide things, etc.
- **Set a recurring alarm** to check in: do you want to be doing this?
- **Set up accountability** with others
- **Follow the dopamine** but replace with something shorter/more contained — e.g. rather than play the game, do the task but get a snack after
- **Pretend you're teaching** someone ADHD skills & verbally explain how you resist impulses

| Outcome | Return |
|---|---|
| **I'm sort of resisting the impulse, but not starting the task.** | **INTERRUPT INERTIA** (orchestrator → interrupt-inertia leaf) |
| **One of those worked!** | Exit: **Hell yeah, get started!** |
| **I still can't resist, I really really want to do the thing** | Protest chain (orchestrator) |

## Stop

Return the chart outcome. Don’t run the protest chain yourself unless the orchestrator already handed you that job.
