# Unstick: clarify the task

Use when the walkthrough is on **PRIORITIZE** or **BREAK IT DOWN** (overwhelm / paralysis / perfectionism → break-down). Part of [Getting started with executive dysfunction](sand-workflow:getting-started-with-executive-dysfunction).

**Entry:** orchestrator says PRIORITIZE or BREAK IT DOWN — start at that section. If PRIORITIZE returns **OVERWHELM: I still don't know...**, continue into **BREAK IT DOWN** in this same skill.

**Do not invent chart branches.** Dig in on tips if they ask; then return the labeled outcome to the orchestrator.

## PRIORITIZE

- Use an important/urgent matrix
- Pick the top 3 things or **1 next thing**

Offer 1–2 tips, then ask:

| Outcome | Return |
|---|---|
| **I know what to do now!** | “Great job! Move to step 2.” |
| **OVERWHELM: I still don't know...** | Continue to **BREAK IT DOWN** below |

## BREAK IT DOWN

- Use Goblin Tools! (https://goblin.tools/ToDo)
- What's the smallest, easiest, **measurable** first step?

| Outcome | Return |
|---|---|
| **I know what to do now!** | “Great job! Move to step 2.” |
| **I still don't know :(** | “Revisit previous to-do lists, ask for help, or take a walk break to think about it. Go to Step 1.” |
| **It still feels too hard or like too much** | **WELLBEING** |

## Stop

Hand back the chart outcome label. Don’t start Step 2/3 yourself — return to the orchestrator.
