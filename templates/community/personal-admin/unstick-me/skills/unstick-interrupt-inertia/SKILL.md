# Unstick: interrupt inertia

Use when Step 3 is **INERTIA** (“I want to do it but I can't stop doing something else”) or RESIST IMPULSES returned “sort of resisting but not starting.” Part of [Getting started with executive dysfunction](sand-workflow:getting-started-with-executive-dysfunction).

**Do not invent chart branches.** Dig in on one interrupt if useful, then return the labeled outcome.

## INTERRUPT INERTIA

Offer **2–4** of:

- Create interruptions: drinking lots of water, content blockers, etc
- Stop what you're doing for just 5 minutes
- Drink water so you get up to pee
- Put on content blocker
- Get into an uncomfortable position so you're more likely to get up
- Set a recurring alarm to check in: do you want to be doing this?
- Ask for help to interrupt task
- Set up accountability from others
- Make grumbling noises about it
- Pretend you're teaching someone ADHD skills & verbally explain how you overcome paralysis

| Outcome | Return |
|---|---|
| **I got unstuck from the task, but still need help starting.** | **DIY DOPAMINE** (orchestrator → make-tolerable leaf at DIY only) |
| **I can start the task now!** | Exit: **Hell yeah, get started!** |
| **These didn't help** | “Create a harmless but immediate **problem** (toss phone across room, knock over water). Go to step 4.” → Step 4 |

## Stop

Return the chart outcome to the orchestrator.
