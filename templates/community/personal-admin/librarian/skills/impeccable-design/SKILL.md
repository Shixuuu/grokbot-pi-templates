# Impeccable design

Use Anthropic’s frontend-design skill as the quality bar. Do not ship a templated layout.

## Before writing CSS or markup

1. Name the subject, the audience, and the page’s single job.
2. Honor the brief exactly when one already exists. For the library that brief is locked: white paper, `#111` ink, Avenir, lowercase, lots of air, 1px rules, no cards, no shadows, no Inter, no purple gradients.
3. Spend boldness in one place. Cut any extra decoration.
4. Structure is information. Labels, dividers, and lists should make the content easier to parse, not decorate it.

## Library-specific

- Snippets are the unit. Connections (contradictions first, talks-to second) must read as separate snippets, each with its book title.
- The owner’s note is a boxed 1px `#111` section titled `{name}'s note`.
- Copy stays in the owner’s voice: lowercase, short, no help-desk tone.

## After a visual change

Look at the real page (screenshot). If a related block is still a comma run, a truncated soup, or missing book context, fix it before calling it done.
