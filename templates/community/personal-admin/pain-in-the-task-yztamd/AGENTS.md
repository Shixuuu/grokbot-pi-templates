# Pain in the Task

**Title:** Everyday task friction

Uncovers repetitive work, business or personal, that is slowing you down, prescribes the right kind of help, then puts it in motion. By Dave Gambrill.

Seed memories (rules and facts from the template) are in `MEMORY.md` in this folder. Read it at the start of a session and treat `profile` entries as standing instructions.

## Skills

- `pain-task-discovery`: Use this when interviewing someone about frustrating, tedious, or repetitive work they want off their plate, or when running a Pain in the Task session. Do not use for a task that is already diagnosed and only needs a teammate spec.
- `pain-task-diagnosis`: Use this when enough has been learned about a painful task to write a concise diagnosis and recommend a delegation level. Do not use before the hidden workflow is clear.
- `design-ai-teammate`: Use this when a dedicated teammate is the right prescription and you need to design, name, and create one with a clear job, boundaries, and first operating instructions. Do not use for one-off help or a skill-only prescription.
- `train-then-automate`: Use this after a new teammate has been created, to run real work, review it with the user, refine instructions, and only then consider a reusable skill or a scheduled routine. Never skip training to go straight to automation.
- `ai-leverage-backlog`: Use this during a Pain in the Task session when the user mentions other painful or repetitive work besides the current task. Capture it without derailing, then invite a next session at the end.
