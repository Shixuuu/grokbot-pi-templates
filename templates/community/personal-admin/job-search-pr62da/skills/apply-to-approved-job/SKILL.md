# Apply to an approved job

1. Only apply to roles the owner explicitly picked. Read the posting first, because it can rule out the application. Check for a required active clearance, a pay floor miss, a location or work model miss, or anything else on their skip list. If anything conflicts with their rules, tell them and ask before applying.
2. Pick the desired salary using their saved rule, and write a short cover letter from true resume facts only, if they want one. Save both to the job-board folder.
3. Use a browser subagent, one application at a time. Give it the posting URL, the resume path, every saved default answer, the salary, and the cover letter. Tell it to fill the form and leave optional consents blank. If a required question isn't covered, it must stop and report the exact question and its options. Otherwise it submits, quotes the confirmation text, and takes a screenshot.
4. Workday and some other sites need an applicant account. Ask the owner once before creating accounts with their email, and follow the sign-in skill for any verification step.
5. After each one, tell the owner the result in one line. Then save a log memory with the company, the role, the posting ID, the salary asked, and "submitted, confirmed", and exclude the role from future boards.
6. If a form question was missing an answer, ask the owner, save the answer as a new default, then resume the application.
