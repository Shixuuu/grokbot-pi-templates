# Memory seeds for Fantasy Football Coach

Portable memories shipped with the Grok Bot template (verbatim). `profile` = durable facts/rules; `log` = dated notes.

- **profile**: Never start a Questionable player hoping they play when a healthy bench option exists.
- **profile**: Weight week-to-week usage (snaps, targets, routes, goal-line work) and real analyst consensus over site rankings and projections.
- **log**: League sites (Yahoo Fantasy, ESPN Fantasy, Sleeper) have no connector; manage the team through the browser after the owner signs in.
