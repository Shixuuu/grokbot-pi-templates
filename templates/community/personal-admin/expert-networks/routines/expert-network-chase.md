# Routine: Expert network chase

> Three times a week, check work Gmail for expert-network replies and finish stuck expert onboarding.

Chase unfinished expert-network applications so the user can take more paid consults. Run Mon/Wed/Fri mornings in the user’s local time. After a chosen end date (or on a run that finds it has passed), send a last status to the user’s chief-of-staff teammate, then delete this routine.

Coverage: the chief of staff may ping later that day only if this run’s ping never arrived. If a later coverage-check message arrives and you already ran that day, reply only “ran, nothing moved” (or the already-sent result) and do not chase again.

Watch networks with open expert/advisor interest forms (e.g. Dialectica while still silent). Scan Guidepoint and AlphaSights mail only in case they reach out for a project (no open signup: Guidepoint only adds advisors for specific project requests; AlphaSights has no expert sign-up). Also scan GLG mail for Member Success / verification / payment / rate follow-ups. DROP Atheneum while onboarding is on hold. DROP Coleman/VISASQ when they are not taking proactive applications. SKIP invitation-only networks such as Third Bridge and ProSapient.

Each scheduled run:
1. Check the user’s work Gmail for replies from watched networks and any new GLG mail. Prefer the Gmail connector. Hand the user the box only for password/2FA or a real decision.
2. Finish stuck onboarding without inventing a password, employment dates, rate, or confidential details. Use the user’s work email and phone from memory/signature. Expert/advisor only — never a paying client.
3. Keep a baseline of which networks are submitted, wait-for-project, dropped, or live (e.g. GLG payment account / rate).
4. ALWAYS message the user’s chief-of-staff teammate after the chase. If nothing moved, send only: “ran, nothing moved.” If something finished or is blocked on the user, tell both the user and the chief of staff. Stay quiet to the user when nothing moved.
5. Always ask the user before sending any outbound email on their behalf.

Fires on:
- cron `43 9 * * 1,3,5`

Ask the importing user for:
- Timezone
