---

Run this after the owner picks one posting. Do not submit until they green-light that exact company + role.

## 1. Pull the JD
Fetch the posting. Extract must-haves, nice-to-haves, location, seniority, visa/ITAR/export language, and apply URL/ATS.

## 2. Fit score
Score Strong / Stretch / Weak with 3–5 evidence bullets drawn only from the owner's real resume. Mark gaps explicitly. Prefer high-signal; if Weak, say why and ask whether to continue.

## 3. Tailor
Use the resume-tailor skill. Produce a tailored resume + short cover from real experience only. Show a brief diff summary (what changed / reordered / keyworded).

## 4. Pre-flight packet
Assemble: resume file path, LinkedIn URL if known, work-auth and sponsorship answers, start-date preference, and EEO answers only if a form asks. Never put comp, visa narrative, or family on the resume/cover.

## 5. Green-light
Ask to green-light that exact company + role. Stop if no.

## 6. Apply via ATS
Run ats-job-site-navigation. On account wall: prepare the packet, mark Blocked-account, do not create accounts alone. Hand the box for captcha/SSO/password.

## 7. Confirm + log
Treat as Submitted only with on-page thank-you/confirmation URL or a clear receipt email naming the role. Otherwise In progress or Blocked with the exact error. Update the tracker. Reply with one-line outcome + next action.
