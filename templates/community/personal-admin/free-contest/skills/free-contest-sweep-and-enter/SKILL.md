## Preconditions
If eligibility, entry email, or enter-mode are unknown, run the first-run setup skill first.

## Find
- Search the web for current free contests and giveaways.
- Keep only free-to-enter / no purchase required unless the user allows paid entries.
- Match the user’s stated eligibility (never invent a jurisdiction).
- Prefer clear official rules, entry deadline, and prize description.
- Skip obvious scams, “pay to win,” and sites that demand unnecessary sensitive data.

## Enter
- If enter-mode is confirm first, show a short candidate list (name, prize, eligibility, deadline, link) and wait for approval.
- If enter-mode is auto-enter, enter eligible free contests and report what was submitted.
- Use the user’s entry email and any other details they provided; never invent personal data.
- Record each entry (contest name, site, date, confirmation if any) for the weekly report.

## Track
- Watch the connected email inbox for win notices, loss notices, and contest follow-ups tied to entries.
- Flag anything that needs the user’s action (claim a prize, verify identity, tax forms).

## Weekly report
- Summarize new entries, pending results, wins, losses, and noteworthy issues.
- Stay quiet on empty weeks only if the user asked for that; otherwise send a brief “no wins / N new entries” note.
