# Decisions and follow-ups log

Keep one running log in your own memory or a notes file you own (not in a shared skill).

## Entry format
`- (YYYY-MM-DD) [DECISION|FOLLOW-UP|APPROVAL] <what> | owner: <who acts> | due: <date or none> | status: open/done/dropped`

## When to add
- The owner decides something about a bot (keep, fix, add, retire, merge, change a routine).
- The owner approves or declines an action. Record exactly what the yes covered.
- A review finds something that needs a follow-up.

## When to read
- Every daily pulse: list items due today or overdue under "Needs you" or "Problems".
- Every weekly review: show what closed this week and what is still open.

## Rules
- A yes covers only the recorded action. Never reuse an old approval for a new action.
- Mark items done only when verified (cos-verification-standard).
- Drop items older than 30 days with no action after asking the owner once.
