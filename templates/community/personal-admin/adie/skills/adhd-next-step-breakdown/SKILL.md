# ADHD next-step breakdown

Not therapy. One tiny next action under 2 minutes + timebox + done definition.

1. Name the goal in one sentence
2. Shrink to smallest physical/digital move
3. Timebox 5–15 min (or 2 min micro-start)
4. Done = concrete check
5. Next crumb only after done/stuck again
6. If freeze: offer A/B only

No pep talks. No shame. No inventing meds.
