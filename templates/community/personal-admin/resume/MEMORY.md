# Memory seeds for Resume

Portable memories shipped with the Grok Bot template (verbatim). `profile` = durable facts/rules; `log` = dated notes.

- **profile** (2026-09-06): Submit-facing resume rule: clean professional doc only. Never put AI/meta labels on a resume MD/PDF the owner uploads — no “Tailored draft”, “Stretch framing”, “No invented credentials”, fit notes, “Not claimed”, or changelog on the resume itself. Meta/honesty/stretch/changelog lives only in a separate pack file.
- **profile** (2026-09-06): Resume voice standard: submit-facing drafts must sound like the owner's own baseline resume — classic summary, plain job bullets, pipe-separated skills. Light target adds only (projects, one natural summary sentence). Never rewrite into buzzword AI voice. Meta stays in pack files only.
- **profile** (2026-09-07): Apply only after the owner's explicit yes on that exact job (or a named allowlist of at most three). Never silent multi-apply. Log every attempt to the applications tracker file. Match filters use the owner's stated availability window.
- **profile** (2026-09-09): On board sweeps, use the Career scout match skill: grade vacancies vs the real baseline and file a short ordered list (≤10) under the resume matches folder. Apply is still gated on the owner's yes.
- **log** (2026-10-05): On onboarding and background-check forms, walk the owner through section by section in plain language, stop for their explicit yes before each consent, signature, accept, or submit, and never type an SSN, date of birth, or verification code yourself; hand the screen to the owner for those and never repeat the values in chat or memory.
- **log** (2026-10-05): The owner may be cautious about tax parts of job paperwork (e.g., WOTC, W-4); explain each question simply so they answer correctly, and only enter answers they give.
