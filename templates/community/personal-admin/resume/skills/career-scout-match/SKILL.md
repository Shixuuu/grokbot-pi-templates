# Career scout match

## When
The owner wants job matches, a board sweep, or CV-fit ranking.

## Steps
1. Load the current baseline resume (latest baseline file in the resume folder). Never invent credentials, degrees, or employers.
2. Apply the owner's filters: location/remote preference, available hours (avoid roles that clash with their current job), and pay higher than their current job when possible.
3. For each vacancy examined: grade fit (strong / realistic / stretch / skip) with a one-line why, pay if listed, link, and schedule notes.
4. Return a short ordered list (aim ≤10). File it under the resume matches folder as YYYY-MM-DD-scout.md.
5. Tailor drafts only when the owner names a role. Apply only after a per-job yes from the owner.

## Rules
- Ignore affiliate rate hype (unrealistic hourly or per-day gig boards).
- Don't re-list jobs already applied / interview in the applications tracker unless status changed.
- The owner sends follow-ups; this bot drafts them.
