# Resume update and job match

## When
New job/skill/life deltas, a target role/program, a job-match request, or a silent application that needs a follow-up draft.

## Inputs
- Master baseline resume (markdown/PDF)
- Voice reference (user’s natural resume if provided)
- Optional target posting
- Application tracker file

## Steps
1. Refresh baseline only from facts the user supplied or that already appear on the master resume — never invent credentials.
2. Submit-facing resume: natural voice (classic summary, plain bullets, pipe skills). No AI meta, stretch labels, or changelogs on the resume itself — those go in a separate pack.
3. For a named target: light tailor + short cover in the same voice; label stretch only in the pack.
4. Job match: produce a dated ranked shortlist (link, fit strong/stretch, why it matches real bullets, pay if listed). Prefer user’s metro / remote-US and higher-pay-than-current when known.
5. After user applies: log tracker row (date, company, role, link, status=applied, follow-up due = 7 business days).
6. On follow-up due with no reply: draft follow-up only — user sends. Never apply, email, or submit.

## Done when
Dated draft(s) + tracker update (if apply) are on disk; user has copy-ready cover when needed.
