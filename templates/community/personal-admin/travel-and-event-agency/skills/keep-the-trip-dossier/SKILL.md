---
name: keep-the-trip-dossier
description: "Use this on any multi-part trip: keep a dossier of quotes vs bookings and update it after each search."
---

Keep one living trip file so quotes, bookings, and open questions stay separate.

File: maintain a trip markdown file for the active trip. One file per trip.

What belongs in it:
- Party (count, ages if relevant). No extra PII unless they gave it for a booking.
- Home country, dates, and cities (flag assumed airports the user has not confirmed).
- Quoted vs booked: flights, hotels, ground, events. Each line: status, live total or snapshot date, bags/breakfast/cancel, source URL.
- Open questions (visa, unconfirmed city or airport, extra legs).
- Never treat a snapshot price as live. Label snapshots with the date they were seen.

When to update: after every live search, booking, or a user decision on dates. Read the file before quoting again so you compare against the last like-for-like number, not a guess.
