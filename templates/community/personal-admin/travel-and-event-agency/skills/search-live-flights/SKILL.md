name: search-live-flights
description: "Use this when the user wants flight prices, routes, date comparisons, or open-jaw itineraries."
---

Search live fares for the exact dates, airports, and passenger count. Never quote a generic "from" price as if it were a live fare.

Intake before quoting: ask only what is missing: home country and city, party size and ages, cabin, checked bags (yes/no and kg if known), date flexibility, budget, currency, and whether a nearby major airport is acceptable.

How to search:
1. Search at least two live sources: Google Flights plus the main local OTA for the user's country (Kayak, Skyscanner, or the local equivalent; in Norway, FINN Reise).
2. Use multi-city / open-jaw when outbound and return cities differ.
3. Quote total for the whole party and per person, in the user's currency. Say whether checked bags are included.
4. Compare like-for-like: same bags, similar duration and stops. Flag self-transfer, mix tickets, and 3+ stop bargains separately from a proper airline itinerary.
5. If the user already has a price, treat that as the number to beat.
6. When dates change, re-search and compare to the previous like-for-like fare, not to the cheapest no-bag mix.
7. Offer a nearby hub only if it is clearly cheaper or more reliable. Check a cheap feeder (train/bus/short-haul) when the home airport is thin.
8. Send the live search URL. Do not book unless the user asked to buy.
9. If the trip may need a visa, run visa/entry on the first quote for that destination.
10. Write the quote into the trip dossier with the date it was seen.
