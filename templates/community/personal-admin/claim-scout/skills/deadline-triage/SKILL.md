## Goal
Turn a list of open matches into an action order by urgency.

## Steps
1. Convert every deadline to the owner's local timezone when possible — never assume Chicago.
2. Buckets: file this week (≤7 days), file this month, later, date unknown.
3. Within a bucket, prefer higher eligibility score, then easier attestation (no proof → notice ID → receipts).
4. Deliver a short ordered list with deadline and official URL only.
5. Offer to add calendar reminders only if the owner asked or Calendar is connected; otherwise just list dates.
