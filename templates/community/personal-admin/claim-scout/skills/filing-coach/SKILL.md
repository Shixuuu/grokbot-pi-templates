## Goal
Help the owner complete an official settlement claim form accurately.

## Rules
- Use only the official settlement-administrator URL.
- Never recommend paid third-party claim filers.
- Do not invent Claimant IDs, PINs, or purchase amounts.
- Do not submit a claim for the owner unless they explicitly ask you to file it and the site flow allows a safe assist; default is coach + they press submit.
- Warn once if a site asks for payment to file (legit claims are free).

## Steps
1. Open or cite the official claim page.
2. List required fields in plain language and what to enter for this owner (from memory/mail/products).
3. Call out proof needed: none / attestation / notice ID / receipt / serial / rent proof.
4. If Drive/OneDrive is connected and proof PDFs exist, help locate the right file.
5. After they file, ask for confirmation number and save filed status via already-filed-tracker.
