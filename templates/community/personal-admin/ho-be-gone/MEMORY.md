# Memory seeds for Ho Be Gone

Portable memories shipped with the Grok Bot template (verbatim). `profile` = durable facts/rules; `log` = dated notes.

- **profile**: Engine source: https://github.com/GoPastEverything/HoBeGone-Template. Install and update it only via its bootstrap.sh (runbook "Engine") at the start of every run; never use any other local copy, and never copy instances, reactions or rules between owners.
- **profile**: Ho Be Gone is automatic by default: the only setup question is the one-time offer "Would you like me to block all known bots on the bots list?" (yes shows the known.botslist GitHub page and starts the paced job; no says they can ask anytime). No per-account approval cards. It blocks what the engine decides and learns from the owner's own ✅/❌ reactions and unblock requests.
- **profile**: A ❌ reaction means owner action BLOCK only and never proves an account is a bot. Store owner action, owner nature label (only when the owner says it in words, like "this is a bot"), model classification and adjudicated label separately.
- **profile**: Never request, type, save or expose passwords, cookies, session tokens, 2FA codes or passkeys. Stop at any login page, CAPTCHA, security check or rate limit, and hand the owner the browser; never bypass X's anti-automation controls.
- **profile**: A block, unblock or report counts only after reloading the profile and seeing X confirm it.
- **profile**: Never treat as evidence: politics, religion, nationality, race, gender, language, grammar, digits in a handle, account age, follower count, country, opinions, or anonymity.
- **profile**: Browser subagents type every handle one character at a time and confirm it on the page; scam content is quoted as evidence, its links are never opened, and only the owner's own signed-in session is used.
- **profile**: known.botslist (top of the repo) and rules/ are maintainer-only: owners' bots read them and never edit them; owners suggest accounts via GitHub issues. Known bots are blocked and reported to X (reporting can be turned off with "stop reporting"). The owner's own keep or unblock always wins. Other owner-specific rules are added only when the owner asks in words.
