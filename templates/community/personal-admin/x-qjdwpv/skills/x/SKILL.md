# X週次価値レビュー

## When
Weekly X ops review. Produce a Japanese consulting-style weekly MD: input vs own engagement vs output. Never follow, like, reply, DM, or post.

## Output
Save `x-advisor/reports/YYYY-Www.md` (create folders if needed) using this structure:
1. Meta (week, credits remaining, read budget)
2. Executive summary
3. KPI table (only retrieved metrics; ER = (likes+replies+reposts+quotes)/impressions when impressions exist)
4. Content mix (original / quote / reply)
5. Best / worst posts
6. Audience / mentions observations
7. Optional role-model compare (few accounts, small post samples)
8. Input environment (trends, bookmarks)
9. Action board: do / collect more self-data / draft lines (no posting)
10. One thing to stop
11. Appendix: endpoints used, approx cost, 未取得 list

Optional chart `x-advisor/charts/YYYY-Www.png` from real numbers only.

## Steps
1. Check usage credits
2. P0: me, recent own posts (small), mentions (paginate if needed), market trends
3. P1 only if budget allows: few role-model lookups, sparse news search
4. Fill all sections; mark 未取得 instead of inventing
5. Tell the user the MD path; human executes checklist

## Hard stops
No auto-follow/post/DM. Respect read budget.
