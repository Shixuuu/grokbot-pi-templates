Use this for native-X entries only (follow / like / repost / reply). Skip Gleam, website forms, Discord, Twitch as the main entry.

Speed matters. Do not burn weekly usage on stuck loops. Accuracy beats a false “entered.”

## Session
- Signed-in X Chrome as the user's account. Never log out. Never type the username into a login form.
- ONE Chrome tab. Close extras first.
- Open each contest by its tweet URL. No profile scrolling to hunt posts. No Home-feed wandering.
- Prefer keyboard over mouse: tweet focused, not in a text field.
- Do not send status chatter. Click, then next URL.

## Keyboard
- L like
- T then Enter to repost
- R reply only if required

If the repost menu is open, click Repost immediately. Do not hover.

## Per contest (read THAT post’s rules)
Each contest has its own steps. Read the tweet text and do every required action for that post before moving on.

Typical requirements (only when the post asks):
1. Open the tweet URL.
2. If heart is already red AND repost is already green AND every required reply/quote/follow is already done, SKIP immediately.
3. Always like if not liked.
4. Follow only accounts named in the tweet.
5. Plain repost if required (T then Enter).
6. Quote repost if required — include every required hashtag and any required answer text.
7. Reply if required — required hashtags, tags, preference text, etc. Never mention Grok Bot, automation, bots, or contest-entering.
   Friend tags (critical): when the post says tag a friend, ONLY use the user’s approved friend rotation. NEVER tag the user’s own account. NEVER tag a brand or company account as a “friend.”
   Mention picker (required): type @ and SELECT each friend from X’s autocomplete dropdown so the tag becomes a real mention — do not leave bare plain-text @handles.
8. Next URL only after verification.

## Verify before “entered”
- Do not trust a Publish/click alone.
- Confirm like, plain RT when required, and that any required reply or quote is visible.
- Confirm friend tags appear as real mentions when a tag was required.
- Like+RT alone is NOT entered when a reply or quote is required.
- Report entered only after those checks pass; otherwise report incomplete/blocked.

## Stuck / idle
- If a pass is looping without new likes/RTs, STOP it.
- If a dump still has URLs and nothing is running, resume a click-only pass.
- If waiting on an orange Auto-review card, laptop offline, or login: speak up in chat immediately.
- Do not let one hard contest stall the rest. Skip it and continue other URLs.
- Ignore X right-rail “Something went wrong” if the tweet itself loaded.

## Skip
- Gleam / off-platform forms
- Crypto
- Country-only (not US or worldwide)
- Already entered (all required steps already done)

## Report
URL + entered / already / skipped / incomplete. Tally only. Never mark entered for a partial.
