# Daily growth loop

North star: meetings booked toward AI-native retainers (PE / mid-market / family office). An SMB starter pilot can be a real wedge, not the identity or the only keyword lane. Niche studio terms are valid when the Ahrefs SERP is weak.

Loop: OBSERVE → DECIDE → ACT → VERIFY → LEARN.

Load standing SEO context (NAP, ICP, competitors, GSC/GA4, Ahrefs/Bing status, what already shipped) before every observe. Do not re-ask basics. Never invent metrics. When unsure, say so.

## Observe
1. Check whether yesterday's blog PR merged and is live. If a PR is still open waiting on approval, do not write another. Ping and stop.
2. Progress, not picks: GSC and Bing Webmaster when verified. Report movement on live URLs already published. Do not invent numbers. Do not use GSC page-2 as the keyword source.
3. Ahrefs is the keyword source. Required before any write. Source low-hanging fruit: high volume + weak SERP. Record volume, KD, SERP strength, ranking URL if any, and competitor presence. Skip terms you already cover well. If Ahrefs is signed out, stop. Do not write the blog.
4. Check inbound/pilot email and booking tools. Check GitHub for open growth PRs.

## Decide
Pick one unused keyword from the Ahrefs fruit list. Prefer PE / mid-market / family-office / diligence / AI-native / fractional CTO angles. Tag impact and time-to-result. Prefer quick wins.

## Act (draft only)
1. Launch a cloud agent on the site repo to author the blog post (direct answer under H1, buyer-question H2s, money-page CTA, 3–5 internal links). No invented stats. No em dashes. Pricing and retainer CTA belong on the blog, not on social.
2. In the SAME PR, commit LinkedIn and X drafts for dedupe. Thought leadership / operator judgment only. No rate cards, no booking links, no "book a slot". Different captions. Do not post.
3. Do not merge. Hand the owner the PR link, the preview URL for the new post, both social drafts, the Ahrefs fruit numbers, and the GSC/Bing progress line.

## Verify / Learn
Dead GSC/Bing → say so; still write if Ahrefs is live. Dead Ahrefs → stop. One line for tomorrow from today's fruit plus progress.
