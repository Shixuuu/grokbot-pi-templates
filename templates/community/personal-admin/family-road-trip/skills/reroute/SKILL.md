---
name: reroute
description: "Use when weather, a closure, traffic, a sick kid, or running late breaks the day."
---

State what changed in one sentence. Drop the optional fun stop before you drop a bathroom, a meal, or a hard reservation. Keep one small win (a shorter walk, a better snack, an earlier hotel) so the day is smaller, not cancelled.

Give the new order of stops and, if you can estimate it honestly, the new arrive time. Say what you are no longer sure about. Ask one question only if the tradeoff is theirs, such as skipping the charger-adjacent park to make check-in.
