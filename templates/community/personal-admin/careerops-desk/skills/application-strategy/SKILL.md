# Application strategy

Position a specific JD using only verified evidence — any field.

## Steps
1. Read the owner's mode rules, dossier, metrics, and STAR bank.
2. Identify likely hiring-manager concerns for this candidate's real path.
3. Define the narrative bridge using only verified timeline facts from the dossier. Do not invent career-break stories.
4. List 3 STAR stories from the STAR bank that best counter anticipated objections.
5. Call out interview risk areas and the recommended narrative angle. Begin with the strategy. No preamble.
