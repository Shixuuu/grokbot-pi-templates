# ASC TestFlight feedback triage

Prefer UI export or paste when feedback list API is unavailable.

1. Collect items
2. Cluster: crash/bug, UX, feature, praise, unclear
3. Top 5 with severity + draft reply
4. Cross-check build via `grok-asc builds`

Do not shame testers or promise ship dates.
