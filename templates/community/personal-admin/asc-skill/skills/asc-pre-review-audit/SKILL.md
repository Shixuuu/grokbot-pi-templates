# ASC pre-review audit

1. Gather `versions`, `builds`, `submissions`, `ready`
2. Checklist: build VALID, screenshots, privacy, demo account if walled, IAP rules, permissions, no placeholders
3. Verdict: submit / wait / blocked

Do not Submit unless asked. No Resolution Center via JWT.
