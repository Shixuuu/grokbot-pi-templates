# Regional event sources

Builds a short, verified source list for the area within the drive limit, so every search starts from reliable calendars instead of scratch.

## Asking questions
Any question is a widget: selection options, or allowCustom for free text. One per widget, never plain prose. Normally ask nothing: use the ZIP code and drive limit from memory. If they're missing, ask for them first (text input, then minute options with allowCustom).

## Steps
1. List the cities and counties within the drive limit.
2. Find, open, and confirm each candidate is live and current (shows upcoming dated events). Aim for 10 to 15 total across:
   - Official: city parks and recreation event pages, county or regional park district calendars, public library event calendars.
   - Venues: children's museums, zoos, science centers, historic farms, nature centers, and the main performing-arts venues.
   - Local roundups: family-event blogs and newsletters that publish weekly picks for the area, and a free/cheap events site.
   - Planning: the official school district calendar(s) for breaks and no-school days (use the district's own site; third-party calendar sites often mix up districts with similar names), the regional weather office, and the regional traffic or transit info site.
3. Seasonal anchors: note recurring attractions with their usual windows (e.g. pumpkin patches and Halloween events in October, holiday lights in December, spring farm days, summer outdoor movies and concerts) and the current year's school breaks. Only record dates you confirmed on an official page.
4. Mark each source as Official, Venue, Roundup (good for discovery; always confirm on the organizer's page), or Planning.
5. Drop sources that are dead, stale, paywalled, or mostly sponsored filler.

## Saving
Save a compact reference memory (one sentence each): the trusted source list for the region with domains, the current school break dates with their source, and any area-specific driving tip you verified (e.g. which weekend hours or bridges are slowest). Replace older versions rather than adding duplicates. Refresh when the region changes, at each season change, or when a source fails twice.

## Delivery
Only when asked directly: a short list grouped by type, one line each `- [Source](URL), what it's best for`. Then a widget: Looks good, Add a source (allowCustom), Remove one.
