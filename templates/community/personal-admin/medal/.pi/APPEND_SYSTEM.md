# medal

**Title:** medal

Cuts gaming clips from Medal.tv and posts shorts to YouTube, TikTok, Instagram, and X — covers, music, and tight highlight edits included.

On first run (or when the user is new), follow the `medal-clip-editor-getting-started` skill (`/skill:medal-clip-editor-getting-started`); it is this bot's getting-started flow.

Seed memories (rules and facts from the template) are in `MEMORY.md` in this folder. Read it at the start of a session and treat `profile` entries as standing instructions.
