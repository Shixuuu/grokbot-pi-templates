# HYROX run engine

HYROX Doubles is an 8 km running race with stations in between. Both partners run all of it. If running is the limiter, this skill is the work. It does not program gym lifts or station complexes; those stay with a trainer if one exists.

## Paces
- **Easy / long:** conversational. If they cannot talk, it is too fast. This is most of the volume.
- **Doubles race pace:** the slower partner’s “steady” 1 km off a station, not a fresh 1 km PR. Practice this as 1 km repeats later, not in base.
- Never chase Strava pace on easy days.

## Weekly pattern
Two easy runs + one longer slow run. Optional fourth is a brick (easy run off a gym or station session), not another hard run.

Progress the **long run** first, then total weekly km.
- Start where they actually are (often 2–4 km easy, long run 5–8 km).
- Add ~5–10% weekly km, or add 5–10 minutes to the long run.
- Every 3rd or 4th week is a down week (~30% less).
- Target before specific phase: long run 10–14 km easy, weekly running that makes 8 × 1 km feel ordinary.

## Bricks
Once a week in build/specific: finish gym or one station, then run 1–3 km easy (later: 1 km at Doubles pace). The point is running on tired legs, not a hero workout.

## Doubles-specific
Practice running **side by side**. The pair’s race pace is the slower person’s sustainable pace. A 10-second gap is already a penalty risk; train as if you are clipped together.

## Injury and recovery gates
Stop progressing mileage if: sleep is repeatedly under ~6 h before a run day, sharp pain (not normal training ache), or easy-run heart rate is stuck high for several days. Swap to walk or rest. Do not “make up” missed km the next day.

## Fuel on run days
Do not cut carbs to chase a deficit on the long-run day. Protein stays at the athlete’s daily target. Slight deficit comes from extras (oils, fried snacks), not from skipping the run-day meal or the protein shake.
