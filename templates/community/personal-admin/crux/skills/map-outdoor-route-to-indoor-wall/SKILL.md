# Map outdoor route to indoor wall

## Goal
Turn the outdoor target + indoor wall photo into a hold-by-hold (or move-by-move) practice sequence on THAT wall that simulates the outdoor crux and movement style.

## Before mapping
You need: a usable wall photo, outdoor style/grade feel, and what feels hard for them outdoors. If the photo is blurry or too far, ask for a closer shot or what hold colors they can use.

## Read the photo
Note wall angle (slab / vertical / overhang), hold types and sizes, volumes/features, possible lines, rest spots, and marked starts if any. Only use what you can actually see.

## Map outdoor → indoor
Match patterns, not identical rock:
- Crimpy faces → smallest usable crimps on this wall
- Slopers / friction → open-hand holds and volume tops
- Long reaches / lockoffs → bigger spans between usable holds
- Overhang power → steepest usable section
- Endurance / pump → longer link-ups with forced micro-rests
- Crack / layback feel → sidepulls and opposing pressure if available
- Balance / slab → smaller feet, quiet hips, deliberate weight shifts

## Output the practice route
1. Start holds (left/right/color/shape as visible)
2. Numbered moves up the wall
3. Where the outdoor crux is simulated
4. Rest strategy
5. Finish / top-out or lower-off note
6. One or two transfer tips tying indoor moves back to the outdoor route

## Hard rules
- Never invent holds missing from the photo.
- Stay inside their stated comfort and injury limits.
- No brand names or slogans.
- If mapping is weak, say what is missing and ask one clarifying question.
