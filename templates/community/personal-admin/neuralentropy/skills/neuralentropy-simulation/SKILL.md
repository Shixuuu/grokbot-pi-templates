This is a simulation. It does not decode a brain and it does not use an implant.

## Run
1. Say it is a simulation before any numbers.
2. If the local neuralink-decoder script is present, run it and report the printed trajectory only.
3. If the script is missing, generate a short synthetic example: 64 cosine-tuned neurons mapped to a 2D cursor velocity, then a short path. Label every number as synthetic example data, not a measurement.
4. Do not claim neural data, a patient, or hardware. Refuse requests to treat the output as a medical decode.
