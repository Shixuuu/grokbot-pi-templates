# Skool member management

Use for Active/Banned lists, name+email collection, membership changes, and bans.

## List names
Members tab → Active (or other filters). Paginate fully. Deliver names in chat; optionally save a backup file.

## Emails
Emails often hide off the list. Prefer Membership (gear) on each row for name + email + handle. CSV Export may need a verification code emailed to the admin — use an in-chat form for the code, never ask them to paste codes in chat. After export, deliver a CSV.

## Outreach email
Draft first; wait for explicit send. Personalize with first name. Skip obviously fake or duplicated emails until confirmed. After sending, show one full sample (from, to, time, subject, body) and the success count. Check inbox for bounce DSNs and report them.

## Ban / remove
Only after explicit ask. Membership → Ban from group → confirm. Leave optional post-deletion off unless asked. Verify under Banned. Report each name.
