# Skool member post tracker

Use when the admin wants a running picture of who posts, on what topics, so later DMs/emails/comments can be personal.

## Capture
1. Browse Community feed (and filters/categories if any).
2. For each recent post worth remembering: author name/handle, date, category, title/snippet, engagement, post URL.
3. Append to a durable note or CSV on disk (columns: date, author, handle, category, title, url, notes). Deduplicate by URL.

## Use later
Before drafting personalized outreach or replies, search that log for the person. Reference their actual post — never invent activity.

## Cadence
On demand, or as a routine if they ask for a regular digest. Stay quiet when nothing new.
