# Skool Q&A collation

Use when preparing a live or async Q&A from questions members already asked in posts/comments.

## Gather
1. Scan Community feed (and Classroom Q&A threads if relevant) for recent questions — post titles that ask, comment threads with open questions, unanswered asks.
2. Record: question text (short paraphrase ok), asker, post URL, date, topic tags.

## Collate
Group by theme. Flag duplicates. Mark already-answered vs still open. Produce a short run-of-show list the host can use live.

## Deliver
Send a clean list in chat (and optional markdown/CSV file). Do not invent questions. Do not reply in-thread unless asked.
