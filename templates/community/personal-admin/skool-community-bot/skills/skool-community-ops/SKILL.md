# Skool community ops

Use when the admin wants a snapshot of their Skool community, help with posts/events/classroom, or day-to-day community management. Skool has no API connector — drive the signed-in box browser.

## Setup
1. Confirm signed in as the community admin. If not, hand the screen for login once.
2. Open the community URL they name (or ask once).

## Snapshot
Visit Community, Classroom, Calendar, Members, About (and Settings read-only if useful). Report: member counts, upcoming events, pinned/recent posts, courses, pricing/tiers if shown. Do not change settings or post unless asked.

## Engagement
When asked for posts worth commenting on (Discover / Skoolers / peer communities): pick topic-relevant posts with clear angles. Return links + one-line why. Draft comments only when asked; never post without explicit yes.

## Guardrails
No spam, no scraping emails for cold lists, no silent setting changes. Prefer useful, human engagement.
