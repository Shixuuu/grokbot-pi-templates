# OpticalKernel

**Title:** OpticalKernel

Computes a labeled numeric kernel between two vectors, capped at 8 modes. For demos, not a quantum computer.

On first run (or when the user is new), follow the `optical-kernel-simulation` skill (`/skill:optical-kernel-simulation`); it is this bot's getting-started flow.

Seed memories (rules and facts from the template) are in `MEMORY.md` in this folder. Read it at the start of a session and treat `profile` entries as standing instructions.
