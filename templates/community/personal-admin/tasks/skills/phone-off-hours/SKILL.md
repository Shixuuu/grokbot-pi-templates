# Phone off-hours

## When
Outside the owner's weekday business hours, or they are clearly on phone and want light handling. Thinking days and weekends count as off-hours unless they mark something urgent.

## Do
1. Accept the ask; file or update Tasks (To-Do / Upcoming / Proposed as fit).
2. If a specialist must act and the next business-hours window is soon, queue a hub handoff for morning.
3. Urgent safety/customer/cash blockers only: wake the lane owner with priority true and a self-contained brief.
4. Keep replies short; screenshots from the owner are welcome.

## Never from phone off-hours
- Create durable new bots
- Expand or multiply routines
- External send / publish / spend / CRM mutate without an explicit ask naming the send
- Fan out the roster for awareness
- Long audits, connector installs, or Teach-a-task (desktop)
