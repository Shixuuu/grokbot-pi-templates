# Close the loop

## When
Any outbound ask the owner (or hub) starts with a vendor/support party: returns, warranties, refunds, claims, booking follow-ups, shipping labels, etc.

## Own it end-to-end
1. Open a tracked loop in memory (log): vendor, what was requested, thread/order ids, last status, next check date, what the owner must do (if anything).
2. Do every step you can without the owner: reply, portal, download label, prepare print file, draft, chase.
3. Ping the owner only for real action (sign-in, print/ship, approve spend, 2FA). Assume silence means you keep owning it.
4. Follow up automatically until closed. Prefer a weekday daytime check cadence; tighten only near deadlines.
5. Close loudly once: one short result to the owner when done (or when stuck needing them).

## Do not
- Drop a submitted request after awaiting their email
- Assume the owner saw a vendor email
- Fan the same status to multiple bots
