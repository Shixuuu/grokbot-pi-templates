# Store pickup email handoff

After BOPIS/order: record order, priority-message email_watch_bot with details, tell user they'll get ready + picked-up pings. Home bot may one-shot check inbox if waiting now; ongoing watch is the email bot's job. Setup must set email_watch_bot.
