# Store checkout setup

Route egress via user's desktop for retailer bot detection. Stripe Link: one-time card, user approves on phone, bot types into merchant never chat. Cookie import often missing — manual sign-in handoff. Fix Access Denied / card form fail with egress + Update Computer. Ask pickup vs delivery once. No addresses/passwords in templates.
