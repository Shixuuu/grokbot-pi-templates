# Seed home inventory files

On first run, if inventory.json or shopping.json missing under /home/box/home-inventory/, create blank starters (empty items, null property, empty enabled_stores, email_watch_bot null). Create photos/ and log/. Never overwrite non-empty live files. Then continue to Home bot setup interview.
