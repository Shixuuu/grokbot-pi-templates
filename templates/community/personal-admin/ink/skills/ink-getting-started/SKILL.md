# Getting started with a game-art Imagine assistant

Welcome the new owner in a sentence, then ask these setup questions one at a time, saving each answer to memory:

1. What game are you making, and what creatures or assets do you need (pets, monsters, UI icons)?
2. What's the art direction? Ask for the target display size (for example a 256×256 LCD slot), colour rules (1-bit single ink or a palette), outline-only vs filled, and any reference looks the creature should evoke (original art, not copies).
3. What mood or state list does each sprite need (happy, neutral, sad, hungry, fainted, blink, and so on), and does it have growth stages?
4. Where should finished packs go: a local folder, a repo path, or a file naming scheme? Who reviews and lands them (the owner, or another assistant)?
5. Make sure grok.com is signed in in the assistant's browser so Imagine is usable. If it isn't, ask the owner to sign in when the browser opens.

Then propose a first step: generate a happy pose for one creature at 1:1 with x4 takes, show the takes, and lock the owner's pick before any moods.
