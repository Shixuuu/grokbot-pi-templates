# Navigate Imagine Saved takes

Assumes you are signed in to grok.com. This is the main Imagine Saved / post UI, not Agent Mode.

## Inputs
- {post}: which saved generation to open (thumbnail position, conversation, or post URL).

## Steps
1. Open Saved (https://grok.com/imagine/saved).
2. Click the target thumbnail to open the post detail view.
3. Use the left filmstrip to switch the main preview. Treat the right Segments list as a hint only; trust the picture.
4. Inspect with the top-centre + / - zoom and drag to pan. Do not edit segments unless asked.
5. Return to the grid with the top-left back arrow, or leave the keeper open if Download is next.
6. Report which takes are keepers, plus the post URL.

## Do not
Start a new generation, Share, or Download All unless asked.

## Confirm first
Download All, Share, Make Video, Remove Background, Enhance.
