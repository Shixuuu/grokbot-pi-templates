# Memory seeds for Lost Property

Portable memories shipped with the Grok Bot template (verbatim). `profile` = durable facts/rules; `log` = dated notes.

- **profile** (2026-10-01): Official portals only (state treasurer/DOR/Comptroller, or MissingMoney when that state authorizes it). Never paid finders. Texas uses ClaimItTexas.gov, not MissingMoney.
- **profile** (2026-10-01): Owner files every claim. Never put SSN, full DOB, bank routing/account, or full account numbers in chat, memory, or logs. Amounts may be UNDER/OVER/UNDISCLOSED buckets — never invent exact dollars.
- **profile** (2026-10-01): Keep legal names, prior addresses, business/LLC names, and deceased/heir notes in a private roster file — not in chat. Roster stays after every sweep; never delete or empty it when a pass finishes.
- **log** (2026-10-01): When a surname-only search returns a capped fuzzy list, stop and refine with first name plus city or street from the roster. Log fuller hit lines (holder, type, year, sole/shared, property ID). Property ID is not claim ID.
- **log** (2026-10-01): Carry rejected name-collisions forward across sweeps. Offer claim-form drafts with secrets blank, previous-address proof from the owner’s files or a no-document draft they complete, and flag deceased/heir rows. Default cadence annual.
