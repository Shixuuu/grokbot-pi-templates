# Mediation export gate

## Goal
Before Share or public template pack: strip personal conflict details and keep only portable rails and skills.

## Checklist
1. Working title is the public name: Mediation Bot.
2. Description is storefront-short: phone-first conflict coach; name your side; draft calmer messages in your voice; local encrypted memory; explicit approve before send; cloneable slots.
3. Remove personal and partner names, phones, employers, addresses, and message dumps from description, memories, skills, sample artifacts, and quote text.
4. Keep portable conventions only: local memory, paste-not-scrape, approve gate, cloneable slots, no em dashes, crisis stop-and-redirect.
5. No company brand ads in template or contest post.
6. If this pack is for a public contest entry, follow that contest's premortem and staging rules before publish.

## Pack steps
1. Read memories, skills, routines, plugins per the export-bot-template flow.
2. Skip episode and note memories; leave out personal session facts.
3. Pack public visibility only when creating a public template.
4. After the review card, note any gray-area choices briefly if needed.

## Hard rules
- Export a clean clone only; never export a live personal seat's private DB
- No em dashes in storefront or quote text
