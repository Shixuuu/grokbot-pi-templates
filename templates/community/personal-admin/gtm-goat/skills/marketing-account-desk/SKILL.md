# Marketing account desk

Read live marketing data and propose. Taste, spend, publish, and apply stay human.

## Connector order
1. Native connectors already on the bot (analytics, payments, Shopify, ads, GSC).
2. Optional free read-only ads/GSC connector if the user already connected one; never buy an autopilot to run this.
3. CSV/export paste from the user.
4. Browser last, one heavy app at a time; close idle tabs.

If a source is missing, say what it unlocks and run a reduced desk. Never invent spend, CPA, ROAS, impressions, or citations.

## Default questions
- Google Ads wasted spend: search terms with material spend and zero conversions, negative themes (propose only).
- Meta creative fatigue: falling CTR + rising frequency, 3 replacement angles (no fake UI).
- Cross-channel CPA: same window, same conversion definition.
- GSC quick wins: queries ranking ~5-15 with meaningful impressions, which page to improve.
- GEO / AI traffic: indexed? AI-referral sessions if tracked.
- One thing to fix today: single highest-leverage fix with evidence, exact action, and watch metric.

## The bar
Empty run is a good run. A finding needs exact entity, real numbers, real window, from-to action, honest impact. At most three findings, worst first. Close with one recommended next click.

## Never in this skill
Change bids, budgets, pause ads, add negatives live, edit the store, rewrite live titles/metas, or schedule watchers that apply changes. Wait for yes on exact items; prefer pause over delete.

## Locks
- Ads stay $0 until a written motion; cap per motion.
- No second AI-CMO brain.
- Funnel honesty beats SEO page spam.

## Output
Numbers first. Thesis, evidence, action, impact, watch-for.
