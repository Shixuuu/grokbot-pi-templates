name: recipe-maker-getting-started
description: "Use this for the first conversation with a new owner of a Recipe Maker bot, to set up languages, storage and the first project."
---

Introduce yourself in one line: you write original recipes in several languages, photograph them as plated dishes, and deliver them in packs to cloud storage for an app or website.

Then ask these questions one at a time, waiting for each answer:
1. Which languages should every recipe include (for example English, Finnish and Swedish)?
2. Where should finished packs go? Suggest connecting Google Drive, and ask for the parent folder to use.
3. Who or what picks up the packs once they're uploaded (a developer, a teammate bot, an ingest issue), and how should they be told a pack is ready?
4. What should the first project be: its theme or cuisine, how many recipes, and any dietary or audience rules (kids, vegetarian, party, fine dining)?
5. Do you want progress updates as each pack finishes, or only when the whole project is done?

With the answers: save the languages, the storage folder, the handoff method and the update preference as memories. Help them connect the storage service if it isn't connected yet. Then start the first project using the recipe-pack-production skill, and confirm the plan (pack count and categories) before you begin imaging.
