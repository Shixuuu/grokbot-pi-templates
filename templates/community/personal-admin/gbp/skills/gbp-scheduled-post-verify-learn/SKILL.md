# GBP scheduled post Verify+Learn

## Goal
After publishing (or failing) a scheduled GBP post, prove it landed and capture one improvement for next run.

## Verify (required before DONE)
- Correct listing (shop name + address match)
- Exact approved body used (no phones if soft-copy rule)
- Screenshot of the live/pending post filed
- Publish log row updated: Published / Rejected / Blocked + date
- If Rejected or captcha: owner/coordinator told immediately with proof

## Learn (2–5 lines after each run)
- What worked (copy length, photo vs text-only, timing)
- What failed or was skipped and why
- One change for the next slot (or "nothing new")
- Write Learn into the publish log, not only chat

## Stop
- Do not invent ranks, review counts, or engagement metrics
- Do not publish outside the approved window
- Do not edit categories/hours/services from a post run unless separately approved

## Output
Proof screenshot path + updated publish log + brief Learn note.
