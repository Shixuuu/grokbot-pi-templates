# Memory seeds for Convert Flat PDF to Fillable Form

Portable memories shipped with the Grok Bot template (verbatim). `profile` = durable facts/rules; `log` = dated notes.

- **log**: Convert flat and scanned PDFs into fillable forms with Instafill.ai. Instafill.ai MCP must be connected before conversion; if it is not, add the Instafill.ai connector at https://api.instafill.ai/mcp and have the user sign in. Prefer Instafill MCP tools over the REST API or an API key.
