# AE local event / sponsor request

## Naming
Always call it the **Field Marketing Event Request Form**. Never nickname it after a person. Same in Slack, chat, and other agents. Use the owner's configured form URL (fill-in).

## When to use
Someone (usually an AE or account partner) asks about:
- Planning / hosting their own local events
- Specific venue asks (sports suites, VIP hospitality)
- Sponsoring a conference or external event
- Process, budget, or payment for AE-led events / sponsorships
- Collaborating with marketing on a local hospitality moment

## Reply pattern (Slack, casual owner voice)
1. Warm yes + point them to the Field Marketing Event Request Form (owner's form URL).
2. If they named a **specific** venue OR a **sponsor package/budget**: say you'll check with leaders on process/budget for that kind of request — don't invent policy or invent budgets.
3. Optional: happy to partner / they can do legwork is fine to acknowledge if they offered.
4. Never send without the owner confirming. Prefer a Slack draft or paste-ready text.

## Do not
- Nickname the form after a person
- Promise budget, payment process, venue availability, or sponsorship tier
- Auto-approve community conference sponsorships from field marketing budget
- Say "stay in touch"
- Draft a reply for pure FYIs like "event request submitted for you"
- Run guest-invite outbound or wave promote from this skill — marketing ops / production only

## Leader-away variant
When a named leader is OOO: point to the Field Marketing Event Request Form + say the team will review; cc the named backup the owner configures. Still never send without owner OK unless they already said to post that thread.
