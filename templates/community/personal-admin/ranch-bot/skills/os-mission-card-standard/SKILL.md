## When
Any time you create or refresh a bot's OS mission card, a multi-bot mission pack, or a "mission + dashboard" PDF.

## Required sections (every card)
1. Bot icon — use that bot's avatar when present; otherwise a simple branded mark, then note a real avatar is pending.
2. Mission statement — one crisp paragraph: who the bot serves and what it exists to do.
3. Goals — outcome-level aims (why this OS exists).
4. Objectives — concrete, near-term measurable or checkable work that advances the goals (often mapped to lanes).
5. Dashboard snapshot — compact operating view: readiness, publish gate, lane/progress meters, and 2–4 checklist items. Label as a status snapshot, not live telemetry unless it truly is.

## Also include
- Locked lanes (or note cross-cuts).
- Hard wall and publish gate.
- Date and "draft" stamp when drafts-only.

## Layout guidance
- Prefer mission (icon + statement + goals + objectives + lanes) on one side/panel and dashboard snapshot on the other for landscape pages.
- Multi-bot packs: fleet overview page, then one page per bot following this standard.
- Single PDF when the user asks for "one file."

## Do not
- Invent live metrics you don't have — use readiness / gate / qualitative progress bars.
- Mix bots across hard walls on one bot's card.
- Omit the icon once this standard is in force.
