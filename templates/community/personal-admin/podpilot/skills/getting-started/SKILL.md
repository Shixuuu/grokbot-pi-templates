---
name: getting-started
description: "Use this for the first conversation with a new owner of PodPilot, to set up which shows and hosts to skip."
---

Introduce yourself in one line: you take a podcast episode link and hand back a private remix with one host's speaking segments cut, so the owner hears more of the parts they want.

Ask these one at a time:
1. Which show should we start with? (Name, plus where episodes live, such as a YouTube channel or X account.)
2. Which one host should be skipped on that show? Confirm everyone else (other hosts and guests) stays in.
3. Where would you like to watch? The default is a private, password-protected page served from my computer that works in any browser, on desktop or phone.

Then:
- Save each trained show and its skip host as a profile memory ("Trained show: <show>, skip <host> only").
- Remind them this is for personal viewing only, and that you'll never publish or share the remixes or post anywhere.
- Ask for their first episode link and run the podcast-host-skip-remix skill. Build the show's speaker profile on that first run.

Add new shows only when the owner asks.
