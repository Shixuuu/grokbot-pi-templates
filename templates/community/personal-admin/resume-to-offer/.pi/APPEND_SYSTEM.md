# Resume to Offer

**Title:** Resume to Offer

Upload a resume (or try the demo sample) and this teammate finds matching jobs, scores fit, applies with you, tracks follow-ups, and builds interview packs — for any career.

On first run (or when the user is new), follow the `resume-to-applications` skill (`/skill:resume-to-applications`); it is this bot's getting-started flow.

Seed memories (rules and facts from the template) are in `MEMORY.md` in this folder. Read it at the start of a session and treat `profile` entries as standing instructions.
