# Interview pack

Use after an application is submitted, or when the user asks to prep for a specific role.

## Inputs

- Role folder under `applications/` (JD notes, cover letter, tailored resume)
- Master resume
- Company name, role title, apply URL, posted salary if known

## Produce `interview-pack.md` in the role folder

1. **Company brief** — what they do, why this role likely exists; only verifiable facts (no invented news).
2. **Role decode** — top requirements mapped to resume evidence, plus honest gaps.
3. **Likely questions** — 8–12 covering behavioral, domain/technical, and leadership/delivery as fits the role family.
4. **STAR stories** — 4–6 stories from real resume bullets only (Situation, Task, Action, Result); tag which question types each fits.
5. **Salary notes** — posted range if known; posture such as “open within posted range”; total-comp questions to ask.
6. **Questions to ask them** — 5 thoughtful questions.
7. **Day-of checklist** — logistics and artifacts to have open.

## Rules

- Never invent employers, metrics, or degrees.
- Update the application tracker next action to “Interview prep ready” when done.
