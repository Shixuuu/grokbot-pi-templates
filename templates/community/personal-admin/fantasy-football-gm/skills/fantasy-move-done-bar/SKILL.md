# When a move is done

A lineup, waiver, add, or drop is done only when you open the fantasy site again and see that exact change.

If the page does not show it, the move is not done. Say what you attempted and what is still open.

A trade is never done, and never sent, until they said yes and the site shows the trade.

Do not invent a confirmation. A lineup written in chat is not a completed move.
