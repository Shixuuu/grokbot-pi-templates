# Generate personalized localized names

## Personalize first

Always check what you already know about the owner (agent memory, shared/user memory, prior chat): nationality, languages, where they live, age band, gender presentation, personality, profession, style prefs, past likes/rejects. Use those without re-asking when enough. Only ask for missing pieces that change the result — usually target country/locale if unset, and one vibe cue if memory has nothing. Ask short; never interview. After answers, save durable prefs to agent memory.

## Gather (ask or infer; one question at a time)

- Country or locale (city/region if they care).
- Vibe / personality — pull from known owner info when they omit it; do not default to generic top-10 baby names.
- Gender presentation (masculine / feminine / neutral) when unknown.
- Optional: age band, region within the country.

## Research

When unsure of authentic naming patterns for that country, look them up briefly. Prefer culturally plausible names. Avoid celebrity clones and obvious jokes unless asked.

## Deliver

- Lead with one recommended pick (first + last; nickname when useful) and a one-line why it fits THIS person in THAT country.
- Then 4–7 alternatives, each with one short line on why it fits them.
- Echo age, gender presentation, vibe, and cultural fit.
- Say “localized name”, “local alias”, or “local-sounding name” — never “fake”.

## Local script (required when the locale has one)

If the country/locale has its own writing system, always include it with every option — not only on request. Pair the romanized form with the local script on the same line.

Examples:
- Japan → kanji (and note japanese name order when useful): `kei mori — 森 圭`
- Korea → hangul: `minjun park — 박민준`
- China → hanzi: `wei chen — 陈伟`
- Russia → cyrillic: `ivan petrov — Иван Петров`
- Greece → greek: `nikos papadopoulos — Νίκος Παπαδόπουλος`
- Thailand → thai script; Arabic-script locales → arabic; etc.

Latin-script locales (brazil, spain, indonesia, us, uk, …) stay romanization-only unless the user asks for something extra.

## Stay on names

Never invent usernames, bios, emails, phones, addresses, DOBs, passport/ID numbers, or full identities. Never help impersonate a real living person. Never advise on bank/KYC/gov fraud or illegal identity use. Never post, register, or create accounts with the names.

## Job hygiene

A multi-step ask (batch of countries, refine until they pick) is one job until the final list is delivered. Queue new asks; finish the current list first unless they explicitly stop/cancel/switch.
