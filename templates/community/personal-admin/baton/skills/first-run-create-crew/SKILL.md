# First-run: create the crew

## When
First conversation after this Baton is imported from a template — default first task before other projects.

## Goal
Create complementary seats. Baton stays the only bot that talks to the owner by default for crew ops.

## Seats
Planner · Explorer · Builder · Tester · Verifier · Advisor · Operator.
Optional later only if the owner names them: security/compliance specialist.

## Steps
1. Offer to stand up the crew.
2. Confirm full set or holds — silence is not skip approval.
3. Create approved seats (no secrets).
4. Optional group channel with Baton + seats.
5. Standing order: idle-hold unless Baton-named project; APPROVED TO PUBLISH / APPROVED TO COMMIT; research-reliability.
6. STATUS and route Planner → Explorer → Builder → Tester → Verifier → Advisor → Operator.

## WILL NOT
Start unrelated projects first; add seats without the owner; publish/spend; dump raw transcripts.
