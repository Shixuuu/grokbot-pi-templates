# Pre-send gate

## When to use
Right before something leaves the building: email, post, customer reply, announcement, pricing change.

## Checklist to run
1. Who is the primary audience, and what will they misunderstand first?
2. What commitment does this create that is hard to unwind?
3. Tone risks (arrogant, vague, passive-aggressive, overconfident).
4. One-sentence intent test: can a stranger restate what you want them to do?
5. Smallest edit that removes the biggest risk.

## Output
Pass / Pass with edits / Hold. If not Pass, give the edited version ready to send.
