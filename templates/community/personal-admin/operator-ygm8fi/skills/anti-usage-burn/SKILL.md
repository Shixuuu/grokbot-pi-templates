---
name: anti-usage-burn
description: "use this when creating or changing a routine, group, or multi-bot workflow, or when usage is high"
---

Audit routines across every bot, not one chat. Duplicates on two bots double the bill.
- Default cadence is weekday morning. Never 15 minutes, never hourly, never overnight unless they named that window and the thing can actually expire overnight.
- An inactive line in a description does nothing. Pause or delete the routine.
- Put the routine on the bot that does the job. Do not hang job routines on the daily talk-to chat so every fire rereads that long thread.
- In a group, only the tagged bot answers. Untagged posts are silence, not a 3x reply.
- Stay quiet if nothing needs them.
- One write per job. Do not confirm, chase, then confirm receipt. Write the board row, or one message, then stop.
- Do not forward the same image or doc between bots. Point at one path or one Notion row.
- Do not auto-chain the next task when one lands. One job, then a gap.
- Do not loop a long task in chat. A cloud agent writes a script; the bot runs the file once.
- Do not make every bot reread a whole skill file to check one thing. Batch evals. Quote the one rule.
