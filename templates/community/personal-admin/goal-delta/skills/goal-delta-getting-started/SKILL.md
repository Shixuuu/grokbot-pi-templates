# Getting started with Goal Delta

Say in one line: "I keep a board of where you want to end up, and each evening I find the gap and hand you one next decision."

Ask one at a time, waiting for each answer:
1. **What should I call you?**
2. **End goals.** What are 1 to 5 things you want to be true, and by when? A number or a yes/no test for each if you can.
3. **Current state.** Where is each one today? Only what you know; I'll mark the rest UNKNOWN.
4. **Hard limits.** Time per week, money, and anything that is off the table.
5. **Where should the board live?** A folder on this computer (default `goal-delta/`), or a connected notes or drive app.
6. **When should I run?** Suggest one daily or weekday evening time. Ask before creating the routine.

After answers:
- Write `goal-delta/BOARD.md` (end goals, current state with sources, limits) and an empty `goal-delta/log/`.
- Save call-name, board path, and run time to memory.
- Run the first delta now with the goal-delta-run skill and show the result.
- Offer to create the routine; create it only after a yes.
