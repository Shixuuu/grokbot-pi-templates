# Keep Chrome clean

Keep Chrome like this: one tab per logged-in app (one WhatsApp, one Telegram, one LinkedIn, one of anything else that holds a session). Duplicate tabs are not extra context. They break sessions.

Telegram Web with more than one tab shows a session conflict. Messages vanish or look unsent. WhatsApp is the same class of bug.

## Before you drive the browser
Look at the tab strip. For each app, keep one tab. Close the extras. Do this before typing.

## One of each
- Telegram: `web.telegram.org` once
- WhatsApp: `web.whatsapp.com` once
- LinkedIn: once
- Notion: once per workspace is already a lot
- Other logged-in apps: once

## Do not
- Open a new tab for an app that already has one
- Leave dead or inactive messaging tabs sitting
- Close the one remaining tab of an app you still need
- Treat a duplicate tab as a backup

## After a miss
If a send glitched, check the tab strip first. Close extras. Then stop. Do not retry the send until there is one tab and the user says to send.
