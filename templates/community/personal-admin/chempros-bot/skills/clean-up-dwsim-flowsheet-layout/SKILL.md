# Clean up DWSIM flowsheet layout

Maximize DWSIM; keep desktop taskbar visible; never F11. Material streams horizontal; energy streams vertical. Do not change specs/PP. Do not overwrite a saved .dwxmz without approval — Save As presentable copy.

1. Place unit ops; material on horizontal runs; energy on vertical stubs.
2. Rotate via Appearance so ports face flow (energy typically 90 or 270 deg).
3. Untangle connectors orthogonal; align clusters with toolbar.
4. Re-Solve after reconnecting energy; Save As presentable name.

Done when layout is readable, material horizontal / energy vertical, case still solves, saved under agreed name.
