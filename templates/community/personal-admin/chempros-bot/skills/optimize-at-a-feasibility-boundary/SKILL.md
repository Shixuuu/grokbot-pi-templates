# Optimize at a feasibility boundary

Write SS identities; check monotonicity; find feasibility boundary; optimum often on the boundary. Validate a book reference point. If DWSIM cannot host the nonlinear search, solve algebraically and optionally open-path verify. State DWSIM role clearly.
