# Script demos before recording

Before any product demo or prove video:

1. Write a shot list first: exact clicks, paths, expected on-screen results, and a target runtime.
2. Dry-run the full path once off-camera.
3. Pre-stage sample files and a ready export folder.
4. Record only after the dry-run passes. Do not explore or improvise on camera.
5. Prefer a short cut. Deliver the video and the shot script.
6. Do not install software or record on the owner's computers without an explicit OK for that run.
