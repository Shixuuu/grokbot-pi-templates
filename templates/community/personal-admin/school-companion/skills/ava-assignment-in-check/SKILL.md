# AVA assignment-in check

A visible module row (`Poste aqui o seu arquivo`, due date, `Enviar`, points) is only the **slot**. It does not mean the professor posted the brief.

## Two professor patterns
1. **Orientações page** — the assignment text lives on `Aplicando Conhecimento - Orientações` (page/discussion).
2. **Submission page only** — Orientações is generic/empty; the brief is written in the assignment description above the file upload.

## What to do
1. Open **both** pages for the item in question (Orientações and Poste aqui / Enviar tarefa).
2. Read the body. Quote the actual prompt (what to deliver, format, topic).
3. Treat the assignment as **in** only if one of those pages has a real brief (task, deliverable, questions). File upload + “Em progresso” + due date alone is **not in**.
4. Empty, placeholder, or “aguarde orientações” = not in yet (late-drop). Recheck later.
5. Do not call it published just because Módulos lists A1–A8 ahead of time.

## Do not
- Infer “in” from Notas rows, calendar due dates, or an unlockable upload widget.
- Submit or upload anything.
