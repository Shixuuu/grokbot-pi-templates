# 参与小红书抽奖帖

## 目标
搜索可参与的抽奖帖，在活动仍有效期间**快速**完成四连，并把足迹写入 Notion。单帖目标：看清要求后尽快关/赞/藏/评，避免反复试探和冗长截图循环。

## 搜索
1. 打开小红书（优先 App；没有 App 再用网页版）。
2. 从「发现」页搜索精确关键词 `抽奖`。
3. 留在默认的「全部」结果里，滑动浏览封面和标题。

## 筛选（放宽）
- **放宽原则**：凡是可以抽奖、且仍在活动期限内的帖子，都可以参与（不限实物/虚拟、不限是否品牌号）。
- **硬条件只有**：像抽奖活动 + 当前时间尚未开奖/未截止。
- **仍直接跳过**：明显诈骗或危险要求（要加微信引流、交押金/先付款、索要验证码或过多隐私且非中奖后必要收件信息等）。
- **查重不用 Notion**：若打开帖子后发现已关注且红心/收藏已亮、自己评论已在，视为已参与，跳过并可选记一条足迹；不要为了查重去翻 Notion。
- 奖品类型、账号体量、评论区热闹程度不再作为否决条件。

## 提速原则
- 单帖只做必要动作：读时间 → 读参与方式 → 扫置顶 → 四连 → 验灯一次 → 记要点走人。
- 少滚动、少重复打开同一控件；坐标点错最多纠正一次。
- 不要在无关图片灯箱、相关推荐卡上浪费时间。
- 中途进度少报；一批做完再汇总。

## 参与方式（顺序很重要）
打开候选帖后，按下面做。

1. **读取活动时间**：看开奖/截止时间。若当前时间已过开奖或活动已结束，跳过。
2. **阅读帖子「参与方式」**：确认是否要求说特定内容、是否要求晒图、是否要求 @ 某人。
   - 指定短评内容或**明确要求**评论 @ 某人：按要求做。
   - 必须晒图、填表付款、或其他当时无法完成的动作：跳过并记下原因（除非用户明确批准该帖）。
3. **查看置顶评论**：只用来发现额外规则（截止时间、补充要求等）。置顶出现 `@我们爱抽奖` 只表示可能使用抽奖组件，**不等于要在评论里 @ 它**；除非参与方式或置顶明确写「评论请 @我们爱抽奖 / @xxx」，否则评论里不要带这个 @。
4. **执行四连**（通过时间与可执行性检查后），尽量一气呵成：
   - 若尚未关注该博主，则关注；
   - 点赞（❤️/👍）；
   - 收藏（⭐）；
   - 发一条**简短**、正向、和品牌/活动相关的评论（一句话；不要复制粘贴垃圾模板；仅当规则明确要求话术或 @ 时才加上）。
   - **验灯一次**：已关注、红心已亮、橙星已亮、评论可见。未生效则谨慎重试一次，仍失败则记录，不要假装完成。

5. 只做规则要求的事；除非用户明确批准该帖，否则不要填表、付款或发送个人隐私信息。

## 记录足迹（Notion）
每处理完一条帖子（已参与或已跳过/失败），立刻写入导入者自建的 Notion 数据库「小红书抽奖足迹」（**仅记账，不用于事前查重**）。
字段建议：
- `标题`：简写「博主 · 奖品」或帖子标题
- `博主`
- `参与时间`：用户本地时区的实际操作时间
- `奖品`
- `帖子链接`
- `开奖时间`：若帖内可见则填写
- `四连验过`：关/赞/藏/评均确认生效则为是
- `状态`：`已参与` / `已跳过` / `失败`
- `跳过原因`：跳过或失败时填写
- `评论`：实际发出的评论文案（若有）

## 风控红线
- 遇平台「异常浏览/机器行为」警告或封禁说明：立即停止本轮与一切自动抽奖，等用户明确允许后再继续。
- 公开使用时保持低量、偏人工节奏；优先 App，避免高频网页连点。

## 停止条件
- 登录 / 验证码 / 二次验证：交给用户处理。
- 已开奖、无法完成的强制要求、或危险诈骗帖：跳过并记下原因（同时写足迹）。
- 参与完若干帖子后，用短表汇报：标题、博主、奖品、链接、四连是否验过、Notion 是否已写、跳过原因。
