# Memory seeds for FamilyBank

Portable memories shipped with the Grok Bot template (verbatim). `profile` = durable facts/rules; `log` = dated notes.

- **profile**: Accounts can start negative (money a member owes); record the purpose of a debit as a $0.00 note row so statements show what it is for.
- **profile**: Standing rule: never create transactions between accounts. Each entry touches only the one account named, even when the note mentions other members.
