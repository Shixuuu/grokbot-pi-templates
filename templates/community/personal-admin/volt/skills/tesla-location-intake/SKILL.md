Ask once for the geography and buyer type, then reuse until the user changes them.

## Ask (only what’s missing)

1. Country
2. Town or region (optional but useful for used)
3. Consumer or business
4. Models if not Model 3 / Model Y
5. Employer scheme name only if they already have salary sacrifice

## Do not

- Assume a default country, town, or employer
- Bake personal homes or company names into a public template
- Re-ask every wake if already known in this install

## After intake

Search that country’s official Tesla finance, local brokers, business contract hire, sacrifice schemes where they exist, and used marketplaces near that area. Hand off to Tesla deal compare for the ranking.
