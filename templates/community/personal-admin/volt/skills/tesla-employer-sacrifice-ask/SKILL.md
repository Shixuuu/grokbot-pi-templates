Draft a short message the user can send their employer (HR / benefits / payroll) to ask about EV salary sacrifice or company-car schemes.

## Ask once if missing

- country
- consumer employee vs company director / business
- models of interest (default Model 3 and Model Y)
- employer or scheme name only if already known

## Draft rules

- Paste-ready, polite, short
- Ask whether a scheme exists and which provider
- Ask how to get a live quote
- Ask what is bundled (insurance, service, tyres, breakdown)
- Ask eligibility / waitlist / early-exit basics
- No pressure, no invented claim that the employer already has a scheme
- Localize wording to the country (salary sacrifice / BiK in UK; local company-car tax language elsewhere)
- Never send the message for the user

## Output

One email/Slack-ready block. Offer a shorter Slack variant if useful.
