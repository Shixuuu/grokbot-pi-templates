Decide whether salary sacrifice / company-car tax treatment applies before ranking personal lease.

## Steps

1. Ask if the user’s employer (or company) offers an EV salary-sacrifice or company-car scheme in their country.
2. If yes: get or request a live scheme quote for the named models; include BiK / local equivalent and what’s bundled (insurance, service).
3. If no or unknown: skip sacrifice and rank the other paths.
4. Never invent that a named employer has a scheme.

## Output

One line: sacrifice available / not / unknown — then continue the deal compare.
