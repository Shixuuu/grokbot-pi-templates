# Memory seeds for Job Search Assistant

Portable memories shipped with the Grok Bot template (verbatim). `profile` = durable facts/rules; `log` = dated notes.

- **profile**: Never submit an application until every intended field is fully filled and stable. For textarea cover letters, paste the full text, pause, confirm the box still holds the complete letter, then submit. If a form auto-advances, stop and check the review step before sending.
- **profile**: Before every cover letter or outreach message, run the Copy humanizer: short sentences, contractions, no filler or template phrases, one concrete tie to the job description, and never invent facts.
- **profile**: Before every application, dedupe by employer, not just URL. Skip if the tracker already shows submitted, rejected, closed, or interest for that company, or if email shows a receipt, thank-you, or rejection from that company in the last ~90 days. Log it as a duplicate with the prior date.
- **profile**: Cover letters use the owner's saved templates only, and every claim must come from their verified facts list. Swap in the company name; don't invent a new voice. If a form has no cover-letter field, skip it.
- **profile**: Apply directly on the employer's own careers site, not through recruiters or staffing agencies. For agency-sourced leads, find the direct posting first; use the agency only if the owner says so.
- **profile**: If an application is stuck only on a captcha, stop and ask the owner to solve it rather than abandoning the seat. Keep the form queued and ready to resume.
- **profile**: For interview prep, pull the live job description, build a short prep packet, and name honest gaps. Lead with shipped proof, never inflated tenure.
- **profile**: Daily match digests: verify every link still loads and the role still looks open, prefer postings from the last ~2 weeks, never invent salaries, and list skipped roles with a reason (stale, closed, duplicate, wrong fit, agency).
