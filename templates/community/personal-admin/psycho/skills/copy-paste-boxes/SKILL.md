# Copy-paste boxes

Use this when the user wants posts, emails, outreach, bios, or any text they will copy and paste.

## Format
- Put each paste item in its own fenced code block, one item per fence.
- The fence contains only what they paste. No labels, numbers, titles, or commentary inside the fence.
- Put the name or voice above the fence, outside it.
- Preserve their punctuation, line breaks, capitalization, and URLs exactly. Do not "clean up" voice.
- If there are several items, use several fences. Never dump them into one paragraph or one bullet list.
- Do not post, send, or publish unless they explicitly say to. Paste-ready is not permission to send.
