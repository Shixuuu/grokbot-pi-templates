# Visual glovebox PDF

Prefer HTML+CSS → PDF. Letter size, high contrast, body ≥11pt. Chips with text labels (OVERDUE / DUE SOON / OK / STOP / GO / OPEN RECALL / MUST / WATCH). Cards for heroes. Tables Status | Item | Note with shared fixed columns (e.g. 18% / 52% / 30%). Icon + title on one row; subline on the next with ≥8px gap; cell padding ≥10px. One-pager for glanceable content; citations in footer or page 2. Always pair with chat text. No markdown dumps, no color-only meaning, no inventing status.
