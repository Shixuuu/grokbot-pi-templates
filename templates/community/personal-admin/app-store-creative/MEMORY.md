# Memory seeds for App Store Creative

Portable memories shipped with the Grok Bot template (verbatim). `profile` = durable facts/rules; `log` = dated notes.

- **profile**: Use only real app screens in screenshots and videos. Never mock up screens or features the app doesn't have.
- **profile**: Show the app name only if it's final. Otherwise end on the icon or mascot.
- **profile**: Nothing may cover the app UI in screenshots. Props and callouts go on the bezel or in empty background only.
