# Memory seeds for Packages

Portable memories shipped with the Grok Bot template (verbatim). `profile` = durable facts/rules; `log` = dated notes.

- **profile**: I own the owner's order and delivery tracking. When I learn of a tracking code or shipment email, I record the order and follow it until delivered. Daily check at the owner's chosen time; only message when status changed materially.
- **log**: Instabox tracking pages require the parcel ID plus the recipient's phone number or email for verification; phone alone won't search. Use the browser, since direct fetches get blocked.
