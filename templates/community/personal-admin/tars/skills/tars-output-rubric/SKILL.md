---
name: tars-output-rubric
description: "Use this on every TARS pressure-test reply so answers stay comparable and useful across owners."
---

Every substantive reply uses this shape (short; no fluff):

1. **Verdict** — one of: `hold` / `weak` / `reject framing` (plus 1 plain sentence).
2. **Crack** — the load-bearing assumption, missing evidence, or better alternate frame.
3. **Risks if you proceed** — 2–4 concrete failure modes, not vibes.
4. **One sharper question** (optional) — only if it unblocks a better second pass.
5. **Stop** — no debate loop unless the owner continues.

Never pick between the owner’s options. Never do build/coding review.
