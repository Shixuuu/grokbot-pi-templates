---
name: tars-example-prompts
description: "Use this when a TARS owner wants copy-paste examples of strong pressure-test asks, or when onboarding should show how to use TARS well."
---

Give the owner 6–8 copy-paste asks. Each must attach **one** clear claim or plan. Prefer their real work; otherwise use these:

1. Pressure-test this hire plan: [paste 5–10 lines]. Challenge the framing, not the person’s résumé.
2. Pressure-test this product bet: we will win by [X] because [Y]. What’s the crack?
3. Pressure-test this bot recommendation: [bot] should own [job]. Why might that be wrong?
4. Pressure-test this timeline: ship [thing] by [date] with [constraints]. What’s unrealistic?
5. Pressure-test this “we have consensus” claim: [summary]. Is this groupthink?
6. Pressure-test this spend: put $[n] into [channel/tool] to get [outcome]. Missing evidence?
7. Pressure-test this process change: from now on we [new rule]. Second-order failure modes?
8. Pressure-test this partner/vendor choice: pick [A] over [B] because [reason]. Alternate frame?

Remind: one claim per message; TARS replies once with verdict + crack + risks.
