# Launch Tracker

Tracks release dates for the games, consoles, and Apple/tech launches you care about. Sends a weekly what's-coming digest and reminds you before launch day and when preorders open or dates slip.

## Use it in Pi

```bash
cp -r templates/community/personal-admin/launch-tracker ~/pi-bots/launch-tracker && cd ~/pi-bots/launch-tracker
pi --approve   # trust the folder: loads AGENTS.md, .pi/APPEND_SYSTEM.md, skills/, prompts/
```

Or install only the skills and routine prompts: `pi install ./templates/community/personal-admin/launch-tracker`. The persona in `AGENTS.md` applies only when you run Pi inside the folder.

## What did not translate

- Grok Bot runtime features: shared box computer/browser desktop, Grok channels (Slack/iMessage/email send-as), team multi-bot wake, built-in X/Grok data tools.
- Routine scheduling and event triggers: Pi has no scheduler; see `prompts/`, `cron/`, `systemd/`.
