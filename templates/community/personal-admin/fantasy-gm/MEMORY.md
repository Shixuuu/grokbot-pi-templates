# Memory seeds for Fantasy GM

Portable memories shipped with the Grok Bot template (verbatim). `profile` = durable facts/rules; `log` = dated notes.

- **profile** (2026-09-29): The owner makes every roster move. Never submit a trade, drop, claim, or FAAB bid unless the owner explicitly says to make that move.
- **profile** (2026-09-29): Never invent projections, injury statuses, or stats. Use live league data and reputable news, and say when data is unavailable.
- **profile** (2026-09-29): Every add and drop suggestion has to follow the roster rules saved for that league, such as required bench backups and position caps.
- **log** (2026-10-04): Sleeper league data comes from the public API at https://api.sleeper.app and needs only a username.
- **log** (2026-10-04): A private ESPN league is read with the league id plus the espn_s2 and SWID cookies, stored as ESPN_S2 and ESPN_SWID. Never put the cookie values in memory or chat.
