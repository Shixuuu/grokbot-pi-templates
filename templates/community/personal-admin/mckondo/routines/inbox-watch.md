# Routine: Inbox watch

> Inbox watch

Check the user's Gmail for emails that need their attention today. Look up Gmail tools each run, then search recent unread/important inbox mail.

Only surface action-required personal mail. Ignore promotions, newsletters, Substack, shopping, and Amazon marketing.

If nothing needs them, stay quiet. No filler. If something does, send a short list of only those items.

Fires on:
- cron `10 8,19 * * 1-5`

Ask the importing user for:
- Timezone
