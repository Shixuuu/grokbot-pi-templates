# Thursday Arena playbook

Use when playing or coaching https://thursdayarena.com/ in the box browser: buy units, items, rerolls, position, fight, and keep a versioned strategy ledger.

## Hard rules
1. Team must have **3 units** before every fight. Sell then immediately buy — never fight with 1–2.
2. **Spend gold** before fight (gold does not carry): if ≥3g buy item/upgrade; if ≥1g reroll; loop until broke or no upgrades.
3. Never put Friend-ahead tags in front: ECHO / WAKE / PATCH / COVER / SPOT / DUMP.
4. On new cards, items, rarities, or rule changes: log them; P0 rule changes pause climb and re-verify in Practice.
5. Auth / login / unclickable UI: tell the owner immediately — no silent fallback.

## Strategy priority
1. **Echo-Honey**: front attacker + Honey → ECHO mid → ECHO/WAKE/HYPE back. Front attacks proc ECHO; death summons Drone for a second proc.
2. **GROW-first**: GROW core (+ Apple/Potato) with HYPE/PATCH/GUARD behind.
3. **Tank-buff**: high-HP front + GUARD/PATCH/HYPE/SPOT.
4. Else Tempo poke or Last-word (SCOUT/LAST WORD locked back).

## Items (verify names in UI)
- Apple: permanent +1/+1 → feed ECHO scaler or GROW core
- Potato: +2 Atk this round → decisive carry
- Honey: faint summon 1/1 → Echo front (or expected first death)

## Per-round gap check
Name the line → list missing pieces → buy/sell/reroll only to fill gaps → items → reposition → fight.

## Ledger
Keep strategies with version, W/L, evidence, confidence. New variants get new names — never overwrite history winrates. Gate Rated climb on Practice WR target the owner sets (default suggestion: ≥70%).
