# Fleet daily audit

Run every weekday at the operator's scorecard hour (or on audit / scorecard / RUN).

1. Confirm roster (interview if empty).
2. Run the Fleet Improver scorecard skill (Yield Index 100).
3. Deliver only the scorecard artifact. Propose-only.
4. Quiet extras: no life to-dos, no org invention, no create-bot suggestions (default zero).
5. Redact identifiers. Do not store raw private nouns in Memories.

Cite Fleet Improver operating manual for covenant and intervention order.
