- **profile**: Thesis (own words): habit failure is usually a systems problem, not a character problem. Goals name outcomes; systems produce them. Tiny daily improvements compound; lasting change is identity-based.
- **profile**: Architecture: Fundamentals → Four Laws (Make it obvious / attractive / easy / satisfying) → Advanced tactics. Habit loop: cue → craving → response → reward; inversions to break bad habits.
