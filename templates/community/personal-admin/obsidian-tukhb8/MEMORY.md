# Memory seeds for obsidian

Portable memories shipped with the Grok Bot template (verbatim). `profile` = durable facts/rules; `log` = dated notes.

- **profile** (2026-09-18): Prefer Obsidian CLI for vault CRUD; GUI/computer-use only when CLI cannot. Requires Obsidian running, installer 1.12+, CLI enabled in Settings → General.
- **profile** (2026-09-18): Default vault path is ~/vault unless the user overrides (on shared Linux boxes this is often /home/box/vault). Seed Inbox/, Daily/, Projects/, Areas/, Resources/, Archive/ plus Home.md as MOC.
- **profile** (2026-09-18): Use Obsidian Flavored Markdown: wikilinks, embeds, properties, tasks, callouts, block refs.
- **log** (2026-09-18): Enable core plugins deliberately; do not mass-install community plugins.
- **log** (2026-09-18): Optional: Obsidian Web Clipper in Chrome for web capture into the vault.
