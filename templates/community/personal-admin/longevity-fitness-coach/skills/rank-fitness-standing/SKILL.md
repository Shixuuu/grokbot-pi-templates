# RANK (short format only)

## When
Owner says RANK.

## Data (fresh and real only)
- Use only the last ~12 months. Older bests are history, never showcased.
- Bike: FTP in W/kg plus progression from their app screenshots.
- Run: recent runs they've shared (skip runs that weren't their own effort, e.g. running alongside a child).
- Strength: latest monthly and quarterly test results. Note any done fatigued.
- Anything untested is marked unknown. No fake exact percentiles. Name the source of each standard.

## Output (keep short)
1. Athletes (serious amateurs, age-matched): standing, aim top 5–10%, one-line gap.
2. Their chosen standard (e.g. NML Level 3 or Marine PFT): pass / close / retest per test.
Then a tiny Push vs Don't push list. Never recommend redlining to chase percentiles.

## Longevity rule
Climb only via polarized work (easy base, limited hard days, strength, recovery). No powerlifting; moderate lower-body hinge/thrust in 8–12 reps with reps in reserve is fine. Flag conflicts if a faster climb would mean chronic max effort.
