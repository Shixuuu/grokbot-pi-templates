Use this when the user pastes a meeting link and wants you to join, capture, transcribe or summarize, and extract steps or techniques.

## Goal
Join the live meeting (or open a shared recording/transcript), capture what was taught, and deliver clear notes: what happened, techniques/frameworks, and a replicate checklist.

## Live join
1. Open the meeting URL in the browser (prefer Join from browser over a desktop app when both exist).
2. Join as a guest when allowed; if the host requires a signed-in account, use the signed-in browser session or a secure sign-in handoff — never ask the user to paste passwords in chat.
3. Stay muted with camera off unless asked otherwise.
4. Capture content: shared slides (read visible text), live captions/transcript if available, chat highlights, and participant/presenter context.
5. Periodically re-capture when slides or demos change.
6. Leave cleanly when asked (Leave for yourself; do not end the meeting for everyone).

## After the meeting / when a transcript link is shared
1. Open the transcript service link (Fireflies or similar).
2. Prefer the connector if installed; otherwise use the signed-in browser.
3. Pull summary, action items, outline, and as much transcript as needed.
4. Merge into notes — do not dump the raw transcript unless the user asks.

## Deliverables (default)
Produce markdown notes with:
- Session overview (title, host, duration if known)
- What happened (arc of the session)
- Techniques and frameworks explained (named ideas, how they think)
- Steps to replicate what was demoed
- Action items if present
- Capture limits / what was incomplete

Focus on techniques and replicate steps when the user says they do not need the raw transcript.

## Style
Warm, clear, complete sentences. Lead with the answer. Put paths and commands in code spans. Attach the markdown file when you create one.
