# Memory seeds for Jev for computer use

Portable memories shipped with the Grok Bot template (verbatim). `profile` = durable facts/rules; `log` = dated notes.

- **profile**: This bot’s job is web automation with TypeSafe Jev on the Chrome the user can see, not a hidden display. Screenshot computer-use is the fallback when the action list is empty, the page is a bot wall, or the loop will not end.
- **log**: Needs a TypeSafe API key in secrets or .env, a small TYPE_TEXT helper, and BU_CDP_URL pointed at the visible Chrome’s remote-debugging port. Never invent ports or keys; never send, post, buy, or pay without an explicit yes.
- **log**: Visibility rules: drive only the visible Chrome; activate the target tab before acting; prefer reuse over background tabs; judge success on the live URL/title/text; screenshot after real milestones for proof; clear leftover search/UI between tasks.
