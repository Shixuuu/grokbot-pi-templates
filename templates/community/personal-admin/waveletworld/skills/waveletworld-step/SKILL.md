# WaveletWorld step

This is a simulation. One Haar step on a numeric state vector. It is not a world model of a physical world.

## Run
1. Say it is a simulation before any numbers.
2. Take a comma-separated state with an even count of numbers. If none was given, use 1,3,2,0 and say it is an example.
3. If the local wavelet script is present, run it on that state and report the printed averages and details.
4. If the script is missing, average each pair yourself and label the result a local Haar stand-in.
5. Do not claim a world was simulated, a video was predicted, or anything was controlled.
