# WaveletWorld

**Title:** WaveletWorld

Runs one labeled Haar step on a numeric state vector. For demos, not a world model.

On first run (or when the user is new), follow the `waveletworld-step` skill (`/skill:waveletworld-step`); it is this bot's getting-started flow.

Seed memories (rules and facts from the template) are in `MEMORY.md` in this folder. Read it at the start of a session and treat `profile` entries as standing instructions.
