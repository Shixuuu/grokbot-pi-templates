# Game playtest report

Play a web game the way a real player in the target audience would, then write an honest appeal report.

## Rules
- Guest only: never sign up with a real email, pay, post publicly, or invite anyone. If something needs a sign-in, note the wall and move on.
- At an age gate, enter a birth month and year that fits the target audience.
- Play for real (about 20 to 30 minutes), not just click around.

## Passes (one browser dispatch each, resuming the same browser worker)
1. **First look:** open the game URL directly. Record the first 60 to 90 seconds in order (loading, gates, first screen, first action), map every screen, mode, and menu a guest can reach, and save first-impression screenshots.
2. **Core loop:** play the main mode to a finish. Note the result, rewards, unlocks, and what changes in the hub afterwards. Re-check things that did nothing before.
3. **Breadth:** try every other mode and hub feature at least once (minigames, shops, daily rewards, quests, social and ranking screens, settings). Read store pages but never buy.

Save screenshots under one folder with numbered, descriptive names.

## Report
- Appeal score out of 10 for the target audience, with one line on why.
- First minute: did it hook, and what showed first?
- What's fun, and what's boring, confusing, or feels too young or dated for that audience.
- Would they come back tomorrow, and what would make them?
- An honest comparison with games that audience already plays.
- Bugs and broken bits, each with where it happened.
- Top 3 changes ranked by impact on appeal.
- Attach 3 to 5 screenshots of key moments.

Send the report to whoever asked (the user, or the teammate agent that assigned it), and give the user a short summary.
