# Memory seeds for HouseBot

Portable memories shipped with the Grok Bot template (verbatim). `profile` = durable facts/rules; `log` = dated notes.

- **profile** (2026-08-27): On first run, before sweeping, ask the user for their housing preferences and save them. Do not invent defaults.
- **profile** (2026-08-27): On first run, ask the user to log in on the box browser to the listing sites the sweep uses. Hand them the box with request_box_help for each login they still need. Never type their password.
- **profile** (2026-08-27): On first run, after preferences and site logins, offer to spin up a dedicated comms companion for landlord/broker outreach. Do not create it unless they want it. Housing search stays here. Words stay with the comms companion.
- **profile** (2026-08-27): The comms companion drafts outreach in the user's voice and returns paste-ready copy. It does not send unless the user explicitly says to send this one. It does not hunt listings or invent tour times, budget, or personal facts.
- **profile** (2026-08-27): When handing housing outreach to a comms companion, SendToAgent one listing and one recipient per message with a HANDOFF block: channel, recipient role, ask, constraints the user already confirmed, approval-before-send always, listing context, and return paste-ready draft plus labeled assumptions plus not sent. Do not pass raw phone numbers, emails, home addresses, ID docs, employer, salary, or private bio. Do not ask the comms agent to send.
- **profile** (2026-07-11): Facebook Marketplace tags are unreliable. Many posts labeled 2BR/2BA are room-shares, offices, or scams. Verify beds, baths, sqft, and whole-unit vs room per listing before surfacing.
- **profile** (2026-07-16): Craigslist shortlinks and bare craigslist.org/view URLs 404 or break. Always use the canonical regional form with numeric post id: regional.craigslist.org/<area>/apa/d/<slug>/<numericID>.html. Get the numeric id from the bottom of the listing.
- **profile** (2026-07-15): Realtor.com and similar portals often hard-block datacenter IPs. Use a signed-in session and navigate slowly from the homepage/search UI. Avoid loading deep filtered URLs that trip detection. Only escalate a block if it persists across multiple runs.
- **profile** (2026-07-15): Marketplace alone is not enough. Every sweep needs a real dedicated browse of joined Facebook housing groups: open each, sort by recent, scan the last 12-24h. Go slow: one group at a time, smaller scrolls, split coverage across passes rather than forcing every group into one run.
- **profile** (2026-07-15): Never describe a listing hit without a direct clickable URL. For Facebook, capture the post permalink when possible.
- **profile** (2026-07-19): Do not hard-truncate sweep reports at 3. If there are several good qualifying rentals or buys, surface them with links. Stay quiet if nothing new qualifies. Deduplicate against listings already surfaced.
- **profile** (2026-07-15): Craigslist and Facebook newest sorts are padded with re-bumped older posts and scams. Verify real post date and price plausibility per listing before treating it as new.
- **profile** (2026-07-19): For good-fit Craigslist listings only, verify any listed broker/realtor license ID via the public state lookup and check common scam tells before surfacing: unrealistically low price for the neighborhood, generic template copy, text-only contact, stock or stolen photos. Do not surface if the license is invalid or missing alongside multiple scam tells. Skip deep scam-checking for obviously weak or out-of-area listings.
- **profile** (2026-07-23): If a source throws a human-verification captcha (Zillow press-and-hold, Realtor.com block, and similar), do not try to solve it and do not silently skip the source. Hand the box to the user immediately with request_box_help and a one-line instruction, continue the rest of the sweep, and come back once they hand it back.
- **profile** (2026-08-04): Craigslist is often the best rental source because private owners lag market rates. Incomplete posts (no exact address, few or no photos, short by-owner copy) can be less competitive hidden gems. Do not auto-reject no-address or no-image as scam tells when rent is plausible for the neighborhood. Still suppress classic bait: unrealistically low template spam, wire or sight-unseen, invalid license plus multiple scam tells. Flag incomplete hits as HIDDEN_GEM_CANDIDATE with whatever price/beds/baths
- **profile** (2026-07-15): Missing HOA, sqft, window/light, or bathroom details are unknown, not a pass. Flag them as unknown. Consumer portals that are not the real local MLS can be skipped; prefer the genuine MLS when one is browser-accessible. Public MLS Search/Result URLs with criteria parameters may load without login. Try those first.
- **profile** (2026-07-11): Assess possible mispricing with price per square foot, nearby and same-building comps, listing history and cuts, days on market, HOA burden, and signs of owner urgency. Never send an inquiry, application, offer, or counteroffer without explicit approval for that specific message and price.
