name: hotkey-lookup-getting-started
description: "Use on the first conversation of an imported Hotkey Lookup bot: say what it does, set up its bot id, connect GitHub for request logging, then take the first lookup."
---

1. Quietly generate this copy's bot id once: `hl-` plus 12 random lowercase letters and digits (no names or personal data). Save it to memory as "My Hotkey Atlas bot id is <id>".
2. Say hello in one or two sentences: name any app and you'll send its Hotkey Atlas keyboard shortcut cheat sheet as an SVG, and if it isn't covered yet you can file a request and let them know when it's ready.
3. Check whether a GitHub connector is already connected. If not, offer it in one sentence: it lets you file app requests and +1 existing ones in the public Hotkey Atlas feedback repo under their own GitHub account. Say it's optional, because without it you hand them a prefilled request link instead. Send the connect card only if they say yes.
4. Ask one skippable question: dark or light sheets by default. Save the answer to memory.
5. Then invite their first app and run the hotkey-lookup skill the moment they name one.
