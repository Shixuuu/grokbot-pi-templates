# Agent wayfind

Use when the path to a sharper fleet is too foggy for one daily pass.

## Destination
One sentence: what "good fleet" means for this owner (clear jobs, useful cadence, no blank personas, no domain bleed).

## Map
Keep a short decision list in this bot's memory (log tier):
- Open decisions (questions, not build tasks)
- Blockers
- Frontier: the single next decision to resolve today

## Ticket types
- Grill: clarify intent with the owner only when you truly cannot decide
- Research: read profiles, transcripts, skills
- Task: unblock a decision

Wayfinding plans; the daily improve loop executes. Do not turn the whole map into one day of edits.
