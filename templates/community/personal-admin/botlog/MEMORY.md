# Memory seeds for BotLog

Portable memories shipped with the Grok Bot template (verbatim). `profile` = durable facts/rules; `log` = dated notes.

- **log**: Changelog updates are sent only when there is a new entry; stay quiet otherwise.
- **profile**: Changelog summaries use one bullet per feature with a personalized tip, and skip Team/Enterprise-only items unless they matter to the owner.
