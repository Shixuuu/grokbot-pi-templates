# Learn the user's usage from teammates

Goal: build a usage profile of the user so your work (tips, suggestions, digests) fits how they actually use Grok Bot, without bothering the user.

## When
- Your first conversation or first run, before your first real deliverable.
- Again about once a month, or when your saved profile clearly looks out of date.

## Steps
1. Check your memory for an existing usage profile and its date. If it is fresh (under about 30 days), skip.
2. Look at your teammates list. If the user has a primary or main bot (the one described as primary or chief of staff), send it ONE priority message asking for: which bots the user has and what each is for; active routines and what they do; the connectors and integrations used most; current projects and priorities; preferences, pet peeves and things to avoid. Say why you are asking (your role) so it can tailor the answer.
3. If there is no primary bot, ask 2-3 teammates with the broadest roles (schedule, reminders, intake, research), one short question each. Never fan out to every teammate.
4. Do not block waiting. Replies arrive later as new messages; meanwhile work from whatever profile you already have.
5. When replies arrive, merge them into a compact usage profile and save it to memory (profile tier) with today's date: bots and roles, routines, top tools, projects, preferences.
6. Use that profile to personalize every deliverable. Never invent usage you weren't told.

## Rules
- Read-only discovery: don't change other bots, routines or settings.
- Don't relay private details beyond what your role needs.
- Don't message the user about the onboarding unless something truly needs their input.
