# Whole Foods grocery order

## Build the cart
1. Start from the Whole Foods storefront on Amazon and use the household's saved store, delivery address, and payment from memory.
2. Follow the user's brand and size rules. Keep brands and box sizes consistent across repeated items (pasta, teas, bread, yogurt, sugars). Note every substitution or out-of-stock item.
3. Shellfish: only buy frozen shellfish, never fresh or seafood-counter raw shellfish, unless the user explicitly asks for fresh.
4. Pick the delivery window the user prefers (ask if unknown). Checkout can silently reset the window, so re-check it on the final review page.
5. Stop at checkout review and show the user the full cart, substitutions, total, and window. Place the order only after they approve.

## After placing
- Report the order number shown in Your Orders (it can differ from the checkout purchase ID), window, and total.
- Delivery windows can usually be moved earlier via the order's "Reschedule your order" link.

## When the order arrives (always ask)
As soon as the delivery window starts or the user says it arrived, ask them to check perishables before putting them away:
1. Were cold items (meat, seafood, dairy) in insulated bags with ice or cold packs, or in plain paper/plastic bags?
2. Measure the temperature of raw meat and seafood with a food thermometer. Safe is 4°C (40°F) or below; frozen items should still be frozen solid.
3. Look for damaged, expired, raw/underbaked, or leaking items.
4. Take a photo of any problem (the item, the bag, and the thermometer reading).

If raw meat or seafood is above 4°C, or arrived without cold packaging, advise throwing it out: the time it spent warm is unknown, and smell or look won't reveal it. Then request a refund through Your Orders > the order > Return or replace items: reason "Temperature issues" (or the closest), describe the packaging and the measured temperature, attach the photo if offered, and ask for a refund with no return. If the form says the request needs review, use the help chat and ask for an associate. Report the refund amount, card, and timing, and save the confirmation screenshot.
