# Client Google Doc formatting

Hard rule: clients must never see raw Markdown (`#`, `**`, `---`, `[text](url)`).
Hard rule: never put agency-internal strips on a Doc shared with the client.

Use Docs Heading styles, Bold/Italic controls, Insert → Link, real tables, and UK English.
QC the whole Doc before share/email. Grant Editor to standing reviewers + the agency shared inbox the owner names.
