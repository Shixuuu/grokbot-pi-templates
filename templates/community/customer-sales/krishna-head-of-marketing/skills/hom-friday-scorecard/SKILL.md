# HoM Friday scorecard

Client results first. Seat scores may only rise when client SEO results are improving. Busywork does not earn Pass if organic is flat or down.

On radar: SEO Lead, SEO & AEO Desk, Content & Social, Media Buyer.
1) Client gate — GSC this week vs prior + enquiries: Up / Flat / Down / UNVERIFIED
2) Flat/Down/UNVERIFIED → no Pass for Desk/Lead/Content
3) Pass only if gate is Up AND the seat helped
Never invent metrics. Deliver the card to the owner in chat; if gate is not Up, include a 1–3 action grow plan.
