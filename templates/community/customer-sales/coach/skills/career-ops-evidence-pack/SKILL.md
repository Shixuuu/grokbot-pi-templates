# Career ops evidence pack

Quiet job-search ops for the owner. Work-facing seats never see this work.

## Scope
- Own (Growth): Queue — triage/create Leads; light Review handoff; evidence pack before any Apply nudge
- Own (Coach): Lead Review + interview prep evidence packs; recommend Status only
- Live source of truth: Airtable Career base — tables Leads, Network, Questions, Templates. Not Notion. No spreadsheet parallel source of truth.
- Hand off: portfolio/blog calendar → Content; workplace performance roadmap stays with Growth — never leak search intent to work channels

## Hard rules
- Look up Airtable schema each run; don't invent rows or Status values.
- Early Status only: Prospect, Lead/Referral, or AI Research unless the owner already set something else.
- Never set Status=Applied or fill Applied (dateTime) unless the owner explicitly confirms in that conversation.
- Chrome-apply ban: never click Apply / submit in a careers site or browser on the owner's behalf — pack evidence, recommend, wait.
- Quiet search: never message work-facing seats or work Slack about job hunt.

## Evidence pack (required before Apply nudge)
For the target Lead, assemble from Airtable (and linked Network / Questions / Templates as present):
1. Company + Role + URL + current Status
2. Fit score (1–5) with one evidence phrase from Role Description / Notes
3. Gaps (missing research, weak Network link, unanswered Questions)
4. Network people linked (or "none")
5. Recommended next Status — wait for confirm before writing
6. One concrete next step (draft reply, ask for intro, deepen research) — not "apply now" unless the pack is complete and the owner asked

Keep the pack short enough to scan. Stay quiet on queue pulses when nothing moved and no decision is due.

## Friday Coach check-in shape
1. Read Airtable Leads (open / needing Review or prep) via connector.
2. Short peer check-in: what moved vs commitments, one win, one stuck, one evidence-backed Lead Review if due.
3. Recommend Status only — wait for confirm before writing.
4. Stay quiet when nothing to hold and no Lead needs review.

## Quiet-success (Coach Friday check-in)
After every successful Airtable Leads live-read, write one memory line: `last-verified <date/time local>: <Status counts>; at-risk: <Lead title or none>`. Stay silent when nothing moved and no decision is due — still record last-verified.
