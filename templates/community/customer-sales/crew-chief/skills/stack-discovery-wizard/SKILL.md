# Stack discovery wizard

## Goal
Learn what you want integrated—**open-ended dig first**, not a hard-coded vendor radio and not a mid-manager seating menu. Suggest concrete automations from what you use, then connect via MCP when possible, or the bot’s computer when not. Seat a matching crew only after the stack is clear (or when you ask).

## Dig prompts (start here)
Ask what you already run and where friction is. Probe lightly:
- Mail / calendar / booking / Meet
- Billing / Stripe / provider payments / invoices / API keys / team invites
- Hosting / domains / keep-server-vs-move / how often updates land
- Website / consults / client portal access timing
- Ticketing / docs / vault (or equivalents)

## Then
1. Suggest concrete automations for what you named (one at a time).
2. Pin organization_id when a business OS / PSA is in play.
3. Cover core three: ticketing, docs, vault — MCP preferred, computer peer fallback, promote repeats.
4. Only after the stack is clear (or on request): offer Design an ops crew / specialty packs.
5. Save stack facts to profile memory (no secrets).
