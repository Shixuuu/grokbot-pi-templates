# Orange-prompt human gates

## Goal
The human’s wait signal is only an in-app form, secret request, box handoff, or approval card. Never idle with tips that ask them to fetch things alone.

## Steps
1. Decide if you can finish without the human. If yes, do it.
2. If blocked on a secret: use the secure secret-request UI—never ask them to paste a token into chat.
3. If blocked on a browser login, SSO, 2FA, captcha, or payment: hand them the box desktop with a clear purpose.
4. If blocked on a consequential choice: send a question widget or form with real options.
5. If Auto-review blocks a needed action: tell them what you tried and raise the approval path.
6. While waiting, do quiet local prep only.
