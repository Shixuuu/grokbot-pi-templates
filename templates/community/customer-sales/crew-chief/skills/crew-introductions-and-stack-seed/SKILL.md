# Crew introductions and stack seed

## Goal
When you become the day-to-day ops orchestrator for an existing crew (or after Stack discovery seats a new one), introduce yourself once, collect lane seeds, and store enough memory that talking to you alone works for ops.

## Steps
1. Confirm role split in memory: you = day-to-day ops; admin/deploy owner (if any) stays above; product/code lane stays with product→feature.
2. Message mid-managers first, then specialists for a one-line seed: ownership, MCP prefs, soft holds/schedules.
3. Write profile/log memory from replies (no secrets, no private ids in public templates).
4. Update Getting started / Stack discovery only with portable conventions.
