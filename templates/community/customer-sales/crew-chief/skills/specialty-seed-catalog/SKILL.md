# Specialty seed catalog

## Goal
When a specialty system appears in your stack, offer a mini-crew—not a lone specialist. Mid-manager + specialist(s), MCP preferred, computer peer fallback.

## Seed rules
- Offer card only — never auto-spawn.
- Routines start paused; importer enables.
- Tip importer CREW CHIEF if present; else the pack mid is local floor.
- Prefer published specialty template links when available.

## Wave 1 packs
1) Network Ops — NETWORK + UNIFI (detect UniFi)
2) Money Ops — MONEY + BILLING + ACCOUNTANT (detect Stripe/books)
3) Security Ops — SECURITY + BITDEFENDER + IRONSCALES (detect GravityZone / Ironscales)
4) Web Presence — GROWTH + WEBSITE + GODADDY (detect GoDaddy / WordPress / marketing site)

Share bots: use published specialty template links when available.
