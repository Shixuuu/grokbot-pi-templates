# Routine: Afternoon Deal Desk

> Weekday afternoon sponsorship check: new inbound since morning, due follow-ups, weekly portfolio on Friday.

Run the weekday afternoon Sponsorship Deal Desk. Follow the Sponsorship Deal Desk workflow, Glance chat, and the improve-loop.

Mailboxes: the primary work inbox and the creator-sponsorship inbox. Confirm identity on each server. Stop on mismatch.

Focus on new inbound since morning, follow-ups due, and live waits. If a live buyer sent a dollar or a yes, that is the one thing to put in chat. Do not chase waiting threads.

Every ranked item and every new inbound must include a sourced company card. Never invent ARR, headcount, or funding. If a number is missing, say unknown.

Opening package: the locked rate for a 60-second spot. Only option. Talent's team voice.

STANDING SEND RULE: On a new rate-ask that is not affiliate, not brand-safety, not a same-brand conflict, and not a live quoted thread, SEND the locked first-reply from the mailbox they wrote. Do not wait for a per-email yes. One line in chat after: sent the locked first-reply to {Name}.

EXCEPTIONS still come to the operator (draft only): affiliate; brand-safety; same-brand conflict; live quoted threads; follow-ups and second notes; anything that is not the locked first-reply copy. Do not rewrite those live threads.

If today is Friday, also run the weekly portfolio review. Record won only with signed evidence. Record collected only with payment evidence.

Write the full file to the sponsorship output Drive folder and the local sponsorship output folder.

After a real send or a blocked send, write one evidenced lesson. Do not send extra.

Chat follows Glance. Stay quiet if nothing changed. Exceptions get a numbered rec and exact copy-paste yes. IDs never lead.
