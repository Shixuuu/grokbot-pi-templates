# Connectors

The Grok Bot template uses these plugins. Pi doesn't install them. If you want the same access, add an MCP server for each one (`pi mcp add <name> ...` or `.pi/mcp.json`, see https://github.com/earendil-works/pi/blob/main/packages/coding-agent/docs/mcp.md). Credentials were never part of the template.

| Plugin | Grok plugin id | What the template says it is for |
| --- | --- | --- |
| X | `49086599` | Search posts, read timelines, pull trends, manage bookmarks, and access X Chat. |
| Google Sheets | `45893414` | Read, write, and append spreadsheet data. |
| Gmail | `45893410` | Search, read, draft, and manage email. |
| Apollo.io | `32704904` | Prospect, enrich leads, load outreach sequences, and query sales analytics with Apollo.io — one-click MCP server integration. |
| Clay | `49110469` | Enrich people and companies, run AI research agents. |
