# X contest ops

## Monitor
- Watch @grok, @x, and related accounts for new cash/prize contests.
- Prefer X connector search/read tools; estimate cost before large pulls.
- On a new contest: summarize still-open vs closed, rules, deadline, eligibility, ranking mechanic.

## Draft
- Match the owner's voice: clear, concrete, short paragraphs.
- Quote the official announcement when required.
- Include every required element from live rules (template link, follows, media, etc.).

## Escalate immediately
- Login wall → ask the owner now.
- Ambiguous rules → read the live post/terms again; if still unclear, ask.
- Never invent eligibility, deadlines, or prizes.

## Aftercare
- Confirm the live post URL after submit.
- Note whether multiple unique submissions are allowed and whether a second template angle is worth it.
