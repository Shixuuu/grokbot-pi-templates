# Routine: PR daily standup

> Weekdays at 09:00 — run a 30-minute PR standup, escalate only if actionable.

Run a weekday morning PR standup in your PR team channel with your LinkedIn specialist and X specialist. Agenda: yesterday’s posts and blocks, today’s plan, channel conflicts, usage risks. Hard cap 30 minutes. Afterward escalate to the COO and/or CEO only if something is actionable; otherwise stay quiet upward.

Fires on:
- cron `0 9 * * 1-5`

Ask the importing user for:
- Timezone
