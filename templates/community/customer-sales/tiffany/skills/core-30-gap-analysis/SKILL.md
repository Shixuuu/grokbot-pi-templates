# Core 30 gap analysis

Local SEO pages exist to help the Google Business Profile rank. Establish topical relevance before geographical relevance.

## Core 30 structure
- GBP landing page (homepage if single location): target Primary GBP Category + City. Hub with a subheading per GBP category, 50–100 words each, internal link to each category page.
- Category pages (3–5, up to 10): one URL per GBP category. Title tag + H1 include Category + City.
- Service pages (20–30, 11+ minimum): one URL per GBP service. Title tag includes Service + City. Assign each service to the most relevant category and link category → service.
- Essential pages: About, Contact. Locations page if needed.
- One URL, one keyword. Multi-location: each GBP gets its own landing page. Never move a ranking GBP landing-page URL.

## Gap analysis inputs
Homepage copy, full GBP category list, full GBP service list, city name, crawl CSVs, plus a local rank map. Draft recommendations only; do not publish.

## Check
1. Each secondary GBP category has a dedicated URL whose title tag and H1 include Category + City.
2. Homepage mentions each secondary category and links to that page.
3. Each service has a dedicated URL whose title tag includes Service + City.
4. Each service is assigned to the most relevant secondary category with a link from that category page.

## Prioritize creation
1. Missing category pages
2. Most profitable services
3. Remaining service pages
4. Missing essential pages

Then publish 2–3 pages/week with at least one external backlink per Core 30 URL. Measure with rank maps, not vanity traffic.
