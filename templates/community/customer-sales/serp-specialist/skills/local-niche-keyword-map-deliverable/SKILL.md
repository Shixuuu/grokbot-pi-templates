# Single-file site-build handoff deliverable

## When
After completing a local niche keyword research run (NICHE + CITY). Also when the user asks to combine files or prepare a handoff for a site-building agent.

## Audience
The primary reader is **another agent (or human builder) who will implement the website**. Write instructions they can execute without asking follow-ups — covering **SEO/IA and visual quality**.

## Always do this
1. **Ship ONE primary file** named `{NICHE-SLUG}-{CITY-SLUG}-SITE-BUILD-HANDOFF.md`
2. Self-contained. Do not require opening discovery.md / matrix.csv / competitors.md to build.
3. Working research files stay in the project folder for audit only.
4. In chat: attach **only** the handoff file by default.
5. **Design is mandatory.** A handoff that only lists keywords/H1s is incomplete. Always include Design system + per-page wireframes + DoD visual QA.

## Required handoff structure
1. **Handoff brief** — niche, city, geo, GO/NO-GO, positioning
2. **Design system (global)** — brand vibe (3–5 adjectives + anti-patterns), color tokens with hex, typography, spacing / max width / radius, component kit (header, footer, CTA buttons, trust bar, card, FAQ accordion, form), imagery rules, mobile-first rules
3. **Visual DoD / QA checklist** — real hierarchy, no lorem, consistent spacing, WCAG AA contrast, no wall-of-text, hero CTA above fold
4. **Build order** — numbered P1 → P3
5. **Global SEO/IA rules** — one KW → one URL; intent traps; internal linking; geo disambiguation
6. **Page specs** — one block per page: page_slug, suggested_url, page_type, priority, primary/secondary keywords, h1, title_tag, meta_description, funnel_to, internal_links_out, serp_grade, why_beatable, content_must_include, cta, avoid, plus design fields layout_template, sections_in_order, hero (headline, subhead, CTAs, media), above_fold_must_show (3 max), social_proof
7. **IA / nav** — primary nav + footer
8. **Competitor URL patterns to beat**
9. **Watch-outs**
10. **Appendix** — keyword → page_slug table

## Tone
Imperative. Builder should not invent a random theme. Prefer "Use these tokens / this section order" over "make it look professional."
