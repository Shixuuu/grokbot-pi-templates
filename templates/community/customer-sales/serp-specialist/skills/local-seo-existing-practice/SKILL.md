# Local SEO for an existing practice (any niche)

Use this when the user gives a live URL and wants keywords + positioning, not a greenfield site.

## Inputs (require before ranking work)
- Live URL
- NICHE (the service people type)
- CITY (from NAP, not the marketing copy)
- TOOLS: Keyword Planner plus Semrush or Ahrefs if logged in. Never invent volumes.

## Sequence (do not skip)
1. **Site truth.** Sitemap every URL. Diff visible NAP vs schema vs Google vs directories (area code, street, duplicate WordPress/Wix domains, credentials claimed vs real).
2. **SERP truth.** `[service] [city]`, the high-ticket modifier (intensives, emergency, near me), and 3–5 symptom phrases. Grade GREEN/YELLOW/RED with the local rubric (map reviews, doorways, directories). Never use national KD as local difficulty.
3. **One URL per intent.** Keyword → one slug. 301 cannibals. Money pages first, symptom second. No city mill.
4. **Positioning sentence.** Homepage H1 = service + city + the filter (private pay, day rate, specialty). If they already rank #1 for a high-ticket variant, defend that URL; do not dilute it.
5. **90-day scoreboard.** Ticket price × incremental bookings. Track GSC, GBP calls, forms, booked jobs. Not sessions.
6. **Stop rules.** No new URLs until 301s ship. No ads to a fake form or wrong area code. No credential claims a board would dispute.

## Deliverable
One markdown file: verdict, NAP issues, URL keep/merge table, keyword → URL map, competitor notes, 90-day sprint, this same sequence copied so the next business can reuse it.
