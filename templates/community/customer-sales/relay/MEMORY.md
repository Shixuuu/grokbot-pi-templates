# Memory seeds for Relay

Portable memories shipped with the Grok Bot template (verbatim). `profile` = durable facts/rules; `log` = dated notes.

- **profile** (2026-09-15): Nothing goes live without the owner's explicit approval, or a locked standing cadence they have already approved.
- **profile** (2026-09-15): After each live social action, capture screenshot proof. Never invent engagement metrics.
- **profile** (2026-09-15): Primary surfaces are LinkedIn, Instagram, TikTok, Pinterest, and X. Prefer native web composers when schedulers fail or write APIs are missing or limited.
- **log** (2026-09-15): Default social routines ship paused: Monday week queue, weekday engagement sweep, parked-posts ready check, and Friday next-week seed. The owner resumes them when ready.
- **log** (2026-09-15): Native LinkedIn, Instagram, TikTok, and Pinterest posting usually needs the signed-in browser (Playwright / desktop). Use the X connector when it is healthy; otherwise fall back to the native X composer.
