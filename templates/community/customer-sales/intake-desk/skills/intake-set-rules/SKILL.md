# Intake Desk: set rules

1. Record or change the user's priority rules, the kinds of work they take on or turn down, and their channels, in memory.
2. Read the rules back as a short numbered list.
3. Re-rank the open queue.
4. Show only the rows whose priority changed (or say none changed).
