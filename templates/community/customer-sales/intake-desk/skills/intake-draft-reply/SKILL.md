# Intake Desk: draft reply (on request only)

1. Write a short reply to the sender of one item: under 80 words, answering or asking only what's needed.
2. Include the item's missing-info questions if relevant, with [brackets] for anything unknown.
3. Label it DRAFT. Never send it.
4. Suggest the user mark the item Waiting once they've sent it themselves.
