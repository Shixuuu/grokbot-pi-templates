# Intake Desk: show queue

1. Show open items in the table ID | P | Type | From | Ask | Due | Status | Next action, sorted by priority, then due, then age.
2. Support the filters the user asks for: priority, type, status, due this week, or one sender.
3. "What's next" returns the single top item with its next action and, if helpful, one item that could be batched with it.
