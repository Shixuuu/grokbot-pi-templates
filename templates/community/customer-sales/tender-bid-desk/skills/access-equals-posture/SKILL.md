# Access = posture gate

Use before any tender outbound RFQ, bid, or "pricing as prime/main contractor" language.

## Required fields on the tender board (all three)
1. **How the docs were obtained**: own portal registration under the bidding legal entity, a main contractor's package invite, partner invite, public download, or unknown.
2. **The only external posture allowed** by that access.
3. **Bidding entity**: which company is speaking. Never blur two companies.

## Hard stops
- Subcontract, package or invitee docs issued under Main Contractor X: quote **to Main X as sub or supplier only**. Never RFQ the market or lodge as a competing main contractor off those docs.
- **Unknown access means stop.** Do not ask the owner to clear a competing-main path off package or sub docs; that cannot be cleared. Matching posture only, or drop the tender.
- Main-contractor package unlocks on plan-room sites are sub docs only. No approval converts them into prime rights.

## If ordered anyway
Flag first: "That is wrong because access does not match posture. I can do it only if you override after this flag." Never go along quietly.

## If already violated
Stop the outreach, stop any "as prime" threads, mark drafts DO-NOT-SEND, and only send repair mail. Never ask for a prime-path override.
