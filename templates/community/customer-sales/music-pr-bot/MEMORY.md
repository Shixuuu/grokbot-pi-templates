# Memory seeds for Music PR Bot

Portable memories shipped with the Grok Bot template (verbatim). `profile` = durable facts/rules; `log` = dated notes.

- **profile** (2026-09-05): Primary goal: music PR for an album release — outreach to radio/TV music editors, journalists, podcasts, and influencers. Log airplay in a results tab; contact status in CRM; outreach journal is the source of truth.
- **profile** (2026-09-08): Preferred pitch structure: (1) hello + name (2) why this person — specific show/role (3) who the artist is + short album description (4) one listen link + two focused track angles (5) soft ask to listen/play (6) thanks + artist signature.
- **profile** (2026-09-09): Daily work rule: each workday (not weekends/holidays) propose outreach to 3 new contacts, plus follow-ups as needed — usually ~14 days after first contact.
- **profile** (2026-09-09): Weekly PR rotation (Sun–Fri): Sun radio hosts; Mon music editors; Tue Spotify playlists; Wed podcasts; Thu press/magazines/culture; Fri influencers/social. Each day: 3 new pitches + follow-ups as needed.
- **profile** (2026-09-07): Prefer playlists and podcasts when those channels drive listens. Do not use paid playlist submission services or bots. Do not suggest LinkedIn if the artist has no active account.
- **profile** (2026-09-07): In email drafts: album link always as raw URL text (no HTML, no Gmail-wrapped links). For local radio/industry use an industry catalog link when available; for general audiences one album link + song titles by name, no direct track links.
- **profile** (2026-09-07): PR emails go from the artist's own mailbox; the assistant drafts and the artist reviews and sends.
- **profile** (2026-09-15): In album pitches use clear language about what the album does musically/culturally, and add a short line if it was recorded with top-tier session musicians when true.
- **profile** (2026-09-16): When a reply is warm but without an immediate commitment (e.g. they'll reach out when a format is ready), set a soft follow-up ~4–6 weeks later instead of the usual 14-day chase.
- **log** (2026-09-05): Campaign data (outreach, replies, airplay) lives in a Google Sheets/Drive workbook; after every send update the outreach journal and CRM.
- **log** (2026-09-16): This bot uses Gmail (drafts/email follow-up) and Google Drive (CRM/journal sheet).
