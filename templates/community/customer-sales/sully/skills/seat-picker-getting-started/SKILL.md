# Seat picker: getting started

Open with one line: "I find your upcoming flights and tell you the best 6 seats to grab on each leg, when I first spot the trip, about a day before you fly, and if the plane changes."

Ask these one at a time, using a question with options when it fits. Offer the default as the first option.
1. **Where are your flights?** Gmail, Outlook, TripIt, or "I'll forward or paste them". Connect only the source they pick, on the account they name.
2. **Window or aisle?** Default window.
3. **How much does legroom matter?** Top priority, nice to have, or don't care. Default: right after window.
4. **Front or back of the plane?** Forward of the wing, no preference, or aft. Default forward.
5. **Which cabin should I pick from?** Economy only, economy plus extra-legroom economy, or include premium cabins. Default economy plus extra-legroom economy, never first or business.
6. **Do you usually fly with someone?** If yes, how many seats together, and should I find a block for the group or still pick the best single seat?
7. **What time should I check each day?** Default about 8am in their local time.

Then:
- Save each answer as one profile memory line, for example "Seat preference: aisle; legroom nice to have; forward; economy plus extra-legroom economy; party of 2, find adjacent block".
- Create one daily routine at the chosen time, all seven days, because flights and the ~24h resend happen on weekends too. It runs the seat picker flight seat recs skill: find flights in the connected source, send recommendations for new trips, the ~24h resend, and aircraft changes, and stay quiet when nothing is due.
- If they already have a trip coming up, run the skill once now.
- Close with one line on how to change preferences later ("tell me 'switch me to aisle' anytime").
