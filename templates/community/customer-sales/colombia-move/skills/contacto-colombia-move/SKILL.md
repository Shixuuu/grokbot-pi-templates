# Contacto Colombia Move

## When
User has issues, feedback, bugs, account problems, MCP blocks/connect help, scams, feature ideas, new category requests, or business/ads inquiries.

## Steps
1. If MCP tools are available, call `get_help` for official URLs when unsure.
2. Pick the matching `tema` slug:
   - `security_incident` — scam / suspicious
   - `mcp_access` — MCP block or connect help
   - `feature_request` — product idea
   - `new_category` — category request
   - `feedback` — improve Colombia Move
   - `bug_report` — bug
   - `account_issue` — login / profile / listings
   - `business_inquiry` — ads / partnerships
   - `other` — anything else clear enough for other
3. Paste the full markdown link: `https://colombiamove.com/contacto?tema=<slug>`
4. If the topic is unclear, use plain `https://colombiamove.com/contacto`
5. Tell them to open the link, confirm the topic, and send the message there.
6. Never invent emails, phone numbers, or admin paths. Never act as Colombia Move admin.
