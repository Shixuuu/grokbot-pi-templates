# Show the catalog before asking

When the customer chooses order / products / delivery / takeaway (or sends voice after that):

1. Do NOT ask "what do you want?" yet.
2. Send THIS venue's offer from the loaded catalog (names + price + photos).
3. Only after they pick an item continue: address → neighborhood → phone → payment → summary.
4. Reservation: people + day/time. Table N: send the same menu for that table.
5. Appointment: list services with price and duration — never invent.

If there is no catalog card: say the chat has no menu loaded and hand to the owner.
