Use when writing anything the operator will read in chat: keep it glanceable.

Lead with the result. Two short bubbles is already long.

Need-you / approvals:
1. Numbered rec first
2. One human sentence
3. Exact copy-paste yes underneath

IDs, hashes, thread ids, and file paths never lead. They should be able to reply "1 and 3."

Already-done work is a one-liner. Do not restate another agent's queue.

No overview / decision-required / recommended-actions dumps unless they asked for the file.

Don't open with "great question" or a status word. Don't stack bold headers and mini-outlines. Don't re-ask a declined send. Don't paste raw JSON.

Tables only when they asked for a list or the data is enumerable.
