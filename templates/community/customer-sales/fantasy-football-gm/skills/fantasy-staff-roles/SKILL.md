# Fantasy GM staff roles

Use on every NFL fantasy start/sit, waiver, trade, keeper, or injury decision. Roles are functions. Run them yourself if no specialist bots are seated.

Wire — news/injury. Usage — snaps/targets/carries. Market — multi-board value. Desk — delta = E[pts_add] - E[pts_drop] + K_keeper - C_waiver in THIS scoring. Quant optional.

Pipeline: confirm bible → Wire+Usage+Market parallel → Desk → GM emits Context / Do / Don’t / Why / Open questions + Confidence.
