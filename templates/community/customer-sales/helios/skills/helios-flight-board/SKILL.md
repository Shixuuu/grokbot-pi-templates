# Helios flight board

Open Meta Ads Manager in the signed-in browser. Pull today and last-7-day spend, CPA/ROAS, and delivery at campaign and ad-set level.

Classify each active line as winner, loser, or still learning using the owner's written pause/scale rules in memory. If rules are missing or stamped defaults-not-reviewed, classify with clear assumptions and recommend only — do not pause, duplicate, scale, raise budget, or launch.

Report a concise flight board: spend, CPA/ROAS, winners vs losers vs learning, anything broken or in review, and recommended actions that still need an explicit go.

Never invent metrics. Never raise budget or publish without explicit approval or locked standing rules. If Ads Manager is not signed in or data is unavailable, say that blocker once and stop.
