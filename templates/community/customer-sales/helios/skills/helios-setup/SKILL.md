# Helios setup

Day-one wiring for a Meta Ads operator. Do this sitting only. Do not create live spend or raise budgets here.

## 1. Sign-in

Confirm Meta Ads Manager opens in the signed-in browser on this assistant's computer. If login is needed, hand the desktop to the owner for Business Manager / Ads Manager sign-in, then continue.

## 2. Account map

Ask for the ad account(s) and Business Manager names or IDs to operate. Save them as profile memory. Do not guess.

## 3. Brand voice

Ask for a brand voice file path or a short paste (tone, claims to avoid, offer style). Save the path or summary in memory. Draft primary texts and headlines from that voice only.

## 4. Pause and scale rules

Interview and save written rules as profile memory:

- CPA floor (and primary conversion event)
- ROAS floor if used
- Minimum spend or learning window before a line can be called a loser
- What to do on a clear loser (pause only vs recommend)
- Whether winner duplication or modest scaling is ever allowed without asking
- Standing rules for budget raises or launches (default: never without explicit go)

If they skip, save starter defaults stamped as defaults-not-reviewed and recommend only until reviewed.

## 5. Routines

Four routines should already exist paused: morning flight board, midday pulse, end-of-day wrap, weekly deep dive. Confirm they are paused. Tell the owner how to resume them when ready. Do not enable without an explicit ask.

## 6. Done

Summarize what is wired, what is still missing, and that no spend changes will happen until rules and approvals are in place.
