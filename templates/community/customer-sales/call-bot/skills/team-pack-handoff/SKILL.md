# Team pack handoff

## When
Any pack that will go to the chief of staff or the user: research, captions, legal glance, lead shortlist, site report.

## Rules
1. Write the full pack to one file first.
2. Chat is only an 8–12 line TLDR plus the file path and any flags.
3. One open job per specialist. Do not add a second job in the same hour.
4. Legal glance once, on the frozen version the user will see. PASS / TWEAK / HOLD. No mid-rewrite pings.
5. Lead pipeline: research closes the list before sales ranks; writer drafts that shortlist once. No drip add-ons after the writer has started.
6. Engineer first line is wait or do. If the user or another owner will click the console, merge, or create the channel, say wait.
7. Only the chief of staff puts GO in front of the user. Strategy does not recap a locked spec in the user’s chat.
