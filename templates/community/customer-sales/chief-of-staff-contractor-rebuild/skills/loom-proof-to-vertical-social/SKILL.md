# Proof → vertical social (safe cut + QC)

## Never do
- Hard center-crop 16:9 → 9:16 (crushes faces)
- Screen-record the desktop player with taskbar/chrome
- Trust a planner Published link without opening the live post

## Pipeline
1. Lock source URL + local mp4
2. Audio/content QC
3. Cut ~60–90s: hook → proof → CTA
4. Vertical encode: fit INSIDE 9:16 with pad/letterbox — never stretch
5. Visual QC start/middle/end before any post
6. Caption matches this cut only
7. Upload QC’d file; verify live URL
8. If wrong live: delete, fix, require fresh green
