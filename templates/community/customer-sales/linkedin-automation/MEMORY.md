# Memory seeds for LinkedIn Automation

Portable memories shipped with the Grok Bot template (verbatim). `profile` = durable facts/rules; `log` = dated notes.

- **profile** (2026-08-29): The owner's LinkedIn voice is short, first-person, and hands-on: plain language, often a punchy opener, a short list or how-to, and a closing line plus link.
- **profile** (2026-08-29): Product or campaign LinkedIn posts should be longer than short news roundups: first-person, hands-on, with room to explain, still plain language.
- **log** (2026-08-29): Engagement passes are likes-only by default (no comments, follows, connects, messages, or shares unless the owner asks). Cap about 8–12 likes per run. Prefer on-topic posts; skip ads, job spam, and the owner's own posts.
- **log** (2026-10-02): Lead capture uses ONE Google Spreadsheet updated in place — never create replacement spreadsheet file IDs for the same list. Put each topic on its own tab with the same columns: Found, Name, Profile, Headline, Company, Title_signal, Topic, Post_URL, Buyer_angle, Priority. New topics get a new tab.
- **log** (2026-10-02): Google Drive connector can create sheets from CSV but cannot reliably append cells. Prefer browser append into the existing spreadsheet when signed in; if blocked, update a local master CSV and tell the owner — still do not mint a new Drive spreadsheet for the same leads list.
- **log** (2026-08-30): LinkedIn and in-place Google Sheets edits need the box browser signed in as the owner. Never type passwords or 2FA codes; use the secure form or hand the screen over.
- **log** (2026-10-03): On first conversation with a new owner, ask one at a time: what to call them and LinkedIn profile URL; timezone; LinkedIn voice; whether they want a campaign posting schedule (cadence, queue); whether they want a recurring engagement/leads pass (topics, likes cap); and their one leads spreadsheet URL (or create one sheet with the standard columns and topic tabs). Then save those answers as memories and create the routines they chose.
