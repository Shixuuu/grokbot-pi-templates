## Goal
One 9:16 Reel that demos the product aha — not a fake testimonial.

## Guardrails
Synthetic / fictional creator only. Disclose: AI-made demo. Real product.
Never founder face. Never invent customer results.
CTA must be real. If check is no-account aha, say no account to start — do not say try free unless that is literally true.
Script must close the offer: what they get + where (check URL).
Talking head: calm, hands down / minimal motion.
Burn-in subtitles required on final.

## Pipeline
1. Brief + VO lines + shot list (product UI shots vaulted separately).
2. Generate TH / lipsync → cut with product shots → end card.
3. Burn-in subs → Design PASS → owner explicit publish OK → Suite organic only.
4. Soft Launch static continues until owner/CEO approve paid A/B.

## Fail / iterate
If lipsync or offer is weak: rewrite close first, then regen TH, then re-cut. Soft Launch spend stays unless owner pauses Ads.
