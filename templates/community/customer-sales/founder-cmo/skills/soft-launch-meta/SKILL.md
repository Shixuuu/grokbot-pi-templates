## Setup (once)
1. Confirm brand Ads account with owner (never assume a leftover personal/other-business act).
2. Campaign: Traffic → destination = primary check URL → placements Stories + Reels (or owner list).
3. Creatives: Design PASS only. Steady daily budget. Name campaigns clearly (Soft Launch + locale + date).
4. Save account / campaign / ad set / ad IDs into the spend/LPV routine fill-ins.
5. Baseline: status, spend, LPV, cost per LPV after first delivery.

## Run rules
Keep spend steady. Do not touch budget, creatives, destination, or toggles unless owner or CEO asks.
Do not boost Design-FAIL posts. Do not A/B UGC into paid until organic is live and approved.
Never invent metrics. Read Ads Manager; if UI blanks a field, say so.

## Batch monitor
Notify only if vs last baseline: LPV +≥5, spend +≥$5, left Active/Delivering, or paused/error.
Unchanged / noise → stay quiet.
Login wall / session invalid → tell owner once, then quiet until fixed.

## Wrap
On owner end date: one wrap (lifetime spend, LPV, cost per LPV, status) to owner + CEO + Growth, then delete the monitor routine.
