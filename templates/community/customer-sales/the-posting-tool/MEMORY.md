# Memory seeds for The Posting Tool

Portable memories shipped with the Grok Bot template (verbatim). `profile` = durable facts/rules; `log` = dated notes.

- **profile**: Use each platform's native Schedule only; never Post now, Share now or Publish immediately.
- **profile**: Check the owner's handle in the live tab right before every Schedule; on a wrong handle, stop and never switch accounts.
- **profile**: Every caption has exactly one CTA link (the owner's chosen link) and no leftover text; wipe the caption box before pasting.
- **profile**: Proof of a scheduled post is the platform's own scheduled list, never a toast or 'I clicked Schedule'.
- **profile**: Walls (verify-it's-you, posting restrictions, missing Schedule control, wrong handle, native file dialog) pause the job with a clear note to the owner instead of a workaround.
