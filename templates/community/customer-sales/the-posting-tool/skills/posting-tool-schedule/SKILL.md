# The Posting Tool: native scheduling from your own Chrome

Free, open-source (MIT): https://github.com/okwithit9-debug/the-posting-tool. You drive the owner's already-open, already-signed-in browser and use each platform's own Schedule feature. No hosted service, no API keys for posting.

## Before the first Schedule
1. Know the owner's handle per platform, their one CTA link, and their timezone (from memory; ask once if missing). Missing = stop and ask; never invent a default.
2. Use the browser window that is already signed in. Never create a second browser profile or log in as someone else.
3. Handle-check the live tab (account chip or profile URL) right before Schedule. Wrong handle = STOP. Never switch accounts.
4. Instagram, TikTok and Pinterest need a Business or Creator account. A personal account is a wall, not a bug.

## Rules on every platform
- Native Schedule only. Never Post now, Share now, Publish immediately, or Now — not even to "recover".
- Wipe the caption box, then paste. Exactly one CTA URL. No leftover text, no second domain.
- Set date AND time, then re-read both fields before committing. Changing time often flips the date. If the requested slot didn't stick, fix it or stop; never commit a wrong day.
- Attach media with the web file input. A native OS file-open dialog with no web input is a wall.
- Walls pause with a clear note to the owner: verify-it's-you, posting restriction, missing Schedule control, stuck date picker, wrong handle, browser crash Reopen.
- Proof is the platform's scheduled list, never a toast or "I clicked Schedule".

## Per platform (commit click, then proof)
- **X**: attach video, paste caption, calendar icon, set datetime, Confirm, Schedule. Never press Escape (it opens Save post?). Proof: Drafts, then Unsent/Scheduled ("Will send on").
- **Threads**: attach video first, set topic, paste caption, header ⋯ next to Drafts, Schedule, set datetime, footer Schedule. Never Escape or cancel (it becomes a draft). Proof: ⋯ next to Drafts, then the scheduled list. The queue caps at 25; skip if full.
- **TikTok Studio**: Upload, attach, stay on the editor (leaving discards it), paste caption, When to post: Schedule (not Now), set exact minute, Schedule. Up to about 10 days out. Proof: Studio Content list.
- **Instagram**: Meta Business Suite, Schedule content (or composer Schedule if it's a real control), attach, paste, set datetime, Schedule. Hidden or laggy Schedule after a Professional convert = wall. Proof: Business Suite Planner row.
- **Pinterest**: create Pin, attach, title, description, destination link, Publish at a later date (never Publish immediately), set datetime. Up to about 14 days out. Proof: Scheduled Pins list.
- **YouTube**: Studio upload, Visibility, Schedule, date/time, Schedule. Proof: Studio content list shows Scheduled.

## Batch
Before a batch, count open slots per platform (for example "12 of 25 left" on Threads). Skip full platforms. After each item, report platform, time (owner's timezone), first caption line, and PASS (on the scheduled list with the right time and one URL) or FAIL/WALL with the reason.
