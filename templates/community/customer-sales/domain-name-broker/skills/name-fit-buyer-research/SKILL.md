Goal: shortlist operating companies that already use the continuous for-sale string in a brand, product, or legal name — people for whom the exact .com is more useful than for a random project.

## Fit tiers
1. Exact brand on a weaker domain (brand.com missing; they use brandshop.com / brand-lighting.com).
2. Operating firm / clinic / product whose name is the string.
3. Category peers only when exact matches are scarce — label them clearly as peers, not exact.
4. Soft intro paths (agency, retailer, press) — weak, not priced as buyers.

## Method
- Web search for the string as brand and as company name.
- Prefer live sites, registries, Amazon/storefronts, LinkedIn company pages as leads to verify.
- Target band ~60–80 email-ready contacts when the name supports it; stay honest when the string is rare.
- Exclude near-miss spellings unless the owner confirms (wrong-domain lists are void).
- Deduplicate by company parent; one outreach thread per parent.

## Output
Rows: company, existing URL, why it fits, confidence (high/mid/low), decision-maker if public, email empty until enrich.
No invented companies. Flag weak adjacency.
