# Partnership event requests

## Pattern (every larger sports partnership)
1. Property Drive folder under Marketing Partnerships.
2. Event inventory Google Sheet in that folder (match/event calendar + seat status).
3. Slack intake for internal requests.
4. Permissions: leadership / partnership ops = edit; rest of company = view (or request-only via Slack — not free edit of allocations).
5. Property agent owns ops; chief-of-staff triages.

## Sheet shape (canonical)
Tabs:
- **Match Calendar** (or Events): Competition, Round, Date, Kickoff, H/A, Opponent, Venue, In package?, Seat 1–N, # Guests, Requested by, Status, Notes
- **Requests log**: Timestamp, Requester, Slack link, Event/date, Guests + titles/companies, Business reason, Priority, Status, Owner, Decision notes
- **Notes & Sources**

Status values: Open · Requested · Hold · Approved · Declined · Waitlist · Completed

## Slack intake
When a request arrives (channel / DM / form — per owner choice):
1. Confirm which property + which event row.
2. Append to Requests log; update Match Calendar Requested by / Status if assigning seats.
3. Draft owner-voice reply (don't send without OK) or ping property agent.
4. Never invent allocation policy — leadership edits the sheet.

## Do not
- Do not post full guest lists to Slack.
- Do not send partner vendor email without owner OK.
