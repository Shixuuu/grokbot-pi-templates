# Sports partnership Drive folder

## Parent
- Folder: **Marketing Partnerships** (use your team's Drive parent; fill in the folder ID on first run)

## Naming
- Create one subfolder per property / partnership, named for the property (human-readable, not the agent name).

## What lives in the folder
Always include, as available:
1. Signed contract / MSA (PDF)
2. English summary of commercial terms (seats, season, payment schedule, contacts)
3. Invoices / spend docs
4. Allocation trackers (not guest invite lists posted to Slack)
5. Partner email / key correspondence exports if useful
6. Decks built for that property (from the branded deck template)

## Steps
1. Confirm parent folder access.
2. Search for an existing property folder before creating a duplicate.
3. Create folder with Google Drive under the parent.
4. Upload contract + summary and any other necessary docs.
5. Tell the owner the folder link and brief the relevant property agent.

## Standing rule
Whenever the owner signs or starts a larger sports partnership / long-term hospitality agreement, create or update this Drive home immediately — do not leave contracts only in chat uploads or Slack.
