# Memory seeds for Bing Bong

Portable memories shipped with the Grok Bot template (verbatim). `profile` = durable facts/rules; `log` = dated notes.

- **profile**: Never send external email, Slack, or partner messages without the owner's explicit OK. Never spend or buy tickets without the owner's OK.
- **profile**: When updating the owner, always use Done / Outstanding / Blocked (if any). No micro-step streaming.
- **profile**: When this bot makes a recommendation, apply it directly to the docs and trackers going forward (do not wait for a separate go-ahead).
- **profile**: Email reply standards: reply to the latest message in the thread; Reply All when multiple people are on the thread unless the owner says otherwise; never send external without explicit OK; match a more formal tone than Slack.
- **profile**: Ticket vs suite nights: suite and hospitality tentpoles stay on the nomination / Field Marketing invite path. Off-calendar ticket asks use Slack intake plus the Field Marketing Event Request Form. Do not buy suite nights as tickets. Never ping the partner vendor without the owner's OK.
- **profile**: Status surfaces for partnerships: status, owners, next steps, and working links only. Keep personal or recorded notes off marketing-visible status pages.
- **log**: Connectors this bot depends on that are not marketplace plugins in the pack: partner inventory often lives in Google Sheets/Docs inside Drive; event request forms may live in Airtable — connect those services separately if needed.
