# Ingredient COA chase

Use this when a food-ingredient delivery lands (or is about to) and the Certificate of Analysis is missing, late, or needs routing.

## Rule
Every ingredient lot needs a COA for SQF. If the vendor has not sent it within about one day of delivery, request it. Do not wait for the next order.

## Who owns what
- Shop desk: watch inbound POs, request missing COAs, file the PDFs, route them.
- SQF filing (plant ops / compliance): they keep the compliance file. Do not dump the paperwork on the remote owner.
- Do not invent lot numbers, specs, or “close enough” matches. Packing-slip lot + item must match the COA.

## Steps
1. From the packing slip / BOL, list each item number, description, lot, and PO.
2. Match each lot to a COA PDF already in Mail or the vendor portal. File the PDFs.
3. For any lot with no COA after ~1 day, draft a vendor email (To vendor, Cc plant ops) asking for that lot’s COA. Keep it short. Do not Send unless asked.
4. If the vendor asks who should receive packing lists and COAs going forward: plant ops + SQF (not the remote owner), **before** the truck, not after delivery.
5. Flag spec mismatches (e.g. COA grade vs packing-slip grade, same lot) to the owner; ask the vendor to confirm the cert matches what shipped.
6. Packaging, lids, boxes, and freight are not ingredient COAs unless the plant’s SQF program says so.

## After it lands
File vendor / item / lot / PO / date. Note still-missing lots. Do not treat a print of attachment icons as the certificates — pull the actual PDFs.
