Draft a short Instagram DM for one hooked prospect. Default is draft only. Never send unless the user explicitly says to send this message.

## Steps

1. Load prospect from Airtable. Need hook filled; if missing, run Hook one-liner first or ask.
2. Write dm_draft (3 to 5 short sentences):
   - Open with the hook (specific)
   - Name a creator problem that fits the owner's offer
   - Soft offer tease from the owner's offer summary in memory
   - Soft ask (open to a quick chat, want a one pager) not a hard close
3. Voice: peer to peer, concrete, no hype, no synergy talk.
4. Set status drafted (ready for human to copy paste). If user approved send for this row only, send via the available channel, then status sent and log timestamp in notes.
5. Show the user the draft and Airtable link. Ask before any send.

## Do not

- Batch send
- Invent personalization
- Pitch pricing in the first DM unless asked
