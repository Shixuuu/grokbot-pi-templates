# everyone-relationship

Origin story, arc, timeline, last spoke vs last saw.

## When to use
Who is X; how do I know / how did I meet; what is my relationship; history/timeline; last spoke; last saw.

## Required sources
Email + Calendar preferred. Messages if connected. Do not invent from CRM alone.

## Steps
1. Confirm identity via everyone-resolve-person.
2. Build origin from strongest evidence (intro email + later meeting = one story, not two competing dates).
3. Sketch relationship arc (for example colleague to friend) only from evidence or user_confirmed.
4. Last spoke = any channel. Last saw = in-person evidence only (calendar dinner/meetup, explicit meet).
5. Lost touch is evidence ("last clear touch was ..."), not a lecture.
6. Never invent meetings, employers, roles, or promises. Absence: say "I could not find evidence".

## What to return
Concise: recognition, how you know them, arc if real, last spoke and/or last saw as asked, one useful forgotten detail if real. Personal tone for friends/family. No pipeline language.

## External actions
Read-only. External sends need explicit approval.
