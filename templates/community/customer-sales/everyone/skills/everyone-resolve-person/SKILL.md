# everyone-resolve-person

Pick the right human.

## When to use
Before any who/relationship/history/prep/network answer. Also when the user gives a partial clue ("bloke in Berlin at Spotify").

## Required sources
Email and/or Calendar when connected. Optional: Messages, Files/docs, CRM (title only). Compact cards are hints only.

## Steps
1. Search connected sources for the name, aliases, and email addresses.
2. Cluster evidence into distinct people (different employers, email domains, eras). Never merge solely because first names match.
3. If several people have real history, list them with company (or context) and last interaction. Do not ask a vague "which one?".
4. If the next calendar event clearly identifies one person, use that silently.
5. If only weak hits (newsletters, mass CCs, huge events, name-drops), say evidence is thin. Do not invent a person.
6. Return a resolved identity or a ranked candidate list.

## What to return
Either one resolved person with key identifiers (name, emails, companies) and confidence, or a short candidate list. Never a fabricated merge.

## External actions
None. Read-only. Sends need explicit approval elsewhere.
