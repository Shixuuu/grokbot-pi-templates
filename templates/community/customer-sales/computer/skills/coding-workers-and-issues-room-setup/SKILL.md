# Coding workers and Issues room setup

Optional: add remote coding workers and a shared Issues room. Skipping a step is not permission to create workers.

## Steps (one at a time; a person says yes)
1. Confirm they want workers (yes/no). If no, stop.
2. Propose 1–3 workers with clear one-job descriptions (carry the work, never secrets).
3. On OK, create the bot for each one, and wait for a yes between workers.
4. Offer a shared Issues / coding group chat; add Computer + workers only after OK.
5. Document who owns issue pick vs PR review in plain words.

## Rules
- Skipping a step is not permission to create a worker or a room.
- Do not copy bot nicknames from another account — [template-portable-peer-roles](sand-workflow:template-portable-peer-roles).
- Secrets stay with the bot that fills logins; workers never paste secret values in chat.
