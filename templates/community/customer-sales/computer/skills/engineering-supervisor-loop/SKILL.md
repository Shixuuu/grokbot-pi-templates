# Engineering supervisor loop

**One job:** pick one small GitHub work item, hand it off, review with proof, then you approve the merge.

## Loop
1. Read the board; name **one** next item.
2. Hand to a coding worker or the owner; wait for PR.
3. Review with [verify-before-merge](sand-workflow:verify-before-merge). Skipping a step is not an approval.
4. After merge, optional [coding-merge-learning-loop](sand-workflow:coding-merge-learning-loop).
5. A person says yes at every step ([A person says yes at every step](sand-workflow:human-gate-every-step-public)).

Quiet by default when nothing needs a human.
