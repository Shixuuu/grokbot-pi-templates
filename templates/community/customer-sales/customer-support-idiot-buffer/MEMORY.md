# Memory seeds for Customer Support Idiot Buffer

Portable memories shipped with the Grok Bot template (verbatim). `profile` = durable facts/rules; `log` = dated notes.

- **log** (2026-09-03): Grok Voice ↔ Twilio bridge hangup gate: hang up only after the errand success or a clear dead-end is confirmed; never mid-ID / mid-reference / on hold. The voice model may request hangup; the operator (or bot) must approve before the Twilio leg ends.
- **log** (2026-09-03): Outbound voice stack: Node bridge that connects Twilio Media Streams (μ-law 8 kHz) to xAI Grok Voice realtime (wss://api.x.ai/v1/realtime?model=grok-voice-latest, audio/pcmu). Place calls with POST /call; expose PUBLIC_HOST over WSS (e.g. ngrok) so Twilio can reach /media-stream.
- **log** (2026-09-03): Coach mode pattern: poll a live transcript (them vs agent), accept steer text from the operator in chat, POST /steer so Grok updates mid-call without announcing that it is being coached. Operator does not need to hear raw call audio.
- **log** (2026-09-03): Enable Twilio dual-channel recording on every outbound bridge call so recordings can be pulled by call SID from Twilio Monitor → Logs → Recordings.
- **log** (2026-09-03): Prefer a custom Grok Voice clone from the xAI console for outbound calls that should sound like the user. Grok Voice Agent Builder free numbers are mainly inbound; Google Voice is a poor fit for this bridge. Keep Twilio and xAI secrets in .env only — never in chat.
- **log** (2026-09-03): Hold-music / IVR: raise VAD threshold and silence duration so hold music does not trigger endless agent speech; cancel in-flight responses while hold music is detected.
- **log** (2026-09-03): Non-marketplace services this bot uses: xAI Grok Voice (realtime WebSocket API) and a self-hosted Node Twilio Media Streams bridge. Twilio marketplace plugin covers Twilio APIs; the bridge itself is local code, not an MCP server.
- **log** (2026-09-04): Optional connective pieces for this bot: prefer the Twilio marketplace plugin for Voice/Messaging APIs; acceptable alternatives when Twilio is unavailable include Sinch (SMS/WhatsApp/voice), Inkbox (email/SMS/iMessage/voice), and Cartesia (TTS/STT/voice cloning). Treat each as optional — install only what the errand needs. The self-hosted Node Media Streams bridge and xAI Grok Voice realtime remain the call path regardless of which marketplace connector is present.
- **log** (2026-09-04): First-run setup skill: before any outbound call, define errand goals and success criteria with the operator, choose a Grok Voice clone from the xAI console when the call should sound like the user, confirm which optional connectors (Twilio preferred; Sinch/Inkbox/Cartesia acceptable) are installed, and verify bridge PUBLIC_HOST plus .env secrets — never put secrets in chat.
