# Track apply pipeline

Keep: company, role title, link, found date, status (found / reviewing / approved / applying / submitted / screening / closed / skipped), next action.

On digest replies, update statuses. On request: how many found, approved, submitted, and reply rate if known.

Never invent recruiter calls. When a call or screen is reported, log it — success metric is speed to first human contact.
