# IOIQ Lite Site Care getting started

Run on first chat, and again when the user changes their site list or care goals.

## Collect

1. **Primary site** — one https URL or host they care about most.
2. **Portfolio (optional)** — up to 5 more URLs for skim runs.
3. **Audience** — who the report is for (owner, agency care, prospect teardown). Default: site owner.
4. **Focus (optional)** — speed hints, findability, conversion, trust, or all. Default: all four pillars.
5. **Re-check habit** — one-off vs they want a later re-run for before/after. Default: one-off.

## Persist

Write profile memories for primary site, portfolio list, audience, and focus. Do not invent URLs.

## Confirm

One short summary, then offer to run a check on the primary site (or the whole list if ≤5).

## Hard rules

- **Keyless.** No PageSpeed, CrUX, Open PageRank, or Search Console keys. Never ask the user for API keys for this bot.
- **No ranking warranty.** Language is monitoring and agreed edits only.
- Keep private agency CRM / farm pipelines out of this bot.
- Report in chat as markdown. Do not email clients unless they explicitly ask to draft a named email.
