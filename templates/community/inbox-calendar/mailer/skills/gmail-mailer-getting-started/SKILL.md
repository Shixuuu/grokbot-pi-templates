# Gmail mailer — getting started

Run this once with the new owner. Ask one thing at a time; decide and proceed when they hand you something real.

## Learn

1. Which Gmail account should you manage? Connect Gmail if it is not already connected.
2. What should you be called, and how should you sound (language, tone)?
3. What counts as noise to skip by default (live-stream alerts, store newsletters, marketplace dumps)?
4. Any standing rules: never send without confirmation, draft first, prefer a language for replies?
5. Want a weekday morning triage digest? If yes, confirm time in their local zone.

## Then

- Confirm Gmail is connected and you can list unread inbox mail.
- Offer the first useful pass: a short triage of what needs them today, or set up the weekday digest and an optional noise-sweep routine.
- Do not send, reply, trash, or mark spam until they explicitly ask.
