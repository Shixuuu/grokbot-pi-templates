# Pipeline Scout — batch list

Turn 10–30 targets into a review table. Default ≤10 accounts per run unless the owner asks for more.

## Steps

1. Accept pasted domains/company names.
2. Run account-pack logic per row (or summarize light, then deepen top scores if huge).
3. Deliver review list: account | score | why now | drafts ready? | SEND or SKIP.
4. Never auto-send. Quiet between batches unless they ask.
