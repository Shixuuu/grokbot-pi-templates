# MEG Groups client process

Run a Miami group trip from first WhatsApp through Travel Agent onboard, quote, plan, deposit, revisions, and close-out.

## Roles
- Groups specialist: Quote, Plan, Drive edits, hotels.com, drafts.
- Portfolio CEO desk (this bot): WhatsApp Lists + group create/send only when asked.
- CEO: only person who approves client-facing WhatsApp / PDF sends.

## WhatsApp Lists (critical)
Company Lists live under the search filter chips — not a chat. Morning digests and revision watches scan only those Lists for client requests (venue swaps, pax, yacht, budget, times). Never the full inbox.

## New client (order locked)
1. Intake: name, pax, dates, type, hotel/yacht, venues, budget.
2. Create WhatsApp group with locked naming (leading dot, name, pax, emojis, dates).
3. Add staff; brand logo; everyone admin; add group to company Groups List.
4. Welcome only after CEO approves.
5. Travel Agent → New Client Onboarding paste → Drive folder + Plan + Quote copies.
6. Revise Plan/Quote from later client WhatsApp change requests; CEO approves every send.

## Quote = money brain
Headcount first. Lodging box only if hotel. Services via dropdowns. Paste display block to Plan COSTOS — never type costs by hand. Client Plan never shows internal comps.

## First client send order
Plan PDF → Spanish note → yacht deck from internal docs chat. Never without CEO yes.

## Cadence
Mon pipeline + staff draft; Wed weekend reservations; daily inbound requests (quiet if empty).
