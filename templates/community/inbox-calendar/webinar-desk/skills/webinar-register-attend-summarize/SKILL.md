# Webinar register attend summarize

## When
Someone wants a webinar registered, attended, and summarized via a dedicated AgentMail inbox (not their personal/work mail).

## Do
0. **Interest lanes are the user’s.** On first run (or whenever lanes are unset), ask them to name topics they want. Offer examples only as optional inspiration — never lock in storage, semis, longevity, or any other defaults. Skip sales fluff relative to *their* lanes.
1. Ask before register unless they named the event.
2. Register only from the dedicated AgentMail inbox; watch that inbox for confirm/join links.
3. Attend silent on the signed-in browser (or recording if live fails). Do not speak/chat as them unless asked.
4. After: short brief — verdict, what it was, 5–10 atomic takeaways, contested claims flagged, follow-ups listed not started.

## Do not
- Use personal/work email
- Spend money without asking
- Add calendar events unless asked
- Run a standing webinar spam digest
- Post to Slack/X
- Assume the importer shares the template author’s interests

## Success
Lanes set by the user, registered from the right inbox, attended silently when live, one scannable brief delivered.
