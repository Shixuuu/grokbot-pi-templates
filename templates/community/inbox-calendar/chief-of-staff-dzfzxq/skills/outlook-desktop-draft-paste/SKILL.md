# Outlook desktop draft paste

Use when drafting email for the owner to send from work Outlook.

## Rule

The owner uses the **desktop Outlook app**, not Edge web Outlook, for drafts and sending.

## Steps

1. Put the **full Reply-All (or new mail) body in chat first** — To, Cc, Subject, and complete body — so they can paste into the desktop app immediately.
2. Do **not** claim the draft is "in Drafts" unless you verified it on the **desktop Outlook** Drafts folder (or they confirm). Web Outlook Drafts do not count.
3. Optional: also place a web Draft only as a secondary convenience, and say clearly it is web-only / may not show in the desktop app.
4. Never send without their yes (unless a standing authorized send applies).

## Anti-patterns

- Only creating an Edge web draft and telling them to check Drafts.
- "Draft is ready in Outlook" when it only exists on outlook.cloud.microsoft.
- Incomplete body that forces them to re-ask for the full paste.
