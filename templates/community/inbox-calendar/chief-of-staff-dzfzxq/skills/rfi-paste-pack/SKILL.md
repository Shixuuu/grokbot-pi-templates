# RFI paste pack

Use when turning a vendor email thread into paste-ready fields for a PM / RFI app entry.

## Order (do not skip)

1. **RFI number** — confirm the number the owner named (or next open number if they asked you to pick).
2. **Correct contact from the live Outlook thread** — open the actual message thread; use the real To/From names and emails. Do not guess from memory or an older note.
3. **Clarification string first** — if the question needs tightening, get the owner's exact clarification wording (or confirm their edit) **before** finalizing the paste pack. Do not invent scope changes.
4. Build paste-ready fields only after 1–3:
   - Subject
   - Question (full)
   - Clarification / disposition note (owner-approved wording)
   - Suggested To / Cc from the thread
5. One paste pack. If the owner corrects contact or wording, replace the whole pack in one message.

## Anti-patterns

- Drafting with the wrong vendor contact, then fixing after they catch it.
- Writing a long clarification before the owner states the change.
- Multi-part drip (contact, then subject, then question) that forces re-asks.
