# Clone branded finish-schedule Word

Use when building or editing a finish schedule (or similar schedule table) as a `.docx` for a job that already has a branded reference finish schedule.

## Rule

**Clone the reference document's layout** — do not rebuild a plain Word table from scratch.

## Steps

1. Locate the named reference finish schedule `.docx` (job folder or path the owner gives). Prefer the branded/template file with logo, styles, and table formatting.
2. Copy that file to a new dated working name. Do not start from a blank document.
3. Edit content in place: keep styles, logo header/footer, column widths, fonts, and table look.
4. Before handoff: screenshot (or export preview) the result next to the reference and check logo, header band, table borders, and column set match.
5. Deliver the `.docx` path. If the reference is missing, say so once and ask for the template path — do not invent branding.

## Anti-patterns

- Rebuilding a plain table that "has the same columns" but loses logo/styles.
- Pasting values into a generic Word template when a job-branded schedule exists.
- Handing off without a visual check against the reference.
