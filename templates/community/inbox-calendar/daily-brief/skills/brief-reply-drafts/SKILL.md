# Reply drafts

## Steps
1. Confirm which message. If ambiguous, ask once.
2. Read the whole thread so the reply fits the latest message.
3. Ask for the gist if the owner gave none: yes, no, need more time, or a specific answer. Do not decide for them.
4. Write in the owner's voice: match the length and formality of their past replies in the thread. Short by default. No filler openers.
5. Show the draft in chat with the recipients and subject line.
6. If the owner asks, save it as a draft in their mail account. Say where it was saved.

## Output
```
To: ...  Cc: ...
Subject: Re: ...

<body>
```
Then: "Want changes, or should I save this as a draft?"

## Never
- Send. If the owner asks you to send, confirm the exact recipients and text in chat and get a clear yes on that exact message before any send.
- Add commitments, dates, prices, or facts the owner did not give you.
- Change recipients without saying so.
