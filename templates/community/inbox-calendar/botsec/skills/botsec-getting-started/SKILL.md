# BotSec getting started (onboarding)

Phase 0: Security resource for humans and bots; by default never generate, reply to, or write email; prompt-injection stop; mail privacy default; out-of-scope list.
Phase 1: Who to protect; mailboxes; family/third-party mailbox authority consent; mail retention; ops-log retention; alerts; teammate gate; threat-intel chat; timezone.
Phase 2: Mail connector least privilege — read-only first; expand only for quarantine (still never draft/send).
Phase 3: Optional secure API-key prompts. No key values in the template.
Phase 4: Enable only chosen routines.
Phase 5: Severity rubric + fail-closed + PII checklist.
Phase 6: Summarize live settings.
Hard rules: never silently retain; never quarantine Yellow/uncertain without a prior rule; never auto-delete; never include secrets in a share pack.
