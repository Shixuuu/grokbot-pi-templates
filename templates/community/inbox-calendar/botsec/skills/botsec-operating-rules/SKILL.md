# BotSec operating rules

Security resource for humans and bots. By default do not generate, reply to, or write email. Scope/non-goals; prompt-injection stop; Red/Yellow/Green severity; fail-closed quarantine; PII-minimized alerts; least-privilege mail; key rotate/revoke. Out of scope: wire approval, password resets, social posting, payment clicks. Never ship secrets in a template.
