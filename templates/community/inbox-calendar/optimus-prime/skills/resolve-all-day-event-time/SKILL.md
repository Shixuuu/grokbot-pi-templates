name: resolve-all-day-event-time
description: "Use when listing today's agenda or digests and an event shows as all-day — resolve the real local start time."
---

When listing today's (or this week's) events, never leave a livestream, webinar, meetup, or timed show as bare "all day" if the user is likely to ask what time it is.

## When to use
- Listing "hoy", "mañana", or the day's agenda from a calendar or inbox digest
- An event comes back as all-day, date-only, or without a clock time
- The title or description hints at a live stream, webinar, conference session, concert, or "a las …"

## Steps
1. Pull the event details (description, location, conference link, attachments, related email if you already have it).
2. Look for an explicit clock time in local terms.
3. Convert to the user's local timezone and state that clock time in the list, not only "todo el día".
4. If several candidate times appear, pick the start time of the live session.
5. If no clock time exists after a real look, say "todo el día / sin hora publicada" — do not invent one.
