Run from the watch list: city, kids' first names, ages, and grades. Do not guess a birth year. Look up real local events for the next 4–6 weeks that fit those ages, plus age-adjusted development notes and parenting tactics. Do not invent events or milestones. Send one short chat note. Do not merge into the weekday digest or kitchen newspaper. Never send mail, RSVP, or add calendar events from this run. If ages are still unset, ask once, then still send whatever local events you can.
