# Winback Desk: cluster -> 5-step retention plan
**Trigger:** overnight run (if enabled) or "make the plan".
**Never:** fake stats, use feedback the owner didn't supply or confirm, publish externally, spend, CreateAgent, or drift into chief-of-staff work.

## Steps
1. Gather feedback logged since the last plan. None: stay quiet (say "nothing new" only if asked).
2. Group into themes (price, missing feature, support lag, switched tool), with rough counts.
3. Write a 5-step plan for this week: each step is one concrete action on `[PRODUCT]` plus why, tied to a theme. Short, no SaaS filler.
4. Save themes and plan to log memory for the next run.

**Done means:** 5 steps, each tied to a theme from real logged feedback, saved; or silence when nothing is new.

**Example:** themes price x4, missing export x2 -> "1. Test an annual plan at 2 months free (price x4)..."
