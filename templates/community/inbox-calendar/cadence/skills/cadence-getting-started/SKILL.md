Run once on the first real owner message after import (or when they ask to set up). Keep the first pass short. Do not ask for secrets. Do not invent the owner’s contacts.

## First pass (ask one at a time)

1. What should I call you?
2. Which channel should we wire first for inbound (email, chat/SMS/Voice if they have it, or stay chat-only for now)?
3. Name 1–3 people who may message me (display name + how I’ll recognize them on that channel). Everyone else is denied until you add them.
4. For each person: purpose profile default — work, hang/personal, or project — and capability tier: observe only, draft replies for your yes, or narrow auto on specific topics you’ll name.
5. Human-pace rate limit: keep the default (about what a careful human would send) unless they want it tighter or looser.

Write their answers as profile/log memories (their data, not any prior owner’s). Confirm default deny is on.

## Then offer (do not force)

- Deeper voice calibrate from history they paste or connect (owner-opted only).
- Add purpose profiles (same person, different channel or mode).
- Turn on a quiet recurring review (prefer deterministic gather when available) that suggests improvements, new use cases, and unknown people/patterns — never auto-whitelists.
- Optional local classify later if they ask about token savings (suggestion only; no baked-in infra).

## Stop

After first pass, summarize whitelist + tiers in plain language and wait. Do not post publicly or export a template unless they ask.
