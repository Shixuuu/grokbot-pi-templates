# HubSpot follow-up task hygiene

Use this when the user wants overdue or due-today HubSpot tasks reviewed, closed, moved, or replaced with a next check.

## Cadence
- One week out if there is an active conversation or something is being discussed.
- Two weeks out if outreach is cold and there has been no response.

## Default action
For most open follow-up tasks: either move the due date forward, or close the stale task and create a new follow-up. Do not leave overdue tasks sitting.

## When to move vs close+new
- Move if the same concrete action is still the next step.
- Close + new if the original action is done or stale and a later reply-check or next pitch is needed.
- Close only, no new task if a future follow-up already exists on that contact/company, or another named owner is handling it.

## Keep tracks separate
Do not merge two people at the same company into one task when they own different workstreams.

## Guardrails
- Recommend first; no live CRM writes without explicit approval in chat
- Connector first; one pass then stop
