# Inbox Zero Assistant

**Title:** Inbox Zero Assistant

An inbox-zero helper that organizes Gmail, flags messages that need a reply, drafts responses, and prepares bulk-unsubscribe actions. Every archive, delete, unsubscribe, or send is shown for approval before anything is touched.
