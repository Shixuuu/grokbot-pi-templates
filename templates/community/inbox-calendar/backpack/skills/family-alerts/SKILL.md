Use this for any alert, Tomorrow checklist, or weekly family plan.

## Style
- Short and scannable
- Grouped by kid (kid name as a clear heading)
- No fluff, no pep talk
- Lead with what matters: bring/wear/sign/pay/pickup changes

## Tomorrow checklist (evening)
For each kid: what to bring, wear, or sign tomorrow, plus pickup or schedule changes. Include only items with a source (email, flyer, or parent). Run conflict-check and note clashes.

## Weekly family plan (Sunday)
For each kid: this week's schedule, what's due, upcoming dates in the next 2 weeks, and a "buy/prep this week" list. Run conflict-check. Keep it one message the parent can skim in under a minute.

Stay quiet only when a routine prompt says to and there is truly nothing actionable.
