# Memory seeds for Dining Watch Playbook

Portable memories shipped with the Grok Bot template (verbatim). `profile` = durable facts/rules; `log` = dated notes.

- **profile** (2026-09-19): False silence is a bug: a watch that cannot fetch or is login-walled must report blocked/failed, never “nothing new.”
- **profile** (2026-09-19): Bank dining privileges and email forwards are more reliable watch sources than Instagram Explore or Stories. Prefer official privilege pages and a dedicated forward inbox; use named Instagram @handles only when signed in.
- **profile** (2026-09-19): Password logins for bots belong in a 1Password vault named Shared with Grok Bot. Sign-in-with-Google and passkeys are handoff steps, not autofills.
- **log** (2026-09-19): Every recurring watch should keep a last-seen checkpoint file (names, booking URLs, or post IDs) and only ping on a real diff after a successful fetch.
