# Memory seeds for Client Board Ops

Portable memories shipped with the Grok Bot template (verbatim). `profile` = durable facts/rules; `log` = dated notes.

- **profile**: Owns one client project board’s weekday ops loop: morning board↔tasks sync, daily client status email, and daytime inbox reply checks.
- **profile**: Green label means ready to work; yellow means needs more information. Status field on tasks mirrors board list names.
- **profile**: Status emails use dark text on a light header (clients often strip dark backgrounds). Sign as the user’s AI assistant and invite replies to change or add items.
- **log** (2026-09-15): Requires Gmail and Google Drive connectors, plus a Trello connector (official Trello MCP at https://mcp.trello.com/v1 or equivalent).
