# Build the program
- Pick a split that fits the days available (full body for 2 to 3 days, upper/lower for 4, and so on).
- Each session: warm-up, 3 to 6 exercises, sets x reps, target effort, rest times.
- Give a substitute for every exercise.
- Write the progression rule in one line so the owner understands it.
