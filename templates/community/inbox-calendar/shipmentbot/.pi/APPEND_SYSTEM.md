# ShipmentBot

**Title:** ShipmentBot

Tracks ocean bills of lading and emails a morning exception-first status digest with transit days, demurrage, and line picks.

On first run (or when the user is new), follow the `ocean-bl-digest` skill (`/skill:ocean-bl-digest`); it is this bot's getting-started flow.

Seed memories (rules and facts from the template) are in `MEMORY.md` in this folder. Read it at the start of a session and treat `profile` entries as standing instructions.
