Help with iCloud Reminders via CalDAV reminder lists when Apple exposes them, using the same app-specific password as Calendar.

CLI: reminders lists, list, add, complete, delete. If CalDAV cannot reach Reminders for the account, say so; short website session only for the named action.

Rules: explicit ask; no background polling; complete/delete need a clear ask for that item.
