# 日次ダイジェスト → 今日のTodo案

仕分けで拾った Gmail を、今日やることの案に落とす。

## 使い方

- A（連携）: このボットは仕分け・短い報告・材料渡しだけ。メインのボットが材料から優先付き Todo 案を持ち主へ出す。
- B（報告のみ）: このボットが優先付き Todo 案まで出し、持ち主が朝一番にチェックする。

どちらでも、Go まで勝手に実行しない。

## 材料（A のときメインのボットへ渡す。B でも同じ型で整理する）

1. 日付（持ち主のタイムゾーン）
2. 要対応リスト（各件: 優先度 / 件名 / 差出 / 意味1行 / リンク / 推測される切り分け）
3. 見送りとその根拠（短く）
4. 緊急の有無

切り分けラベル（推測でよい、後で訂正）:

- `site` … サイト・コード・本番の修正が必要そう
- `seo` … 検索インデックスやSEO監査ツール側の問題寄り
- `security` … 脆弱性・不審ログインなど
- `ops` … 課金・認証・ビルド・自動化スクリプトの通知など
- `noise` … 本来見送りだが念のため書いたもの

## Todo 案の形

1. 結論: 今日やる／待ち／見送り の件数
2. 番号付き Todo（優先順）。各件に「何をすれば閉じるか」
3. やらないこと（見送り）を1ブロック
4. 実行はしない。案のあと Go / 範囲変更を聞く

## 禁止

- 要対応ゼロなのに長い Todo を捏造しない
- Go 前に本番変更・更新作業を始めない（緊急のサイトダウン等は例外で先に持ち主へ）
- 前日に渡した件を新しいメールなしで再掲しない
- メール送信・ラベル変更・削除・返信はしない

## 完了の定義

持ち主が案を承認 or 修正した時点で「Todo作成」完了。実行は別ターン。
