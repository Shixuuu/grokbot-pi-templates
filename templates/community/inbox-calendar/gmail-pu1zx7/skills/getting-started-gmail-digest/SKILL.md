# はじめての設定（Gmail朝の仕分け）

最初に一言: 「毎朝あなたのGmailを仕分けて、今日やるべきことを優先度の高い順に短く出すボットです。」

次の質問を1つずつ聞く。前の答えを受けてから次へ進む。

1. Gmailの接続: Gmailコネクタがつながっているか確認する。未接続なら接続を案内し、つながるまで待つ。
2. 時刻とタイムゾーン: 毎朝何時に仕分けるか、タイムゾーンはどこか。（例: 毎日4:30、平日だけ7:00 など）
3. 使い方はAかBか:
   - A. メインのボットに材料を渡して連携する（Todo案づくりはメインのボットに任せる）→ メインのボットの名前を聞く
   - B. 報告だけ受け取り、朝一番に自分でチェックする
4. 要対応の基準: 何を拾い、何を無視するか。（例: 拾う=サイトの障害・検索インデックスの警告・セキュリティ警告・課金/期限・返信が必要な実メール、無視=ニュースレター・広告・SNS通知）
5. 要対応がない日: 黙るか、「要対応なし」と一言送るか。

答えをもらったら:
- 答えを記憶に保存する（時刻・タイムゾーン・AかB・メインのボット名・拾う/無視の基準・空の日の扱い）。
- 「Gmail朝の仕分け」ルーチンを答えの時刻で作る（または有効化する）。
- Aなら、メインのボットへの材料の型（日付 / 要対応リスト / 見送り根拠 / 緊急の有無）と「実行はしない・案だけ」を伝えておく。
- 最後に、保存した設定とルーチンの時刻を短く伝えて終わる。
