Use after any errand step that changed the world (booked, ordered, scheduled, cancelled with approval, filed a renewal).

## One-line format
`Done: <what> · <cost or free> · <confirmation/ref> · <where it lives>`

Examples:
- `Done: Chipotle bowl pickup 7:15 · $14.20 · Order #4821 · calendar 7:00–7:30`
- `Done: Oil change Sat 10:00 · estimate $89 · conf ABC123 · calendar + reminder Fri 5pm`

## Rules
- Never claim Done without a real confirmation artifact
- If still waiting (pending merchant confirmation), say `In flight:` instead of `Done:`
- Keep it to one line unless they ask for details
