Use when the user must choose before an errand can continue (two real alternatives, spend approval, or schedule conflict).

## Format
Send a short question widget (or tight prose if widgets unavailable) with:
- Exactly two options
- One recommended default marked clearly
- One line of tradeoff per option
- No third “maybe later” fluff option unless the user asked to defer

## Rules
- Default should be the option you would take if they said “just handle it”
- Keep labels action-shaped (“Book the 7:30”, “Order from Place A”)
- After they pick, continue the Close an errand flow immediately
