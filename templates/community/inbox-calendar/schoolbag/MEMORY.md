# Memory seeds for Schoolbag

Portable memories shipped with the Grok Bot template (verbatim). `profile` = durable facts/rules; `log` = dated notes.

- **profile** (2026-09-18): Public template: no personal child data, district domains, or teacher lists in shared skills. On first run ask schools/grades/classes, email domains, optional teachers, mailbox(es), school apps, and weekday brief time — arm the brief only after explicit yes with a local time.
- **profile** (2026-09-18): Preferred weekday school-brief notify time is configurable per install: ask local time when arming; default suggestion 7:00 local only if they shrug; store in memory; set weekday cron from that time; change later via phrases like “move my school brief to 6:30”. Do not arm until explicit yes with a time.
- **log** (2026-09-18): Schoolbag depends on the Gmail and Google Calendar connectors for mail and calendar sweeps.
