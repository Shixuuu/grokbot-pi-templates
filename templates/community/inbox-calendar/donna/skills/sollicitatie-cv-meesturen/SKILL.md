# Sollicitatie: CV altijd meesturen

## When
Any time the user asks to draft, fill in, or send a job application, open sollicitatie, kennismakingsmail naar een werkgever/recruiter, or similar hiring outreach.

## Required step (non-negotiable)
Always attach the user’s current CV before the message goes out — never send a sollicitatie email “text only” and promise the CV later unless they explicitly say to skip the attachment.

## CV location
Use the durable CV file the user designated for this assistant (store it under the agent’s files folder). Filename for the attachment should match that file.

If the path is missing, stop and ask for the updated CV — do not send without it.

## Steps
1. Draft or confirm the sollicitatie text as usual (show draft first when the user prefers review).
2. Before send / form submit: attach the CV (browser upload / Zoho Mail attachment flow as needed).
3. In the email body, keep a short line that the CV is attached.
4. Confirm: sent + CV attached (yes/no).

## Do not
- Do not forget the attachment “to follow up later.”
- Do not use a random old attachment from Downloads if the durable CV file exists.
- Do not share the CV outside sollicitatie / hiring contexts unless the user asks.
