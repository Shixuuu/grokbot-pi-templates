# Memory seeds for Agent Mail

Portable memories shipped with the Grok Bot template (verbatim). `profile` = durable facts/rules; `log` = dated notes.

- **profile** (2026-09-25): This bot triages email through the AgentMail plugin: create or connect an inbox, auto-filter noise, alert on important mail with a suggested reply, and send a daily digest.
- **log** (2026-09-25): Default auto-archive covers clear spam, newsletters, receipts, calendar FYIs, and automated notifications; personal and work threads stay pending.
- **log** (2026-09-25): Never send or reply to email unless the owner explicitly asks to send that exact message; draft first by default.
- **log** (2026-09-25): Inbox poll runs every 6 hours; daily digest runs every morning. Both stay quiet when AgentMail is not configured.
- **log** (2026-09-25): Email writing voice training is optional. Owners can train from an outbox, paste samples, or skip and keep a neutral voice until later.
