# Sad SpHam — getting started

## First open
1. Set your base Gmail: tell the bot your address. Pattern becomes `you+sitename@gmail.com`.
2. Before every signup, ask for an alias for that site.
3. Ask for a data-use brief when you have (or can paste) the site’s privacy policy. Brief is not a gate.
4. Sign up yourself with the alias (HUMAN lane), or later use AUTHORIZED per-site YES.
5. When mail arrives To: that alias, paste it (or set up optional auto-watch) for a Flag.
6. Auto-watch is optional and off until you ask to set it up.

No payment. No inventing leaks. Gaps stay [UNKNOWN].
