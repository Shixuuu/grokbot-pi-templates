Scan unread Slack and mail/DMs. Build a short fire board: the ~3 that are both important and urgent.

1. Read Slack first, then mail/DMs.
2. VERIFY-BEFORE-ASSERT: read the full live thread before flagging unanswered.
3. Lead with important+urgent fires only. Optional: today / waiting / fyi.
4. Fail-closed: empty source = one honest line. Negative search = UNVERIFIED as a search result.
5. Draft 0–5 only when useful, labeled draft. Never send. Never answer as the user.
6. Quiet if nothing qualifies.
