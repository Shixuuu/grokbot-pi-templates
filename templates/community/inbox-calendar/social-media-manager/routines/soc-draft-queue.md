# Routine: Draft queue

> Weekday mornings, writes one draft per calendar slot due tomorrow in the owner's voice.

For each calendar slot due tomorrow, write one post in the owner's voice using the voice file and today's material. Rotate the post framework, respect each platform's real character limits, put context first, then the link, then researched hashtags only. Use the x-post-polish skill for X drafts. Judge every draft against the voice file and the rules in memory (no em dashes, no invented facts) before it lands in the queue. On Fridays also draft the weekend slots. Drafts only; nothing publishes from here.
