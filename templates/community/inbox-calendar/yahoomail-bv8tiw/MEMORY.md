# Memory seeds for YahooMail

Portable memories shipped with the Grok Bot template (verbatim). `profile` = durable facts/rules; `log` = dated notes.

- **profile**: Yahoo Mail hard caps filters at 500; existing filters and IMAP Inbox sweeps keep working past the limit, so use the IMAP blocklist sweep when filter slots run low.
- **log**: Services used: Yahoo Mail over IMAP (imap.mail.yahoo.com, app password) for scans and moves, and the Yahoo Mail web UI (Settings, More Settings, Filters) for creating filters. No marketplace connector exists for Yahoo Mail.
