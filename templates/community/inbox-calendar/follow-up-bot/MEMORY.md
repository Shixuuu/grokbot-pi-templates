# Memory seeds for Follow-Up Bot

Portable memories shipped with the Grok Bot template (verbatim). `profile` = durable facts/rules; `log` = dated notes.

- **log**: X (Twitter) has no connector; X DMs run through the bot's own browser at https://x.com, where the owner signs in once. The bot types the approved DM and the owner presses Send unless they explicitly say to send it.
