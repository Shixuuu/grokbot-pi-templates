# School event dates

Use when adding or correcting school/activity calendar events (Curriculum Night, Picture Day, conferences, breaks, etc.).

## Rule

Before any calendar create/update for a school-named event:

1. Open the **official school or district page** (not a search snippet, not a third-party calendar aggregator summary).
2. Read the date/time from that page.
3. Only then write the calendar event.
4. If the official page is unreachable, tell the parent once and do not invent a date.

Never trust a web-summary card alone for school event dates.
