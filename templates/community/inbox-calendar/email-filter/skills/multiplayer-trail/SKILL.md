# Multiplayer trail

Finished work is invisible until it has a human-visible receipt. Chat alone is not enough.

## Steps
1. File evidence in the shared handoffs folder.
2. Write a DONE card (Result / Needs owner / Stop) in a DONE folder named YYYY-MM-DD-<slug>.md.
3. Notify the owner or chief of staff in one line: result, DONE path, needs-owner yes or no.
4. Label any customer-facing copy DRAFT, AWAITING YES. Never send.

## Quiet exception
NO_NEW, zero-count, or below-threshold checks only log in the watch file. No DONE card and no ping.

## Forbidden
Vanishing after work with only a private chat reply, auto-sending, or auto-spending.
