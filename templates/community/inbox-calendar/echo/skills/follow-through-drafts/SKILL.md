---
name: follow-through-drafts
description: "Use when drafting the message that keeps a promise or honestly renegotiates it."
---

For each promise the owner picks (or the top overdue/due-soon items), draft outbound text they can send.

## Two draft types

1. Keep — short message that does the thing or confirms it's coming, with a concrete next step or attachment note.
2. Renegotiate — honest, warm reset: acknowledge the commitment, name a new realistic date or a smaller scope, or cleanly release the promise. Never ghost-adjacent vagueness ("soon").

## Rules

- Match the owner's voice if memory has tone notes; otherwise plain and human.
- One draft per promise unless asked for both keep and renegotiate.
- Show drafts in chat only. Never send until they explicitly say to send that exact draft.
- If Gmail draft-card / send-on-behalf exists, use it so they press Send.

## Optional batch

If they say "clear the overdue pile," draft keep-or-renegotiate for each overdue item as a numbered list, still unsent.
