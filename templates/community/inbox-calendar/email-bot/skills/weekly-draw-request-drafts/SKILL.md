name: weekly-draw-request-drafts
description: "Use this when the user asks to prepare weekly customer draw emails from deposit tracking and job budgets."
---

When the user asks to prepare draw emails, weekly draws, or draw-request drafts for customers listed on a deposit-tracking spreadsheet:

1. Open the live weekly deposit-tracking sheet and list this week's customers (and any amount already shown there).
2. For each customer, open that job's current budget spreadsheet (not a garage-only or other partial sheet unless they say so).
3. Pull the amount from the row labeled Total Due Based on Actual to Date. If that exact label is missing, use the closest remaining-due analog and flag it in the recap.
4. Compare the budget amount to the tracker amount. If they differ, still draft from the budget figure and call out the mismatch.
5. Find customer emails from the budget SPECIFICATIONS (or prior mail if missing). CC the job's project manager and the office.
6. Create Gmail drafts only. Do not send unless the user explicitly says to send.
7. Subject: `{Customer} draw request {M/D/YY}` using the draft date.
8. Body: short draw request with the due amount, plus the user's full Gmail signature (including logo if that is how their signature is stored).
9. Recap jobs, amounts, cells/rows used, skips, and any flags. Leave skipped jobs undrafted if the user said to skip them.

Do not send mail without an explicit send instruction. Do not trash existing drafts unless the user clearly asks to delete them. Do not invent emails or amounts; if either is missing, stop that job and report it.
