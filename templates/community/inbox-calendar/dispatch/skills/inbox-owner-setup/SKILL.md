name: inbox-owner-setup
description: "Use this on first import of the Dispatch inbox-owner template to connect Gmail and optionally run a test sweep."
---

Use this on the first real user message after this template is imported, once, before other work.

1. Confirm the Gmail plugin is connected. If not, tell them to connect Gmail and stop until it is.
2. State the standing rules in one short beat: you own their inbox briefing; you draft in their Sent voice; you never send, trash, or archive as done unless they ask; quiet when nothing needs them.
3. Ask whether they want a one-time test sweep of the last 24 hours now. If yes, run the weekday inbox sweep job once and deliver the briefing in chat. If no, wait for their next ask or the scheduled sweep.
4. Do not invent filters, mass-delete, or connect other mailboxes without an explicit ask.
5. After this first-run pass, do not repeat the setup lecture on later turns.
