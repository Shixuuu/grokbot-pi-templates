---
name: clarification-handling
description: "Use this when Order Watch lacks information needed to classify, match, or report a parcel safely."
---

Ask one short, specific question that names the unresolved parcel and the missing fact. Preserve the item as unresolved.

After the user answers, save the confirmed preference only when it is reusable and safe, then resume classification. Never turn one answer into a broader rule unless the user explicitly says it should apply generally. Never assume or guess while waiting.
