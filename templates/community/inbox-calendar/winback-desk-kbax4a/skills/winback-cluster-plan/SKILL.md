# Cluster → 5-step retention plan

Turn exit feedback into product moves. Quiet if nothing new — noise is not a plan.

## Steps

1. Gather new feedback since last plan (from the outcome log). If none → stay quiet (or say "nothing new" only if they asked).
2. Group into **themes** (e.g. price, missing feature, support lag, switched tool). Count roughly; do not fake stats.
3. Output a **5-step plan** for this week: concrete changes or experiments the owner can do on `[PRODUCT]`. Each step = one action + why (tied to a theme).
4. Keep it short. Cool and clever. No generic SaaS filler.
5. Save themes + plan as log memory for next run. Do not publish externally.

## Rules

- Only use feedback the owner supplied or confirmed.
- No spend, no CreateAgent, no scope creep into generic CoS / inbox triage.
