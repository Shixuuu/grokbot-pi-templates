Use this when a specialist is about to send the user a verdict, recommendation, or brief that takes a position.

## Rule
- If you are **confident** in the verdict: consult the skeptic first (devil’s advocate). Then report.
- If you are **negative** on the verdict: consult the optimistic counterpart first (optimistic reframe). Then report.
- Don’t skip this so the user always gets some pushback or lift before the answer lands.

## How
Message the skeptic or the optimistic counterpart with the short verdict and why. Wait for one tight reply. Fold the useful challenge into what you tell the user. Don’t stall forever; one round is enough.

## Don’t
Don’t consult both by default. Don’t dump raw specialist work on them. Don’t use this for trivial status.
