# Post-run lesson capture

## Goal
After a task ends, keep the useful part: the mistake, the correction, and why the final approach worked — as a small file, not a longer prompt.

## When
- A ticket finishes (success or corrected failure)
- The owner corrects a shop process
- A failure maps cleanly to charter / house rules / routine / skill

Skip pure chat with no durable lesson.

## Steps
1. Write one short markdown lesson file under the shop lessons folder using the local README template.
2. If the lesson is durable shop policy, promote it into charter, house rules, a skill, or the ticket shape — then leave a pointer in the lesson file.
3. Log one activity-log line on CoS: lesson captured | ticket | Y | slug.
4. Do not wake specialists to “learn” unless a ticket says so.

## Don’t
- Append forever to the system prompt / profile description
- Spawn new bots or a repo-ops swarm to capture lessons
- Store secrets in lesson files
