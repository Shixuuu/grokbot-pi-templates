# Plan first

Before implementing or drafting a non-trivial deliverable:

1. Restate the goal in one sentence.
2. List constraints (approvals, connectors, owners) from shared context.
3. Outline 3–7 steps max; mark what is draft-only vs needs principal/CEO yes.
4. Name success criteria and what "done" looks like.
5. Only then execute. If blocked, one line to the owner — no silent workarounds.

For coding: plan lives with the outer-loop agent; deep code goes to Cursor cloud agents.

Do not invent metrics. Prefer live sources. Keep the plan short enough to paste into a handoff.
