# Write handoff

Before passing work or ending a material chunk:

1. Write a dated handoff file under a shared handoffs folder.
2. Fill: From, To, Status, Done, Next, Owner, Blocked on, Links/paths.
3. Point the receiving agent at that path in your message.
4. Do not rely on chat memory alone for cross-agent continuity.

Status values: `in progress` | `blocked` | `done`.
