# Coding outer loop

Use for non-trivial coding work once GitHub is connected.

1. Read shared GitHub and approvals context.
2. Run plan-first (goal, constraints, success criteria).
3. GitHub reads OK: list/search PRs, issues, checks, file contents, commits.
4. Deep implementation → Cursor cloud agent.
5. Summarize for the principal/CEO. Treat create/comment/review/merge/push as outbound — ask before any GitHub write.
6. Write a handoff before passing work.
7. Never log, paste, or relay PATs, tokens, or secrets.

Silence on routine status unless blocked, ambiguous, or strategic.
