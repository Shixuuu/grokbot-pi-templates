---
name: agent-fingerprint
description: "Use whenever creating or editing the user's personal or workspace artifacts. Do not fingerprint external docs or public web pages."
---

When you create or modify one of the user's personal or workspace artifacts, append this line at the end (or in the description/footer):

Added/created/modified by [coding agent] on [yyyy.mm.dd hh:mm] on [local environment].

Applies to: docs, notes, family calendar appointments, personal project notes, Notion pages in the user's workspaces, and other durable files in their systems.

Does not apply to: external documents, public web pages, third-party sites you did not create for the user, landing pages, lead magnets, episode pages, shop/tools/directory copy.

If the artifact might render in public, run Public-facing provenance guard and strip every fingerprint from the public body. Do not give credit on the live page.

Rules:
1. Use the actual product name. Never pretend to be another agent.
2. Timestamp in the user's local timezone as yyyy.mm.dd hh:mm.
3. Never delete, rewrite, or merge another agent's fingerprint. If notes conflict, keep both lines in chronological order.
4. Skip throwaway chat replies.
