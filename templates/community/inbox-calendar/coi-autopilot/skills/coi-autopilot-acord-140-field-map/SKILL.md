# ACORD 140: complete field map (logical keys)

Based on public descriptions of the 2014/12 edition; the user's licensed blank controls (map by meaning, name the edition). Use these keys when mapping the user's blank (coi-autopilot-pdf-fill) so the map is reusable across editions. Fill rules live in coi-autopilot-acord-140-property: only stated facts, never guessed protection/construction class or year built, no default coinsurance/valuation/deductible, state selections never pre-checked.

Repeat tokens: {n} = premises block (2 per page; more pages as needed); {m} = subject-of-insurance row 1-6 per premises (overflow to ACORD 101); {b} = blanket summary row; {k} = additional interest entry.

- **Header:** `hdr_agency_customer_id` AGENCY CUSTOMER ID · `hdr_date` DATE · `hdr_agency` AGENCY · `hdr_carrier` CARRIER · `hdr_naic` NAIC CODE · `hdr_policy_number` POLICY NUMBER · `hdr_eff` EFFECTIVE DATE · `hdr_named_insured` NAMED INSURED(S)
- **Blanket Summary:** `blanket{b}_num` BLANKET # · `blanket{b}_amount` AMOUNT · `blanket{b}_type` TYPE
- **Premises Information:** `prem{n}_num` PREMISES # · `prem{n}_street` STREET ADDRESS (city, state, zip) · `prem{n}_bld` BLDG # · `prem{n}_bld_desc` BLDG DESCRIPTION
- **Subject of Insurance (rows 1-6):** `prem{n}_soi{m}_subject` SUBJECT OF INSURANCE · `prem{n}_soi{m}_amount` AMOUNT · `prem{n}_soi{m}_coins` COINS % · `prem{n}_soi{m}_valuation` VALUATION · `prem{n}_soi{m}_causes` CAUSES OF LOSS · `prem{n}_soi{m}_inflation` INFLATION GUARD % · `prem{n}_soi{m}_ded` DED · `prem{n}_soi{m}_ded_type` DED TYPE · `prem{n}_soi{m}_blanket` BLANKET # · `prem{n}_soi{m}_forms` FORMS AND CONDITIONS TO APPLY
- **Additional Information:** `prem{n}_addl_info` BUSINESS INCOME / EXTRA EXPENSE / VALUE REPORTING: additional information text · `prem{n}_value_rpt_period` VALUE REPORTING: PERIOD · `prem{n}_value_rpt_type` VALUE REPORTING: TYPE
- **Additional Coverages:** `prem{n}_spoil_yn` SPOILAGE COVERAGE (Y/N) · `prem{n}_spoil_desc` SPOILAGE: DESCRIPTION OF PROPERTY COVERED · `prem{n}_spoil_limit` SPOILAGE: LIMIT · `prem{n}_spoil_ded` SPOILAGE: DEDUCTIBLE · `prem{n}_spoil_refrig_maint_yn` REFRIGERATION MAINTENANCE AGREEMENT (Y/N) · `prem{n}_spoil_breakdown` OPTIONS: BREAKDOWN OR CONTAMINATION · `prem{n}_spoil_power_outage` OPTIONS: POWER OUTAGE · `prem{n}_spoil_selling_price` OPTIONS: SELLING PRICE · `prem{n}_optional_cov_desc` OPTIONAL COVERAGES (description) · `prem{n}_sinkhole_accept` SINKHOLE COVERAGE: ACCEPT · `prem{n}_sinkhole_reject` SINKHOLE COVERAGE: REJECT · `prem{n}_sinkhole_limit` SINKHOLE: LIMIT · `prem{n}_minesub_accept` MINE SUBSIDENCE: ACCEPT · `prem{n}_minesub_reject` MINE SUBSIDENCE: REJECT · `prem{n}_minesub_limit` MINE SUBSIDENCE: LIMIT · `prem{n}_historical` PROPERTY DESIGNATED HISTORICAL LANDMARK · `prem{n}_open_sides` # OF OPEN SIDES ON STRUCTURE · `prem{n}_loc_remarks` LOCATION / SUBLOCATION REMARKS
- **Construction:** `prem{n}_const_type` CONSTRUCTION TYPE · `prem{n}_hydrant_ft` DISTANCE TO HYDRANT (ft) · `prem{n}_station_mi` DISTANCE TO FIRE STATION (mi) · `prem{n}_fire_district` FIRE DISTRICT · `prem{n}_fire_district_code` FIRE DISTRICT CODE NUMBER · `prem{n}_prot_cl` PROT CL · `prem{n}_stories` # STORIES · `prem{n}_basements` # BASEMENTS · `prem{n}_yr_built` YR BUILT · `prem{n}_total_area` TOTAL AREA (sq ft)
- **Building Improvements:** `prem{n}_upd_wiring` WIRING (checkbox) · `prem{n}_upd_wiring_yr` WIRING: YEAR · `prem{n}_upd_roofing` ROOFING (checkbox) · `prem{n}_upd_roofing_yr` ROOFING: YEAR · `prem{n}_upd_plumbing` PLUMBING (checkbox) · `prem{n}_upd_plumbing_yr` PLUMBING: YEAR · `prem{n}_upd_heating` HEATING (checkbox) · `prem{n}_upd_heating_yr` HEATING: YEAR · `prem{n}_upd_other` OTHER (checkbox + description + year)
- **Building Details:** `prem{n}_bcegs` BUILDING CODE GRADE (BCEGS) · `prem{n}_tax_code` TAX CODE · `prem{n}_roof_type` ROOF TYPE (material) · `prem{n}_other_occupancies` OTHER OCCUPANCIES · `prem{n}_wind_class` WIND CLASS (e.g. semi-resistive / resistive)
- **Heating (edition-dependent; confirm on your blank):** `prem{n}_heat_primary` PRIMARY HEAT SOURCE: BOILER / SOLID FUEL / OTHER · `prem{n}_heat_boiler_elsewhere` BOILER: INSURANCE PLACED ELSEWHERE (Y/N) · `prem{n}_heat_secondary` SECONDARY HEAT SOURCE: BOILER / SOLID FUEL / OTHER · `prem{n}_heat_solid_fuel_details` SOLID-FUEL / WOOD STOVE / FIREPLACE INSERT details (manufacturer, installed by, date, UL, chimney/flue, clearance)
- **Exposures:** `prem{n}_exp_right_desc` RIGHT EXPOSURE: DESCRIPTION · `prem{n}_exp_right_ft` RIGHT EXPOSURE: DISTANCE (ft) · `prem{n}_exp_left_desc` LEFT EXPOSURE: DESCRIPTION · `prem{n}_exp_left_ft` LEFT EXPOSURE: DISTANCE (ft) · `prem{n}_exp_front_desc` FRONT EXPOSURE: DESCRIPTION · `prem{n}_exp_front_ft` FRONT EXPOSURE: DISTANCE (ft) · `prem{n}_exp_rear_desc` REAR EXPOSURE: DESCRIPTION · `prem{n}_exp_rear_ft` REAR EXPOSURE: DISTANCE (ft)
- **Burglar Alarm:** `prem{n}_burg_type` BURGLAR ALARM TYPE / DESCRIPTION · `prem{n}_burg_cert` CERTIFICATE # · `prem{n}_burg_cert_exp` CERTIFICATE EXPIRATION DATE · `prem{n}_burg_central` CENTRAL STATION (checkbox) · `prem{n}_burg_keys` WITH KEYS (checkbox) · `prem{n}_burg_local_gong` LOCAL GONG (checkbox) · `prem{n}_burg_company` ALARM COMPANY (installs/services) · `prem{n}_burg_extent` EXTENT (ISO) · `prem{n}_burg_grade` GRADE (ISO, e.g. AA/A/B/C) · `prem{n}_guards_num` # GUARDS / WATCHMEN · `prem{n}_guards_hourly` CLOCK HOURLY (checkbox) · `prem{n}_guards_other` OTHER ROUNDS (checkbox + description)
- **Fire Protection:** `prem{n}_fire_type` FIRE PROTECTION TYPE (sprinklers / standpipes / CO2-chemical systems) · `prem{n}_sprinkler_pct` % SPRINKLERED · `prem{n}_fire_alarm_mfr` FIRE ALARM MANUFACTURER (UL?) · `prem{n}_fire_central` FIRE ALARM: CENTRAL STATION (checkbox) · `prem{n}_fire_local_gong` FIRE ALARM: LOCAL GONG (checkbox)
- **Additional Interest:** `ai_acord45_attached` ACORD 45 ATTACHED (more interests)
- **Additional Interest (repeat per interest):** `ai{k}_loss_payee` INTEREST: LOSS PAYEE · `ai{k}_mortgagee` INTEREST: MORTGAGEE · `ai{k}_other` INTEREST: OTHER + description · `ai{k}_rank` RANK · `ai{k}_name_addr` NAME AND ADDRESS · `ai{k}_cert_required` CERTIFICATE REQUIRED (checkbox) · `ai{k}_loan` REFERENCE / LOAN # · `ai{k}_loc_bld` LOCATION # / BUILDING # · `ai{k}_item_desc` ITEM DESCRIPTION
- **Remarks:** `remarks` REMARKS (property line)
- **Signature:** `sig_producer` PRODUCER'S SIGNATURE · `sig_producer_name` PRODUCER'S NAME · `sig_producer_license` STATE PRODUCER LICENSE NO · `sig_npn` NATIONAL PRODUCER NUMBER (NPN) · `sig_applicant` APPLICANT'S SIGNATURE / DATE

When mapping a blank, list any key with no matching field as "not placed" and any blank field with no key as "unmapped" so the user can confirm.
