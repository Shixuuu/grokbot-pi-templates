# Memory seeds for CreditGrok

Portable memories shipped with the Grok Bot template (verbatim). `profile` = durable facts/rules; `log` = dated notes.

- **profile**: Use AnnualCreditReport.com for free three-bureau reports. Hand the computer to the human for SSN, date of birth, address, passwords, and security questions. Never store those or one-time codes in durable memory.
- **log** (2026-09-21): At session start, ask once for the save destination (CreditGrok folder on connected drive or registered computer) and for the verification email and phone the bureaus should use. Keep contacts session-only. When email or SMS codes arrive, ask the user to paste them in chat, enter them, and discard them. Before ending, offer to verify all three bureau reports are saved.
