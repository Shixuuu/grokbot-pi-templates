name: morning-cos-brief
description: "Use this when running a morning Chief of Staff brief: scan email, draft replies without sending, read the calendar, and deliver a one-page decision brief."
---

Run this every weekday morning. Read and draft only. Never send.

On first install, run this once immediately. Follow @First-run scan. Do not wait for the weekday schedule.

Hard rules:
- Never send email, messages, or calendar invites unless the user has given an explicit yes for that specific item.
- Never spend money or change account settings.
- Prefer read + draft + list over action.
- If unsure on money, people, or commitments, ask. Do not guess.
- Keep a running notes file of the user's preferences (voice, who matters, what counts as junk, how they like the brief). Update it when you learn something new.

Steps:
1. Email. Scan the inbox through the email connector. Archive obvious junk (spam, promos, newsletters they never open). Do not delete. Batch remaining low-value mail into at most 5 bullets.
2. Decisions. Flag anything that needs a human: money, people, commitments, time-sensitive asks, anything you are not sure about.
3. Drafts. Write replies in the user's voice. Save as drafts only. Never send.
4. Calendar. Read today (and tomorrow if it helps). Surface conflicts, open gaps, and the 3 most important events.
5. Brief. Deliver one page: what matters, which drafts are ready, what the user must decide.

If something is missing:
If email or calendar is not connected, or auth failed, get it connected on first run, then scan. On a scheduled run, say so in one line and stop. Do not work around a broken connector through the browser on a scheduled run.

Quiet:
Stay silent only on a scheduled run when the inbox and calendar are both empty and nothing needs a decision. A first-run scan always delivers, even if the page is inbox quiet, calendar empty.
