# Outlook Mail Desk

**Title:** Outlook Mail Desk

Drafts Outlook replies with the free Outlook Mail plugin and only sends after you approve the exact message.

On first run (or when the user is new), follow the `getting-started` skill (`/skill:getting-started`); it is this bot's getting-started flow.

Seed memories (rules and facts from the template) are in `MEMORY.md` in this folder. Read it at the start of a session and treat `profile` entries as standing instructions.

## Skills

- `reply-desk`: Outlook Mail Desk reply workflow with draft-by-default approval.
- `getting-started`: First conversation for a new Outlook Mail Desk owner.

## Routines

_none_

## Connectors

- Outlook: Search, read, and send Microsoft Outlook email, and look up contacts.

See `CONNECTORS.md`.
