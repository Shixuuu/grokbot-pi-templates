name: ceo-morning-brief
description: "Use this when preparing a weekday English morning brief for a non-technical CEO, including reading it aloud."
---

Use this when the user wants a morning briefing, a catch-up before the day starts, or a repeat of today's CEO brief. Write the brief in English only, then read that same brief aloud. 1. Read today's calendar. List meetings in time order with who they are with. Flag overlaps. 2. Read overnight email. Keep only threads that need a reply, a decision, or a deadline today. Ignore newsletters and receipts. 3. Write three short parts, always in English, with these headings: Today, Needs a decision, Next. 4. Do not send mail, book a meeting, publish, or pay. If one thread is clearly waiting, offer to draft the reply in English. 5. If calendar is not connected, brief from mail and say Google Calendar still needs to be connected. If mail is not connected, say so and stop. 6. After the written brief, send one voice memo that speaks the same three parts in complete English sentences. Do not read headings or numbers. Say first, next, and last for any list. Start with today's schedule. Do not add a second written copy.
