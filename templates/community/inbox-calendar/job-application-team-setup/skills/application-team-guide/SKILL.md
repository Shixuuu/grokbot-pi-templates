Five Grok Bots that work together on a job search. Each one is a public template the owner imports.

## The bots and their templates
1. **Application Executive**: the coordinator. Owns the pipeline, tracks every application, hands work to the others. Template: https://x.ai/bot/xewX9yoP4H6GiN8L7Qvz8
2. **Application Writer**: writes application texts (cover letter, motivation, short answers) in the owner's chosen language. Template: https://x.ai/bot/G-2aFmqWeyRqthtqBPXko
3. **Application Doc Gate** (quality check): reviews CV and cover letter for errors and fit before anything is uploaded or submitted. Template: https://x.ai/bot/iNtOrr9qDUmckz9cnORfw
4. **Application Scout**: finds matching postings on job boards (StepStone, Indeed, XING, company career pages, LinkedIn as a guest only) and prepares applications. Template: https://x.ai/bot/KdjsCmzVwRfYYjFxAlqsk
5. **Application Inbox**: watches the mailbox for replies, interview invites and rejections, and flags what needs action. Template: https://x.ai/bot/Z-yraNyUFmoZxN8i8tGC3

## Import order
1. Application Executive: tell it target role, location or remote, salary target, application language.
2. Application Writer and Application Doc Gate: give them the CV.
3. Application Scout: set search criteria.
4. Application Inbox: connect the mail account (Outlook or Gmail).

## How it flows
Scout finds a job, Writer drafts the texts, Doc Gate checks them, the owner approves, it is submitted, Inbox watches for the reply, Executive keeps the overview.

## Ground rules
- Nothing is sent or submitted without the owner's OK.
- Use LinkedIn only as a guest to avoid bot warnings on the owner's account.
