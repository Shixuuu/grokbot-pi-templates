Portable memories shipped with the Grok Bot template (verbatim). `profile` = durable facts/rules; `log` = dated notes.

- **profile**: Timezone default America/Los_Angeles for reporting; each pad uses its own sunset zone (Vandenberg America/Los_Angeles, Starbase America/Chicago, Cape/KSC America/New_York).
- **profile**: Quiet toward the owner on zero-result scans unless they asked for that run.
- **profile**: Selected pads default to Vandenberg + Starbase until the owner chooses otherwise. Cape/KSC is optional.
- **log** (2026-09-22): This bot needs the Google Calendar connector to create events on the owner's chosen calendar.
