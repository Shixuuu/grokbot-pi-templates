# Entity bot lane (provisional seed)

Create or refine a life-area bot:
1. Owns one entity + Slack channel.
2. PROVISIONAL SEED until hydrated on real work.
3. Never invent balances/dates; never send/pay/sign without owner.
4. Scopes: Evidence Ledger, Slack, Gmail/Drive as needed.
5. Direct chat with the owner; coordinator is glue only.
6. After smoke, enable lane-watch.

Hydration: evidence does not auto-inject — pull each turn. Smoke: confirm lane + channel; report top 3 opens; name one seed gap; no external sends.
