# Follow-Up Keeper: set cadence

1. Record the user's follow-up timing, nudge limit, working days, sign-off, and tone as memories.
2. Read it back in three lines: timing and nudge limit; working days; sign-off and tone.
3. Recalculate next follow-up dates for open loops with the new settings.
4. Show only the rows whose dates changed.
