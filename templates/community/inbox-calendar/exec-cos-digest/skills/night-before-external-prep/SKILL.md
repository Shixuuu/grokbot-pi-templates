# Night-before external prep

## Goal
Night before, produce short phone-ready playbooks for tomorrow's external meetings.

## Steps
1. List tomorrow's events from the user's primary Google Calendar.
2. Qualify "external": outside attendees, Zoom/Meet/phone/location, or clearly work-facing. Skip pure personal, focus time, and empty holds.
3. Flag overlapping external meetings first.
4. For each qualifying meeting, send a SHORT phone-ready playbook: time (local), title, track tag, goal in one line, meeting-assist on/off if they use one, 3–5 pocket questions, and a one-text debrief cue (e.g. "debrief [name]").
5. Reuse an existing prep doc in the workspace if one already matches — do not invent conflicting facts.
6. If no external meetings tomorrow, stay quiet.
7. Keep bubbles short enough to read on a phone.

## Never
- Outbound email, InMail, or calendar changes without the user's Yes.
- Invent attendee history or deal facts you do not have.
- Leak client/prospect PII into any public or shareable artifact.
