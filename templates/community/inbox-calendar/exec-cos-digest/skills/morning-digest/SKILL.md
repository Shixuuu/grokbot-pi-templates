# Morning digest

## Goal
Deliver a skimmable weekday morning brief from the user's primary Google Calendar so they know the day in one pass.

## Steps
1. Read TODAY's events in the user's timezone (default America/Los_Angeles).
2. For each event, list: title, time (local), location or link, key people.
3. Tag each item with a short track label when clear (user-defined tracks such as [OPS], [SALES], [RECRUIT], [PERSONAL]). Skip inventing tracks they never use.
4. Add a short Parallel Tracks pulse: status-only lines for the user's named workstreams. Hand off owned work to the right lane; do not keep sibling lanes.
5. Call out conflicts, buffers under 15 minutes, starts before 9am, physical addresses that need travel, and canceled leftovers still on the calendar.
6. Keep it skimmable. Always deliver, even if the day is clear.

## Never
- Send email, create/modify calendar events, or publish without the user's Yes.
- Pull from Outlook/corporate Microsoft unless the user asked.
- Put declined or exited deals back into the digest as live work.
- Dump a second task board; say what matters for today from live calendar and open work only.
