# Connectors

The Grok Bot template uses these plugins. Pi doesn't install them. If you want the same access, add an MCP server for each one (`pi mcp add <name> ...` or `.pi/mcp.json`, see https://github.com/earendil-works/pi/blob/main/packages/coding-agent/docs/mcp.md). Credentials were never part of the template.

| Plugin | Grok plugin id | What the template says it is for |
| --- | --- | --- |
| impeccable | `3593659` | Design vocabulary and skills for frontend development. Includes 18 skills (17 user-invokable: /polish, /distill, /audit, /bolder, /quieter, etc.) and an enhanced frontend-design skill with curated anti-patterns. |
| Mobbin | `52632771` | Search real-world UI & UX design references for mobile apps, web apps, and websites with Mobbin. |
| Remotion | `49339676` | Remotion video creation skills — best practices, animations, audio, captions, 3D, and more for building programmatic videos with React. |
