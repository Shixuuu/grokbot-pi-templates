# Frontend slides

HTML slides for a talk, pitch, or product page-as-deck. Chassis from Zara Zhang's Frontend Slides (https://github.com/zarazhangrui/frontend-slides): fixed 1920x1080 stage, one HTML file, no reflow on phones.

Look from Katagami, not from Zhang's 30 templates. If a look is not locked, three lettered vibe cards then D, or two mix stills applied to a title slide, they tap. Impeccable detect. Real drawings. Unspeak.

Do not run Zhang Phase 2 (preset covers, STYLE_PRESETS, bold-template-pack). That fights Katagami. If a look is already locked, ask before reusing it.

Do not vibe-pick with /bolder or /quieter unless they ask.

Impeccable detect. Write the log. Hand the HTML. If the deck is shipped software in a repo, a cloud agent builds; you still invent and draw.

Group rooms cannot take pictures. Send stills of the deck to the 1:1 chat.
