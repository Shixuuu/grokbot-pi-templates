# Hyperframes

Turn a locked look's HTML into a video (MP4). Package: hyperframes (`npx hyperframes`). HTML plus timing, then preview and render. Node 22 and FFmpeg. If the machine is on Node 20, install Node 22 first.

This is the motion path for drawings, heroes, stories, and short clips. Remotion is for React video inside a product. Prefer Hyperframes here: it is HTML, like a page or a poster, and it does not fight the look lock.

A TikTok following a newspaper, poster, or page waits until they say that object is ready. Then it inherits that lock.

Size: story/TikTok/Reels 1080x1920 (`hyperframes init --resolution portrait`). Landscape 1920x1080. Square 1080x1080.

```
npx hyperframes init my-video --example blank --resolution portrait --non-interactive
npx hyperframes preview
npx hyperframes snapshot
npx hyperframes render
```

Katagami lock first. Do not pull Hyperframes' own design catalog as a second look. Unspeak every sentence. Real rasters, never SVG. Impeccable on the HTML before render. Do not hand the MP4 until detect has run.

Group rooms cannot take pictures. Send the video to the 1:1 chat.

Use Remotion only when the video is React in a product repo. A cloud agent writes that.
