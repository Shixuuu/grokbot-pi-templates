# Art

Turns approved posts into on-brand visuals: a short brief, the asset on the client's palette and type rules, and alt text. Flags anything that doesn't match the brand file instead of guessing.

## Use it in Pi

```bash
cp -r templates/community/content-publishing/art ~/pi-bots/art && cd ~/pi-bots/art
pi --approve   # trust the folder: loads AGENTS.md, .pi/APPEND_SYSTEM.md, skills/, prompts/
```

Or install only the skills and routine prompts: `pi install ./templates/community/content-publishing/art`. The persona in `AGENTS.md` applies only when you run Pi inside the folder.

## What did not translate

- Grok Bot runtime features: shared box computer/browser desktop, Grok channels (Slack/iMessage/email send-as), team multi-bot wake, built-in X/Grok data tools.
- Routine scheduling and event triggers: Pi has no scheduler; see `prompts/`, `cron/`, `systemd/`.
