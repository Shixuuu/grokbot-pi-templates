# Brand guidelines craft

## When
Before building brand guidelines (or email playbook / merch / launch docs) in Figma, especially from a thin prompt.

## Goal
Thin prompt to art-level, exploratory brand documentation that feels finished and shipped, never WIP. Match professional denseness. Inventory intake, analyze, shape, then build. Never jump straight to frames. Do not ship junior craft. No named outside designers, schools, galleries, or inspired-by lines anywhere. Never pull outside references during builds.

## Visual goal (every project)
Professional denseness: art-level look/feel, vector graphics, full-page mockups (single-page OK), detail depth, and breathing room. Build from intake and tone/ref analysis only. Never pull outside references during builds. Never copy art, marks, or IP. The Figma file must feel shipped on every frame.

## Locked bar (exploratory depth)
- Finished product only: no process or meta notes on canvas. Chat attestation stays in chat only.
- Wayfinding spine (required for brand guidelines): overview page, table of contents, and section title slides. Apply to new builds; apply to existing files only when asked.
- No image clipping: art and mockups fully visible.
- Cover / first slide: clean and finished.
- Full-page creative encouraged: prefer full-bleed application frames when craft wants air.
- No lean/MVP 5–8 hard cap. Frame count follows the brand.
- Professional denseness: art-level look/feel; vector graphics; full-page mockups.
- Application / graphic art: use high-craft image generation. Never crude shape stubs.
- Every content frame enforceable: construction and/or ratios and/or don'ts and/or proof.
- No empty page framing. Section titles allowed when they name the section and set tone.
- No vanity filler or merch spam.
- Tone/ref analysis is CRITICAL and non-optional.
- Intake + analysis only during builds.
- Tone source / full adaptation: voice, palette, AND font choices plus surfaces must feel like the ref.
- Brand vs flavor / SKU: single SKU pack = flavor lane under parent brand OS. Soft Accents flavor-owned unless buyer supplies a true brand Soft Accent.
- Lockups: if no official mark/SVG, derive a finished wordmark from intake + tone. If official logo supplied, use that. Never slap marks over your-wordmark placeholders.
- Bookend / last slide = CLOSE ONLY and brand-only: no thanks or gratitude. Contact only if buyer asked. NEVER next-steps, CTA theater, or sales buttons.
- Buyer-safe proactive suggestion (after ship only): ONE short next-step max per ship in buyer chat; wait for yes; never on the bookend.
- New work → new file unless explicitly asked to edit an existing one.

## Voice
Decisive senior. Short bullets when they help. Natural prose otherwise. Avoid em dashes.

## Mandatory BEFORE Figma
1. Clarify the brief
2. Tone/ref analysis of intake only
3. Stay on intake + analysis; never scrape outside refs mid-build
4. Map for exploratory depth with wayfinding spine; separate parent brand OS from flavor/SKU lanes when needed
5. Asset gather from intake
6. Missing: make/skip/wait once. Logo exception: derive finished lockup if needed and none supplied
7. Outline then build
8. Build: art-level denseness; new file unless asked; high-craft app art; wayfinding; finished cover; no clips; bookend close-only brand-only
9. Ship: link + page map + screenshots + chat attestation (never on canvas)
10. After ship (optional): ONE short buyer-safe next-step suggestion; wait for yes

## Hard fails
- Invented brand facts → stop
- Skip tone/ref analysis → stop / rework
- Outside reference scrapes mid-build → stop / rework
- WIP / meta on canvas → rework
- Missing wayfinding spine on new builds → rework
- Clipped art → rework
- Unfinished cover → rework
- Single flavor treated as whole brand → rework
- Mark-over-placeholder or gap-only lockup when logo needed → rework
- Bookend with thanks, next-steps, CTA, or suggestions → rework
- Naming outside craft refs on canvas or attestation → rework
- Editing existing buyer files without ask → stop
- Crude shape stubs as application art → rework

## Anti-jobs
No outbound sends. Never credit outside craft sources on the deliverable. Never put thanks, next steps, or suggestions on the last slide. After ship, at most ONE grounded chat suggestion in buyer chat; wait for yes.
