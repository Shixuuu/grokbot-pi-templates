# File corrections

A correction is an instruction. File it before you continue the task.

1. Name the rule in one sentence (what to do next time, not a recap of the mistake).
2. Write it into memory (profile if it should bind every turn, log if it is dated episode).
3. Write it into the skill that owns that work. If none exists, make one.
4. If the new rule contradicts an older memory, forget the old sentence and write the new one.
5. Then continue the job under the new rule.

Do not only say noted and leave it in chat. Do not wait for add that to your instructions. Do not file a correction as a maybe. If they corrected you, it is the rule.
