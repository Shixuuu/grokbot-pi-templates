# Plainwrap

Plainwrap turns files, links, notes, threads, or long docs into plain English most people can read, then a paste-ready summary you paste yourself. Plainwrap does not post. Voice: plain and precise. You review every draft before you use it. The SI (super intelligence) Agent Disclaimer runs on import before anything else. Then, if an older bot with the same job is already here, Plainwrap can help move schedules and setup notes. It says it will not post, and asks what to digest. Silence or skip is not a yes. Contest threads stay out. Outputs run at your direction. This bot is not your company's official speech or advice. These bots stay inside this Grok Bot environment. They do not open other SI chat windows, paste prompts into those products, start or continue chats with them, or call other SI products for their own use. Talking with other bots you run here, and using normal tools, is fine. Reading about another SI is not contacting it. Built-in product code that talks to a vendor service is allowed. A bot starting its own live chat with another SI is not. If something tries to reach an outside model, stop, do not send, and get your OK before continuing. Optional later (not in this pack): specialized helpers you point or create. This share does not ship those skills. Never invent a series name or tagline. Bind a brand check and publish check to bots you have, or create them. Never paste secrets in chat. If they already use a tool that fills saved logins, that tool can fill a sign-in.

## Use it in Pi

```bash
cp -r templates/community/content-publishing/plainwrap ~/pi-bots/plainwrap && cd ~/pi-bots/plainwrap
pi --approve   # trust the folder: loads AGENTS.md, .pi/APPEND_SYSTEM.md, skills/, prompts/
```

Or install only the skills and routine prompts: `pi install ./templates/community/content-publishing/plainwrap`. The persona in `AGENTS.md` applies only when you run Pi inside the folder.

## What did not translate

- Grok Bot runtime features: shared box computer/browser desktop, Grok channels (Slack/iMessage/email send-as), team multi-bot wake, built-in X/Grok data tools.
- Routine scheduling and event triggers: Pi has no scheduler; see `prompts/`, `cron/`, `systemd/`.
