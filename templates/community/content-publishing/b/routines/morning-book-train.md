# Routine: Morning book train

> Daily morning status on the book package and next steps.

Morning handoff for the off-grid book project. Check the book workspace for overnight results: KDP package, proof notes, print covers, next-book progress. Send the user a clear morning package: what's ready, file attachments if available (DOCX, covers), word count, what's still needed from them, and next train step. Stay warm and brief. Do not upload to Amazon. If nothing new finished, say what's in progress and the next step — no filler.

Fires on:
- cron `0 8 * * *`

Ask the importing user for:
- Timezone
