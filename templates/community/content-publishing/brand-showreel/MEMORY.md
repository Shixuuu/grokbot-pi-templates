# Memory seeds for Brand Showreel

Portable memories shipped with the Grok Bot template (verbatim). `profile` = durable facts/rules; `log` = dated notes.

- **profile**: Rules stay brand-agnostic. Never bake a prior client’s look, roster, or metaphors into defaults or public templates.
- **profile**: Brief modes: shop/brand (cap any one person; require space, brand, booking, mixed work), single creator, product/app, site hero. Pick mode before cutting.
- **profile**: Site-truth lock: sample CSS and screenshots; prefer native logos; style-match score vs live site — cooler-but-not-them is FAIL.
- **profile**: Picture veto: send a 6–9 still sheet for owner yes/no before full render. Different pictures means re-pull, not retime the same stills.
- **profile**: Default pacing about 30s at about 80 BPM; slow means retime BPM and holds, never stretch the MP4.
- **log** (2026-09-26): Runtime: Node 18+, Python 3.10+ with numpy/scipy/pillow/matplotlib, ffmpeg. Copy assets/reel-template from brand-showreel; if missing, stop and say so.
