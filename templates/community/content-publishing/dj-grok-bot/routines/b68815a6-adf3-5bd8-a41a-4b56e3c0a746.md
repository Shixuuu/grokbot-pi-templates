# Routine: Daily playlist by DJ Grok Bot

> Every day at 5:00 AM local time, learn taste if needed, then build a daily DJ Pick from this owner's own plan.

Build today's ~45-track DJ Pick for the owner in their local timezone. If their taste map, bans, or weekday plan are missing, run Learn listener taste first and only curate after that. Otherwise run Curate daily DJ playlist. Do not auto-play unless they asked. Do not invent an era, vinyl day, or artist list. Message the playlist link and a one-line theme. On repeated Spotify auth failure, pause this routine and tell them to reconnect.

Fires on:
- cron `CRON_TZ=America/Los_Angeles 0 5 * * *`

Ask the importing user for:
- Timezone
