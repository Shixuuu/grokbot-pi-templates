Maintain one sheet per PC in durable memory. Group tables onboard everyone before play.

## Onboarding order
1. Ask each player: character name, ancestry/species, class, level (default 1), one personality hook, optional look.
2. Ability scores — offer:
   - **Fast:** standard array 15,14,13,12,10,8 assigned to STR DEX CON INT WIS CHA
   - **Custom:** point-buy lite (budget 27, costs as 5e) if they care
3. Derive and announce in one compact block, then save to memory. Next player.
4. When roster complete, post a party summary to the room.

## Level-1 quick kits (streamlined)
Use these hit dice and starting sketches unless the table prefers full PHB detail.

| Class | Hit die | Armor/AC sketch | Signature |
| --- | --- | --- | --- |
| Fighter | d10 | Chain/shield ~16–18 | Second Wind (1/rest heal 1d10+level) |
| Rogue | d8 | Leather ~12–14 | Sneak Attack 1d6 once/turn with advantage or ally adjacent |
| Wizard | d6 | 10+DEX | 3 cantrips, 2 level-1 slots; Arcane Recovery later |
| Cleric | d8 | Medium/shield ~15–18 | 3 cantrips, 2 level-1 slots; Turn Undead optional |
| Ranger | d10 | Medium ~14–16 | Favored terrain flavor; 2 level-1 slots optional |
| Barbarian | d12 | Unarmored 10+DEX+CON | Rage: resist blunt/pierce/slash, +2 melee damage (1/rest at L1) |
| Bard | d8 | Light ~12–14 | 2 cantrips, 2 level-1 slots; Bardic Inspiration d6 (CHA/rest) |
| Paladin | d10 | Heavy/shield ~16–18 | Lay on Hands pool = 5×level; Divine Sense flavor |

Proficiency bonus: +2 at levels 1–4. Skills: pick 2–4 that fit class + hook. Weapons: one clear attack line (`longsword +5 to hit, 1d8+3`) beats a gear essay.

## Sheet fields (always)
Name · player · class · level · ancestry · STR/DEX/CON/INT/WIS/CHA with modifiers · HP current/max · hit dice · AC · proficiency · skills · attacks/spells (short) · inventory · conditions · notes · look (for portraits)

## Modifier cheat
Score 8–9 (−1), 10–11 (0), 12–13 (+1), 14–15 (+2), 16–17 (+3), 18–19 (+4).

## During play
- Damage/healing: update current HP and announce the new total.
- Loot/level-up: update sheet; keep announcements short.
- Missing player: park the PC or run as quiet hireling only with table consent.
- Sheets are table-visible by default. Hide only what the host marks secret.

## Party summary format
`**Party** — Name (Class L1, HPcur/max, AC) · …`
