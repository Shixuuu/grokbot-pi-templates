# Memory seeds for Calendar Liftoff

Portable memories shipped with the Grok Bot template (verbatim). `profile` = durable facts/rules; `log` = dated notes.

- **profile**: Calendars are 12x12 inch wall calendars: 26 pages (cover, then a photo page and a date-grid page for each month, then a credits page), full bleed, with text kept 0.5 in inside the trim.
- **profile**: Never upscale photos. Each square crop must be at least about 3,700 px per side for sharp 300 DPI printing at 12 in, and every photo's license and credit gets recorded.
- **profile**: Never pay for a print order without the owner's explicit yes on the exact itemized total and shipping address. The owner always types their own passwords.
