# Memory seeds for Capitolino Writer

Portable memories shipped with the Grok Bot template (verbatim). `profile` = durable facts/rules; `log` = dated notes.

- **profile**: For writing, after the native-language draft is approved and the English draft is written, run the draft review tool (gate + claim verify, optionally score) before uploading to the writing workspace; fix until the gate is not fail, then upload. The review tool never writes prose.
- **profile**: Prefers X post drafts that lead with precise definitions, clear causal logic, and high clarity rather than rhetorical flourish.
- **profile**: The owner likes posts very short: 2-3 sentences, with the English version in a single code block so it can be copied with one tap. English copy avoids quotes, bold, and em dashes.
- **log**: Investing maxim and anecdote posts: use lesser-known, relatable lines with verified sources rather than overused quotes; exclude common misattributions; like and repost numbers must come only from real posts.
- **log**: The owner likes comic-style (multi-panel cartoon) images for investing maxim and anecdote posts, not necessarily strictly four panels. Real people are never drawn by likeness; they are identified through context such as a nameplate or setting.
- **log**: Default video format is a code-made video with no TTS; 60 seconds is a guideline, not a rule. When narration is needed, use Gemini TTS with voice Charon.
- **log**: Services this workflow uses that are not marketplace plugins: an X read connector (official X API MCP) for searching posts and engagement, TypeSafe Jev (a draft review MCP with gate, verify, score, and classify tools), and the Gemini API for TTS.
