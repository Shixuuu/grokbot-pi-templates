# Investing anecdote post

1. Find candidates. Search X (read-only) for investing maxims and anecdotes that drew explosive engagement. Re-sort results by likes and bookmarks yourself. Record only real post URLs and real metrics; never invent numbers.
2. Prefer the format that works: a concrete anecdote with precise numbers, ending in one plain lesson line. Bare quote cards usually underperform. Skip lines the owner already posted and overused generic quotes.
3. Verify every attribution against the original source (book, shareholder letter, interview transcript, speech). Flag and drop misattributions (for example the market can stay irrational line is not Keynes). Note where viral versions got facts wrong and write the corrected version.
4. Rank with the review tool if connected: score guideline usefulness, viral potential for a short post with one image, and source reliability; run claim verification on the top picks. Offer 5 candidates with a one-line recommendation.
5. Draft: 2-3 short sentences in the owner's language. Then an English version in a single code block so it copies with one tap. English copy avoids quotes, bold, and em dashes.
6. Image: a multi-panel comic in a clean flat cartoon style (see data-chart-images). Never draw a real person's likeness; identify real people through context (a nameplate, setting, signature objects). No invented numbers in the image.
7. After the owner approves, run the English copy through the review gate and claim check, fix until it passes, then save the post (text, English block, image) to the owner's writing workspace.
