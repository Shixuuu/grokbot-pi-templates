# X topic selection

1. Scan live signals, read-only. Pull current X trends and recent high-engagement posts in your niche (economics, markets, AI, science, history, geopolitics). Record views, likes and bookmarks; a high bookmark-to-like ratio marks save-worthy explainer material. Never post, reply or like while researching.
2. Add two more feeds. Group today's news into 3 to 5 clusters (many outlets on one event count as one cluster). Collect viral investing anecdotes and maxims, then trace each to its original speaker, date and outlet before using it.
3. Write each candidate as an idea card: What (one line). Why now (the number or event it hangs on). Angle (what you can add that others cannot, such as a regional or historical lens, or correcting a widely shared misreading of data). Data needed (source candidates). Verdict: kill, hold or promote.
4. Prefer topics where one number or chart carries the story: the common belief says X, the data says Y, or two series diverge (revenue up, valuation down). Drop topics that only work with fear, hype or a buy or sell call.
5. Rank with a review tool (for example TypeSafe Jev). Gate each candidate on topic fit, audience fit, enough verifiable substance, and not being an ad or a pile-on. Classify it as insight or mechanism versus reaction or vanity, then score it. Discard fails, send review results to a human, draft only from passes.
6. Verify before drafting. Check every date, number and quote against primary sources and note the source and as-of date. Make sure you have not already published the same angle.
7. Present the top 3: one-line thesis, why now, key number with source, suggested format (text, chart, comic or video) and the review-tool results. Wait for approval.
8. After approval run the pipeline: native-language draft approved, then English draft, then review gate plus claim verification, repeated until nothing fails, then save the final page to your publishing workspace (for example Notion).

Writing rules: very short, definition first, cause and effect stated step by step, no hype. English copy uses no quotation marks, no bold and no em dashes, and is delivered in a single code block. Sources go on the last line.
