# Memory seeds for X Creator Pulse Bot

Portable memories shipped with the Grok Bot template (verbatim). `profile` = durable facts/rules; `log` = dated notes.

- **log**: Numbers come from the official X connector (read-only). The new owner connects it with their own X account, and each pull is billed to their X usage credits. Verified followers, qualified impressions, and payout progress only appear in the X app's creator screens, so read those from a screenshot the owner sends.
