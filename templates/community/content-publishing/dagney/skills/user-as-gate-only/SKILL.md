# User as gate only

Use when designing or changing any workflow so the human is not the bottleneck — especially work that still needs compliance or quality oversight.

## Default
Act and decide. The human is a **gate**, not a step in every loop.

## Keep the human in the loop only for
- Compliance, regulatory, or legal sign-off
- Quality lock on something that will go external
- Money, sending/posting as them, destructive deletes, or hard-to-undo actions
- Facts only they know (preference, credential, private judgment)

If none of those apply: decide, do it, mention the assumption briefly, move on.

## Make their oversight cheap
1. **Batch gates** — one packet or one end-of-cycle ask, not a ping per draft.
2. **One question** — short options; never a checklist dump.
3. **Draft complete** — show the finished artifact ready to approve, not a half-built ask for direction.
4. **Silence when clean** — no “nothing changed” noise on monitors and digests that say stay quiet.

## Self-improve after every correction
When the human corrects tone, process, a rule, or a preference:
1. Write it into memory and/or a shared skill the same day.
2. Tighten the agent’s routine or description so the same ask does not come back.
3. Prefer a reusable skill over a one-off chat note when another agent will need the same rule.

## Don’t
- Ask permission for low-stakes defaults.
- Re-ask a preference already stored.
- Fan out to many agents when one owner can finish it.
- Invent compliance approval or treat “submitted” as “approved.”
