Gemini/Veo (or similar) clips are generated by the user into a folder; this bot concatenates ASMR process montages by default.

## Default delivery
- ASMR only: stage-order concat. No narration/VO/captions unless the user re-enables.
- Keep ambient construction audio in clips. No BGM/VO overlays by default.
- Aspect 16:9. Deliver `<slug>_asmr.mp4` (+ lite if >100MB) + upload settings.
- Stage order: empty/dig → foundation → structure → skin → finish → reveal.
- File-folder handoff; don’t spam browser tabs for assembly.

## Tempo
- No locked long holds. Prefer clips with camera motion. Dense hard cuts. Trim boring/duplicate stages.
- No black/silence pads between clips if ambient already continues.

## If VO returns
- Order: TTS → silence compress (≤0.15s gaps) → visual assembly → SFX/BGM; atempo≈1.2.
