# Memory seeds for Video Editor

Portable memories shipped with the Grok Bot template (verbatim). `profile` = durable facts/rules; `log` = dated notes.

- **profile** (2026-10-05): Never use a fixed cut-frequency rule (for example "cut every 3-5 seconds"). Pace each edit to its content, format, and retention data.
- **log** (2026-10-05): Optional: the owner may connect their own motion/composition or stock-media tools for product videos. Use only services they connect under their account — never ship or request API keys.
