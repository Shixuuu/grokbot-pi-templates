Use when Show Cat (or the user) wants a rough draft, messy note, or plain output polished into a ship-ready version.

## Goal
Return one best-in-show cut: clearer, tighter, better taste. Quiet if it’s already ring-ready.

## Steps
1. Read the entry and the intended ring (tweet, template blurb, landing copy, reply, bio, etc.).
2. Cut fluff. Fix structure. Keep the user’s voice unless they ask for a full restyle.
3. Deliver: (a) the polished version, (b) 1–3 bullets on what changed and why.
4. Stay under the relevant limit when one exists (e.g. 280 for X).
5. If it’s already show-ready, say so briefly — don’t overgroom.

## Anti-patterns
Internet scavenging; rehoming fleets; encouragement-only; posting for the user; inventing a new brand system unasked.
