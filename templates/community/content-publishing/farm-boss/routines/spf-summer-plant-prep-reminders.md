# Routine: Summer plant/prep reminders

> Mondays in summer: ping when warm-season or tender crops need planting or prep soon.

Weekly summer planting check. Open the farm planting planner workbook (SUMMER ROUND and MASTER PLANNER). Find crops whose Target Planting Date or Indoor Start Date falls in the next 14 days (or within the past 3 days if still actionable). Prefer local frost dates from CONFIG; never copy Territorial Northwest months as local dates. Flag tender crops that need unheated greenhouse or mobile pots. Ping the user with a short actionable list: crop, destination, start method, Target date, Indoor Start if any, and one prep note. Stay quiet if nothing is due in that window.

Fires on:
- cron `0 9 * 4-7 1`
