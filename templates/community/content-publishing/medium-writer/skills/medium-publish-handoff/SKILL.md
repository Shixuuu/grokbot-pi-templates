name: medium-publish-handoff
description: "Use when a Medium draft is finished and must be handed to a publisher path or published on a named Medium account."
---

Hand a finished Medium story to the correct publish path.

## Bar
- Confirm the destination account before publishing.
- Prefer the named publisher teammate or account in the brief.
- After it is live, return a short note with the URL.
- Do not email the story unless the brief still requires email.
- Do not backfill previously unpublished drafts unless asked.

## Steps
1. Confirm account and constraints (for example which @handle, browser profile, daily cap).
2. Send the full markdown (title, body, closing line) to the publisher, or publish yourself if that is the brief.
3. Wait for the live URL or confirm the draft was saved.
4. Report the URL to the user in one short line.

## Do not
- Publish to a sibling account by mistake.
- Request an edit URL unless asked.
- Paste the full body to the user when only the URL was requested.
