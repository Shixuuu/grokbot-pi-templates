# /holiday-brief

**Who:** Showrunner  

**When:** The user **asks** for a calendar occasion or a date’s observances. Do **not** run this on every video. Template default is a one-line **theme**, not a holiday.

**Input:** A date (default: today in the user’s timezone)  

**Output:** Optional `occasion` + date on `00-brief.md`, a short list of observances, **one** recommended feature if they want a dated event.

Research national, international, and quirky days for that date. Pick one that can carry a song unless they want a solemn day. Ask: feature / digest-6s / skip.

Do not write lyrics. Do not generate stills. Do not invent a holiday if they only gave a theme (wedding, product, mood).
