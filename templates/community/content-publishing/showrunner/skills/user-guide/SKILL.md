## Start here

**Do you have your own song and a reference image?**

- **Yes** — attach audio (or parts to join) + photo(s); tag each photo **exact** or **inspiration**.
- **No / partial** — we can compose the song and/or generate world-lock from the theme.

**Limits:** audio/images/docs **25 MB** each; video **200 MB**; up to **6** attachments per message. Split large masters into parts under 25 MB and say “join into one master.”

**Delivery (hard rule):** Showrunner always DMs products as **Save/Download file attachments** in this 1:1 chat — audio, world-lock stills, story stills, briefs (`.md`), clips, and `final.mp4`. Even when the crew works in the group, files still arrive here. Inline/gallery images are preview only, not delivery. `/workspace` paths are not delivery. Showrunner does **not** wait for you to ask “show me.” If you cannot Save, ask for a re-DM as a file.

## Kickoff form (fill and send)

```
New music video.

Theme: [one line]
Aspect: 9:16 | 2:3 | 16:9
Scope: digest-6s | feature

AUDIO: Grok make the song [style]  OR  attached mp3/wav is the MASTER (do not compose)

REFS (optional): exact | inspiration — or none

IMAGINE: Bots run Grok Imagine  OR  I will run Grok Imagine
```

**Example (upload + user-run Imagine):** Theme folk/blues/lo-fi; feature; 9:16; master in 6 parts under 25 MB to join; I will run Grok Imagine; ref photo = inspiration; I’ll mux myself.

**Example (bots compose):** Theme cozy tea chorus; digest-6s; 9:16; Grok make the song (spoken-sung English); no refs; I will run Grok Imagine.

## Approvals (in order)

1. **Song locked** — after you hear the master DM.
2. **World-lock Continuity** — identity pins are Continuity-checked first. On PASS, stills are DMed as files for **Save confirm** (“I can Save these”). Then shot list + Imagine brief (you need not ask).
3. **Story stills locked** (Continuity on story stills) → then videos (never video first).
4. **Clip approval** (Continuity on clips as needed) → then stitch ask → mux (you or Editor Bot).

**Budget:** N clips on the shot list = N stills + N videos whose lengths **sum to the song** (digest = one 6s). Then **HARD STOP**. Regen only a named still/clip.

## Grok Imagine (bots-run vs you-run)

**You-run:** Showrunner DMs refs + brief as Save files; you paste on **your** PC at grok.com/imagine.

**Bots-run:** Uses Showrunner’s Agent Computer (separate login; can spend **your** credits). After Save confirm, Showrunner asks before spend, hands you the screen (header / Cmd+Shift+I → full screen), you sign in (never paste passwords in chat), then hand control back. When work is done, **Showrunner logs out**; screen again only if sign-out needs your click.
