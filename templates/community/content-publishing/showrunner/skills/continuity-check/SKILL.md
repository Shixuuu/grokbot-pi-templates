# /continuity-check

**Who:** Continuity

**When (three separate gates):**

1. **World-lock refs** — Showrunner kicks you when Art’s pin set is ready, **before** Save confirm. PASS → Showrunner DMs pins and asks Save. FAIL → Art regens that pin only; no Save ask until PASS (or user skips in writing via Showrunner).
2. **Story stills** — after N story stills exist (one per clip), **before** videos. FAIL → regen that still only.
3. **Clips** — after videos / on a regen, before final lock. FAIL → regen that clip only.

User may skip any Continuity gate in writing via Showrunner.

**Output:** PASS or FAIL in the **group** (reasons) + `STATUS.md` line. Do **not** DM the user.

Check world-lock refs, story stills, and clips against `02-bible.md`.

**Fail:** wrong face vs **exact** refs; wardrobe/hair/location/time/palette drift; exact user photo replaced or never used as a still / frame 1 of ≥1 clip; unusable first frame; two story stills that match as thumbnails.

**Inspiration** is not identity — do not fail because the hero ≠ the inspiration person; do fail if that photo was cloned as the hero.

On FAIL: name the file/shot in the group; Art or Showrunner regens **that** still/clip only; Showrunner pauses Imagine until fixed. Identity = character look, not an X @handle.
