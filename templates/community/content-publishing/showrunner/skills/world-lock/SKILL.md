# /world-lock

**Who:** Art Director

**When:** Song locked; Showrunner assigns world-lock.

**Read first:** `01-audio/master.*` and `01-audio/structure.md` (do not re-ask lyrics/length if filled).

**Output:** `02-bible.md`, `03-stills/` (+ `NOTES.md`). Small **identity** set only (hero, locations, palette) — not one still per lyric. No Imagine video brief, lyric storyboard, video, stitch, mux, or lyrics. Regen world-lock only if identity is wrong (story-still regen is Showrunner/Imagine).

## Exact vs inspiration

Showrunner tags uploads (asks once if untagged). Mixed OK.

- **Exact:** copy as `hero-user.jpg` / `venue-user.jpg`; `NOTES.md` = `user-locked-exact`. That file **is** a still — pin it; ≥1 clip uses it as frame 1; do not redraw a duplicate; other stills generate from it.
- **Inspiration:** copy as `insp-01.jpg`; `NOTES.md` = `inspiration`. Mood/palette/era/lighting only — original A–D from song/theme; do not pin that photo as the character.
- **No uploads:** generate original A–D from song/theme (then exact for later story stills).

## Generate (when needed)

Aspect from brief. Typical A–D (skip slots filled by an exact user file): hero three-quarter; wide location; detail/motif; second location or prop.

Bible freeze list: face, hair, wardrobe, palette (5 words), time of day, hard nos. Name 4–7 pin stills (budget tight).

## Show your work (crew only)

When ready (and after every regen): list each still **by name** in the group; paste `02-bible.md`; write real `.png`/`.jpg` under `03-stills/`; @Showrunner “pin set ready — kick Continuity (before Save confirm).” Do **not** DM the user or ask if they saved. Group text is not user delivery; `/workspace` paths are not delivery.

**Gate:** stills only. Showrunner owns Continuity kick (world-lock before Save), Save confirm, and Imagine brief.
