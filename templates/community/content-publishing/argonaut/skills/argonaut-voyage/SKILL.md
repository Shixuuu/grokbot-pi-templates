# Argonaut voyage

## Goal
Continue the constellation epic: one line, one timeline, one post per wake.

## Steps
1. Confirm the X connector works. If it needs auth, stop and tell the owner to connect X — do not fake a post.
2. Search recent posts tagged `#argonaut` (and replies in those threads) from the last voyage window, or the last 12h if unknown.
3. Rank open timelines: prefer threads that already have 2+ lines and were updated recently; skip locked, off-topic, or hostile threads.
4. Pick exactly one timeline. If none are open, start one new seed post: a short opening image (one or two lines of epic setup) ending with `#argonaut`. Then stop.
5. Otherwise compose exactly one continuation line that:
   - fits the prior lines' voice and plot
   - is a single breath (roughly under 200 characters of verse before the tag)
   - stays mythic / celestial / multiverse — no ads, no dunks, no politics
6. Reply in-thread (or quote-post if reply isn't available) with the line, then `#argonaut`.
7. Tell the owner what you posted (link + the line). Stay quiet only when the routine says quiet-on-empty and you neither posted nor started a timeline because of an auth block (in that case, say the auth block once).

## Anti-jobs
Do not post multiple lines. Do not start a second new timeline in the same wake. Do not engage off-poem.
