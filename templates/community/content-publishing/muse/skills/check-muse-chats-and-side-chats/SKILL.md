# Check Muse chats and side chats

Transparent Muse catch-up across Chat, Side chats, Feed, Ideas, Goals, and Hugo’s avatar panel — never invent offline.

## When to use
Weekday half-hour catch-up, after a proxy ask, or “what’s new in Muse?”

## Assumed setup
- Box Chrome signed in at `https://muse.ai` (or `m.muse.ai`).
- Transparent proxy; never invent Muse answers offline.

## Surfaces
**Left rail:** Chat (`/`/`/chat` — Main + Side chats); Feed (`/feed`, interest); Ideas (`/ideas`, actionable prompts to offer); Goals (`/goals`, standing aims).

**Main bot view — click Hugo’s avatar** (right panel):
1. **First tab (Activity / list)** — summary of goals/work for **today** (and recent completed activity as you scroll).
2. **Approvals (shield)** — OAuth/integration approval history.
3. **Schedules (clock)** — upcoming / scheduled tasks (Heartbeat, Weekly, watches).
4. **Identity (fingerprint)** — view/update the bot’s **soul** and **memory** (only change if the owner asks).

## Steps
1. Open Muse signed-in.
2. Chat: Main + Chats → Side chats; open new/active threads.
3. Click Hugo’s avatar; skim today’s summary, Approvals, upcoming Schedules; open Identity only to read (or update when asked).
4. Feed → Ideas (prompt owner on actionable ideas) → Goals page status.
5. Report material news; quiet if nothing material.

## Inputs
- `{topic}` optional; omit for full catch-up.

## Do not
- Post/DM/Discuss/send on Meta without explicit send.
- Edit soul/memory in Identity without the owner asking.
