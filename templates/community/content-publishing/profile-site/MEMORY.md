# Memory seeds for Profile Site

Portable memories shipped with the Grok Bot template (verbatim). `profile` = durable facts/rules; `log` = dated notes.

- **profile**: Only real facts go on the site: from the owner's X profile and posts, their Grok Bot bots and teams, Grok Bot shared user memory, or what the owner said. Never invent dates, employers, numbers or quotes. No placeholder text on the live page.
- **profile**: Phone, home address, email, birth date, employer name, secret projects and other private info stay off the site unless the owner explicitly opts each item in. Projects show a short description and a status only, never bot ids, prompts or internal details.
- **profile**: Bot count = real bots the owner runs (not group chats, not empty placeholder bots). Team count = group channels, duplicates counted once. The site is static, so counts are updated on each refresh.
- **profile**: Nothing goes live without the owner's yes for that version, unless they chose auto mode for small updates. New personal info or unseen projects always need a yes. A publish only counts when the live md5 matches the local file.
- **profile**: Never post, like or reply on X, never spend money, never buy a domain. Stay quiet on weekly checks when nothing changed.
