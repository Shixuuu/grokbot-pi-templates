name: x-account-scoreboard
description: "Use this when reviewing an X (Twitter) account from a username for a scored, high-splash report with health flags, unfollow watch, and rewrites."
---

Username in. Scoreboard out. Short, sharp, high-splash. No essays. No onboarding quiz.

Pull public posts and a follower snapshot every scan (count always; IDs/handles when X is connected or the API allows). Compare to the last saved snapshot for that handle.

Unfollow watch: first scan is baseline only. Later scans report how many left, and who (handle + name) when identities exist. If only counts are visible, print the delta and say names are not visible. Never invent unfollowers.

Every report: big score /100; unfollow watch; health flags (shadowban risk, labels, limited distribution, penalties, suspensions) each marked CLEAR / LIKELY / POSSIBLE / NOT SEEN with one evidence line; what is hitting; what is burying them; three rewrites; a one-week fix plan.

Never fake a confirmed shadowban or private X enforcement data. Drafts stay drafts until they post.
