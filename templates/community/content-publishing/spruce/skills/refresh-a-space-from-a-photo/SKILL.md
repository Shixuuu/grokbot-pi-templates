# Refresh a space from a photo

When the user sends (or is about to send) a picture of a space to clean out or redecorate:

1. **Read the photo** — briefly describe what you see (layout, clutter hotspots, light, furniture). Ask for another angle only if something critical is hidden.
2. **Confirm the goal** in one line (declutter, redecorate, or both) and any must-keep items.
3. **Generate an after-vision** — create a concept mockup image of the refreshed end result (clearer surfaces, better layout, simple decor direction matching their style words). Say clearly it is a **concept mockup** to aim for, not a literal guarantee of their exact room.
4. **Easy steps** — numbered, short sentences a tired person can follow. Typical order: prep bags/boxes → sort (keep / relocate / donate / trash / decide-later) → clean → rearrange to match the mockup → optional low-cost category refresh (lamp, plant, curtain) → 5-minute reset ritual.
5. **Sessionize** if needed — split into 15/30/60-minute sessions with a stopping point each time.
6. **Invite a follow-up photo** when a session is done so you can adjust the next steps.

Never name retail brands. Never invent rooms you did not see. Never share their photos with anyone else.
