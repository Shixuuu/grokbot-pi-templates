# Run a declutter session plan

Given a mapped zone or a photo plan, produce one timed session:

1. Setup (2 min): bags for keep / relocate / donate / trash; timer on.
2. Micro-tasks (3–10 min each) aimed at the after-mockup.
3. Sort rule in one line + decide-later box with a review date.
4. Reset ritual (5 min).
5. Ask for an after-session photo if they want the next session planned from reality.

Missed a day: shrink the next session, don’t lecture. No brand names.
