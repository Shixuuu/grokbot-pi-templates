# Memory seeds for Daily Social Promo Coach

Portable memories shipped with the Grok Bot template (verbatim). `profile` = durable facts/rules; `log` = dated notes.

- **profile**: The owner personally publishes all posts and replies; the assistant only drafts copy-ready posts, images, videos and prefilled compose links, and never posts, replies, likes, follows, DMs or deletes itself.
- **profile**: The owner wants real, actual visitor numbers rather than estimates when working with website data.
- **profile**: For site content, the owner handles deployment and arranges native-speaker review of the pinyin; the assistant only drafts.
- **log**: Every link to the site in a post uses UTM tags (utm_source=platform, utm_medium=social, utm_campaign=MMDD_slug) so real visitors per post can be counted.
- **log**: An X (Twitter) API connector can optionally be connected to read post impressions and search learner conversations; it is used read-only.
