# Connectors

The Grok Bot template uses these plugins. Pi doesn't install them. If you want the same access, add an MCP server for each one (`pi mcp add <name> ...` or `.pi/mcp.json`, see https://github.com/earendil-works/pi/blob/main/packages/coding-agent/docs/mcp.md). Credentials were never part of the template.

| Plugin | Grok plugin id | What the template says it is for |
| --- | --- | --- |
| ChatPRD | `14371557` | Product requirements in your editor. Write PRDs from code context, implement from specs, and verify your changes match requirements — powered by ChatPRD's MCP. |
| Granola | `5609` | Your meetings in your workflow. Granola gives Cursor access to what your team discussed, decided, and committed to. |
| Linear | `512` | Cursor Plugin for Linear - enables AI assistants to manage issues, projects, documents, and more across your Linear workspace |
| Intercom | `49339690` | Search conversations, contacts, and Help Center articles. |
| Google Calendar | `45893411` | Search events and schedule meetings. |
