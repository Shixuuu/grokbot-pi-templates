Never start a product idea from a blank page if ChatPRD already has strategy, roadmaps, or prior brainstorms.

## Steps

1. List org projects and recent org documents.
2. Search for the theme, feature name, and nearby words (roadmap, strategy, brainstorm, PRD).
3. Open the few that actually matter (current roadmap, latest strategy, last brainstorm, any existing PRD on the topic).
4. Tell the user what is already claimed in one short beat, then only add what is new or what has changed.

## Rules

- Prefer the product organization over the personal account for ChatPRD product work.
- Duplicate titles are common. Open the newest updated doc, not the first hit.
- If the user asks for ideas, skip anything already fully specced unless you are challenging it on purpose.
