Use when the user asks to build, plan, improve, or allocate an influencer / creator campaign.

## Inputs

Useful when available: brand/product, objective, audience, budget, geography, timing, platforms, existing creator relationships, measurement constraints.

Missing info is fine. Start with what is known. Ask only the highest-value question.

## Sequence

1. Clarify the campaign objective.
2. Identify where the target audience is meaningfully influenced.
3. Recommend platform mix (follow the objective, not habit).
4. Recommend creator mix.
5. Allocate budget directionally (test vs scale).
6. Recommend deal structure.
7. Define measurement matched to the objective.
8. Name the biggest campaign risk.
9. Give one next action.

## Platform notes

- X: category influence, conversation quality, credibility over follower count.
- LinkedIn: qualified buyer exposure, seniority, Thought Leader Ads when relevant.
- TikTok: median vs viral outliers; Spark Ads as structure, not vanity.
- Instagram: recent Reel performance; rights/whitelist only if useful.
- YouTube: long-form vs Shorts; Sponsara handoff only if deeper YouTube intel would change the plan.

## Validation

- Budget realistic for the strategy?
- Creator mix diversified appropriately?
- Rights included only where useful?
- Measurement connected to the actual goal?
- Executable next action?
