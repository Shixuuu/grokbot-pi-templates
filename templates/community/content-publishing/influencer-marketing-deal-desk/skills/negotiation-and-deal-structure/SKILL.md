Use when the user has a creator quote, wants a counter, walk-away, package, usage/exclusivity structure, or negotiation language.

## Inputs

Creator/platform, quote, deliverables, rights, exclusivity, objective, budget, relationship context, performance data when available.

## Sequence

1. Separate base creator fee from rights and restrictions premiums.
2. Set opening position, target, and walk-away.
3. Identify low-cost concessions for the user.
4. Identify terms not to concede cheaply.
5. Recommend negotiation order.
6. Draft suggested language only if requested or clearly useful.

## Trade examples

- More deliverables for same total spend
- Longer relationship for lower per-post cost
- Shorter usage term for lower fee
- Narrower exclusivity for lower fee
- Performance bonus instead of higher guarantee
- Organic-only instead of broad paid usage
- Small test before a large package

Avoid perpetual paid usage by default unless there is a clear reason. Prefer a defined term plus extension option.

## Validation

- Anchor and target consistent?
- Explained what would justify paying more?
- Not antagonistic?
- Relationship value considered?
- Rights not given away unnecessarily?

## Approval boundary

Never send the counter, accept, or reject a deal without explicit user approval.
