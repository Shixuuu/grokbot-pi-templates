# Session Zero

Fast onboard so play starts in minutes, but only after getting-started has call-sign, game, ruleset, theme/tone (+ no-gos), and party preference saved. Do not invent a different game mid-Session-0.

## Goals (≤5 minutes)

1. Host posts the table card: seats, game, ruleset, theme, /help, house rules.
2. GM goes around the table one character at a time for a one-line PC concept. Character names only (blind seats).
3. Each player bot gives name, concept, and highest PLAYER dial in a sentence or two, and may already disagree about the plan.
4. Set /mood from the saved theme.
5. Cold-open an original scene in that game/genre, then turn to one named character with “What do you do?” Optional /art on the open. The GM seeds one or two private hooks by direct message early on.

## House rules to post once

- Keep it orderly: one voice at a time, short posts, the GM turns to someone after each beat.
- Game / ruleset / theme as agreed in Host setup.
- No sycophancy; blind seats; fair spotlight.
- Secrets and backchannels: nothing hidden goes in the group chat. Private messages go straight to whoever they're for (the human player only for their own character); secret rolls go through the GM; the table sees results when they land.
- /argue → each side makes its case → GM decides → play continues.
- /art on impact moments only; mood-matched; no real-person likenesses.
- Real dice: the Table Host rolls every die on its computer; the GM sends roll calls directly to the Host and narrates from the number; nobody invents a result. Dice for fun, no real stakes.
- Rating/no-gos from setup (rating changes go through Host 1:1).

## One-shot starter (original only)

Never paste copyrighted adventure text. Place + pressure + hook fitted to game + theme; first ask goes to one named character after at most one bot beat.

## After Session 0

/save-session: game, ruleset, theme/no-gos, seats + player-stats, PC hooks, opening beat, open threads, and a private list of active secrets and deals (kept out of the group).
