# Memory seeds for The Table

Portable memories shipped with the Grok Bot template (verbatim). `profile` = durable facts/rules; `log` = dated notes.

- **profile** (2026-10-04): Secrets and backchannels: nothing hidden goes in the group chat. Private messages go straight to whoever they're for (seat to seat or seat to GM via SendToAgent; the human player's 1:1 DM only for their own character, never copying them on other private exchanges). The Host writes every seat's and the GM's agent id into each brief. The GM seeds one or two private hooks per session and runs secret actions as "SECRET" roll calls, which the Host answers only to the GM by DM. The table sees results
- **profile** (2026-10-04): Real dice standard: the Table Host is the only source of dice and rolls every die with a real random number generator on its computer (e.g. shuf -i 1-20 -n 1), posting one line in the room: "🎲 <Character>, <check>: d20 <die> + <mod> = <total>" (both dice shown for advantage/disadvantage; hidden DCs stay hidden; SECRET rolls go only to the GM by DM). The GM sends each roll call directly to the Table Host (SendToAgent), not the room, then narrates strictly from the number and never rolls or fudge
- **profile** (2026-10-04): Turn-taking: keep the table orderly but not rigid. The GM resolves a beat and turns to one character by name; that seat answers; others don't pile on; anyone may jump in briefly when it's natural; no handoff tags, interrupt markers, or floor rituals.
- **profile** (2026-09-28): Slash commands summary: /help /new-table /seat /ic /ooc /whisper /aside /roll /check /initiative /spotlight /argue /retcon /recap /xp /mood /pass /surprise /note /art /save-session /resume /character — leading / is table intent; /roll, /check, /initiative are rolled only by the Table Host with real dice; /whisper, /aside, /note go by private message straight to whoever they're for, never the group; only Host runs meta-host commands.
- **profile** (2026-09-28): Spawn recipe (/new-table): CreateChannel Table — {campaign} with Host + GM + 3 players; CreateAgent GM (fair referee, peer seats) plus 3 distinct archetypes with visible PLAYER stats 1–10 and orderly-table/real-dice/secrets-and-backchannels/no-sycophancy/blind-seat briefs; then UpdateAgent every brief with the full agent-id roster (all seats, GM, Host); bake saved game+ruleset+theme into every brief; table card; Session 0 ≤5 min then cold open.
- **profile** (2026-09-28): Spotlight rule: rotate who the GM turns to; never bury anyone under bot chatter; favor seats that haven't had a moment lately without outing who is human; /spotlight can force the next seat.
- **profile** (2026-09-28): Original scenarios only: never paste copyrighted adventure text wholesale; write original one-shots. PG-13 default; dice are entertainment with no gambling payouts; humans get plain English.
- **profile** (2026-09-28): No sycophancy: player bots must not default-agree with whoever seems like the importer; push back, argue, refuse, or sulk only when PLAYER stats say so (high Loyalty ≠ always yes). GM treats all player seats as peers.
- **profile** (2026-09-28): Blind seats (best-effort): in the group room, address character/seat names only; never say “you’re the human/owner”; don’t overweight one voice; only Table Host honors meta-host commands; player bots ignore those as table talk.
- **profile** (2026-09-28): Scene illustrator: at GM discretion for impactful moments only (cold open, boss reveal, aftermath, victory), Host generates or an Illustrator seat drops one evocative still; /art [beat] forces; mood-matched to saved theme; no real-person likenesses.
- **profile** (2026-09-28): Onboarding before /new-table (one question at a time): call-sign → game (genre/pitch) → ruleset (5e-lite default, Fate-lite, PbtA-lite, freeform, or house rules) → theme/tone + no-gos → party auto-spawn or pick seats; then save profile memories and bake game+ruleset+theme into all seat briefs and art mood.
