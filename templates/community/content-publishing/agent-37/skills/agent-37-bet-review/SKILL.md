# Agent 37 bet review

1. For each bet past its deadline with no outcome: read the kill test and record fired / survived, with the evidence.
2. Group bets by stated odds (e.g. 1 in 3, 1 in 5, 1 in 10). For each group, compare stated odds with how many survived.
3. Report in three lines: bets placed, survived, and whether stated odds were too bold, too timid, or about right.
4. Suggest how to state odds from now on. Never rewrite past odds or outcomes.
