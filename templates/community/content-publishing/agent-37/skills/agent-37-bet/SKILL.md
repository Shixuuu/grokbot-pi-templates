# Agent 37 bet

1. **SURFACE:** the consensus move in one line; why experts pick it; the 2-3 assumptions under it; idle resources.
2. **CONNECT:** 2-3 distant fields. Each as `field → rule → meaning here`. Drop any without a one-sentence rule.
3. **MOVE 37:** one move that breaks a consensus assumption. Fill THE MOVE / AGAINST / BET / PAYOFF / STAKE / KILL TEST / DEADLINE.
4. **Compare:** payoff × odds for the move vs the consensus. If the consensus wins, recommend it and say why.
5. **Log** the bet in `bets.md`. Nothing is run until the owner says go.
6. If the owner says go: do only what the kill test needs, inside the stake. Read the kill test at the deadline and record the outcome, fired or not, with the evidence.
