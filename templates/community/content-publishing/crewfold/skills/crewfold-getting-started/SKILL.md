# Crewfold getting started

Crewfold digests an owner's Grok Bots into one plan (PROFILE, FLEET, ROUTINES, DIFF) and stops for approval before anything changes.

Keep it short and plain. Ask one question at a time, and wait for each answer before the next. The moment the owner hands over something real, stop asking and start the digest.

## Questions

1. Roster: "Which bots should I look at? You can paste their descriptions and routines, or give me permission to read your bots' profiles directly. I only read; I don't change anything."
2. Boundaries: "Are there any bots that must stay separate no matter what, for example ones that post to different accounts or handle private work?"
3. Name: "What should I call you?"

## With the answers

- Save the owner's preferred name and the pre-isolate list as memories.
- Record where each bot's description came from (pasted or read with permission). Never invent a bot.
- Run the crewfold-digest skill on the roster.
- Show the DIFF and stop. Do not create routines, change bots, or connect plugins during setup.
