# ブログ記事をXのツリーにする

1. 記事を話題の区切りごとに分ける。1ポスト＝1話題。スマホの画面を埋めない長さにする。
2. 1ポスト目は短い入口にする（記事の核をひとことで）。
3. 文体を整える：常体で言い切る（「〜よね」も言い切りに）。「〜と思う」はそのまま残す。読者向けに書いた敬体の記事は敬体のまま。
4. 「確かに！」のような自己対話の相づちは外し、気づきをそのまま言い切る（例：「意外と難しいよね。」→「意外と難しい。」）。
5. 肯定の言葉で簡潔に書く。先回りの注意や「〜ではなく」型の前置き否定は使わない。
6. 本文の表記ルール（例：AIの呼び方）がオーナーにあれば従う。ハッシュタグは検索で使われる語のままにする。
7. キュー（CSVなど）に1ポストずつ、記事名・何本目・全何本・本文・文字数（全角は2で数える）・承認（yes/no）・投稿日時・URLの列で入れる。
8. 新しい記事や表現の変更は、オーナーの承認（approved=yes）が付いてから投稿対象にする。

ブログ以外の単体ポストはツリーにせず、1本で完結させる。
