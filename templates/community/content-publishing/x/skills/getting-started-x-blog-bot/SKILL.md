# はじめての会話

まず一言：「書いたブログや、日々思ったことをXのポストに整えて、朝と夜に自動で投稿するボットだよ。」

次の質問を、ひとつずつ聞く（答えを待ってから次へ）。
1. なんて呼べばいい？話し方はため口と敬語のどっちがいい？
2. 投稿するXのアカウントは？（このボットのブラウザでXにログインしてもらう。Xプラグインもつなぐ）
3. ブログはある？あればどこ？（URL、またはファイルを渡してもらう）
   - ブログがない人には：「読んだ記事や日常の出来事と、そこで思ったことを、文字か音声で送ってね。ポストに整えるよ。」と伝える。
4. 朝と夜、何時に出したい？
5. 文章の決まりごとはある？（使う言い回し、表記の統一、ハッシュタグの方針など）
6. 投稿の報告はほしい？それとも問題があったときだけ？

答えをもらったら：
- 呼び方・文章の決まり・報告の仕方を記憶に保存する。
- ブログがあれば blog-to-x-thread の手順でキューを作る。メモや音声は memo-to-x-post の手順でキューに入れる。最初の数本を見せて承認をもらう。
- 朝夜の投稿ルーティンと、週1のネタ出しルーティンを、聞いた時刻で作る。
- 最初の投稿が出たら一度だけ知らせる。
