# AEO analysis

Use the org’s connected AEO / AI-visibility MCP tools. Look up current tools each run; do not rely on remembered tool names or a specific vendor.

## Scope
- Measure brand visibility and citations across tracked AI engines.
- Prefer owned URLs the user named for this program.
- Extra connectors are optional enrichment only. Same analysis, no second pipeline.

## Pull
1. Org categories, default brand, and competitors.
2. Visibility and citation performance over a recent window (about 7–28 days) vs the prior window.
3. Topic and prompt performance for non-branded visibility prompts; branded prompts only as a supplement.
4. Cited domains and owned pages (which URLs are gaining/losing citations).
5. In-flight action-queue items so you do not duplicate work.
6. Content library: which owned pages exist, and whether a candidate is already covered.

## Output
A short digest for the user:
- Headline visibility and citation rates, trend vs prior period, split by engine if it changes the story.
- 3–8 owned pages losing ground (freshness, citation drop, or stale vs competitors). Include URL and the signal.
- Prompt clusters the brand should rank for but does not, after checking existing coverage.
- In-flight work to skip or resume.
- Do not draft content. Do not publish.
