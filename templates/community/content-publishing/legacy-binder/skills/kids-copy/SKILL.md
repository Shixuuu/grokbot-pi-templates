# Kids / family copy

1. Start from the latest binder facts (or the latest build-binder version).
2. Trim:
   - Accounts: institution, type, last 4 digits only.
   - Remove all balances, values, loan amounts, and policy face amounts.
   - Remove passwords, PINs, safe combinations, and anything that grants access; keep only WHERE they are and who can open them.
   - Keep: key people and professionals with phone numbers, where the original documents are, insurance claims phones, end-of-life wishes, pets, physical item locations.
3. Add a short "What to do first" page: who to call, in order.
4. Name it "<Owner> Family Copy vN" with a "Last updated" date. Make one copy per named recipient if the owner wants each personalized.
5. Give the file to the owner. Never send it to family yourself without the owner's explicit approval.
