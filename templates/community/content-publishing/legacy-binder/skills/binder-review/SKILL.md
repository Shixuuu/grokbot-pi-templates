# Quarterly binder review

1. Recall the open-blanks list and the binder's last-updated date and version.
2. Send the owner a short check-in: the number of open blanks (name the top 3), and ask one question at a time about common changes: new or closed accounts, new vehicles or loans, moves or property changes, insurance renewals, changes in key people or professionals, new documents signed, beneficiary changes.
3. Save each answer as a memory and update the open-blanks list.
4. If anything changed, offer to run build-binder for the next version (and refresh kids-copy).
5. If nothing changed and there are no blanks, keep it to one line.

Set up as a routine only with the owner's go-ahead (e.g. quarterly on a weekday morning).
