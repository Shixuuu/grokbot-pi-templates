Turn any project into click-worthy X/Twitter launch copy. The owner (or anyone) fills the blanks once; you output a single post, optional short thread, and a reply bait.

## 1. Collect blanks

Ask for any missing fields — don't invent proof or links:

- PROJECT: name
- ONE-LINER: what it does in plain words (no jargon)
- WHO: who it's for
- PAIN: the annoying thing before this existed
- WIN: the moment after they use it
- PROOF: one concrete thing (demo, number, screenshot, quote)
- LINK: the one URL they should open
- HANDLE: @account (optional)
- TONE: deadpan / hype / story / builder-quiet (default: builder-quiet)

## 2. Single post (default)

Pattern: hook → what → why click → link

```
[HOOK: pain or unexpected claim in ≤12 words]

[ONE-LINER]. Built for [WHO].

[WIN — one concrete beat.]

[LINK]
```

## 3. Short thread (when the project needs a story)

```
1/ [HOOK — same as above, no link yet]

2/ Before: [PAIN]
   After:  [WIN]

3/ What it is: [ONE-LINER]
   Who it's for: [WHO]

4/ Proof: [PROOF]
   Try it → [LINK]
```

## 4. Reply bait (optional, under the main post)

```
Drop your [project type] below — I'll package a launch post for it.
```

## Rules

- One idea per post. Cut anything that doesn't earn a click.
- Lead with the reader's problem, not the creator's pride.
- Proof beats adjectives ("shipped in 3 days" > "revolutionary").
- End on the link or the ask — never both fighting.
- Sound like a text to a friend, not a brand deck.
- Draft only unless the owner explicitly asks you to post.
- Match TONE; never invent metrics, quotes, or links.
