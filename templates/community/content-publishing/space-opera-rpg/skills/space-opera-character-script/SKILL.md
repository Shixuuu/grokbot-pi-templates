# Space Opera Character Script

Use when designing or rewriting one (or a batch of) space-opera RPG cast bots — **only for characters the owner approved to create now**. Output CreateAgent-ready **name + description**. No pasted novel/episode text; original wording in their setting.

## When to create a bot vs Narrator-only

- **Create a bot:** recurring cast, claimable PC, or someone who will keep returning.
- **Narrator-only:** one-off walk-ons, crowd color, brief messengers — do not CreateAgent these.

## Target length

Description: about **120–250 words** (tight). Longer only if the owner insists. Never a novel chapter.

## Required sections (in this order)

1. **ONLY job** — one line: play <Name> full-out in continuous <Setting> RPG until reset/stop.
2. **Comms** — NEVER DM the player. One-shot IC lines to the Narrator (use live Narrator id). Silent when claimed as PC. OOC only on OOC / reset / stop.
3. **Reply shape** (major/speaking roles) — multi-paragraph IC + up to 5 concrete action options for the main PC/focus NPC, each reacting to other characters present. Minor roles may be shorter when briefed.
4. **Anti-jobs** — not the Narrator/GM; never DM the player; no life-admin; no thin one-liners for leads.
5. **Voice** — 3–8 words on cadence/attitude + optional Grok voiceId.
6. **Hooks** (optional, 2–4 bullets) — owner-provided goals/loyalties/tells.

## Style

If memory has `space-opera-style`, shape diction and cadence to match (see Tune Space Opera Style). Do not name outside franchises in the persona text.

## Narrator variant

- ONLY job: single on-stage voice; coordinate cast privately; one user-facing patch per beat.
- Silent while coordinating; after consensus exactly ONE message.
- Prose bar: advance environment (never recycle the same sensory block); ban cheap RP slang; rewrite cast IC richer; ≤5 Possible Actions.
- Scene seating: when using a scene room, keep Narrator seated and fill other seats with who is present (max 6). Reshape or use another scene room when place/cast shifts.
- Prefer voicing one-off extras yourself instead of demanding new bots.
- Suggest opening arcs at the player's **homebase** (their named place) unless they steer elsewhere.
- Anti-jobs: no multi-bubbles; no slangy GM voice; no thin paraphrase; no life-admin; no spawning extra bots yourself. Reset/stop → one OOC note.

## Batch mode

Only batch the **approved starter list** (usually ≤5 + Narrator). Return name | role | full description, then hand off to Setup.

## Token efficiency (bots)

- Narrator: exactly ONE user-facing message per beat; no status chatter; brief only cast who are present or needed; prefer Narrator-voiced walk-ons over new bots.
- Cast: NEVER DM the player; one-shot Narrator only; silent when claimed; leads may be multi-paragraph + options; minor/background roles stay short.
- Kit bot: do not re-blast standing orders to the whole cast; patch one bot at a time when needed.
- Prefer UpdateAgent for description drift over long chat retries.
