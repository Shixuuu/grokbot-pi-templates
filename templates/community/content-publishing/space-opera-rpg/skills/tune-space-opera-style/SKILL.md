# Tune Space Opera Style

Use when the owner wants to set or change writing style, Narrator pacing, option shape, or how the kit talks to them OOC. Also run after Getting Started once a style is chosen, and when the weekly play tune-up routine fires.

## Style menu (pick one primary; optional secondary note)

Offer these as plain choices — examples of *approaches*, not named franchises:

1. **Literary / novelistic** — dense sensory paragraphs, interiority, slower scenic burns.
2. **Teleplay / episodic** — snappy dialogue, clear scene/act turns, leaner narration.
3. **Political intrigue** — subtext, faction pressure, careful public vs private speech.
4. **Military / procedural** — crisp status, chain-of-command texture, mission framing.
5. **Frontier grit** — lean diction, dry humor, scarce resources, hard bargains.
6. **Found-family drama** — relationship stakes first, warmth and friction in the crew.
7. **Pulp adventure** — bold set pieces, cliffhanger endings, higher pulp energy.
8. **Hard systems** — technical clarity, logistics and constraints matter on-page.

Write the choice to memory as `space-opera-style: <name>` plus one sentence of owner notes (pacing, humor, darkness).

## Communication dials (ask briefly)

- **Possible Actions:** short (3) / standard (≤5) / richer wording.
- **OOC check-ins:** rare (only when stuck) / weekly routine only / ok to ask mid-play if something feels off.
- **Address:** how the kit should talk to the owner out of character (casual / neutral / formal).

Save as memory facts.

## Apply

1. Update Narrator description (or SendToAgent Narrator) with the style + prose bar + dials — keep ONE-message-per-beat and cast coordination rules.
2. For live cast, prefer UpdateAgent on descriptions that need the style line; only SendToAgent (held/false) one bot at a time when a chat brief is required — never fan-out the whole cast in one turn.
3. Confirm to the owner in one short message what changed.

## Anti-jobs

Do not rename to franchise titles. Do not paste copyrighted prose as style samples. Do not spawn new bots just to change style.

## Token efficiency

- Keep apply steps short. No full-persona paste. No transcript dumps.
- Narrator stays one message per beat; minors stay short; walk-ons stay Narrator-voiced.
