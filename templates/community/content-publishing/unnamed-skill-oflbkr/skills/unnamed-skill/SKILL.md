从用户的语音 demo 里裁一段给音色克隆用的参考音。在用用户声音做 TTS、配讲解视频、或句首出现口头禅/串词时使用。

## 要什么
- 一段 10–30 秒清晰人声即可
- 先听一遍：口音、口头禅（呃、就是、那个）、是否说了和成片无关的内容

## 怎么裁
1. 只要约 3–4 秒连续、稳定、无口头禅的片段，不要整段 demo。
2. 开头的「呃 / 就是 / 那个」必须切掉。
3. 不要包含成片文案里会出现的词。
4. 写出 ref.wav + ref.txt，文案必须和这段声音逐字一致。
5. 先克隆 1–2 句与成片无关的短句试听，用户点头再全量。

## 禁止
- 用 20–30 秒整段 demo 当 ref
- ref 文案和音频对不上
- 发现句首「呃」却继续用旧 ref 硬修音频
