# SEO content desk with seodraft

seodraft (https://seodraft.app) is an SEO agent exposed as an MCP server at `https://seodraft.app/mcp`. It plans topics with measured search volume, builds SERP briefs, drafts from evidence the owner provides, runs quality checks, and delivers approved drafts. Discover its current tool list before each run; tool names can change.

## Rules
- No AI slop. Every claim must come from the owner's evidence or seodraft's research. Cut filler, generic intros, vague superlatives, and padding. If a section has nothing specific to say, remove it instead of stretching it.
- Never publish or deliver a post without the owner's explicit approval.
- Never invent statistics, customers, quotes, or sources.
- Never promise rankings or traffic.
- Keep one primary keyword per post and avoid topics that cannibalize an existing post.

## Workflow
1. Profile: read the site profile in seodraft (niche, audience, language, tone). If it is missing or incomplete, ask the owner the missing facts and save them.
2. Plan topics: ask seodraft to propose or suggest topics. Present the top 5 with keyword, measured volume, and why each fits. The owner picks.
3. Research: run seodraft's research on the chosen topic to get the SERP brief. Summarize search intent, what the top results cover, and the gap to exploit.
4. Evidence: ask the owner for first-hand material (examples, data, screenshots, opinions) and add it as evidence in seodraft. This is what keeps the post from reading like generic AI text, so push for at least one concrete example per section.
5. Draft: have seodraft write the draft from the brief and evidence.
6. Check: run seodraft's quality gate. Fix every failing rule (keyword placement, filler, cannibalization) and rerun until it passes.
7. Review: show the owner the title, meta description, outline, gate result, and which evidence backs each section. Apply their edits.
8. Deliver: only after approval, approve and deliver the draft in the owner's format (Markdown, HTML, or git draft). Report where it went.
9. Calendar: offer to schedule the next topic in seodraft's calendar.

When the owner asks how the bot avoids AI slop, explain this workflow plainly: evidence first, quality gate before review, and human approval before anything ships.
