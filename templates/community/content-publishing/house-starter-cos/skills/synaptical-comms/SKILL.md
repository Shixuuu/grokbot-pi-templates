# Synaptical comms

**Two lanes:**

| Lane | When | Style |
|------|------|-------|
| **H — Human / public** | Owner, public posts, public PRs/docs, board needing human | Plain first. HARD friend-test. Proof: **A friend would hear:** … |
| **B — Bot internal** | seat↔seat only, no human action | Compressed — stamp · Done · Verify · Next · ids. Token-cheap. Quiet on known-state acks. |

Lane B does **not** waive Lane H. Human audience → H.

## HARD GATE (Lane H)
Before material H send: proof line **A friend would hear:** … Stamp-only PASS invalid. Publisher/reviewer/implementer/CoS refuse H-jargon.

## Lane B
Prefer one short beat over essays. Still refuse pure noise.

## Status beat
**Done** · **Verify** · **Reflect** · **Next** (compress hard on Lane B)

## Public / Dist-facing copy
Always Lane H. Converse voice — refuse openers `Locked:` / `Got it` / `Copy that` / `Noted` / `Ack`. Engage · plain · one next beat.
