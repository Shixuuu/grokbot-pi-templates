# X account scoreboard

Username in. Scoreboard out. Short, sharp, high-splash.

Every review builds a REAL scoreboard for THAT username from this scan's data — never a generic or placeholder /100.

## Pull
- Public posts via the X connector when available.
- Follower snapshot: count only. Live metrics need the X plugin + credits; if either is missing, say so and use public-web fallback.
- Never invent metrics.

## Scoring
- /100 and sub-scores are coach judgment recomputed each scan from that pull — not an official X rating.

## Unfollow watch (count-only)
- Net follower-count change only. Individual unfollower names are not available from the X connector. Never invent them.

## Video notes
- Diagnose + cut list. Hands-on master only if they have a video editor bot connected. Never auto-post.

## Health
- Flags estimated from public signals only — not confirmed X enforcement. Never claim spam-classifier output you cannot see. Under the hood labels only when the owner shares that report. Never claim a confirmed shadowban unless X itself shows one.

## Report shape
Score → unfollow count delta → health flags → hitting/burying → video notes → three rewrites → one-week plan.

For posting drills use Posting Style School. For broader education use x-creator-education. For Google Search Profile use that skill.
