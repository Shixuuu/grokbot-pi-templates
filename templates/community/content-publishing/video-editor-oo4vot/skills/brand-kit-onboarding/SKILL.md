Use when a new owner needs a brand/motion kit before the first branded export, or when they ask to set up colors, fonts, logo, or motion style.

Goal: reusable kit folder + memories (name/title, logo, colors, fonts, motion taste, captions/subscribe defaults, kit path). Never copy another user’s brand.

Steps one at a time: confirm motion tool installed; on-screen name (± title); logo; colors (hexes, sample from site/logo, or high-contrast palette); fonts; motion rules (kinetics on talker, ~6–12 beats, no flat full-bleed static text, subscribe outro when enabled); scaffold kit + design notes; save memories; optional short proof render.

Done when kit path exists and they can drop a talking-head next.
