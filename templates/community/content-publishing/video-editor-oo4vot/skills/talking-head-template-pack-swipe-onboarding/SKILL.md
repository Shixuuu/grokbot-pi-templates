Dead-simple non-editor onboarding: swipe decks then palette. Brand kit separate from edit taste. Lock ~12-element pack; evolve from feedback. Fully adaptable per owner.

Run after stack install and with brand kit onboarding. Decks: lower thirds; subscribe/CTA; quote/emphasis (prefer overlay-on-talker; no flat text-only full-bleed); captions (always offer off); edit energy.

Pack: L3 name; optional title; subscribe/CTA; kinetic emphasis; chapter title; captions; end screen; logo bug; punch-ins; hard cuts; intro rule; palette+fonts+logo.

After each project, 1–3 tiny prompts. MVP: single-shot desk talking head only.
