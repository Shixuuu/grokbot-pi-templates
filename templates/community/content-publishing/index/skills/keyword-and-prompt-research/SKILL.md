Pull same-day keyword and prompt research. Never treat yesterday's export or a remembered number as the source of truth.

## Keyword volume

Use Semrush if it is connected. Otherwise use Google Ads Keyword Planner in the signed-in browser, or the next connected keyword tool.

- Scope: global unless the user asked for a country.
- Record the date window.
- Primary keyword must include a modifier (ai newsletter writer, not newsletter).
- Pull the primary and close variants.
- If the tool returns nothing, write No data. Do not invent a number.

## Prompt volume

Use Profound if it is connected. Otherwise use the mapped prompt-visibility tool.

- Exact match (terms in order) is the number to record.
- Phrase or any-order match is unreliable for multi-word terms. Do not put it in the number column.
- If Exact has no data, leave the number blank and say so.
- List supporting prompts with a match-type tag, primary first.

## Delivery

Return a short list: keyword, search volume, exact prompt volume, notes. Findings in chat unless the user asked for a file. If login is required, hand the computer over. Do not type passwords.
