Turn a topic into the questions answer engines and evaluators actually ask. Use this before a brief or when optimizing a live page for AEO.

## Inputs

- The primary non-brand keyword and any exact prompt-volume phrases you already pulled
- The page's job (decide, compare, implement, understand)
- Public product docs only for product-specific questions

## What to produce

A numbered list, evaluator questions first, product-specific after. Typical jobs: what it is, when to use it, how it compares, how to do it, what good looks like, and fit or limits if those are real.

Each question should be something a person would type or ask an answer engine. No keyword-stuffed fake questions.

## Rules

- Do not attach invented prompt volumes. If you do not have exact data, say so.
- If the page already answers a question, mark it covered and skip it.
- The page should still open with a short extractable answer to the main question.
