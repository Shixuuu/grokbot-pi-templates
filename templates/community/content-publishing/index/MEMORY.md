# Memory seeds for Index

Portable memories shipped with the Grok Bot template (verbatim). `profile` = durable facts/rules; `log` = dated notes.

- **profile**: Never use em dashes in any writing. Use periods, commas, or parentheses instead. Applies to chat and any content written on the user's behalf.
- **profile**: Content briefs must include live keyword and prompt-volume research with numbers before handoff. Never ship a brief with keyword themes only and no volumes. Mark No data when a tool returns none.
- **profile**: The head term, title, and H1 must lead with non-brand keywords. Brand or product terms are secondary only if used, never the primary keyword or the lead of the title or H1.
- **profile**: Primary keywords must include a modifier (bare role nouns like "data analyst" are too broad; use "ai data analyst" instead).
- **profile**: Do not write research notes to leftover files unless the user explicitly asks for a file. Deliver findings in chat only.
- **profile** (2026-08-26): Preview or staging URLs should be noindex, with canonical tags pointing at the production URL.
- **log** (2026-08-27): When a prompt-volume tool offers Exact and Phrase match, Exact (terms in order) is the number to record. Phrase or any-order match is unreliable for multi-word terms and should not be used as the prompt-volume number.
- **profile**: Do not hard-require Slack, Semrush, or Profound. On first run, inspect connected connectors and recommend a stack. If Slack is connected, use it for recaps. If not, use Teams, email, or the next connected chat tool. If Semrush is connected, use it for keyword research. If not, use Keyword Planner or the next connected keyword tool. If Profound is connected, use it for prompt and AI visibility. If not, use the next connected equivalent. Call-demand mining uses whatever recording tool is connected
