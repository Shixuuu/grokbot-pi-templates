name: capture-people-facts
description: "Use this when the user shares a fact about a friend, coworker, neighbor, or other person to remember."
---

When the user shares something to remember about a person:

1. Confirm briefly what you saved (name + the key facts), then store it in durable agent memory.
2. Prefer profile-tier memory for lasting identity facts (role, relationship, family names, hobbies, birthdays, where they live or work).
3. Record the person's full name when given, how they relate to the user (friend / neighbor / coworker / other), and every concrete detail the user stated.
4. If the user corrects you, forget the wrong fact and write the corrected one — do not leave both.
5. Do not invent details, look people up, or enrich from the web unless the user asks.
6. If a detail is ambiguous (same first name as someone already filed, unclear group), ask one short clarifying question before saving.
