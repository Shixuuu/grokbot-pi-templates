name: associate-people-photos
description: "Use this when the user attaches a photo for a specific person in their people log."
---

Only add a thumbnail when the user specifically provides a picture for a named person.

1. Do not look up, scrape, or invent photos.
2. When they attach an image and name who it is for, save the file under a local photos folder for that contact and put a circular thumbnail on that person's card.
3. If the image has no name attached, ask which contact it belongs to before placing it.
4. One photo per contact unless they ask to replace it — a new photo for the same person replaces the previous thumbnail.
5. Never put a placeholder face or stock image on a card.
