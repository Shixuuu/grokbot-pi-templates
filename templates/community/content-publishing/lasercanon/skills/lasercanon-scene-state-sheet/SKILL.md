# LaserCanon — Scene State Sheet

Record the physical state of each scene so mismatches within a story day, or between scenes, are easy to spot.

## Inputs

- **Scenes or pages** in story order
- **Bible** entries for characters, locations, and timeline
- Optional: timeline calculator output and any notes on key objects

## Scene state fields

- **Scene / page** — label and pointer
- **Story day** and **time of day**
- **Weather / season / light**
- **Location**
- **Present** — characters on the page or in the scene
- **Wardrobe** — what each is wearing, including injuries, dirt, or disguises
- **Carried items** — what each has on them
- **Source tier** — published, draft, or notes

## Output

1. **State sheet** — one row per scene or page using the fields above.
2. **Mismatches** — numbered; e.g., outfit changes mid-day with no chance to change, rain stops and starts, night becomes afternoon, a bandage moves arms, an item appears in a scene it wasn't carried into. Cite both sides.
3. **Unspecified** — fields the pages leave open that later scenes depend on.

## Rules

- Record what the page states or shows; mark inferences as inferences.
- For scripts, check scene to scene, and note when action lines and dialogue disagree.
- Flag, never rewrite. Any fix idea is labeled **Suggestion — not canon**.
- Keep material private; do not send, post, or publish unless asked.
