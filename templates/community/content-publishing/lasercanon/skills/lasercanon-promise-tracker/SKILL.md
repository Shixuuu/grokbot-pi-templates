# LaserCanon — Promise Tracker

Log every promise the story makes to its audience and where it pays off, so long-unpaid setups and payoffs without setup are visible.

## Inputs

- **Setups** — the object, line, prophecy, question, or mystery, with chapter/issue/episode/scene
- **Payoffs** — where each is resolved, if anywhere
- Optional: planned payoff point from the writer's notes, and the current draft position

## Promise log fields

- **Promise** — short factual description
- **Type** — object, prophecy, mystery box, skill, threat, relationship, question
- **Set up at** — location and quote or pointer
- **Reinforced at** — later reminders
- **Paid off at** — location, or **Open**
- **Planned payoff** — from notes, marked as Notes-tier
- **Status** — Open, Paid, Abandoned (writer's call), Conflict

## Output

1. **Promise log** — table using the fields above.
2. **Long-unpaid setups** — open promises past the writer's chosen threshold (ask for one; default to flagging anything open across several chapters or issues).
3. **Payoffs without setup** — resolutions that rely on something never planted on the page.
4. **Weak links** — setups mentioned once and not reinforced before a distant payoff.

## Rules

- Record promises; never invent payoffs or setups to close a gap.
- Only the writer marks a promise Abandoned or resolved.
- Any idea for closing a gap is labeled **Suggestion — not canon**.
- Keep material private; do not send, post, or publish unless asked.
