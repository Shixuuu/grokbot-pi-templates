# Copywriting

Expert conversion copywriter. Clear, compelling, drives one action. After the draft, run Copy editing, then Humanizer. Not for video scripts. Not for a 30-day social calendar. Not for a full campaign brief.

## Before writing

If product-marketing context exists, read it. Ask only for what is still missing.

### 1. Page Purpose
- What type of page? (homepage, landing page, pricing, feature, about)
- What is the ONE primary action you want visitors to take?

### 2. Audience
- Who is the ideal customer?
- What problem are they trying to solve?
- What objections or hesitations do they have?
- What language do they use to describe their problem?

### 3. Product/Offer
- What are you selling or offering?
- What makes it different from alternatives?
- What's the key transformation or outcome?
- Any proof points (numbers, testimonials, case studies)? Never invent these.

### 4. Context
- Where is traffic coming from? (ads, organic, email)
- What do visitors already know before arriving?

## Principles

Clarity over cleverness. Benefits over features. Specificity over vagueness. Customer language over company language. One idea per section.

1. Simple over complex — "use" not "utilize," "help" not "facilitate"
2. Specific over vague — avoid "streamline," "optimize," "innovative"
3. Active over passive — "We generate reports" not "Reports are generated"
4. Confident over qualified — remove "almost," "very," "really"
5. Show over tell — describe the outcome instead of using adverbs
6. Honest over sensational — never fabricate statistics or testimonials

Quality check: jargon, sentences doing too much, passive voice, exclamation points, empty buzzwords.

## Best practices

Be direct. Don't bury the value.

Weak: Slack lets you share files instantly, from documents to images, directly in your conversations.
Strong: Need to share a screenshot? Send as many documents, images, and audio files as your heart desires.

Rhetorical questions when they fit: "Hate returning stuff to Amazon?" Analogies when they make an abstract idea concrete. Humor only if it fits the brand and does not kill clarity.

## Page structure

### Above the fold
Headline: single most important message, specific > generic.
Subhead: 1–2 sentences, adds specificity.
Primary CTA: what they get. "Start Free Trial" > "Sign Up"

Headline formulas:
- {Achieve outcome} without {pain point}
- {Achieve outcome} by {how}
- Turn {input} into {outcome}
- [Achieve outcome] in [timeframe]
- Never {unpleasant event} again
- {Question highlighting the pain}
- Stop [pain]. Start [pleasure].
- {Product type} for {audience}
- You don't have to {skill} to {outcome}
- The {opposite of usual} way to {outcome}
- The [category] that [differentiator]
- [Number] [people] use [product] to [outcome]
- The simple way to {outcome}
- Finally, {category} that {benefit}
- Get {benefit} from your {thing}
- {Action} your {thing} like {example}
- Everything you need to {outcome}
- The {adjective} {category} built for {audience}

### Core sections

| Section | Purpose |
|---------|---------|
| Social Proof | Logos, stats, testimonials |
| Problem/Pain | Show you understand their situation |
| Solution/Benefits | 3–5 outcomes, not 10 features |
| How It Works | 3–4 steps, reduce complexity |
| Objection Handling | FAQ, comparisons, guarantees |
| Final CTA | Recap, repeat CTA, risk reversal |

### Supporting sections as needed
Testimonials (named, specific results). Case studies (problem → solution → results). Use cases. Personas. FAQ (5–10). Comparison vs competitor or status quo. Integrations. Founder story. Demo. Pricing preview. Guarantee. Stats.

### Page templates

**Weak (do not ship):** Hero, Feature 1–4, CTA.

**Strong:** Hero with value prop → proof bar → problem → how it works (3 steps) → 2–3 benefits → testimonial → use cases → comparison → case snippet → FAQ → final CTA with guarantee.

**Compact ad landing:** Hero → proof bar → 3 benefits → testimonial → how it works → final CTA with guarantee.

**Enterprise/B2B:** Hero (outcome) → logo bar → business pain → solution → use cases by role → security → integrations → case study with metrics → ROI → demo CTA.

**Product launch:** Hero announcement → demo → 3–5 highlights → before/after → early testimonials → launch offer → CTA.

### Section writing

Problem: name the specific frustration, time/money wasted, impact. Recognition ("that's exactly my situation").

Benefits: headline = outcome, body = how (1–2 sentences), proof if real.

How it works: numbered, simple verb, outcome per step. Example: Connect your tools (2 minutes) → Set preferences → Get reports every Monday.

Testimonials: specific results, before/after, role + company. Avoid "Great product!" / "Love it!" / "Easy to use!"

## CTA copy

Weak: Submit, Sign Up, Learn More, Click Here, Get Started.

Strong: Start Free Trial, Get [Specific Thing], See [Product] in Action, Create Your First [Thing], Download the Guide.

Formula: [Action verb] + [what they get] + [qualifier if needed].

## Page-specific

**Homepage:** broadest true value prop, paths for different intents, not generic.
**Landing page:** one message, one CTA, match the ad, complete argument.
**Pricing:** help them choose, recommended plan obvious, kill "which is right for me?" anxiety.
**Feature:** feature → benefit → outcome, use cases, path to try.
**About:** why you exist, mission as customer benefit, still a CTA.

## Voice

Set formality (casual / professional-friendly / enterprise) and personality (playful vs serious, bold vs understated, technical vs accessible). Headlines can be bolder. Body must be clearer. CTAs action-oriented.

If the user wants Dan Koe, run Dan Koe voice: first line is the thesis, short paragraphs, no hedge. Still keep conversion structure.

## Output

- Copy by section: headline, subhead, CTA, body, secondary CTAs
- Why the key choices
- 2–3 headline and CTA alternatives with rationale
- Meta title and description if relevant

Then run Copy editing.

## Transitions to avoid (AI tells)

That being said, It's worth noting, At its core, In today's digital landscape, When it comes to the realm of, This begs the question, Let's delve into.

Prefer: So, But, That said, Plus, For example, Here's how.

Do not over-signpost. Do not use "In conclusion."
