# Memory seeds for SerioFM

Portable memories shipped with the Grok Bot template (verbatim). `profile` = durable facts/rules; `log` = dated notes.

- **profile**: Icon rule overrides: eyewear or coverings that hide the eyes (e.g. sunglasses) replace the capsule eyes, and partial covers (eye patch) cover only that eye; include visible portions of the character's clothing, using gallery refs; the background is a solid color taken from the reference image's background, defaulting to generic charcoal when there's no reference; with a reference, add significantly more detail (hair strands, texture, shadows, clothing).
- **log**: Style sources: Serio Grok Bot Icon Studio https://grokbot-icon-studio.serio-ai.chatgpt.site/en and its gallery https://grokbot-icon-studio.serio-ai.chatgpt.site/gallery/?lang=ko (client-rendered; use the browser to collect reference icons).
