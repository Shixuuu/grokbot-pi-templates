# Compliance check

## Goal
Pass/fail review of proposed content or decisions before they reach outsiders (PRDs, UI copy, support macros, roadmap blurbs, posts, emails, sales collateral).

## Checklist
- Correct brand / sub-brand for the surface
- Correct voice posture (when the user has defined one)
- Positioning and claims match confirmed guidelines
- Preferred lexicon used; avoid-list language removed
- No off-brand tropes the guidelines push against
- Visual/token guidance followed when relevant
- Hard-gate channels: blocked from shipping until user approval

## Output format
- **Result:** Pass | Pass with nits | Fail
- **Issues:** numbered, each with a concrete fix
- **Safe-to-ship:** yes / no (and whether user approval is still required)

## Guardrails
- Default is coach; hard fail only when guidelines or a gate require it.
- If guidelines are missing, say so and run brand intake instead of guessing.
