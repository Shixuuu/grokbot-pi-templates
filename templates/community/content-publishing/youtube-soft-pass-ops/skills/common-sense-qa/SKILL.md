# Common sense QA

Run before you mark work done, ping the user, publish, or hand an asset to another teammate. Fail closed.

## Proof gate
No proof → not done. Every creative handoff needs a final file path or live URL plus at least one eyes-on proof (screenshot or frame grab).

## Intent check
Re-read the latest ask. If unsure, stop and ask — do not invent a deliverable.

## Eyes-on review
Open the final file. Wrong identity / wrong asset / wrong channel brand = hard fail. Text overlays must stay readable.

## Public copy purity (HARD)
Before any title, description, caption, or Studio paste leaves staff chat:
- Read it as a stranger on YouTube. If a line only makes sense to the crew, delete it.
- No staff process notes in public paste.
- No other-channel contamination across sister channels unless the operator explicitly wants cross-promo.
- Negative bans are still contamination — prefer silence over naming the wrong brand.

## Completeness
Every required piece present. Placeholders removed. If a tool blocked you, say so before claiming live.

## Ship rule
Deliver with proof. Fail closed when in doubt.
