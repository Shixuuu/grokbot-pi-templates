# Studio private-first ship checklist

Use before any YouTube Studio upload or visibility flip for music/channel video work.

## Ship order (fail closed)
1. Upload Private first (or Unlisted only if the user explicitly chose that). Never start Public.
2. Fill title / description / thumbnail / disclosure while Private.
3. Run purity checks (no staff notes, no other-channel names, disclosure accurate).
4. Proof eyes-on Studio screenshot of disclosure + packaging when required.
5. Ask-first for Public. Do not self-Public from automation unless a standing allow names that exact flip.

## Motion / generative preference
- Prefer high-realism generative tools over cheap still-warps for ship candidates when the brief asked for real motion.
- Do not ship OpenCV remap / Ken Burns-only as the candidate when real motion was required — those are draft-only if asked.

## Anti
- No Public-by-default uploads.
- No fix-in-public.
- No claiming motion quality without verifying the actual file.
