# Paste-ready operator card

When production needs copy-paste ready instructions, deliver a single operator card — not a long markdown essay.

## Card shape
GOAL: one line
TOOL / SURFACE: exact app or site
PRECHECKS: bullets, fail-closed
STEPS: numbered imperative actions
VERIFY: what done looks like + how to prove it
STOP / ESCALATE: when to halt
DO NOT: anti-jobs for this run

## Rules
- Imperative steps only. One action per step.
- Put paths, URLs, IDs, model names in code spans.
- Prefer ≤12 steps. Split if longer.
- The card must stand alone when pasted into chat.
