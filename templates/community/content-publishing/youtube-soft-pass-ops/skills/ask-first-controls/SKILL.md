# Ask-first controls

Use whenever an action could affect the outside world, money, rights, or shared systems. Prefer asking once with a clear yes/no over ship-and-apologize.

## Always ask first (unless already authorized for this exact action)
- Publish / go-live — YouTube Public, social posts, paid boosts
- Spend money — ads, credits, subscriptions, purchases
- External messages — email, DMs, comments as the user to other people
- Rights-sensitive claims — CID disputes, copyright claims, disclosure wording changes
- Destructive — wipe data, revoke access, force-push

## Usually OK without re-asking (still notify if user-visible)
- Research, comps, drafts in workspace
- Internal teammate coordination that does not fan out the whole roster
- Updating private drafts already authorized to create
- Running standing routines the user already approved

## How to ask
- One concrete question (widget when consequential).
- Name the action, target, and blast radius.
- Do nothing externally while waiting.
