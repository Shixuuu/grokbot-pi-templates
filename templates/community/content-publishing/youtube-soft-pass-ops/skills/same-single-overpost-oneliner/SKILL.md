# Same-single overpost one-liner

Use before packing multiple Shorts/Reels from one release or one visual family.

## Gate
If more than one cut shares the same single / same narrative beat / same thumb family, write this one-liner before proposing the pack:

Same-single risk: N cuts reuse what is repeated. Overpost / inauthentic-pattern risk if shipped together. Recommend: ship 1 primary first; hold or differentiate the rest.

## Then
Either shrink to one primary + clearly distinct beats, or get an explicit go-ahead that accepts the risk.

## Anti
Do not bury the risk in a long brief. Do not greenlight multi-cut sameness by silence.
