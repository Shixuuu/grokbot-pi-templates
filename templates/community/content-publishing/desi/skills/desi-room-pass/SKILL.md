Use this when the user sends room or furniture photos for a redesign, asks for a layout, mood board, buy list, or room-size estimate from pictures.

# Room pass — Interior Design Desk

Run this checklist for each room (or project batch). Quality-tier buys only unless the owner set a hard budget.

## Space (required on every photo pass)
1. Estimate **length × width × height** (or floor L×W + ceiling height if walls don’t support all three).
2. State **confidence as a percent** (e.g. 40% / 65% / 85%).
3. Name the **scale reference** used (door ~80", standard chair, sofa depth, phone on floor, outlet spacing, owner-provided dims, etc.). If nothing usable is in frame, say so and keep confidence low.
4. Ask for a tape measure **only** when confidence is under ~60% or a buy/placement is tight and fit depends on inches. Skip the ask when confidence is solid and nothing hinges on an inch.

## Design output (in order)
1. **Size** — L×W×H, confidence %, scale reference.
2. **Read** — what’s there, palette, problems (scale, clutter, contrast, flow).
3. **Keep / move / park** — inventory of existing pieces and where they go.
4. **Layout** — before→after (zones, anchor, rug, seating, art height). Text plan; mood board / mock when tools allow.
5. **Style options** — primary direction discovered from the photos + 1–2 alternates that still work with owned pieces (why, and what would change).
6. **Buy list** — quality items with shop links, why each complements the set, rough price band, size notes; mood board of picks.
7. **Next measures** — only if confidence is low or fit is tight; otherwise omit.

## Rules
- Discover style and palette from the photos every time; no locked house style unless the owner set one this session.
- Prefer rearranging what they own first; buy only to fill a real gap.
- Do not invent tape-accurate dims without a clear scale reference.
- Do not place purchase orders or spend money.
- Do not sell furniture or log sale proceeds (out of scope).
- Do not send filler when there is no new photo or question.

## Photo tips to request when estimates are weak
Wide wall shots, one corner with floor+wall, standing height (not crouch), and one known-size object or tape in frame.
