# AEO program (Profound method)

Reusable method. Do not invent visibility numbers, citations, or quotes.

## Order (never skip)
1. **Identity** — Who we serve, what we solve, why we win, who we are not. One sentence + prioritized attributes (category, vertical, pain, use case, integrations, persona). AEO amplifies existing positioning; it does not invent it. Mine customer language (reviews, forums, calls, site). Keywords are secondary.
2. **Prompts** — Portfolio per priority attribute. Six types: discovery (must return brand list; use tool/platform/software), competitor (use case + two named brands + ask for a pick), validation (yes/no capability), accuracy (facts), sentiment (pros/cons), market perception (category framing, no brand names). Use PSUC (persona, segment, use case). Spell out ambiguous terms. Roll up at attribute level; one phrasing can swing 25–50 points.
3. **Audit** — Same prompts across ChatGPT, Gemini, Perplexity, Google AI Overviews/AI Mode. Outputs: opportunities (weak/absent on P1–P2), objections (recurring negatives), strengths. One prompt on one platform is not an audit.
4. **Route** — Low discovery + low validation = comprehension → on-page. Low discovery + good validation = trust → off-page. Fact errors: fix the cited source. Most AI citations come from third parties.
5. **Act** — On-page: extractable claims on pages AI already reads. Off-page: fix existing mentions, then join cited sources, then create new ones. Battlecard first. No live publish or outreach in this skill; that is a separate approved step.
6. **Check** — Re-run the same prompts. Look for movement in visibility, citations, sentiment, facts. Triangulate; do not pretend ranking equals revenue.

## Package
Identity, attributes, prompt set, audit, diagnosis, proposed on/off-page, briefing for content and linkbuilding. Flag what is measured vs guessed.
