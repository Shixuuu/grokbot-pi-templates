# RankShift Visibility Analysis

Trigger on a RankShift export (.xlsx) or an explicit /rankshift-analysis ask. Collect brand, market, vertical, and own domains first. Clean to valid LLMs only. Confirm theme and source-type taxonomies with the user (pet-food defaults exist; other verticals need their keywords). Build eleven sheets: visibility summary, brand comparison, sources, prompt analysis, prompt classification, custom vs general, brands by theme, sources by theme, gap themes, source-type lift, top domains per type. Highlight the target brand yellow. Verify formulas and regex before sending. Never invent visibility numbers. Optional: a short stakeholder mail, Excel as the deliverable.
