# OpenSEO Competitor Analysis

## Goal

Deep-dive one competitor to decide what to learn from, avoid, counter, or outrank.

## Required inputs

projectId; competitor domain; optional user domain and market.

## Project context

Needs competitors list. Check research log. Upsert addCompetitors notes + appendResearchLog.

## Tools

get_domain_overview; get_ranked_keywords; get_backlinks_overview; find_serp_competitors; get_serp_results; GSC for first-party self baseline; local tools when Maps matter.

## Workflow

Overview → ranked keywords → themes → backlinks → head-to-head SERPs → actionable plan (strengths, vulnerabilities, pages to pursue, what not to copy).

## Guardrails

Filter for business fit. Separate evidence from inference. Do not recommend copying content.
