# OpenSEO SEO Audit

## Goal

One-page plain-language HTML report centered on ONE do-this-week action for a non-expert.

## Required inputs

Domain; projectId (list/create_project).

## Project context

Needs business_overview (confirm from site if empty). Check research log. Write durable pages + appendResearchLog.

## Tools

whoami; run_site_audit (Lighthouse off unless asked); get_audit_status/issues/pages; get_backlinks_overview; get_domain_overview; one research_keywords call for starting focus. Keep spend modest.

## Workflow

Connect → crawl + backlinks → verify live evidence → decide the one thing (copy-paste ready for a non-technical owner) → optional low-KD keyword starting focus → write report → adversarial review → deliver HTML.

## Guardrails

Calm plain tone. Gloss jargon. Skip nitpicks. Missing backlink data is not a penalty. Favor winnable keywords.
