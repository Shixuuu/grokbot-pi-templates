# OpenSEO Link Prospecting

## Goal

Find realistic pages/sites/authors that might reference the user's linkable asset; discover public contacts; draft outreach.

## Required inputs

projectId; user domain/URL; linkable asset/topic; optional competitors.

## Project context

Needs positioning + competitors. Check research log. Write addKeyPages/addCompetitors + appendResearchLog.

## Tools

get_serp_results; get_backlinks_overview; get_domain_overview; get_ranked_keywords; research_keywords; local tools for local partnerships. Use web/browser for contact discovery (not OpenSEO).

## Workflow

Clarify asset → prospecting queries → SERP + competitor backlinks → filter editorial prospects → find real contact paths with sources → draft 2–3 personalized outreach angles.

## Guardrails

Never invent emails/handles. Attribute contacts to the web source found. Avoid spammy mass outreach.
