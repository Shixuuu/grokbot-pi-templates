# OpenSEO Competitive Landscape

## Goal

Who is winning this SEO market, what content works, and where are the openings?

## Required inputs

projectId; topic/seeds/market/domain; optional known competitors.

## Project context

Needs competitors (minimal setup / find_serp_competitors + confirm). Check research log. Write addCompetitors notes + appendResearchLog.

## Tools

research_keywords; get_keyword_metrics; get_serp_results; find_serp_competitors; get_domain_overview; get_ranked_keywords; get_backlinks_overview; GSC when comparing self; local tools for Maps markets.

## Workflow

Build 5–10 representative queries → find recurring domains → size top 3–5 → theme keywords → synthesize gaps and next workflow.

## Guardrails

SEO competitors are not always business competitors. Label domain types. Estimates are estimates.
