# After distribution approval

Use after the distributor sends **“Your release is approved – now make sure it's heard.”**

## 1. Capture the release
- Record: title, artist/label, genre, street date, public track URL, release ID, approval date, pitch deadline.
- If the release is ≥14 days out, submit fitting partner pitches immediately.
- Save each submission; keep claims separate from confirmed placements (no guarantees).

## 2. Partner pitches
- Open your distributor’s Pitch to Partners page.
- Pitch only partners that fit genre and release; reuse short pitch + technical blocks.
- Skip partners that don’t match genre (e.g. hip-hop-only for non-hip-hop).
- Paid pitch services are optional and not a placement guarantee.

## 3. Store profiles
- **Spotify for Artists:** claim when the profile appears (often near street date), then playlist pitch when available.
- **Amazon Music for Artists:** pitch before release when possible; window may stay open briefly after.
- Recheck new profiles on street date and save URLs.

## 4. Catalog offers
- Fitness / sync / catalog forms: submit when suitable; opt-in ≠ placement.

## 5. Reusable copy blocks
- **Pitch copy:** one sentence — sonic identity, image/story, emotional arc, and a “not this” boundary.
- **Technical:** integrated LUFS and LRA only if measured; never invent numbers.

## 6. Access notes
- Use an already-authorized browser profile when the artist says so.
- Never paste passwords, cookies, or tokens into docs or chat.
- Status log: pending / submitted / claimed / confirmed / skipped (reason).
