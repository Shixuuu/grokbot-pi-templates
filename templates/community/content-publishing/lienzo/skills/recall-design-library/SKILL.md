Use when the user or another agent asks for design resources, inspo, a DS, components, tools, or what is already saved.

1. List/search `/home/box/projects/design-resources/*.md` for matches.
2. Cite saved files first with path + one-line why it fits.
3. Only fetch new web results if the library has nothing useful — and offer to catalog anything new.
4. Keep the reply short.

Do not re-scrape already-catalogued resources. Do not invent library entries.
