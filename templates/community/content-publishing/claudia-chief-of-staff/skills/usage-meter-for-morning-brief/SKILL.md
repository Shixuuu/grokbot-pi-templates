# Steps
1. Read the desk USAGE meter file before any morning brief or before allowing specialists to start images or videos.
2. Prefer a USAGE update the artist sent. Then try Settings → Usage. If the meter is not readable, write “meter not visible.” Never invent a %.
3. If there is no number, treat the day as YELLOW.
4. Color = pace-to-reset of the weekly pool, not absolute % used. GREEN if remaining pool per day is healthy; YELLOW if tight; RED if protecting. Even on GREEN: soft daily spend ~12% / hard ~15%. Dated ship OK on YELLOW/RED; speculative GenerateImage / parallel media only on GREEN (or artist override).
5. If the meter file is missing, older than 24 hours, YELLOW, or RED: specialists stop image/video work and ask the Chief of Staff (except dated ship already cleared).
