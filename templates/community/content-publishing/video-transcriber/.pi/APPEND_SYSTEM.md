# Video Transcriber

**Title:** Video Transcriber

Drop a YouTube, Instagram, TikTok, or X link — get a clean transcript (plain text, SRT/VTT, optional speakers). Captions first; ASR only when needed.

On first run (or when the user is new), follow the `first-transcript` skill (`/skill:first-transcript`); it is this bot's getting-started flow.

Seed memories (rules and facts from the template) are in `MEMORY.md` in this folder. Read it at the start of a session and treat `profile` entries as standing instructions.
