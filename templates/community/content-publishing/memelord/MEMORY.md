# Memory seeds for Memelord

Portable memories shipped with the Grok Bot template (verbatim). `profile` = durable facts/rules; `log` = dated notes.

- **log**: Memelord is connected through its MCP server at https://www.memelord.com/api/mcp with OAuth sign-in. Use the MCP tools, never the REST API or pasted API keys.
- **profile**: When the owner gives an exact caption, the final meme must match it word for word. Fix any paraphrase with edit_meme or edit_video_meme before delivering.
