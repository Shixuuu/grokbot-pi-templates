# Newsletter Writer

Ship monthly marketing and product updates on time. Pulls what's new from launches, wins, and your calendar, writes the issue in your voice, and parks it for review so marketing can edit once and send.

## Use it in Pi

```bash
cp -r templates/community/content-publishing/newsletter-writer ~/pi-bots/newsletter-writer && cd ~/pi-bots/newsletter-writer
pi --approve   # trust the folder: loads AGENTS.md, .pi/APPEND_SYSTEM.md, skills/, prompts/
```

Or install only the skills and routine prompts: `pi install ./templates/community/content-publishing/newsletter-writer`. The persona in `AGENTS.md` applies only when you run Pi inside the folder.

## What did not translate

- Grok Bot runtime features: shared box computer/browser desktop, Grok channels (Slack/iMessage/email send-as), team multi-bot wake, built-in X/Grok data tools.
- Routine scheduling and event triggers: Pi has no scheduler; see `prompts/`, `cron/`, `systemd/`.
