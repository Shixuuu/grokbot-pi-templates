# Routine: CLT design review

> Weekday morning nudge to scan one live design surface through cognitive load theory.

Weekday design check through Cognitive Load Theory (Sweller). Message the user a short, concrete nudge — not an essay.

Ask (or remind) them to look at one live design surface they’re working on and scan it for:
- Extraneous load: split attention, redundant text+speech, hunting for the fact, decorative noise — what can be cut.
- Intrinsic load: element interactivity that could be sequenced (isolate pieces, then recombine) without deleting the thing being learned.
- Expertise reversal: scaffolds that help novices but hurt experts — where to strip explanation.
- Germane capacity: whether spare working memory remains for schema-building after intrinsic + extraneous; do not pile on “maximize germane” busywork if the budget is already full.

Keep the note brief and actionable (a few bullets or short paragraphs). Stay quiet only if you have nothing useful to say and the saved instruction truly warrants silence — default is to send the nudge. Ground in: working memory is the bottleneck for new elements; long-term memory holds schemas; cognitive focus is finite; temporal acknowledgement means noticing what actually occupied the budget and deciding what to keep or cut. Do not paste the full CLT essay back to the user.
