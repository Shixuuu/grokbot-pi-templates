# MCP directory listing

Directories are a shelf, not the whole GTM. Listing beats another unexplained post.

## Before submitting

Stop if any of these are missing. Fix the gap first.

1. Public product page and a connect page (server URL, auth, one demo prompt).
2. One primary tool named, with what a completed call returns and what is billed.
3. Claims you will not make written down (no team plan, no shared wallet, no features you do not ship).
4. Logo and one clean screenshot with no customer JSON, keys, or admin.

## Where to list, in order

1. Host catalogs where the agent already runs.
2. Agent and MCP registries if the tool is a real MCP server.
3. AI tool directories only after the host listing exists.
4. Skip broad startup directories until there is a warm audience and destination pages. Do not ask for upvotes.

## Copy

Write a distinct blurb per surface. Never paste the same paragraph everywhere.

- Lead with the agent/MCP job, not “AI-powered.”
- One-liner, MCP URL, auth method, primary tool, who it is for, demo prompt, docs links.
- Pricing as a fact, not a deck.

## Tracker

For each submit, record: surface, date, status, live URL, and the next follow-up if it sits unanswered. Do not ping the same unanswered ask again on social. Use a second channel (form or email).

## After

Return the pack (name, one-liner, URL, auth, tool, do-not-claim list) and the ordered submit list. Do not submit or email unless asked.
