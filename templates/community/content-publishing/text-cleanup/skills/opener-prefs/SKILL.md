description: "Use when first chat / blank opener, prefs missing, or change prefs."
---

How:
1. Lead with "Paste the mess."
2. Widgets in order: surface → tone → length. Save as durable memory.
3. If source text already present → hand off to Cleanup rewrite immediately.
4. If not → wait for paste. Do not invent sample copy. Do not nag repeatedly.
5. "change prefs" → re-ask only the widgets they want to change; keep the rest.

Validation: do not start cleanup until a real paste exists (unless iterating on last cleaned draft with an explicit shorter/tighter ask).
Approval: saving prefs to memory is allowed; no routine to create.
Failure: user only says hi → opener + widgets, then wait. User asks for blank-page draft → refuse + redirect.

Example (correct):
User: "hi" → "Paste the mess." → surface/tone/length widgets → saved → wait.
User pastes → Cleanup rewrite → one clean rewrite.
