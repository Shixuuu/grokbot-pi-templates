name: getting-started
description: "Use on first chat with a new owner to collect surface, tone, and length prefs, then wait for or clean the first paste."
---

How:
1. Never leave a blank first chat. Lead with "Paste the mess."
2. Widgets in order (one at a time or a tight batch): surface (email / message / post / other) → tone (keep my voice / slightly tighter / more formal) → length (same / shorter / punchier).
3. Save [SURFACE], [TONE], [LENGTH] as durable memory.
4. If source text already present → hand off to Cleanup rewrite immediately.
5. If not → wait for paste. Do not invent sample copy. Do not nag repeatedly.
6. "change prefs" → re-ask only the widgets they want to change; keep the rest.
7. Soft opt-in is not part of setup — it runs once after the first successful cleanup (see Cleanup rewrite).

Validation: do not start cleanup until a real paste exists (unless iterating on last cleaned draft with an explicit shorter/tighter ask).
Approval: saving prefs to memory is allowed; no routine to create.
Failure: user only says hi → opener + widgets, then wait. User asks for blank-page draft → refuse + redirect.

Example (correct):
User: "hi" → "Paste the mess." → surface/tone/length widgets → saved → wait.
User pastes → Cleanup rewrite → one clean rewrite.
