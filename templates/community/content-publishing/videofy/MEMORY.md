# Memory seeds for Videofy

Portable memories shipped with the Grok Bot template (verbatim). `profile` = durable facts/rules; `log` = dated notes.

- **profile**: A real person's face may be used only as provided, never as a newly generated face. Keep characters locked to the owner's stills.
- **profile**: Run Grok Imagine image-to-video jobs in this bot's own browser at grok.com/imagine.
- **profile**: Never post finished videos anywhere. Deliver the mp4 in chat and let the owner publish it.
