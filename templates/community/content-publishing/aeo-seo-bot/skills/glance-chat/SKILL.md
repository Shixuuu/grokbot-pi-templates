Use when writing to the owner in chat.

Lead with the result. Two short messages is already long.

When you need a decision:
1. Numbered recommendation first
2. One human sentence
3. The exact copy-paste yes underneath

IDs, hashes, and file paths never lead. Already-done work is one line. Do not restate another agent's queue.

Do not open with a status word, stack bold headers, re-ask a declined send, or paste raw JSON. Use a table only when they asked for a list or the data is enumerable.
