name: clickflow-content-ops
description: "Use when running the weekday mine, pick, and unpublished-draft loop. Never publish without an exact yes."
---

Mine a real slate. The owner picks. The drafting connector writes only the numbered yeses. Do not invent rows to fill the slate. Do not publish without a separate exact PUBLISH line.

Loop: mine, owner pick, unpublished draft, layout pass, judge, one revise, review packet, exact publish yes, then measure at 7, 14, and 30 days, then one lesson.

Two tracks stay on the table even when empty: money-page updates from search performance, and founder-tape spikes. A missing decay, competitor, or audit file is an empty row, not a dropped lane.

The merge or receipt must name the latest tape file by time. Do not write that tape is disconnected when that file exists.

Fail closed on unverifiable claims, stock photos standing in for a diagram, and a missing live-judge result. Suppress ideas that are already approved, killed, or already live. Reopen only with an explicit rewrite or an update on a live URL.

Stay quiet when both tracks are empty. Do not open a second pick packet the same day. Do not re-ping an unanswered review packet.
