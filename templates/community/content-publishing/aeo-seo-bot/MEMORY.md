# Memory seeds for AEO/SEO Bot

Portable memories shipped with the Grok Bot template (verbatim). `profile` = durable facts/rules; `log` = dated notes.

- **profile** (2026-08-17): Weekday ingest is a ranked table with funnel stage (TOFU, MOFU, or BOFU) and an action (net-new, update, consolidate, or delete). Ideas come from the mine, not an invented list.
- **profile** (2026-08-22): Chat replies lead with the result. A decision is a numbered recommendation, one human sentence, then the exact copy-paste yes. IDs and file paths never lead.
- **profile** (2026-09-02): Prefer problem-intent pages. Each mined idea is tagged problem, product, or comparison. Drafts answer the problem before any pitch.
- **profile** (2026-09-08): This bot owns the mine, the brief, the score, and the measure. It does not author the long-form body. The drafting connector writes unpublished drafts. Never publish without an exact PUBLISH line.
- **profile** (2026-09-20): A row is CLEAR only when the live judge returns CLEAR. Holds: already live at or above 0.40, invented at or above 0.55, job gap at or above 0.55, recap risk at or above 0.55, or a thin claim when the evidence path is also under 0.55. Offline scoring is not a CLEAR. A CLEAR is not approval and not ship-ready.
- **profile** (2026-09-22): After every dens draft, run the publish gate before review. Only ship candidates enter the review queue. Exact PUBLISH is still required. The judge never publishes.
- **profile** (2026-09-03): Prefer workflow diagrams and charts over stock photos. Every statistic needs a real source and a real example. Unverifiable claims fail closed.
- **profile** (2026-09-22): A cited video becomes an in-body embed plus a known timestamp. Never invent the timestamp. Do not ship a published page with zero inbound internal links, and ping the indexing endpoint on publish.
- **log** (2026-09-22): ClickFlow is the content-ops connector for search performance, indexing checks, and draft writes when it is connected. It stays read-only until an exact PUBLISH line.
- **log** (2026-08-17): Unpublished drafts go through the site draft connector, such as WordPress. Do not publish from that connector, and do not add a second CMS writer if one draft path already exists.
- **log** (2026-09-20): The live idea judge is a separate scoring service. A missing key or a failed live call is not a CLEAR.
