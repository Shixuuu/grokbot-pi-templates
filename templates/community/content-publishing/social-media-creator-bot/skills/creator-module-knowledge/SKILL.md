# Creator Module Knowledge

Principles and rules per curriculum module. Pull the matching module when doing creator work.

For workflow (ideas, scripts, analyses, collabs), also use the Social Media Creator skill.

## Module 00 — Build Your Instagram Profile Strategically
### Core principles
- Profile = business card and conversion after a viral entry; must match the Reel or people bounce.
- Bio 3–4 short lines: topic + credibility proof + personality/unfair advantage; SEO keywords.
- Handle: real name or name+niche signal; avoid cold UGC/function names.
- Explore/Reels era: single-video quality > feed-grid curation.
### Actionable rules
- Stranger check: in 10 seconds it’s clear who/what/for whom.
- Keep the bio a living document.

## Module 00-1 — Strategy Into Practice: Build Community
- Profile extends content strategy; expectation mismatch after a viral click kills follows.
- Verification optional, never a substitute for content+community.
- Sharpen handle + bio + avatar in one pass; no generic bio fluff.

## Module 01 — Intro / Welcome / Platform
- Right audience > follower count; discipline > motivation; growth is wavy.
- Practice: extract the principle → transfer to your niche (don’t copy 1:1).
- IG = home base (Reels discovery + Stories bond); TikTok = reach cross-post; YouTube = later after short-form proof.
- Produce once for IG, distribute everywhere; better to test 50–100 Reels than burn weeks on one long-form.

## Module 02 — Perspective Shift / Formats / CapCut
- Shift: viewer benefit over ego; 50/50 personality↔value; document the journey before “made it.”
- Reels = acquisition; Stories = bond; watch time is the king KPI.
- CapCut default; auto-captions; rough cut→audio→captions→effects.

## Module 03 — Focus / Stories / Camera / Light & Sound
- Niche/core topic as anchor; trends only with fit; explicitly list what does NOT belong on the profile.
- Stories: high frequency with arc; watch time; interaction; reverse-engineer avatar daily life.
- iPhone often 4K/60; Action Mode; frontal light; framing close/medium/wide; caption-safe; phone is enough.

## Module 04 — Quality vs Quantity / Viral Analysis / Rough Cut
- Early: quantity with hypotheses (~30/month); later double winners; batches ≥4; ~100-video commitment.
- View multiplier: talking/value > silent transition vanity.
- Success triangle: knowledge ∨ personality ∨ packaging; steal frames, own the story.
- Rough cut sets tempo; cut empty silence; B-roll/punch-ins against jump cuts.

## Module 05 — Content Pyramid / Hooks / Color / Test Reels
- Foundation (1 sentence) → pillars → community/Stories; pillar durable, concept episodic.
- Hook 1–3s spoken + on-screen; ≥3 variants; no “Hi I’m…”; value-linked CTA.
- 1–2 signature looks; keep skin tones natural.
- Test Reels: non-follower value; limits ~5 parallel / ~20 day; keep DMs.

## Module 06 — Community / Live / Framing / Efficiency
- Trust is currency; Stories+DMs+replies = minimum care.
- Live 20–30+ min; don’t quit with few viewers; smartphone is enough.
- Framing steers attention; change shot size.
- Batch sessions (≥4); one shoot → multiple cuts; systems > motivation.

## Module 07 — Brand Thinking / Collabs / Keyframes
- Think like a brand; inversion (dream-brand dealbreakers → do the opposite); selective no.
- Only recommend what you’d use; organic proof before paid; format > brand script; standalone value.
- Keyframes/zooms = pattern interrupts, sparingly on emphasis.

## Module 08 — Mindset / TikTok / Captions
- Discipline/systems; views ≠ self-worth; posting shame is the entry fee.
- TikTok: output + hook fit; cross-post from IG; not a community foundation alone.
- Captions mute-proof; hook line at second 1; safe zone.

## Module 09 — Cases / Mask / Explainer / Account / Trends / Carousel
- Case teardown → 3 transferable moves + 1 own variant.
- Mask/split only when the dialogue frame helps.
- Viral explainer: optical hook→problem→solution→CTA; 4–6 angles / 30–60s; cuts ~1–3s.
- Account analysis: bio, pillar mix 50/50, hook patterns, cadence, growth vs bond.
- Trends: separate topic vs format; steal/replace/adapt; niche fit only; virality checklist.
- Carousel: slide-1 hook; every card stands alone; save-worthy; CTA at the end.

## Module 10 — Negative Hook / Music / Expert
- Cold start: Before → But today → Therefore (1–3 tips); often under ~90s.
- Duck music under dialogue; signature SFX sparingly; trend audio only with fit.
- Earn expertise as payoff — don’t brag it as the intro.

## Modules 11–12 — Foundation / Workbook / Export
- Foundation: positioning + avatar + pillars + platform roles + cadence + 100-video runway.
- Start avatar one-sided; list pain points; 3 concept ideas per pillar.
- Export 9:16 1080×1920; mute-proof check; hook-frame preview.

## Module 13 — Recipe / Reaction / Fitness Vlog
- Recipe: visual hook, process beats, payoff shot, save CTA.
- Reaction: clear point of view + timing; value = your take.
- Vlog: cold open → day beats → reflection; personality + packaging.

## Reference
- 4-act: Hook · Setup · Payoff · CTA; format > script; brand fit > reach; paid after organic.
- Anti-patterns: logo-first, ad-speak, gloss without story.
- Phases: 0–1k find format → 1–10k double winners → test collabs → multi-platform → systems.
