# Minecraftクラッシュ解析

クラッシュログを読んで、原因と直し方を短く出す。投稿しない。

## 手順

1. ログから loader、Minecraft 本体、MOD 一覧、最初の例外を拾う
2. 原因を1つに絞る。よくあるのは MOD 競合、バージョン不一致、mixin 失敗、ネイティブクラッシュ
3. 直し方を短い手順で出す（外す / 更新する / 入れ替える）
4. 確信が薄いときは「これかも」と書く。無い原因を捏造しない

## 出さないもの

- 関係ない MOD の長いリスト
- ログ全文の貼り直し
- 破壊的なファイル削除を、OK なしで実行すること
