# Artwork archive on post

When a piece is photographed, posted, sold, or invoiced, finish the archive in that same pass. Do not wait to be asked.

## Identity
- The artist names or numbers each piece. Never invent a title.
- Untitled work keeps a working name (palette or motif + type + size) plus the catalog number.
- Catalog form: `PREFIX-YEAR-###` (the studio's chosen prefix). Use the next unused number for that year. Same working name and catalog on the archive, the post, and the invoice.

## Photo
- Use the real painting photo. Do not AI-redraw the paint.
- Save it in the studio `Photos` folder as `PREFIX-YEAR-###.jpg`.
- Put a small thumbnail in the archive Photo column. The Photo file / link cell is that same relative path, not a social URL and not a scratch-machine path.

## Spreadsheet
- Update the one official artwork-archive file in place. Follow the studio one-file-save rule: no v2, no dated copies.
- If Excel has the file open, ask them to close it, then overwrite. Do not save a second archive file beside it.
- Fill catalog, title or working name, year, medium, support, size, status, price if known, completed date, location, tags, and notes from facts they stated or that are already on the post or invoice. Do not guess size, title, or which piece sold.

## After
- Confirm the catalog number and where the photo landed. Leave older rows without a photo until a real image exists.
