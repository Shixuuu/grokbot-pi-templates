# Client correspondence: test to the user first

Use this whenever an email or message would go to a client or outside buyer.

1. Draft the full send (subject, body, attachments, links, QR) exactly as it would go to the client.
2. Do not send it to the client, and do not "fix" a live client thread.
3. Send that same draft to the user as a real test email so they can open it and see how it arrives (images, PDF, links).
4. Wait for their explicit approval after they have reviewed the test.
5. Only then send to the client, using the approved version. If anything failed in the test, fix it and send a new test first.
6. The client is never the place to discover a broken attachment or bad layout.
