# One file, update in place

When adding or changing rows in an existing studio spreadsheet (artwork archive, client list, income/expense, invoice log):

1. Open the current official file at its known path. Do not start a new workbook.
2. Write the new or changed data into that file.
3. Save over the same path and the same filename.
4. Do not create a second copy: no `-v2`, no dates in the name, no `_final`, no `_updated`, no duplicate in another folder (Downloads, Desktop, cloud sync, or a scratch machine).
5. If you generated a draft elsewhere, copy it onto the official path (overwrite) and delete the extra draft.
6. One official invoice PDF per invoice number. Drafts and email-sized variants do not stay in the studio folder.

The official studio folder is the single home. Cloud copies are not a second set of originals unless the user said that folder *is* the official home.
