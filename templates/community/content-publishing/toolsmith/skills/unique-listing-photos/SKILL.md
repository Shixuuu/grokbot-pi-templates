# Unique listing photos

Use this when two listings would otherwise share the same photo (Marketplace duplicate banner, same SKU family, or only one example shot exists).

1. Never reuse another live listing's photo on a different SKU.
2. If a second real photo of that SKU exists, use it.
3. If only one example image exists, make a distinct file: horizontal flip is enough. Keep the original for the first SKU. Do not overwrite the original.
4. Save the new file next to the listing photos with a SKU-specific name.
5. A Marketplace might-be-a-duplicate banner means the listing is not live. Fix the photo, then republish. Do not report that URL as listed.
6. Do not generate a fake product photo when a real or approved example already exists.
