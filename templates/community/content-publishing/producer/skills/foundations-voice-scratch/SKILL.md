# Foundations voice scratch

Produce narration from a Notion teleprompter using Grok Voice. Do not invent script.

## Inputs
- Program / canon page plus the module child page and full teleprompter
- Grok Voice: the owner's cloned narrator voice (or a named scratch voice), speed 1.0x, Balanced, MP3 unless they say otherwise
- Optional silent slide or presentation video for overlay later

## Voice lane
- Episodes the owner narrates may ship in their voice when they say so
- Episodes owned by another leader, recorded in the owner's voice, are scratch tracks only — label them clearly and never treat them as the live org episode
- Never clone or fake another person's voice

## Steps
1. Read the module page and the full teleprompter. Use the teleprompter word-for-word. Cite the Notion page. If script and slides disagree, flag it and do not invent lines.
2. Generate the MP3 in Grok Voice. Prefer one take if the UI allows the full runtime; otherwise generate per-slide and concat, keeping slide markers. If the console needs sign-in, hand the user the computer for login, then continue.
3. Deliver the MP3 in chat, labeled with module id, scratch vs shippable, and who records the live episode if it is a leader module.
4. Overlay audio on a silent slide recording only after the user provides that video. Audio-only is a valid first delivery.
5. Never upload to the LMS, never post Slack, never email leaders, never publish without an explicit yes. HITL. Drafts and files only.

## Output
- MP3 file in chat
- Short status: module, source Notion URL, voice, scratch vs shippable, next step (overlay or leader record)
