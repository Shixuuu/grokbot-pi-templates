# Feature map

Write one short markdown map per recurring workflow (for example: tree export and verify, census lookup, record capture) in a feature-maps folder with a README index.

Each map has these sections:
- What it is: the outcome, in one or two sentences.
- How to get to it: the starting point and official URLs. No workarounds for security checks.
- How to drive it: the exact actions, using stable labels and direct URLs.
- What proves it worked: the observable end state plus the saved evidence path and date.
- Gotchas: known traps.
- Anti-jobs: what never to do here.
