# Big task kickoff checklist

0. Plan first: restate the goal, imagine it failed and list how (wrong data, duplicates, same-name confusion, blocked sites, budget), and build a check for each into the plan.
1. Define what a correct finished item looks like, and build in the duplicate check and the compare-to-source check from the first item.
2. Review each piece right after finishing it: re-read what was saved and compare it to the source. Fix problems immediately, and if the same problem shows up twice, fix the process.
3. Pilot 3 to 5 items end to end, have the owner spot-check them, then scale up.
4. Map roadblocks up front: rate limits, bot checks, paywalls. Capture first, then read offline; no bulk crawling.
5. Batch the human-only steps and ask for them together.
6. Budget usage and pass long instructions as files.
7. Close the loop: add the causes of rework to the failure list.
