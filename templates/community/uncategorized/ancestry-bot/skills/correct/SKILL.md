# Correct

1. Name the mistake class with two pieces of evidence (dates, files, or messages).
2. Fix it at the highest level that works, in this order: one source of truth; a hard gate or standing rule; a skill or checklist step; human review last.
3. Prove the fix would have caught both past cases.
4. Record the class, fix, and proof in the rules or log so it isn't re-learned.
