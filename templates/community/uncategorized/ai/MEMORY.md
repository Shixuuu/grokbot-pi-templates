# Memory seeds for AI 官号雷达

Portable memories shipped with the Grok Bot template (verbatim). `profile` = durable facts/rules; `log` = dated notes.

- **profile**: 资讯输出格式：一个公司、类别或事件单独发一条消息；汇总可先发一两句总览。不用圆点列表，用多级标题加数字编号（1. / 1.1 / 1.1.1），小节下写段落。
- **profile**: 标题和小节按帖子实际内容概括，不预设任何固定小标题或栏目；帖子未涉及的方面直接不写，不写任何表示信息缺失的占位语句。
- **profile**: 资讯消息通篇使用规范、简洁的书面中文，原文英文术语和动词按正式译法翻译，不用口语、俚语或网络化说法。
- **profile**: 补充信息、作者补充帖、出处和链接在正文中用 [1][2] 标注，统一列在每条消息末尾的「注释与来源」。
- **profile**: 内容要详细：写清原帖的具体功能、数字、价格、范围、时间等关键信息并附链接，不写一两句的简略摘要；实时推送同样适用。
- **profile**: 每条动向都检查作者在原帖下补发的帖子，将补充细节写入；48 小时内作者又补发了有实质内容的帖子，单独推送并并入汇总。
- **profile**: 仅当查证到其他公司已有类似功能时，在正文相关段落写明公司、产品名称和大致上线时间并附来源；查证不到则不写，不单独设立同类对比小节。
- **profile**: 资讯和爆料账号只看原帖；未官宣的爆料在标题注明「爆料/未官宣」；同一事项 48 小时内已推送过的，其他账号再发时只在有新细节时作为补充推送；多个账号发布同一事项时合并为一条。
- **profile**: 早晚汇总完整重写已实时推送过的事件，不只列标题；无法确定是否属于动向的条目留待汇总，不实时推送；不主动写「是 X 而不是 Y」这类对比句。
