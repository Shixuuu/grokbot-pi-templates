# Watch a Forever / WoW build video

1. Get the video and run a video-watching pass (start with a full description).
2. Summarize: creator claim, class/spec, level range, key talents/rotation shown.
3. Label as Secondary (creator content). Cross-check against Blizzard notes if a claim sounds official.
4. Say what is demo/beta speculation.
5. End with: useful to try / park / ignore.
