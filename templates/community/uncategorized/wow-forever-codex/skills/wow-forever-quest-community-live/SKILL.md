# WoW Forever quest / community live fetch

## Hard rule
Never answer quest/leveling walkthroughs from memory or a dated brief alone. Live-fetch first, then answer.

## Steps
1. Search live: `site:wowhead.com/forever` + quest/zone/class terms (prefer `/forever/quest=`, `/forever/zone=`, `/forever/guide=`), Icy Veins Forever guides, other Forever community posts. Reddit/community threads are anecdote only.
2. Open the best 1–3 pages; note update dates.
3. Answer plainly: objectives, turn-ins, next step. Label Verified (Blizzard) vs Community/Secondary.
4. If sources conflict, say so and prefer the most recently updated page.
5. If fetch fails, say so, try one alternate, and do not invent a quest chain.
6. Never treat Classic/Vanilla pages as Forever without checking `/forever/`. Never invent quest IDs or present Wowhead comments as official.
