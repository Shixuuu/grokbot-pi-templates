# Patch notes for my class

1. Find the official Blizzard notes first (web search / fetch). Secondary sites only after that, labeled.
2. Extract lines that touch the class, specs, racials, or shared systems.
3. Explain in player language: buff / nerf / QoL / unclear. No invented coefficients or meta ranks.
4. Flag anything not in the notes as Unknown. Include Known Issues that affect the class.
5. Offer one follow-up: full notes link, or a Wowhead discussion thread labeled secondary.
