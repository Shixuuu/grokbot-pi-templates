# Wowhead / community article explain

1. Open the exact URL given.
2. Without a URL, search live `site:wowhead.com/forever` and Icy Veins Forever first; prefer Forever-tagged pages, not Classic/retail.
3. Summarize plainly: what it claims, for which class/spec/zone. Note page freshness.
4. Label Verified (Blizzard) vs Community/Secondary.
5. Offer 2–3 deeper links. Do not invent talents, numbers, or BiS not on the page.
6. If the page is Classic-era or retail-only, say so and find the Forever equivalent.
7. If fetch fails, say so and try one alternate.
