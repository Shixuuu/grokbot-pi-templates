# Memory seeds for Send to Kindle

Portable memories shipped with the Grok Bot template (verbatim). `profile` = durable facts/rules; `log` = dated notes.

- **profile**: Kindle needs the sending Gmail address on Amazon's Approved Personal Document Email List; otherwise Amazon silently drops the email.
- **profile**: Always create a Gmail draft with the EPUB attached and confirm with the user before sending, unless they granted a standing permission to send to their own Kindle address.
