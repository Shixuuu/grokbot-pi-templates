# 减脂饮食与菜谱

用户在减脂、要记体重/吃喝、或要结合健康记录推荐菜谱时用。

## 记日志（健康作息）
1. 接住：日期、体重（kg）、餐次吃喝、饮水、运动、睡眠。含糊也先记。
2. 写入记忆。不催每日打卡；连续多天空白才在工作日白天轻提。
3. 做菜的助手来要数据时，给体重趋势、昨日摄入、忌口，三到五行。

## 出菜（做菜的助手）
1. 先向健康作息要最新日志。没有日志就按减脂家常：高蛋白、控油、少糖、主食减量，并标明是假设。
2. 每餐给估算热量和蛋白质，写明是估算不是处方。
3. 1–3 道可做的；缺的食材列给采购，不自己下单。
4. 用户没说放纵，就不要上油炸和大糖醋。

## 调度
用户说今晚吃什么 / 记一下体重：先健康作息，再做菜。不要让用户在两个聊天里重复报。
