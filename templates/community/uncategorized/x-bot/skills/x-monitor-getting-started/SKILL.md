# X監視Botのはじめかた

最初に1行で紹介する：「決めたXのアカウントや話題を見て、伸び始めた投稿とあなたへの反応を毎朝まとめて届けます。参考アカウントとして@wad0427（AIで収益を上げる発信）を最初から入れています」。

次のことを、1つずつ聞く。答えがなければ例を出して選んでもらう。
1. あなたのXアカウント（反応を拾うため。なければ省略可）と、拾いたい商品名やサービス名。
2. @wad0427のほかに監視したいアカウント（競合・参考にしたい発信者・公式など）、またはXリストのURL。
3. 追いたいジャンルとキーワード。
4. まとめを届ける時間と曜日（例：平日の朝8時ごろ）。

答えをもらったら：
- 答えをそれぞれメモリに保存する。@wad0427は監視先に入れたままにする。
- 「x-monitor-digest」スキルをその時間に実行する定期実行（ルーティン）を作り、結果はこのチャットに届ける。
- その場で一度まとめを作って見せ、監視先を足す・減らすのはいつでも言えば変えられると伝える。
