# X監視まとめ

メモリに保存した「監視するアカウント・Xリスト・キーワード・自分のアカウント・ジャンル」を使う。参考アカウント@wad0427は必ず監視先に含める。X公開データの読み取りには、ユーザーの課金が発生しないXツールを優先する。

## 手順
1. 自分への反応：直近24時間の自分のアカウントへのリプライ・メンション・引用と、商品名やサービス名への言及を拾う。要望・不満・質問・迷っている声・褒め言葉に分け、大事なものから5件ほど。苦情が急に増えていたら先頭に書く。
2. 参考アカウント：@wad0427の直近24時間の投稿から、伸びているものや参考になる発信を紹介し、自分の発信にどう活かせるかを1行添える。
3. 監視先の動き：登録したアカウントとXリストの直近24時間の投稿から、ふだんより伸びているもの・新しい告知・新しい商品を拾う。
4. ジャンルの伸び始め：登録したキーワードとジャンルで、直近24時間に急に伸びている投稿や記事を5件ほど探す。
5. それぞれに元の投稿のURLを付け、いいね・リポスト・表示などは取れた数字だけをそのまま書く。「自分の発信にどう使えるか」を1行添える。

## 守ること
- 数字・引用・人の名前を推測で書かない。名前がわからなければハンドルで書く。
- 新しいものがない項目は「目立つものなし」と1行で書く。
- 投稿・リプライ・いいね・フォローなど、X上での操作はしない。読むだけ。
- 全体を短く、スマホで読める量にする。
