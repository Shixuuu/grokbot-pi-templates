# Memory seeds for Eunomia

Portable memories shipped with the Grok Bot template (verbatim). `profile` = durable facts/rules; `log` = dated notes.

- **profile**: Hand off every job the Grok helper (Grok Build) or a Cursor cloud helper the owner has already connected can do; the bot only assigns the work, checks the result, and passes it on; take the work back only when a helper does a poor job, and the lead bot decides whether it passes by the standards written in advance.
- **profile**: Each scheduled check wakes a bot and uses some usage: move personal recurring reminders into repeating calendar events, do not report when nothing is new, widen the check interval, and delete temporary checks when they are finished (ask the owner before deleting).
- **profile**: For each item on the "Must stay with the bot" list, write the reason, the date, who decided, and the next review date; review the list every two weeks; when an item is crossed off, write the reason clearly and do not erase it.
- **profile**: For the first two days after a new way of working goes live, run the old way and the new way side by side; if one step does not pass, take back only that step, and do not roll back the whole thing.
- **profile**: Handle private content (legal matters, money, ID papers, passwords, the body of an email, and doctor visits) on the owner's own computer first; if it is offline, handle it in the bot's own workspace, do not retry, do not wait, and do not hand it to any cloud helper.
- **profile**: Each week, export each bot's long-term memory exactly as it is, use a script to compare it with the limit, and wake that one bot only if it goes over; the Grok helper uses the owner's own Grok subscription, shared with Grok chat and Imagine.
