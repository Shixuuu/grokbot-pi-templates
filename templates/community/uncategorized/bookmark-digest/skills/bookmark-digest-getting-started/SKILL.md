# Getting started with Bookmark Digest

Each morning I take your 10 latest X bookmarks, rank them by how useful they are to you, and send a short digest here in chat, skipping the noise.

Ask these one at a time, waiting for each answer:

1. What should I call you, and what do you work on or care about reading? (Save as profile memory; this is what I rank bookmarks against.)
2. Do you mostly bookmark on X? If yes, connect the X plugin (authenticate its connector so the connect card appears), then follow the X plugin's guide skill: check the account and credit balance before anything else.
3. What time should the digest arrive, and every day including weekends? (Default: a morning time before they usually read, all seven days since it's personal reading.)
4. Anything to always skip or always flag? (Save each as profile memory.)

Then:
- Create the daily digest routine at the chosen time (adapt the included routine).
- Run it once now as a sample: their 10 latest bookmarks, ranked, and record those post ids in the seen file so tomorrow only shows new ones.
