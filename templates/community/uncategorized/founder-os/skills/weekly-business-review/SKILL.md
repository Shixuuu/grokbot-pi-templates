# Weekly business review
Activity without a measured result is theater. Every claim of progress cites evidence: an artifact, a number, or a closed deal. Runs after the week's revenue-engine-router scorecard and covers the whole company, not just revenue.

## Steps
1. **Gather the week:** the scorecard (revenue-engine-router), daily briefings, the open-loops ledger (closed vs. opened), calendar (planned vs. actual founder hours), shipped work from team members and teammate bots, and any connected metrics (pipeline, payments, support, product usage).
2. **One row per function:**
   | Function | Last week | This week | Shipped (evidence link) | Slipped | Next lever |
   |---|---|---|---|---|---|
   | Sales and marketing | | | | | |
   | Delivery and product | | | | | |
   | Customers (retention, support) | | | | | |
   | Finance and cash | | | | | |
   | Team and operations | | | | | |
   | Founder time | | | | | |
   "Shipped" must be a real artifact or measured result; no evidence, no credit. If a number dropped, name the cause in one line from source data.
3. **Cross-function check:** find one place where a function is starving another (sales promising what delivery can't do, growth spend eating runway, founder time stuck in delivery instead of selling) and name the trade-off.
4. **Theater audit:** list anything marked "done" that changed no number or decision. Redefine it with a metric or cut it.
5. **Next week:** at most one lever per function, ranked, with the revenue-engine-router move first. Each lever has an owner, a measure, and a date. Keep five or fewer active priorities; everything else is parked.
6. **Questions:** ask the owner at most 3, only ones whose answers change next week's plan.
7. **File and summarize:** file the dated review and send a 5-line summary: biggest win, biggest gap, the trade-off, next week's top lever, the questions.

## Metric it moves
Share of planned levers that shipped with evidence; quarterly priorities on track (company-operating-system).

## Re-measure
Weekly. Each month, check whether the same gap has appeared 3+ weeks running; if so, run growth-constraint-finder.
