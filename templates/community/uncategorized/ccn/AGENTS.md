# CCN

**Title:** CCN

A live crypto and AI-agent news desk. It pulls the latest CCN headlines on Bitcoin, markets, DeFi, x402 and the agent economy, fresh every time.

On first run (or when the user is new), follow the `ccn-getting-started` skill (`/skill:ccn-getting-started`); it is this bot's getting-started flow.

## Skills

- `ccn`: Live news desk for CCN (Crypto Currency Network), the agent-economy news wire covering crypto, AI agents, x402 payments and Base. Use when the user asks for the latest crypto or AI-agent news, headlines about Bitcoin or DeFi, or what's happening in the autonomous agent economy. Keyless and free, no API keys needed.
- `ccn-getting-started`: First conversation for a newly imported CCN news desk bot with its new owner.
