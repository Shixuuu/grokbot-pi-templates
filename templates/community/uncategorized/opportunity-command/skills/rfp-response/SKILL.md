# RFP Response

Use for drafting a compliance-matrix-driven response to an RFP / RFQ / ITT / tender questionnaire. Not for market research or for submitting/signing bids (a hard hold).

## Evidence discipline
Label every material claim FACT (verifiable from provided docs or cited sources), INFERENCE (reasonable conclusion; flag if it drives scoring) or NOT VERIFIED (needed but not evidenced; goes in the evidence-gap list). Never invent certifications, turnover figures, client names, or win rates.

## Required inputs (ask only if missing)
1. Solicitation pack: requirements, mandatory items, evaluation rubric, format rules, page limits, deadline, submission method
2. Offering description (scope you can actually deliver)
3. Proof pack: past performance, CVs, certificates, audited numbers (FACT only)
4. Commercial constraints (price bands, terms you can and cannot accept)

## Steps
1. Extract requirements: pull every numbered requirement and every shall/must/mandatory item; separate Mandatory, Scored, Informational, Forms/attachments; note format rules (page caps, file types, portal vs email, bid bond).
2. Map scoring criteria: criteria to weight to response section. If weights are missing, mark NOT VERIFIED and ask before inventing weights.
3. Compliance matrix (backbone): one row per requirement with Req ID, short text, type, compliant (Y/Partial/N/Gap), evidence reference and response section. No orphan rows.
4. Draft the response in the buyer's order and words, answering each scored criterion directly with evidence.
5. Evidence-gap list: every NOT VERIFIED item with the owner and what would close it.
6. Final compliance review against the matrix and format rules. Stop before submission; submitting needs the owner's approval.
