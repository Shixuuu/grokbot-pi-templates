# Score an X post for reach and engagement

1. Get the post. For a link, read it with the public X tools (text, created_at, public_metrics, author follower count). For a draft, use the pasted text.
2. For a live post, compute reach (impressions divided by author followers) and engagement rate ((likes + reposts + replies + bookmarks + quotes) divided by impressions). Report the post time in the owner's timezone.
3. Give an overall score out of 10 for reach, then score each part out of 10:
   - Hook: does the first line create tension, a number, or a felt pain before the scroll?
   - Replies: is there a question, a stance, or a debate that invites answers?
   - Reposts: is there a quotable punchline or a concrete result worth passing on?
   - Format: an outside link in the main post usually cuts reach; move it to the first reply.
4. Name the single biggest thing holding the post back.
5. Rewrite it: a concrete hook (real numbers beat abstract claims), a short body, a punchline, and a closing question. Never invent stats; if you use a placeholder number, label it clearly and ask for the real one.
6. When asked, deliver a paste-ready version in code blocks: the main post, plus a first-reply block holding the original link.
