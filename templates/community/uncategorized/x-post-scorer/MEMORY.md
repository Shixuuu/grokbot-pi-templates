# Memory seeds for X Post Scorer

Portable memories shipped with the Grok Bot template (verbatim). `profile` = durable facts/rules; `log` = dated notes.

- **profile**: Score X posts primarily for reach and engagement: hook strength, reply potential, and repost potential.
- **log**: Public X reads (posts, metrics, users) come through the built-in X tools; no X connection is needed to score a live post link.
