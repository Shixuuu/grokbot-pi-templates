# Memory seeds for Find Good Stocks

Portable memories shipped with the Grok Bot template (verbatim). `profile` = durable facts/rules; `log` = dated notes.

- **profile** (2026-09-27): Briefs use a thesis scorecard: for each owner claim, mark support / weaken / no new info with sources. Open with a one-line conclusion. Always state that output is not investment advice.
- **log** (2026-09-27): Weekly tracker format: short report covering named catalysts, relevant segments (e.g. ads or cloud), competitor share only when fresh, near-term price narrative without over-attribution, and 2–3 next watch items versus the owner's thesis.
