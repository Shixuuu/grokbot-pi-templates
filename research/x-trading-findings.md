## Methods & limits

- **X search** (`x` namespace `search_posts_all`; `user-X` exposes no search tool): trading-focused queries combining `url:"x.ai/bot"` / "grok bot" / "grokbot" with keyword groups for stocks/trading, portfolio/investing/watchlists, options/earnings/screeners/market digests, crypto/memecoins/prediction markets, and tickers/brokers (Robinhood, Alpaca, Coinbase). Five ran by relevancy and one by recency; one earlier attempt hit 429. Each call returns at most 25 posts, so this is a sample, not an exhaustive crawl.
- **Blocks**: the first ~6 X calls returned HTTP 429. That was X rate-limiting the shared Grok Bot X access, not this user's quota. Calls worked after about 1 minute. Relevancy results don't include link entities, so t.co links were resolved with curl. One post (@IdeaBottie) linked a truncated/invalid id (`x.ai/bot/qwgeekgKf6`), which was skipped.
- **Directory mining**: keyword scan of the earlier merged directory data (/tmp/xf) for bots with an X post URL, then manual review. Excluded false positives such as fantasy football, inventory 'stock', domain watchlists and pitch decks. Bots found by both methods are marked `x-search`.
- **Inclusion rule**: only bots whose X post or API name/description is about trading, investing or markets. Excluded from X results: Validator, Market Intelligence (general topic tracking), The Page, Base Preflight, Hurricane Watch and Capitolino Writer (content tool). NsCDfZMFctaP1WIp_48k4 is included with a note because the post describes a memecoin scout but the API description is a solopreneur chief of staff.
- **Verification**: every share id was checked against GetPublicGrokBotTemplate at concurrency 3 with backoff. No rate-limit failures.
- **inCatalog**: shareId membership in `/workspace/grokbot-pi-templates/catalog.json` → `templates[].shareId`.
- **Categories** were assigned by hand from the API description: stocks, options, earnings, portfolio, crypto, macro, other-markets (prediction markets, multi-asset/quant desks, other market tools).
